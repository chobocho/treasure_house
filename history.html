  • pinball/pinball-tutorial.pptx — 총 305페이지 한국어 튜토리얼 PPT
    • 15개 챕터: Canvas 기초 → 게임 루프 → 벡터 → 삼각함수 → 물리 적분 → 충돌 → 플리퍼 역학 → 테이블 구성 → 전체 코드 워크스루(50장) → 심화 해설 → 테스트 → 최적화 → 확장
    • 수식 유도(반사 공식, 회전행렬, 최근접점), 퀴즈/연습문제, 코드 슬라이드 포함
