문제 : 샘에서 바다로, 최대 물줄기

물길(간선)마다 견딜 수 있는 강폭(용량)이 정해져 있어요. 한꺼번에 얼마나 흘려보낼 수 있을까?

🏞️ 유량 네트워크

  • 샘(Source) : 물이 솟아나는 시작점
  • 바다(Sink) : 물이 도착하는 끝점
  • 물길(간선) : 방향이 있고, 강폭(용량) 만큼만 흐름
  • 유량(flow) : 각 물길에 실제로 흐르는 물의 양

📏 규칙 두 가지

① 용량 제한 : 어떤 물길도 강폭을 넘길 수 없다.

② 보존 법칙 : 샘·바다를 뺀 모든 지점은 들어온 물 = 나간 물. (고이지 않는다!)

바다로 도착하는 물의 총량을 최대로 만드는 것이 목표 🌊

💡 핵심 한 줄 : 아직 여유가 있는 물길을 따라 샘→바다 경로를 찾아 물을 조금씩 더 흘려보내길 반복 → 더는 못 보낼 때가 최대 유량입니다.

핵심 개념

잔여 용량 · 증가 경로 · 병목

🪣 잔여 용량

강폭 − 현재 유량 = 아직 더 흘릴 수 있는 양. 게다가 흘려보낸 물을 되돌릴(취소할) 역방향 여유도 생겨요.

🛶 증가 경로

잔여 용량이 모두 0보다 큰 샘→바다 경로. 이 길이 있으면 물을 더 보낼 수 있다는 뜻!

⛓️ 병목

경로에서 가장 좁은 물길의 잔여 용량. 딱 그만큼만 물을 더 흘릴 수 있어요.

역방향(취소) 간선이 왜 필요할까요? 한 번 잘못 보낸 물도 나중에 되돌려 더 나은 길로 재배치할 수 있게 해주기 때문이에요. 이게 최대 유량을 보장하는 비밀! 🔁

최대 유량 = 최소 컷 (Max-Flow Min-Cut 정리)
동작 · Edmonds-Karp

증가 경로를 하나씩 흘려보내기

BFS로 가장 짧은 증가 경로를 찾아 병목만큼 물을 흘리길 반복 (간선 라벨 = 유량 / 강폭)

흐르는 강물 이번에 찾은 증가 경로 꽉 찬 물길(병목)
알고리즘

Ford-Fulkerson 한눈에

📋 절차

  • 모든 유량을 0으로 시작
  • 잔여 그래프에서 증가 경로를 찾는다 (BFS = Edmonds-Karp)
  • 경로의 병목만큼 정방향 +, 역방향 − 로 갱신
  • 경로가 없을 때까지 반복 → 합이 최대 유량

🔁 핵심 루프

flow = 0
while (BFS로 증가 경로 발견):
    b = 경로 위 잔여용량의 최솟값  // 병목
    경로를 따라:
        cap[u][v] -= b   // 정방향 사용
        cap[v][u] += b   // 역방향(취소) 확보
    flow += b
return flow

⏱️ Edmonds-Karp(BFS 사용)는 O(V·E²) 보장. 가장 짧은 경로부터 채우므로 안전하고, 구현도 간결합니다.
