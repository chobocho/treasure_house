1장. 오목의 역사와 규칙

1.1 오목의 기원

오목(五目, Gomoku)은 가로·세로 19줄 또는 15줄 격자 위에서 두 사람이 번갈아 돌을 놓아 먼저 다섯 알을 잇는 사람이 이기는 게임이다. 한자 표기인 「五目」은 일본어 ‘고모쿠나라베(五目並べ)’에서 왔지만, 그 뿌리는 훨씬 오래되었다.

  • 고대 중국 (기원전 ~ 기원후): 격오(格五), 오자기(五子棋)라는 이름으로 기록.
  • 일본 헤이안 시대 (10~11세기): 「겐지모노가타리」에 비슷한 놀이 등장.
  • 에도 시대 (17~18세기): 「오목나라베」로 정착.
  • 1899년: 일본 언론인 구로이와 루이코(黒岩涙香)가 「렌주(連珠, Renju)」라는 명칭을 제정. 흑백 균형을 위한 흑 금수 규칙은 1903년(삼삼 금지) 이후 단계적으로 도입.
  • 1988년: 국제렌주연맹(RIF) 창설.
  • 2009년: 한국에서도 한국렌주연맹(KRF) 활동 본격화.

1.2 보드와 도구

  • 보드: 가로·세로 15선 (렌주 표준) 또는 19선 (자유오목·바둑판 사용).
  • 돌: 흑돌·백돌. 흑이 선(先).
  • 천원(天元): 보드 정중앙(H8). 첫 수의 표준 위치.
  • 화점(★): 시각적 기준점.

1.3 기본 규칙 — 자유 오목 (Free Gomoku)

  1. 흑이 먼저 두고, 이후 번갈아 둔다.
  2. 돌은 격자의 교차점에 둔다.
  3. 가로·세로·대각선 어느 방향이든 같은 색 돌이 정확히 5개 연속되면 승리.
  4. 보드가 다 차도록 5목을 만들지 못하면 무승부.

1.4 렌주 규칙 (Renju) — 흑 제약

자유 오목은 흑이 압도적으로 유리해서, 균형을 맞추기 위해 흑에게 금수(禁手) 를 부과한다.

흑 금수 설명
장목(長連) / 6목 이상 6개 이상 연속도 패배
삼삼(三三) / 쌍삼 한 수로 열린3 두 개를 동시에 만들면 패배
사사(四四) / 쌍사 한 수로 4 두 개를 동시에 만들면 패배

백에게는 금수가 없다. 백은 6목, 쌍삼, 쌍사 모두 허용되며, 6목도 5목으로 인정되어 승리한다. 한편 흑이 금수 자리에 두는 수가 동시에 정확한 5목을 완성하면 5목이 우선하여 흑의 승리다.

1.5 무르기·시간 규칙

  • 공식 대국에선 한 수 둔 뒤 손을 떼면 무르기 불가.
  • 시간은 보통 각자 30분 + 1수 30초 또는 블리츠 5분.

1.6 핵심 변형 규칙

1.6.1 5수 2수 룰과 Soosõrv-8

구 RIF 룰(5수 2수, 五手二手): 흑 1수 → 백 2수 → 흑 3수 → 백이 흑백 교체권(swap) 행사 가능 → 백 4수 → 흑이 5수 후보 두 개를 제시 → 백이 그중 하나 선택.

Soosõrv-8 (현 RIF 공식 룰): 흑이 1~3수를 두고 백이 교체권 행사 가능 → 4수 후 다시 교체권 → 5수 후보 개수(1~8개)를 선언·제시하고 상대가 그중 하나를 선택. 현재 세계선수권 등에서 쓰이는 표준이다.

1.6.2 스왑(Swap) 룰

Swap1: 흑이 처음 3수를 둔 뒤, 백이 “이 진형을 흑으로 가질지 백으로 갈지” 선택.

Swap2 (자유오목 국제 표준): 선수(先手)가 3수를 두면 상대는 ① 백을 잡거나 ② 흑을 잡거나 ③ 2수를 추가로 두고 선택권을 상대에게 넘기는 세 가지 중 하나를 고른다.

1.6.3 호환 변형

  • 자유오목(韓): 금수 없음, 흑이 매우 유리.
  • 표준오목(日): 흑 금수 적용, 균형.
  • 렌주(國際): 5수2수 + 금수, 정밀.

3장. 기본 용어 사전

3.1 모양(形, Shape) 용어

1. 5목 (五目, Five)

다섯 개 연속. 승리 조건.

2. 4 (四, Four) — 활4와 충4

다음 수로 5목이 되는 모양. 양끝이 모두 열린 활4는 막을 수 없는 즉승형이고, 한쪽이 막힌 충4는 상대가 반드시 남은 한 자리를 막아야 한다.

열린4 (활4)
막힌4

열린4(활4) 는 흑이든 백이든 두는 즉시 승. 가장 강한 한 수.

3. 3 (三, Three)

다음 수로 4가 될 수 있는 3.

열린3 (활3)
막힌3 (면삼)
점프3 (도3)

4. 2 (二, Two)

2개 연속. 그 자체로 위협은 아니지만 모든 모양의 씨앗.

5. 쌍삼(雙三, Double-3 / Double-Open-3)

한 수로 열린3 두 개 를 동시에 만든 모양.

  • 흑은 금수.
  • 백은 합법, 그리고 매우 강력.

6. 쌍사(雙四, Double-4)

한 수로 4 두 개를 동시에 만든 모양. 둘 다 막을 수 없으므로 다음 수에서 승.

  • 흑은 금수.
  • 백은 합법 → 승리.

7. 사삼(四三, Four-Three / Sword-Three)

한 수로 4와 열린3을 동시에 만든 모양.

  • 상대는 4를 먼저 막아야 함 → 그 사이 흑이 활4 완성 → 승.
  • 흑·백 모두 합법, 가장 자주 쓰는 결정타.

8. 사사삼(四四三)

한 수로 4 두 개 + 3 하나를 만드는 슈퍼 모양. 흑에게는 쌍사(4-4)에 해당하여 금수다. 같은 라인 위에서 한 수로 생기는 두 개의 4도 똑같이 금수에 포함된다. (단, 그 수가 동시에 정확한 5목을 완성하면 5목 우선으로 흑 승리.) 백에게는 합법이며 즉승급 모양.

3.3 전술 용어

호점(好點)

양쪽 모두에게 좋은 자리. 누가 먼저 두느냐가 승부를 가르는 자리.

노림(狙い)

지금 두지 않더라도 다음·다음 수로 무엇을 만들지 계획해 두는 모양. 「이 ●는 ○○를 노리고 있다」.

봉수(封手)

상대 위협을 차단하면서 동시에 자기 모양을 만드는 일석이조.

강수(强手) / 약수(弱手)

상대가 반드시 응해야 하는 수가 강수, 응하지 않아도 되는 수가 약수.

VCF (Victory by Continuous Fours)

4(충4)만 계속 둬서 강제로 5목을 만드는 수순. 상대는 매번 4를 막을 수밖에 없다.

VCT (Victory by Continuous Threats)

4와 3(활삼)을 섞어 가며 위협을 이어가 강제 승하는 수순. VCF보다 길고 어렵다.

정전기 (停戰棋)

양쪽 모두 더 이상 위협을 만들 수 없어 형세가 굳은 상태.

4장. 3 (三) — 모든 공격의 출발점

4.1 왜 「3」이 핵심인가

  • 3은 다음 수에 4(충4)를 만들 수 있는 가장 작은 위협.
  • 상대는 활3를 그대로 두면 다음 수에 활4 → 승이 되므로 반드시 막아야 함.
  • 즉 「활3 = 강수」. 상대 응수를 강제하므로 우리가 페이스를 쥔다.

4.2 활3(열린3)의 5가지 모양

활3은 「양쪽 끝이 모두 활4로 갈 수 있는 3」.

① 직(直) 활3 — 가로/세로/대각 일직선

양 옆 어디든 한 수로 활4 (· · ● ● ● ● ·).

② 도(跳) 활3 — 점프형 1

빈칸에 채우면 직 활4가 된다.

③ 도 활3 — 점프형 2

역시 사이 메우면 활4.

④ 양도(兩跳) 활3 — 양쪽 점프

좌 또는 우 어느 빈칸을 메워도 활3 → 활4. 흔치는 않지만 함정 모양.

⑤ 굴절 활3 — 두 방향 동시

대각선과 가로가 한 점에서 만나는 형. 한 수로 활3이 두 개 되는 자리는 흑 금수(쌍삼)이지만, 백은 강력한 무기.

4.3 막힌3(면삼)의 모양

활3와 모양은 같지만 한 쪽이 막혀 있다.

  • 활4가 한 방향만 가능 → 상대가 그 방향만 막으면 무력화.
  • 그래서 막힌3 자체는 약수에 가깝다. 단, 다른 위협과 결합 되면 위력이 살아난다.

4.4 활3가 등장하면 어떻게 응수하는가

상대 활3에 대응하는 방법은 두 가지.

응수 A — 직접 막기 (직지, 直止)

응수 B — 어깨 막기 (견지, 肩止)

· · ● ● ● · ·   →   · · ● ● ● · ·

응수 C — 무시하고 더 큰 모양 만들기

상대 활3을 막는 비용보다 내 활4가 더 큰 위협일 때만 가능. 매우 드물고, 계산 실수면 즉시 패배.

5.1 4의 정의

「4」 또는 「충4」는 다음 수에 5목이 되는 4개 연속(또는 사이가 비어있는 형).

  • 충4(막힌4): 한 끝이 막혀 한쪽만 5목 가능 → 상대가 그 한 끝을 막으면 무력화.

5.4 4를 만드는 5가지 표준 방법

방법 1 — 활3에서 발전

활3는 양쪽 어디든 활4 가능. 활4 = 즉승 이므로 상대는 활3을 반드시 막는다.

방법 2 — 막힌3에서 발전

막힌3은 한쪽으로만 4. 상대가 막으면 끝.

방법 3 — 도3에서 발전

도3에서 사이를 메우면 활4가 된다. 그래서 도3도 활3과 거의 동등한 강수.

방법 4 — 두 3의 교차 (쌍사)

두 개의 3이 ★에서 교차하면 한 수로 4가 두 개 — 쌍사. 백은 즉승, 흑에게는 4-4 금수다.

방법 5 — 사삼(43) 노림수

4와 활3을 한 수로 동시에 만드는 결정타. 7장에서 상세.

5.5 충4의 기능 — VCF의 도구

충4는 그 자체로 즉승은 아니지만 상대를 강제로 응수시키는 도구. 충4를 계속 던지면서 다른 위협을 동시에 만들면 → VCF.

흑: 또 충4 (다른 방향) →  백: 또 막을 수밖에 없음
... 결국 흑이 5목 또는 활4 만듦

  3. 도4 = 사이 메우면 5목. 도형을 정확히 세는 연습 필수.
  4. 충4의 진정한 가치는 「VCF의 부품」.
  5. 4 만나면 무조건 막아라. 안 막으면 다음 수 패배.

6장. 5목 — 끝내기의 미학

6.1 5목의 정의

같은 색 돌이 가로·세로·대각선 어느 방향이든 정확히 5개 연속되면 승리.

렌주 흑은 6목 이상은 패배(장목 금수). 백은 6목도 5목으로 인정 → 승.

6.2 「길게 늘어진 모양」의 함정 — 흑의 장목

흑이 한 수로 6개 연속을 만들면 그 자체로 패배. 「자기 5목」을 만들려다 6번째 자리에 잘못 두면 끝난다. 자주 발생하는 실수:

「F7」 자리에 둬야 했다. F7: ● ● ● ● ● 5목 (왼쪽 끝).

6.3 두 개의 5목이 동시에 가능한 자리

「양쪽 5목」 자리는 둘 중 어디로 두어도 5목이 되는 자리.

복잡하니, 핵심은 활4의 양쪽 끝이 모두 5목 자리라는 점이다.

6.4 5목 만들기 vs 5목 막기 — 우선순위

백이 다음 수에 5목 만들 위치는 한 자리. 흑은 활4가 있어 어디든 5목 가능. 흑이 둘 차례 → 흑이 먼저 5목 → 흑 승.

흑은 충4(한 끝만 5목). 흑이 5목 두면 → 흑 승. 그러나 흑이 5목 자리가 아니라 백 충4를 막아야 할 자리에 두면? 흑은 지금 자기 5목 만들 수 있으니 무조건 두어 승리.

6.5 흑의 「5목 vs 6목」 구분

흑은 자기 5목 자리를 둘 때 6번째 자리에 닿지 않는지 검산해야 한다.

4연속의 오른쪽 사이 칸에 두면 떨어져 있던 ●와 이어져 ● ● ● ● ● ● = 6목 (장목, 흑 패배). 정해는 왼쪽 끝 — 그쪽은 정확히 5목이 되어 즉승이다. 같은 4라도 양끝의 운명이 다르다.

6.6 백의 「6목 = 5목」 처리

백은 6목이 그대로 승리. 이걸 활용하는 전술이 있다.

일부러 6목을 노릴 일은 없지만, 이미 4개가 떨어진 위치에서 6목이 되도록 두면 합법 이라는 점이 흑보다 한 가지 안전 옵션.

6.7 결정타 5종

  1. 5목 자리는 절대로 다른 자리에 두면 안 된다. 즉승을 놓치는 게 가장 큰 실수.
  2. 흑은 6번째 자리 를 항상 검산. 장목은 패배.
  3. 백은 6목·5목 모두 합법.
  4. 양쪽이 4·5목 가능할 때는 자기 5목 자리 가 최우선.
  5. 결정타 5종을 외워라: 활4·도4·충4·사삼·VCF.

7장. 더블 위협 — 쌍삼·쌍사·사삼

7.1 왜 「더블 위협」이 결정타인가

상대는 한 수에 하나만 응수할 수 있다. 한 수로 두 개의 큰 위협 을 만들면 상대는 둘 중 하나를 포기해야 한다. 이것이 모든 결정타의 기본 원리다.

위협 두 개 결과 (백 차례 가정) 흑 합법성
활3 + 활3 (쌍삼) 다음 수에 활4 두 개 → 백 막을 수 없음 → 흑 승 금수
4 + 4 (쌍사) 두 충4 동시 → 백 막을 수 없음 → 흑 승 금수
4 + 활3 (사삼) 백 4 막아야 함 → 활3 살아남아 활4 → 흑 승 합법
4 + 4 (둘 중 하나가 5목) 한 수 5목 → 흑 승 합법 (5목은 금수와 무관)

흑은 사삼만 사용 가능. 백은 모두 사용 가능 → 백이 결정 단계에서 더 자유롭다.

7.2 쌍삼(雙三)

정의

한 수로 활3 두 개를 동시에 만든 모양. 흑은 금수.

모양 예시 (백이 만들면 합법)

★에 두면 가로 ○○○ 활3 + 세로 ○○○ 활3 = 쌍삼. 다음 수에 활4 두 개 — 흑은 하나만 막을 수 있다. 백 절대 우세.

흑이 쌍삼을 만들면?

즉시 패배. 둘 수 없는 자리(금수).

쌍삼 회피 — 흑의 「2 + 3」 전략

흑은 한 수로 활3 두 개를 만들 수 없으니, 대신 활3 하나 + 활2 하나, 혹은 활2 두 개의 교차 로 발전시킨다.

활3 하나 + 활2 하나 = 합법
활2 두 개의 교차 = 합법

7.3 쌍사(雙四)

정의

한 수로 충4 두 개 또는 충4 + 활4 를 동시에 만든 모양. 흑은 금수.

백의 쌍사 (합법, 즉승)

★에 두면 세로 충4 + 가로 활4. 흑은 두 위협을 한 수에 막을 수 없다 → 다음 수 백 5목.

흑의 쌍사 — 금수

같은 모양을 흑이 만들면 둘 수 없다. 「내가 충4 두 개 만들 수 있는 자리」를 발견했다고 좋아하면 안 된다 → 흑이라면 그 자리는 사용 불가.

「5목 + 충4」는 쌍사가 아닌가?

한 수가 5목이라면 게임이 그 순간 끝난다. 즉 다른 충4가 있더라도 무시. 흑·백 모두 합법(애초에 5목이 우선).

7.4 사삼(四三) — 가장 자주 쓰는 결정타

정의

한 수로 충4 하나 + 활3 하나 를 동시에 만든 모양. 흑·백 모두 합법, 그리고 사실상 즉승.

작동 원리

사삼 자리 ★ 둠 →
  상대는 충4 막아야 함 (안 막으면 5목)
→ 그 사이 우리는 활3 → 활4 가능
→ 활4는 막을 수 없음 → 5목 → 승

모양 예시 1 — 직각형

이전 (흑 차례)
흑이 E4(★)에 두면

E4 한 수의 효과:

  1. 세로 E4-E5-E6-E7 = 충4 (E8이 ○로 막혀 5목 자리는 E3 하나). 백은 E3을 막아야 함.
  2. 가로 D4-E4-F4 = 활3 (C4·G4 양끝 개방).
  3. 백이 E3을 막는 사이 흑은 C4 또는 G4로 활4 → 막을 수 없음 → 5목.
사삼 → 4 막기 → 활4 → 5목 (총 4수, 흑 승)

모양 예시 2 — 대각 사삼

대각 E6-F7-G8 활3이 이미 있다. 여기에 가로·세로의 4가 한 점에서 겹치도록 돌을 쌓으면, 그 교차점이 사삼 자리가 된다.

7.5 사삼의 응수 — 막을 수 있는가?

원칙적으로 막을 수 없다. 단 두 가지 예외.

예외 1 — 우리에게 더 빠른 위협이 있을 때

사삼 자리에 두지 못하게 막는 자리가 동시에 우리 활4·5목이라면 무시 가능. 매우 드물고 계산이 정확해야 한다.

예외 2 — 사삼 자리가 흑 금수일 때

흑이 사삼이라고 봤지만 그 자리에 두면 동시에 다른 곳에서 활3 하나 더 만들어 쌍삼이 되는 경우. 흑은 그 자리에 둘 수 없으니 사삼이 무효.

7.6 「가짜 사삼」

가짜 1 — 충4 막는 자리가 활3도 막아 버리는 경우

충4 끝점이 활3 라인 위에 있어, 백이 충4를 막으면서 동시에 활3의 한쪽도 막아 버리면 → 활3는 활4로 못 큼.

이런 자리는 사삼처럼 보여도 결정수가 아니다.

가짜 2 — 활3가 사실은 막힌3

끝쪽이 보드 끝 또는 상대 돌로 막혀 있는 「가짜 활3」.

7.7 4-4-3 (사사삼)

한 수로 충4 두 개 + 활3 하나. 백은 합법(쌍사이지만 백은 OK), 흑은 쌍사 부분이 금수.

흑은 한 수로 4가 두 개 생기면 같은 라인 위에서 생기는 두 개의 4라도 4-4 금수다 (RIF 렌주 규정). 단, 그 수가 동시에 정확한 5목을 완성하면 5목이 우선해 흑 승리. 따라서 흑에게 사사삼 자리는 사실상 금수 — 회피해야 한다.

8장. 렌주 26주형(정석) 개관

8.1 정석(주형)이 왜 26개인가

렌주의 첫 3수는 규칙으로 형태가 제한된다.

  • 1수 (흑): H8 (천원).
  • 2수 (백): 천원에 인접한 8자리 중 하나. 회전·반사로 같은 모양을 묶으면 실질 후보는 두 가지 — 바로 위(직접, 표준 표기 H9) 또는 대각(간접, 표준 표기 I9).
  • 3수 (흑): 천원을 중심으로 한 5×5(F6~J10) 안. 역시 대칭을 제거하면 직접타에서 13가지, 간접타에서 13가지.

그래서 첫 3수의 표준형(주형, 珠型)은 13 + 13 = 26개이고, 각각에 일본 연주 전통의 이름이 붙어 있다. 직접타는 D1~D13, 간접타는 I1~I13으로 번호를 매긴다 (D = direct, I = indirect).

대칭 계산: 직접타는 H열 기준 좌우 반사 대칭이라 H열 위 3곳 + 오른쪽 절반 10곳 = 13. 간접타는 H8-I9 대각 기준 대칭이라 대각선 위 3곳(F6·G7·J10) + 한쪽 절반 10곳 = 13.

8.2 표기 약속

이 책의 모든 주형 그림은 흑 1수 = H8, 백 2수 = 직접타 H9 / 간접타 I9로 통일한다. 실전에서는 회전·반사된 모양으로 나타나도 같은 주형이다. 번호 순서는 표준 차트의 배열(직접: 왼쪽→오른쪽·위→아래, 간접: 위→아래·오른쪽→왼쪽)을 따른다.

8.7 5수 2수 룰과 주형

  1. 흑 1수 → 백 2수 → 흑 3수(여기까지가 주형). 백은 이 시점에 흑백 교체(swap)를 선택할 수 있다.
  2. 백 4수.
  3. 흑이 5수 후보 두 곳을 제시하고(구 RIF 룰. Soosõrv-8에서는 1~8곳 선언), 상대가 그중 하나를 고른다.

따라서 흑은 「한쪽은 강하고 한쪽은 약한」 후보를 낼 수 없다 — 두 후보 모두 비슷한 가치가 되도록 제시해야 하며, 이것이 화월·포월 같은 필승 주형이 실전에서 그대로 끝나지 않는 이유다.

8.8 주형 학습법

  1. 이름이 아니라 모양으로: 직접/간접 + 3수의 위치(붙임·한 칸·대각·멀리)로 기억한다.
  2. 대표 3종 먼저: 화월 → 포월 → 항성 순으로 4·5수의 감각을 익힌다.
  3. 백의 시점도 연습: 같은 주형을 백 입장에서 받아 보며 교체권 판단 기준을 만든다.
  4. 금수 의식: 주형 단계부터 흑은 쌍삼·쌍사 라인을 피하면서 모양을 키우는 버릇을 들인다.

8.9 본 장 요약

  1. 첫 3수의 표준형은 직접 13 + 간접 13 = 26주형.
  2. 흑 필승 증명: 화월·포월. 백 우세: 혜성·유성·류성.
  3. 주형의 우열 때문에 교체권(swap)과 5수 복수 제시 룰이 존재한다.
  4. 이름 암기보다 모양 분류와 대표 주형의 수순 감각이 먼저다.

8장 보강편. 주형 선택과 5수 2수 실전 운용

왜 「주형 선택」이 승부의 절반인가

26주형의 우열이 알려져 있기 때문에, 현대 렌주의 오프닝은 「누가 좋은 모양을 두느냐」가 아니라 「누가 균형점을 정확히 아느냐」의 게임이다. 이 보강편은 5수 2수 / Soosõrv-8 룰에서의 실전 운용을 다룬다.

교체권(swap)의 판단

  • 흑이 화월·포월처럼 강한 주형을 두면 → 백은 교체해서 흑을 가져가는 것이 정석.
  • 흑이 혜성·유성처럼 약한 주형을 두면 → 백은 교체하지 않고 백으로 이긴다.
  • 따라서 흑(가초, 假初의 흑)은 자신도 상대도 확신할 수 없는 중간 난이도 주형을 고르는 것이 실전 전략이 된다. 자기만 변화를 깊이 아는 주형이 최선의 무기다.

5수 후보 제시의 요령

  1. 두 후보의 가치를 비슷하게: 한쪽이 명백히 강하면 상대가 약한 쪽을 고른다. 결국 「내가 낸 후보 중 가장 약한 수」가 내 수가 된다.
  2. 대칭 동형 금지: 회전·반사로 같은 자리 두 곳을 내는 것은 한 곳을 낸 것과 같으므로 규정상 허용되지 않는다.
  3. Soosõrv-8의 개수 선언: 후보를 많이 낼수록(최대 8) 상대 선택권이 커진다. 자신 있는 국면일수록 적게, 형세가 불투명할수록 많이 내며 균형을 잡는다.

주형 단계 체크리스트

  1. 이 주형은 직접인가 간접인가? 3수는 천원에서 어느 방향·거리인가?
  2. 알려진 우열은? (흑 필승 / 흑 유리 / 호각 / 백 우세)
  3. 교체권이 행사될 국면인가? 내가 백이라면 가져올 것인가?
  4. 5수 후보 두(여러) 곳은 어디인가? 가치가 균형인가?

26주형의 개별 좌표·이름은 8장 본문(8.3~8.4)의 표준 그림을 기준으로 하라. 더 깊은 변화는 renju.net의 주형 데이터베이스와 AI 분석(부록 참고)으로 검증하며 학습하는 것이 안전하다.

9장. 흑의 포석 전략

9.1 흑의 딜레마

  • 흑은 선수이므로 본질적으로 유리하다.
  • 그러나 렌주 규칙에서는 금수(쌍삼·쌍사·장목) 가 큰 제약.
  • 즉, 흑의 포석은 「강한 형을 만들면서도 금수 자리를 피하는 길」 을 찾는 것이 목적.

9.2 핵심 원리 5개조

원리 1 — 「2 + 2」를 「3 + 2」로 키워라

한 수로 활3 두 개(쌍삼)를 만들 수 없으니, 활3 + 활2를 만든다. 다음 수에 활2를 활3으로 키우면 사삼 가능.

원리 2 — 사삼을 미리 설계하라

포석 단계에서 이미 「몇 수 후 어디서 사삼이 터질지」를 머릿속에 그려야 한다.

원리 3 — 라인은 두세 개를 동시에 살려라

한 라인만 발전시키면 백이 그 라인을 막아 무력화. 가로·세로·대각 중 최소 2개 라인에 동시에 돌이 걸리도록 둔다.

원리 4 — 금수 자리에 「가두기」당하지 마라

10.1 백의 입지

  • 백은 후수. 본질적으로 불리하다.
  • 그러나 금수 없음 + 6목도 5목으로 인정. 결정 단계에서 매우 자유롭다.

10.2 핵심 원리 5개조

원리 1 — 흑의 활3는 「때로 무시」 가능

흑의 활3을 막지 않고 자기 활3·활4·사삼을 만들 수 있으면, 그 쪽이 더 빠를 때가 있다. 속도 계산 이 백의 무기.

원리 2 — 흑을 「금수 자리로 유도」

백은 흑이 결정수를 두려는 자리가 쌍삼·쌍사가 되도록 먼저 모양을 짠다. 흑이 그 자리에 못 두면 결정 실패.

원리 3 — 모든 라인을 동시에 견제

흑의 라인 하나만 막으면 다른 라인이 살아 있다. 백의 한 수가 흑의 두 라인을 동시에 약화 시키는 자리(호점)를 노린다.

원리 4 — 6목과 쌍사를 적극 활용

결정 단계에서 백은 흑이 못 두는 모양을 합법적으로 둘 수 있다. 백이 후수임에도 결정타에서는 자유 라는 비대칭이 백의 생존 라인.

원리 5 — 견지(肩止) > 직지(直止)

흑 활3 막을 때, 어깨로 견제하면 자기 모양도 동시에 만들 수 있다. 직접 끝점만 막는 것은 「수동」. 단, 견지는 활3 라인 자체를 끊지 못하므로 자기에게 연속 4 위협 같은 더 빠른 수가 준비됐을 때만 성립한다 — 아니면 흑이 곧장 활4로 이긴다.

11장. VCF의 원리 (Victory by Continuous Fours)

11.1 VCF란

VCF = Victory by Continuous Fours = 연속 4 강제승.

  • 한 쪽이 충4(또는 활4) 만 계속 두어 상대를 응수에 묶고, 결국 5목을 만드는 수순.
  • 상대는 매번 4를 막을 수밖에 없으므로 선택지가 없다.
  • 즉, 「VCF 가능한 자리 = 사실상 즉승 자리」.

VCF 한 수 시각 예

11.2 VCF가 작동하는 조건

  1. 첫 수가 충4.
  2. 상대가 충4를 막는다 → 우리 다음 수도 충4.
  3. 이걸 계속 반복 가능.
  4. 마지막 충4가 5목이 되면 끝.
[VCF의 도식]

흑: ●●●●·  (충4) → 백 막음
흑: 다른 라인에서 ●●●●·  (충4) → 백 막음
... 반복 ...
흑: ●●●●● (5목) → 승

11.3 VCF 패턴의 종류

패턴 A — 한 라인에서 직선 충4

한 라인의 두 끝점이 모두 4가 되는 경우는 「활4」이며 즉승.
한쪽만 4가 되는 충4는 막히면 끝. 그래서 단일 라인 VCF는 불가능.

→ 단일 라인 VCF는 없다. VCF는 항상 여러 라인을 오가며 발생.

패턴 B — 가로·세로 교차 VCF

패턴 C — 대각 + 직선 VCF

대각으로 충4 만들고, 백이 막을 때 그 자리가 가로/세로로 또 충4를 만드는 자리가 되도록 사전 설계.

패턴 D — 충4 → 새 활3 → 충4

충4 두면서 동시에 다른 라인에 새 활3 생성. 백 막은 후 그 활3을 충4로.

11.4 VCF의 「강제력」

VCF의 강력함은 상대가 자기 응수 외에는 둘 수 없다는 것.

[강제력 비교]

활3 만들기: 상대는 직지·견지·무시 3가지 선택.
충4 만들기: 상대가 5목을 막을 자리는 정확히 1개. (막을 자리가 2개라면 그것은 활4 = 막을 수 없는 즉승.) 다른 선택은 즉시 5목 패배.

VCF 도중 백은 자기 모양을 만들 시간이 없다. 매번 흑 충4를 막는 데 한 수씩 다 쓴다. 그동안 흑은 모양을 점점 키운다.

11.5 VCF 탐색의 계산량

VCF 탐색은 컴퓨터가 잘하는 영역.

  • 매 수 후보 = 충4가 되는 자리 (보통 2~5개).
  • 깊이 7~13수 정도면 대부분의 VCF 발견 가능.
  • 사람은 패턴 인식으로 「대략 가능한가?」 직관, 깊이는 컴퓨터에 비해 짧음.

Yixin·Pisq7 등 AI는 VCF 탐색을 100수 이상까지 한다.

11.6 VCF의 예 (간단)

세로 G6 G7 G8 = ●●● 활3. 가로 G7 H7 = ●● 활2.

흑이 G9(또는 G5)를 두면 세로 G6 G7 G8 G9 = ●●●● 활4 (G5·G10 양끝 모두 빈) → 백은 한쪽밖에 막지 못하므로 그대로 즉승.

이처럼 활3이 이미 있으면 「VCF」라 부르기도 전에 한 수로 끝난다. 진짜 VCF 계산이 필요한 것은 충4(한쪽 막힌 4)를 연속으로 던져야만 하는 모양이다.

11.7 「VCF 가능」 신호 인식법

머릿속으로 빠르게 검사:

  1. 활3 또는 활2가 여러 라인 에 걸쳐 있는가?
  2. 각 라인의 끝점이 다른 라인의 발전점 인가? (다라인 교차)
  3. 자기 돌이 두텁게 깔려 있어 매 수 충4가 또 만들어지는가?

세 가지가 모두 「예」라면 VCF 가능성 매우 높음.

VCF 신호 모양 3종

11.8 VCF의 「실수」 — 자살수

VCF 도중 한 수가 잘못되면 백은 5목 또는 활4를 만들어 즉승.

[VCF 도중 흑이 잘못 둠]

흑: 충4
백: 막음 (이때 백이 자기 활3을 만드는 자리에 막음)
흑: 또 충4 만들려고 두려는데, 백이 자기 활3에서 활4로 갈 수 있음
흑: 자기 충4 두기 vs 백 활3 막기 = 둘 다 못 함
→ 흑 패배

VCF는 「틀림없이 끝까지 강제수」 일 때만 발동. 중간에 강제력이 끊기면 위험.

11.9 VCF vs VCT

구분 VCF VCT
사용 위협 충4 (강제수) 충4 + 활3 (혼합)
강제력 매 수 강제 매 수 강제는 아님, 활3은 응수 선택지 多
길이 보통 5~15수 보통 7~25수
계산 단순 복잡

VCT는 13장에서 본격적으로 다룸. 이 장과 다음 장은 VCF에 집중.

11.10 본 장 요약

  1. VCF = 충4 연속 강제승.
  2. 단일 라인 VCF 불가, 다라인 교차 가 본질.
  3. 강제력 = 상대 선택지 0~1.
  4. VCF 가능 신호: 다라인 활3·활2 + 끝점 교차 + 두꺼운 자기 진영.
  5. VCF 도중 잘못된 한 수는 자살수가 될 수 있음.

13장. VCT의 원리 (Victory by Continuous Threats)

13.1 VCT란

VCT = Victory by Continuous Threats = 연속 위협 강제승.

  • 충4 + 활3 + (드물게) 도3, 막힌3 등 모든 강제수를 섞어 강제승 만드는 수순.
  • VCF의 상위 개념. VCF는 충4만 사용, VCT는 활3·점프3까지 모두 사용.

VCT 시각 예 (5수 강제승)

13.2 VCT가 VCF보다 어려운 이유

  • 활3에 대한 응수는 직지·견지·무시 3가지.
  • 모든 응수에 대해 5목으로 가는 길이 보장돼야 진짜 VCT.
  • 즉 분기(branching) 검토 가 필요.
[VCF]                       [VCT]

흑 충4 → 백 막 (1자리)        흑 활3 → 백 응수 (3가지)
    ↓                            ↓        ↓        ↓
  흑 충4                      가지A    가지B    가지C
                              모두 5목까지 강제승 보장 필요

13.3 VCT의 분기 처리

가지 A — 백 직지(좌)

흑 활3
백 직지

이후 흑은 우측으로 발전 → 충4 또는 새 활3.

가지 B — 백 직지(우)

좌측 발전.

가지 C — 백 견지

백 견지

견지는 라인을 끊지 않으므로 다음 수에 흑이 활4 가능. 실제로는 견지로 막힐 위협을 흑이 사전에 봐야 한다.

VCT 정해는 모든 가지에 대해 강제승 길이 있어야 한다.

13.4 VCT의 길이

VCT는 보통 7수~25수. 25수 넘는 VCT는 인간이 외워서 두기 거의 불가능. 컴퓨터의 영역.

13.5 인간의 VCT 직관

사람은 깊은 VCT를 다 못 본다. 대신 신호로 인식:

  1. 다라인 활3·활2 가 풍부.
  2. 사삼 자리 가 두 곳 이상 (한 자리 막혀도 다른 자리).
  3. 백의 모양이 수동적(자기 활3 없음).

이 세 가지가 모두 「예」면 VCT 가능성 매우 높음. 정확한 수순은 못 봐도 「공격하면 이긴다」 판단 가능.

13.6 VCT 발견의 4단계 사고

1. 활3 만들 자리 모두 나열.
2. 각 활3에 대한 백의 가능한 응수 3가지 모두 검토.
3. 응수 각각에 대해 다음 수에 5목·활4·사삼 가능한지 체크.
4. 모두 강제승이면 VCT 성립.

13.7 VCT 실패 신호

다음 중 하나라도 나타나면 VCT 불가능 (또는 매우 깊은 수순 필요):

  • 활3 만든 후 백이 견지로 막으면서 자기 활3 만드는 자리.
  • 흑이 활3 만들 자리가 금수 (쌍삼).
  • 백의 활3·활4가 흑보다 빠른 라인에 있음.

13.8 VCT 예제

예제 13-1

대각 F6 G7 H8 I9 = ●●●● — 양끝 E5·J10이 모두 빈 활4가 이미 완성된 모양이다. ❶ E5(또는 J10) → 5목. 위협 수읽기 전에 모양 읽기가 먼저라는 것을 보여 주는 예.

예제 13-2 (5수 VCT)

정해 첫 수: ❶ I7 — 가로 F7 G7 H7 I7 = ●●●● 활4 (E7·J7 양끝 빈) + 대각 G5-H6-I7 활3 동시 발생 → 즉승 (3수). 4와 활3이 함께 생기는 사삼 모양이므로 금수가 아니다.

13.9 VCT vs 무승부

VCT가 성립하지 않으면 양 쪽 모두 결정수가 없어 무승부 가능. 흑은 VCT 못 만들 때:

  • 포지션 우위 (좋은 진영) 만 유지하며 백 실수 기다리기.
  • 또는 새 라인 시작 (보드 다른 쪽).

13.10 본 장 요약

  1. VCT = 충4 + 활3 + 점프3 등 모든 강제수.
  2. 활3은 응수 3가지 → 모든 가지 검토 필요.
  3. VCT 길이는 7~25수, 깊은 VCT는 컴퓨터의 영역.
  4. 인간은 신호 인식 으로 VCT 가능성을 직관 판단.
  5. VCT 못 만들면 무승부 또는 포지션 게임.

19장. 금수 규칙 정리

19.1 금수의 정의

렌주 규칙에서 흑에게만 적용되는 「둘 수 없는 자리」. 백은 모든 자리에 자유롭게 둘 수 있다.

금수 종류 한자 영문 흑이 두면
삼삼(쌍삼) 三三 Double-3 즉시 패배
사사(쌍사) 四四 Double-4 즉시 패배
장목 長連 Overline 즉시 패배

19.2 삼삼(三三) 금수

한 수로 활3 두 개를 동시에 만든 모양.

  • 가로 ●★● → ★를 두는 순간 ●●● 활3 (양끝 빈 칸).
  • 세로 ●★● → 역시 ●●● 활3.
  • 두 활3 동시 → 쌍삼 → 흑이 두면 반칙패.

19.3 사사(四四) 금수

한 수로 4 두 개(충4든 활4든)를 동시에 만든 모양. 같은 라인 위에서 한 수로 두 개의 4가 생기는 경우도 쌍사다.

  • 세로 ○●●●★ = 충4 (위가 ○로 막혀 5목 자리는 아래 한 곳).
  • 가로 ★●●●○ = 충4 (오른쪽이 ○로 막혀 5목 자리는 왼쪽 한 곳).
  • 두 4 동시 → 쌍사 → 흑이 두면 반칙패.

19.4 장목 금수

흑이 6개 이상 연속 만들면 패배. 5목과 동시에 6목이 되는 자리도 패배.

19.5 「쌍삼·쌍사·장목」을 만들면서 동시에 5목인 경우

5목이 우선. 5목은 즉시 승리이므로 다른 금수 조건 무시.

단, 착수한 결과 같은 라인에서 6개 이상이 이어지면 그것은 5목으로 인정되지 않는다 — 장목으로 흑 패배다 (아래 ★).

결론: 흑은 5목 만들 자리가 한 자리 더 있을 때 6번째 자리에 두지 않도록 주의.

19.6 「겉보기엔 금수, 실제론 합법」 케이스

아래 모양들은 금수처럼 보이지만 합법.

케이스 1 — 활3 하나 + 막힌3

★의 세로(●★●)는 활3이지만, 가로(○●★●)는 왼쪽이 ○로 막힌 막힌3. 막힌3은 활3으로 세지 않으므로 활3은 1개 — 합법.

케이스 2 — 5목과 동시 발생

앞서 본 「5목 우선」 원칙.

케이스 3 — 4 + 3 (사삼)

충4 + 활3 = 사삼 → 합법. 이건 결정타.

케이스 4 — 단순 「가짜 활3」

보드 끝, 자기 돌, 상대 돌로 막힌 가짜 활3 두 개 → 실제로는 활3이 아님 → 합법.

19.7 「겉보기엔 합법, 실제론 금수」 함정

함정 1 — 점프 활3도 활3이다

점프(띈) 활3은 직 활3과 똑같이 활3으로 카운트된다. 직선과 점프가 한 점에서 교차하면 쌍삼.

★의 가로 ●●★는 직 활3, 세로 ●·★●는 점프 활3(사이를 메우면 곧장 활4) — 합쳐서 쌍삼 금수다.

함정 2 — 「5목 만드는 자리」 옆이 6목

· ● ● ● ● ★ ● · 형. ★은 5목이 안 되고 6목만 됨 → 패배 자리.

19.8 금수 검증 알고리즘 (사람용)

흑이 두려는 자리 ★에 대해:

  1. 5목 검사: ★ 두면 5목 가능 라인 있는가? → 있으면 합법(승리).
  2. 6목 검사: ★ 두면 6개 이상 연속? → 있으면 금수(패배).
  3. 활3 카운트: ★ 주변 4방향(가로·세로·두 대각)에서 활3 개수 세기.
  4. 충4 카운트: 4방향 충4 개수.
  5. 활3 ≥ 2 → 쌍삼 금수.
  6. 충4 ≥ 2 → 쌍사 금수.
  7. 그 외 → 합법.

정밀 규정 주석: 어떤 3이 활4로 발전하는 자리가 그 자체로 금수라면, 그 3은 활3으로 세지 않는다(렌주 규정의 재귀 예외). 입문~중급에서는 위 7단계로 충분하다.

훈련 단계:

  1. 표준 모양 보드(이 장 19.2~19.4의 그림) 외우기.

20장. 금수 활용 전술

20.1 금수는 「흑의 약점」이지만 동시에 「전술 도구」

흑 금수는 본질적으로 흑에게 불리한 제약. 그러나 다음 두 가지 면에서는 백의 무기 가 된다.

무기 1 — 흑의 결정수 자리를 금수로 만든다

백이 사전에 라인을 깔아 흑이 사삼·5목 만들 자리를 쌍삼이 되도록 유도.

무기 2 — 자기 자유도를 활용

백은 쌍삼·쌍사·6목 모두 합법. 결정 단계에서 더 많은 결정타 자리 보유.

20.2 백의 「유도」 4단계 패턴

1. 흑 진영의 다음 활3 발전점을 예측.
2. 그 자리 주변에 자기 ○를 두 곳 깔아 흑이 그 자리에 두면 활3 두 개가 동시 발생하도록 만든다.
3. 흑이 그 자리에 두려고 할 때 두지 못함(쌍삼).
4. 흑은 차선책으로 약한 자리에 둘 수밖에 없음.

이 패턴은 「예방 사삼」 또는 「유도 봉수」라 불린다.

20.3 유도 예제

예제 1

흑의 세로 활2(F6-F7)와 가로 활2(D5-E5)가 모두 F5 한 점을 향한다. 그러나 F5는 두 활3이 동시에 생기는 쌍삼 금수(✕) — 백이 흑의 응수를 이 방향으로 몰아 「합치는 자리」를 금수로 만들어 둔 유도의 결과다. 흑은 모양을 합치지 못하고 차선 수로 물러서야 한다.

예제 2 — 변 1선 유도

변 가까이 흑 진영. 백 ○(B3·F3)이 흑 돌의 대각 위쪽을 눌러 중앙 방향 발전을 차단했다. 흑이 2선·1선 쪽으로만 발전하게 되면 양끝이 보드 벽에 막혀 활3이 가짜 활3이 된다. 백이 D2·E1 부근을 추가로 누르면 흑의 변 진영은 질식한다.

20.4 흑의 「유도 회피」

흑은 백의 유도에 빠지지 않으려면:

회피 1 — 한 발 빠르게

백이 유도 자리를 깔기 전 자기 결정수를 만든다. 사삼·활4를 빨리 던지는 것이 핵심.

회피 2 — 라인 우회

유도된 금수 자리 대신 다른 라인 으로 발전. 진영을 다라인으로 펴 두면 한두 자리가 막혀도 다른 라인 살아 있음.

회피 3 — 활3을 「2 + 1」로 분할

한 자리에서 두 활3 만드는 모양은 만들지 않음. 항상 「활3 + 활2」 또는 「활2 + 활2」.

회피 4 — 백 진영 압박

백이 유도 모양 짤 시간을 안 주기 위해 흑이 강한 활3·사삼을 이른 단계에 던진다.

20.5 백의 「쌍삼·쌍사 즉승」 노림

백은 결정 단계에서 한 수에 활3 두 개(쌍삼)를 만들면 즉승.

★ = G5. 두면 ↘대각 F6-G5-H4 활3 + ↗대각 H6-G5-F4 활3 — 쌍삼, 백은 합법 → 즉승급. 백은 이런 X자 교차점을 적극 노리고, 흑은 같은 모양을 만들 수 없으므로 미리 한 귀퉁이를 끊어야 한다.

20.6 「6목 활용」 전술 (백)

백은 6목도 5목으로 인정. 이를 활용하는 두 가지 모양.

활용 1 — 「긴 줄 위협」

이미 ●●●●가 있고 양쪽이 비어 있을 때, 백은 어느 쪽 끝이든 두면 5목. 더 옆에 두면 6목으로 또 5목.

활용 2 — 「6목 유도」

흑의 ●●●●에서 한쪽 5목 자리(✕)가 옆의 ● 때문에 6목이 되는 위치라면 흑은 거기 두지 못한다 → 백은 반대쪽 끝 한 곳만 막으면 흑의 4가 무력화된다.

20.8 본 장 요약

  1. 흑 금수는 본질적 약점이지만 백의 유도 무기 로도 작용.
  2. 흑은 다라인 분산 + 빠른 결정 으로 유도 회피.
  3. 백은 결정 단계에서 쌍삼·쌍사 적극 노림.
  4. 결정 단계의 비대칭이 렌주의 균형을 만든다.

23.2 스크립트 1 — 단일 보드 이미지 (omok_board.py)

ASCII 보드 텍스트 → PNG 변환. 스크립트 2~4가 이 모듈의 parse_board·draw_board를 import 하므로 반드시 같은 폴더에 저장한다.

# omok_board.py — 단일 보드 이미지 생성 (스크립트 2~4가 이 모듈을 import 한다)
from PIL import Image, ImageDraw, ImageFont
import sys

CELL_SIZE = 50
MARGIN = 40
BOARD_COLOR = (217, 178, 122)
LINE_COLOR = (42, 31, 18)
BLACK = (10, 10, 15)
WHITE = (244, 241, 232)

def parse_board(text):
    """ASCII 보드 텍스트 → 2차원 리스트.
    기호: ● 또는 B = 흑, ○ 또는 W = 백, · 또는 . = 빈 칸."""
    board = []
    for line in text.strip().splitlines():
        tokens = line.split()
        if not tokens:
            continue
        row = []
        for t in tokens:
            if t in ("●", "B"):
                row.append("B")
            elif t in ("○", "W"):
                row.append("W")
            else:
                row.append(".")
        board.append(row)
    width = max(len(r) for r in board)
    for r in board:                      # 줄 길이 맞추기
        r.extend(["."] * (width - len(r)))
    return board

def draw_board(board, out_path="board.png"):
    """2차원 리스트 → PNG 저장."""
    rows, cols = len(board), len(board[0])
    w = MARGIN * 2 + CELL_SIZE * (cols - 1)
    h = MARGIN * 2 + CELL_SIZE * (rows - 1)
    img = Image.new("RGB", (w, h), BOARD_COLOR)
    d = ImageDraw.Draw(img)
    for x in range(cols):                # 격자
        d.line([(MARGIN + x*CELL_SIZE, MARGIN),
                (MARGIN + x*CELL_SIZE, h - MARGIN)], fill=LINE_COLOR)
    for y in range(rows):
        d.line([(MARGIN, MARGIN + y*CELL_SIZE),
                (w - MARGIN, MARGIN + y*CELL_SIZE)], fill=LINE_COLOR)
    r = CELL_SIZE // 2 - 4               # 돌
    for y in range(rows):
        for x in range(cols):
            c = board[y][x]
            if c not in ("B", "W"):
                continue
            cx, cy = MARGIN + x*CELL_SIZE, MARGIN + y*CELL_SIZE
            fill = BLACK if c == "B" else WHITE
            d.ellipse([cx-r, cy-r, cx+r, cy+r], fill=fill, outline=LINE_COLOR)
    img.save(out_path)
    return out_path

if __name__ == "__main__":
    text = sys.stdin.read()
    out = sys.argv[1] if len(sys.argv) > 1 else "board.png"
    draw_board(parse_board(text), out)
    print("saved:", out)

23.3 스크립트 2 — 수순 번호 표시

대국 진행을 나타낼 때 돌 위에 번호 표기.

# omok_board_numbered.py

from PIL import Image, ImageDraw, ImageFont
import sys, json

# (앞 스크립트와 동일한 색상·크기 설정)
CELL_SIZE = 50
MARGIN = 35
BG = (240, 217, 181)
LINE = (50, 50, 50)
B = (10, 10, 10)
W = (245, 245, 245)
WB = (40, 40, 40)


def draw_numbered(moves, w=15, h=15):
    """
    moves: [(x, y, color, num), ...]   color: 'B' or 'W', num: 수순 번호
    """
    img_w = MARGIN * 2 + (w - 1) * CELL_SIZE
    img_h = MARGIN * 2 + (h - 1) * CELL_SIZE
    img = Image.new("RGB", (img_w, img_h), BG)
    d = ImageDraw.Draw(img)

    # 격자
    for i in range(w):
        x = MARGIN + i * CELL_SIZE
        d.line([(x, MARGIN), (x, MARGIN + (h - 1) * CELL_SIZE)],
               fill=LINE)
    for j in range(h):
        y = MARGIN + j * CELL_SIZE
        d.line([(MARGIN, y), (MARGIN + (w - 1) * CELL_SIZE, y)],
               fill=LINE)

    # 돌 + 번호
    r = CELL_SIZE // 2 - 4
    try:
        font = ImageFont.truetype("DejaVuSans-Bold.ttf", 18)
    except IOError:
        font = ImageFont.load_default()

    for x, y, color, num in moves:
        cx = MARGIN + x * CELL_SIZE
        cy = MARGIN + y * CELL_SIZE
        if color == "B":
            d.ellipse([cx - r, cy - r, cx + r, cy + r], fill=B)
            text_color = (255, 255, 255)
        else:
            d.ellipse([cx - r, cy - r, cx + r, cy + r],
                      fill=W, outline=WB, width=2)
            text_color = (10, 10, 10)
        # 번호
        txt = str(num)
        try:
            bbox = d.textbbox((0, 0), txt, font=font)
            tw = bbox[2] - bbox[0]
            th = bbox[3] - bbox[1]
        except AttributeError:
            tw, th = d.textsize(txt, font=font)
        d.text((cx - tw // 2, cy - th // 2), txt,
               fill=text_color, font=font)

    return img


if __name__ == "__main__":
    # 입력: JSON
    # 예: [[7,7,"B",1],[7,8,"W",2],[8,7,"B",3]]
    moves = json.load(sys.stdin)
    img = draw_numbered(moves)
    img.save(sys.stdout.buffer, format="PNG")

23.4 스크립트 3 — 옵시디언 일괄 변환

# obsidian_omok_render.py
"""
옵시디언 마크다운 파일에서 코드블록 ASCII 보드 추출 → PNG 자동 생성
"""

import re, os, sys
from pathlib import Path
from omok_board import parse_board, draw_board

PATTERN = re.compile(
    r"```\s*\n((?:[· ●○\d \nA-Z]+\n)+?)```",
    re.MULTILINE
)


def render_md(md_path, out_dir):
    text = Path(md_path).read_text(encoding="utf-8")
    matches = PATTERN.findall(text)
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    base = Path(md_path).stem
    count = 0
    for blk in matches:
        try:
            cells = parse_board(blk)
            if not cells or len(cells) < 3:
                continue
            img = draw_board(cells)
            count += 1
            img.save(out_dir / f"{base}_{count:03d}.png")
        except Exception as e:
            print(f"skip: {e}", file=sys.stderr)
    return count


if __name__ == "__main__":
    src = sys.argv[1] if len(sys.argv) > 1 else "."
    out = sys.argv[2] if len(sys.argv) > 2 else "./images"
    src = Path(src)
    if src.is_dir():
        for f in sorted(src.glob("*.md")):
            n = render_md(f, out)
            print(f"{f.name}: {n} 보드")
    else:
        n = render_md(src, out)
        print(f"{n} 보드 생성")
