내적 — 성분의 곱의 합, 그리고 코사인

내적은 성분끼리 곱해 더한 수 a·b = a₁b₁ + a₂b₂ + a₃b₃ 입니다. 정의는 대수인데, 뜻은 기하입니다.

정리 M1 1학년

두 벡터의 내적은 a·b = |a||b|cos θ이고, 교환·분배 법칙을 만족한다

쓰는 도구: 고등학교 코사인 법칙. 가정: 두 벡터가 0 이 아니어야 사이각 θ 가 정해집니다.

증명
  1. 교환·분배는 정의에서 바로 나옵니다: Σaᵢbᵢ = Σbᵢaᵢ, Σaᵢ(bᵢ+cᵢ) = Σaᵢbᵢ + Σaᵢcᵢ. 실수의 곱과 합의 법칙
  2. 그러면 |a−b|² = (a−b)·(a−b) = |a|² − 2a·b + |b|². 1단계를 두 번
  3. 두 벡터를 변으로 하는 삼각형의 셋째 변이 a−b 이므로 코사인 법칙이 |a−b|² = |a|² + |b|² − 2|a||b| cos θ 를 줍니다. 여기서 0 이 아니라는 가정을 쓴다 — 삼각형이 있어야 한다
  4. 2와 3을 비교하면 a·b = |a||b| cos θ.

어디에 썼나: 두 방향이 수직인지(내적 0), 한 방향으로의 성분이 얼마인지(투영) — 9부의 총추력 계산.

라그랑주 항등식 — 외적의 크기는 사인

정리 M3 1학년

라그랑주 항등식 |a×b|² + (a·b)² = |a|²|b|² — 그래서 |a×b| = |a||b|sin θ

쓰는 도구: M1, M2의 성분식.

증명
  1. 외적의 성분은 세 쌍 (i, j) = (2,3), (3,1), (1,2) 의 aᵢbⱼ − aⱼbᵢ 이므로 |a×b|² = Σi<j (aᵢbⱼ − aⱼbᵢ)². 부호는 제곱에서 사라진다
  2. 펼치면 Σi<j (aᵢ²bⱼ² + aⱼ²bᵢ²) − 2Σi<j aᵢbᵢaⱼbⱼ.
  3. (a·b)² = Σᵢ aᵢ²bᵢ² + 2Σi<j aᵢbᵢaⱼbⱼ. 합의 제곱
  4. 2와 3을 더하면 교차항이 지워지고 Σi≠j aᵢ²bⱼ² + Σᵢ aᵢ²bᵢ² = (Σᵢaᵢ²)(Σⱼbⱼ²) = |a|²|b|².
  5. M1 을 넣으면 |a×b|² = |a|²|b|²(1 − cos²θ) = |a|²|b|² sin²θ, 그리고 0 ≤ θ ≤ π 에서 sin θ ≥ 0.

def solve(a, b):
    """A x = b. 부분 피벗팅(각 열에서 절댓값이 가장 큰 행을 피벗으로).

    피벗을 고르지 않으면 첫 피벗이 0 인 행렬에서 멈추고, 0 에 가까운
    피벗으로 나누면 반올림 오차가 커진다. O(n³) 시간, O(n²) 공간."""
    m = _copy(a)
    x = [float(v) for v in b]
    n = len(m)
    for col in range(n):
        piv = max(range(col, n), key=lambda r: abs(m[r][col]))
        if abs(m[piv][col]) < 1e-14:
            raise ValueError('특이 행렬 — 해가 하나로 정해지지 않는다')
        m[col], m[piv] = m[piv], m[col]
        x[col], x[piv] = x[piv], x[col]
        for r in range(col + 1, n):
            f = m[r][col] / m[col][col]
            if f:
                for k in range(col, n):
                    m[r][k] -= f * m[col][k]
                x[r] -= f * x[col]
    for r in range(n - 1, -1, -1):
        s = x[r]
        for k in range(r + 1, n):
            s -= m[r][k] * x[k]
        x[r] = s / m[r][r]
    return x

def rank(a, tol=1e-10):
    """행 사다리꼴로 줄여 피벗 개수를 센다. 직사각 행렬도 된다."""
    m = _copy(a)
    rows, cols = len(m), len(m[0]) if m else 0
    r = 0
    for col in range(cols):
        if r == rows:
            break
        piv = max(range(r, rows), key=lambda i: abs(m[i][col]))
        if abs(m[piv][col]) < tol:
            continue
        m[r], m[piv] = m[piv], m[r]
        for i in range(r + 1, rows):
            f = m[i][col] / m[r][col]
            for k in range(col, cols):
                m[i][k] -= f * m[r][k]
        r += 1
    return r

오일러 방법 — 지금의 기울기로 한 걸음

해를 식으로 못 쓰는 비선형 방정식(드론 전체)은 작은 걸음 dt 로 나눠 나아갑니다. 가장 단순한 것은 지금의 기울기를 걸음 내내 쓰는 것입니다: xn+1 = xn + dt·f(xn).

py/droneshow/rigidbody.py13–16무엇을 적분하는지 모르는 적분기
def euler(f, x, dt):
    """오일러 한 걸음: x + dt·f(x). 전역 오차 O(dt)."""
    d = f(x)
    return [x[i] + dt * d[i] for i in range(len(x))]

기울기가 걸음 동안 변하면 그만큼 어긋납니다. 걸음당 어긋남은 dt² 에 비례하고, 걸음이 1/dt 개이므로 끝의 오차는 dt 에 비례합니다(1차).

RK4 — 기울기 넷을 섞는다

걸음의 처음, 가운데 두 번, 끝에서 기울기를 재어 1 : 2 : 2 : 1 로 섞습니다. 한 걸음에 계산이 네 배 들지만 오차는 dt⁴ 에 비례해, 같은 정확도를 훨씬 큰 걸음으로 얻습니다.

py/droneshow/rigidbody.py19–27고전 룽게-쿠타 4단
def rk4(f, x, dt):
    """고전 룽게-쿠타 4단. 전역 오차 O(dt⁴) (T21)."""
    n = len(x)
    k1 = f(x)
    k2 = f([x[i] + 0.5 * dt * k1[i] for i in range(n)])
    k3 = f([x[i] + 0.5 * dt * k2[i] for i in range(n)])
    k4 = f([x[i] + dt * k3[i] for i in range(n)])
    return [x[i] + dt / 6.0 * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i])
            for i in range(n)]

뉴턴-오일러 회전 방정식

정리 T8 1학년

강체의 회전 방정식 Jω̇ = τ − ω × Jω. 대각 관성 J에서 토크가 없으면 운동에너지와 각운동량의 크기가 보존된다

쓰는 도구: M21(각운동량과 토크), L3, M2. 가정: J 는 몸체에 고정된 대각 행렬(주축 좌표) — 모양이 변하지 않는 강체.

증명 — 방정식
  1. 세계에서 본 각운동량 H = RJω 의 변화율은 세계 토크입니다: Ḣ = Rτ. M21 을 점 질량마다 더함 — 내부의 힘은 짝지어 지워진다고 둔다
  2. L3 에서 Ḣ = R(Jω̇ + ω × Jω). J 가 몸체에 고정이라는 가정 — 몸체에서 본 J 의 변화율은 0
  3. 두 식에서 R 을 떼면(R 은 가역, T4) Jω̇ = τ − ω × Jω.

증명은 다음 장에 이어집니다 — 보존 법칙.

토크가 없으면 무엇이 보존되나

정리 T8 — 증명 계속 1학년

쓰는 도구: M2(외적은 두 벡터에 수직), M1, M11.

증명 — 보존
  1. 에너지 E = ½ω·Jω. J 가 대각이므로 Ė = ω·Jω̇. 대각 가정을 여기서 쓴다 — 대칭이면 충분
  2. 토크가 0 이면 Jω̇ = −ω × Jω, 그리고 ω·(ω × Jω) = 0. 그래서 Ė = 0. M2
  3. d/dt |Jω|² = 2Jω·Jω̇ = −2Jω·(ω × Jω) = 0. M2 — Jω 에도 수직
  4. 세계에서 본 H 는 1단계에서 τ = 0 이므로 벡터째로 멈춰 있습니다 — 몸체에서 보면 도는데, 세계에서 보면 가만히 있습니다.

def flat_rates(a, j, yaw, yaw_rate, g):
    """가속도 a, 가가속도 j, 요와 그 변화율 → 몸체 각속도 [p, q, r].

    ż_B = ω × z_B = q·x_B − p·y_B 이고, ż_B 는 f/|f| 를 미분한
    h = (j − (z_B·j) z_B)/|f| 다. 그래서 p = −h·y_B, q = h·x_B.
    r 은 y_B ⊥ x_C 를 미분해 얻는다(x_C = 요 방향의 수평 단위벡터):
    r = (β p + ψ̇ (y_B·y_C)) / α, α = x_C·x_B, β = x_C·z_B (T12)."""
    f = [a[0], a[1], a[2] + g]
    x, y, z = _axes(f, yaw)
    h = V.scale(V.sub(j, V.scale(z, V.dot(z, j))), 1.0 / V.norm(f))

    alpha, beta = V.dot(xc, x), V.dot(xc, z)
    r = (beta * p + yaw_rate * V.dot(y, yc)) / alpha
    return [p, q, r]
