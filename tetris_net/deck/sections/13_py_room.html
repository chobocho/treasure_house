{{N}}room.py — Go 판과 나란히 놓고 읽을 수 있게

함수 이름·순서·주석까지 room.go/room.mjs 와 맞췄다. 세 구현이 다르게 생기면 어디서 갈렸는지 찾는 데만 하루가 든다 — 스타일 통일이 여기서는 취향이 아니라 도구다.

{{N}}32비트를 손으로 지킨다

MASK32 = 0xFFFFFFFF

def rng(self):
    x = self.rng_state
    x ^= (x << 13) & MASK32
    x ^= x >> 17
    x ^= (x << 5) & MASK32
    self.rng_state = x & MASK32
    return self.rng_state

파이썬 정수는 무한 자릿수다. 마스크를 빼먹으면 x << 13 이 45비트가 되고, 몇 번만 돌아도 수백 비트짜리 수가 된다. 그래도 동작은 하고 난수처럼 보인다 — 골든 벡터가 없으면 못 잡는 버그다.

오른쪽 시프트에는 마스크가 없다x >> 17 은 자릿수가 줄어들기만 하므로 안전하다. 왼쪽 시프트 두 곳만 씌우면 된다.

{{N}}조회 헬퍼 — 한 줄씩

Go 에서 8줄이던 occupied() 가 리스트 컴프리헨션 한 줄이다. 같은 일을 하고 같은 결과를 낸다 — 골든 벡터가 그걸 보장하므로 각 언어에서 가장 자연스러운 방식을 써도 된다.

{{N}}진입점

{{N}}좌석 잡기·놓기·준비

next((k for k, s in enumerate(self.seats) if s is None), -1) — Go 의 for 루프와 같은 일이다. 검사 순서(자리 먼저, 그다음 PC 당 좌석 수)를 주석까지 같은 문장으로 적어 뒀다.

{{N}}시작

{{N}}타겟 고르기 — min 과 키 함수

  even :  min(cand, key=lambda j: (self.seats[j]['recv'], j))
  ko   :  min(cand, key=lambda j: (-self.seats[j]['height'], j))

  튜플의 두 번째 칸이 동률일 때 낮은 번호를 강제한다.
  Go 는 루프에서 <(엄격 부등호)를 써 첫 번째 것을 유지하는 방식으로 같은 결과를 낸다.
  두 방식 다 맞지만, 어느 쪽도 규격에 적어 두지 않으면 갈릴 수 있다.

{{N}}중계·탈락·끊김

sorted(self.peers) — 파이썬의 set 도 순회 순서가 정해져 있지 않다(문자열 해시 랜덤화 때문에 실행마다 달라질 수 있다). Go 의 sort.Ints 와 같은 이유로 필요하다.

{{N}}탈락 통보와 연결 끊김

{{N}}hub.py — 락이 필요 없는 이유

  Go   :  방마다 고루틴 하나 + 채널.  "이 상태는 저 고루틴만 만진다"로 직렬화.
  파이썬:  Room.handle 이 동기 함수다.
           asyncio 는 await 지점에서만 양보하므로 handle 이 도는 동안
           다른 코루틴이 끼어들 수 없다 — 그 자체로 원자적이다.

  그래서 방 전용 태스크도, 락도 필요 없다.
  단, handle 안에 await 를 하나라도 넣는 순간 이 보장이 사라진다.
  room.py 에 async 가 한 줄도 없는 건 우연이 아니다.

{{N}}Peer — 큐 하나와 쓰기 태스크 하나

Go 와 완전히 같은 대책큐가 차면 기다리지 않고 끊는다(put_nowait + QueueFull). finish() 는 None 을 넣어 쓰기 태스크에게 "큐를 다 비우고 나가라"고 알린다 — Go 의 close(send) 와 같은 신호다.

{{N}}방과 허브

time.monotonic() 을 쓴다. time.time() 은 NTP 보정이나 서머타임으로 뒤로 갈 수 있다 — 그러면 hitTTL 판정이 뒤집힌다.

{{N}}연결 하나의 일생

봉투 파싱 문제가 없다 — 딕셔너리는 v 가 정수든 불리언이든 신경 쓰지 않는다. Go 가 넘어졌던 자리(10부)를 파이썬은 그냥 지나간다.

{{N}}방으로 넘기고, 나갈 때 치운다

finally 안에서 bye 를 넣고 방이 비면 지운다. Go 의 defer 와 정확히 같은 자리다.

{{N}}설정 병합

isinstance(v, bool) 을 먼저 거르는 이유파이썬에서 bool 은 int 의 하위 타입이다. isinstance(True, int) 가 True 이고 True > 0 도 참이라, 거르지 않으면 {"max": true} 가 좌석 1석으로 해석된다.
