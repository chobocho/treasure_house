Fn · FnMut · FnOnce

트레이트클로저가 붙잡은 것을여러 번 부를 수 있나
Fn읽기만 한다(&)예, 동시에도
FnMut고친다(&mut)예, 한 번에 하나씩
FnOnce가져가 버린다(이동)한 번만

main.rs 의 |k, r| win.is_key_pressed(k, r) 는 창을 읽기만 하므로 Fn 입니다. 다른 언어에서는 함수 타입 하나로 뭉뚱그리는 것을, Rust 는 "붙잡은 것을 어떻게 쓰나"로 나눠 빌림 규칙과 맞물리게 합니다.

받는 쪽은 가장 느슨한 것을 — actions 는 pressed 를 여러 번 부르니 FnOnce 는 안 되고, 고칠 일이 없으니 Fn 으로 충분합니다.

가짜 키보드로 시험하기

한 프레임에 키 둘 — Space 와 ← 를 같이 누르면 표 순서대로 "왼쪽 → 하드 드롭". 순서가 반대면 다른 자리에 떨어집니다. 이 순서를 시험이 못 박아 둡니다.

창을 시험하는 법 — 가상 X 서버

  1. Xvfb :77 -screen 0 640x700x24 를 뒤에 띄우고, trap ... EXIT 로 끝날 때 죽이게 걸어 둔다.
  2. DISPLAY=:77 tetris-gui --seed 7 — 창이 가상 화면에 뜬다.
  3. xdotool search --name Rust 로 창을 찾고 windowfocus — 창 관리자가 없어서 포커스를 직접 준다.
  4. xdotool key Left … 로 키 19개를 0.2초 간격으로, 사이사이 xwd 로 찍는다.
  5. 마지막에 q 를 보내고 프로세스가 정말 끝났는지 kill -0 으로 확인한다.
