표를 시험하는 법 — 성질로 묶기

킥 표 80칸(표 넷 × 상태 넷 × 다섯)을 하나하나 대조하는 대신 SRS 가 지키는 성질 하나를 겁니다: A→B 로 돌 때의 킥은 B→A 로 돌 때의 킥과 부호만 반대입니다. 옮겨 적다 한 칸만 틀려도 이 시험이 잡습니다.

Python 의 hypothesis, Java 의 jqwik 같은 속성 기반 시험을 손으로 작게 한 셈입니다. Rust 에도 proptest·quickcheck 크레이트가 있지만, 상태가 4×2 뿐이라 반복문으로 충분합니다.
