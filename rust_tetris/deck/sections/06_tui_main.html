키 → 명령 — 데이터를 품은 enum

Java 17+
sealed interface Command
    permits Play, Restart, Quit {}
record Play(Action a) implements Command {}
record Restart() implements Command {}
record Quit() implements Command {}
TypeScript
type Command =
  | { kind: "play", action: Action }
  | { kind: "restart" }
  | { kind: "quit" };
합 타입 — Play 만 Action 을 품고, 나머지 둘은 빈손입니다. 코어의 Action 에 "끝내기"를 섞지 않고 프런트엔드 쪽에서 감쌌습니다. 코어는 프로그램이 끝난다는 것을 몰라도 됩니다.

RAII — 소멸자가 확실히 불리는 언어

언어정리 코드빠뜨리기 쉬운 경우
Godefer restore()defer 를 안 쓰면 그만. os.Exit 는 defer 를 건너뛴다

Pythonwith + __exit__with 를 안 쓰면 그만

코드설명
struct TerminalGuard;필드 없는 구조체 — 크기 0. 존재 자체가 "터미널을 바꿔 놓았다"는 표시
execute!(...)?queue! 와 달리 바로 flush
let _ = execute!(...);drop 은 오류를 돌려줄 수 없으니 일부러 버린다고 적는다

함정 — _guard 와 _ 는 다르다

✔ main.rs 의 실제 코드
let _guard = TerminalGuard::enter()?;
// _guard 는 main 이 끝날 때 drop
✘ 한 글자 차이
let _ = TerminalGuard::enter()?;
// 그 자리에서 바로 drop!
// raw 모드가 곧장 풀린다

_guard 는 "안 쓰는 변수"라 경고만 꺼 줄 뿐 이름이 있는 변수이고, 범위 끝까지 삽니다. _ 는 변수가 아니라 "버리기" 패턴이라 값이 그 문장 끝에서 바로 해제됩니다.

Mutex 잠금에서도 같은 함정 — let _ = m.lock() 은 잠그자마자 풉니다. 경비원 타입은 언제나 이름을 붙여 받으세요.

루프 읽기 — 입력 · 시간 · 그리기

  1. 입력 — poll(16ms) 로 기다리다 키가 오면 처리하고, 이후로는 poll(0) 으로 쌓인 것만 비웁니다. 키가 없으면 16ms 뒤 다음 단계로.
  2. 시간 — 지난 시간을 ms 정수로 넘기되, last 는 넘긴 만큼만 앞으로 옮깁니다. 0.7ms 같은 나머지가 버려지지 않고 다음 프레임에 더해집니다.
  3. 그리기 — 합성 → 차분 → 출력. prev.as_ref() 는 Option<Screen> 을 Option<&Screen> 으로 — 옮기지 않고 빌린다.
