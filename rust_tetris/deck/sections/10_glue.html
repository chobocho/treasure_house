mount ② — 프레임 루프

줄왜
Math.min(100, now - last)탭이 숨었다 돌아오면 수 초가 한 번에 온다. 조각이 순간이동하지 않게 프레임당 100ms 까지

함정 — 메모리가 늘면 옛 뷰는 죽는다

Rust 의 Vec 이 더 큰 메모리를 요청하면 WASM 은 memory.grow 를 하고, 그 순간 JS 가 들고 있던 memory.buffer 는 길이 0 짜리 떨어진(detached) 버퍼가 됩니다. 뷰를 한 번 만들어 두고 재사용하면 언젠가 빈 화면이나 TypeError 를 봅니다.

이 게임은 tt_init 뒤로 할당이 거의 없어 실제로는 잘 안 일어나지만(점수 문자열 정도), 싸게 막을 수 있으니 막아 둡니다. wasm-bindgen 이 만든 글루도 같은 이유로 매번 뷰를 확인합니다.

키보드 — 반복은 이동만

판"누르고 있으면 반복"을 누가
TUI터미널의 키 반복 — 모든 키가 반복된다(Space 를 누르고 있으면 하드 드롭이 연달아 나간다)
GUIminifb KeyRepeat::Yes/No + 170ms/50ms 설정
WASM브라우저 e.repeat 를 보고 이동이 아니면 버린다
세 판의 키 반복 처리가 다른 것은 바깥 세상이 다르기 때문입니다. 그래서 코어 밖에 둡니다.

단독 페이지 — wasm/web/index.html

$ make wasm $ python3 -m http.server -d wasm/web # → http://localhost:8000
file:// 로 열면 안 된다 — 브라우저가 fetch('tetris_wasm.wasm') 을 막습니다. 로컬 서버가 필요합니다. 이 덱은 .wasm 을 base64 로 품어 fetch 없이 바이트로 load 하므로 파일 하나로 열립니다.

진짜 .wasm 을 node 로 시험한다

네이티브 시험(9장)과 무엇이 다른가 — 9장은 같은 Rust 함수를 x86/ARM 으로 컴파일해 불렀고, 여기서는 wasm32 로 컴파일된 바로 그 파일을 V8 이 돌립니다. "import 0개"와 내보내기 이름은 이쪽에서만 확인할 수 있습니다.

글루까지 node 에서 — 가짜 rAF 와 캔버스

vm.runInContext 로 tetris.js 를 브라우저인 척하는 객체 위에서 실행합니다. requestAnimationFrame 을 "예약 표"로 바꿔 두면 프레임을 시험이 원하는 시각에 하나씩 돌릴 수 있습니다. Go 의 가짜 시계, Java 의 Clock.fixed 와 같은 요령입니다.

4부 정리

Rust 기능쓰임
crate-type = ["cdylib", "rlib"], 프로필.wasm 과 네이티브 시험을 한 크레이트에서
#[unsafe(no_mangle)] extern "C"JS 가 부를 이름과 호출 규약
thread_local! + RefCellstatic mut 없이 전역 게임 하나
제네릭 + FnOncewith_app 하나로 일곱 함수의 "init 전" 처리
원시 포인터, unsafe 블록버퍼 주소 넘기기(안전) / 시험에서 읽기(unsafe)
경계는 좁게, 실패는 값으로 — 패닉이 FFI 를 넘으면 abort 이므로, 내보내기 함수는 잘못된 입력에 0·널을 돌려줍니다. 경계 안쪽은 1~3부의 평범한 Rust 입니다.
