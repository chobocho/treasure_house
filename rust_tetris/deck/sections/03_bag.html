정수 넘침 — 디버그는 패닉, 릴리스는 감싼다

Java·Go 는 언제나 감싼다, Python 은 큰 정수로 자란다. Rust 는 디버그 빌드에서 넘침을 버그로 잡고, 의도한 넘침은 wrapping_*·checked_*·saturating_* 로 적게 합니다. 4장의 tick 이 saturating_add 를 쓰는 이유입니다.

impl Trait 반환 — 반복자를 그대로 내준다

Java
Stream<Kind> peek() {
    return queue.stream();
}
Python
def peek(self):
    return iter(self.queue)

Rust 의 peek 은 Vec 을 새로 만들지 않고 큐를 빌린 반복자를 돌려줍니다. 4장의 Game::next_kinds 는 여기에 .take(5) 를 이어 붙일 뿐입니다.

빌림이 살아 있는 동안 — 반복자를 들고 있는 동안에는 draw()(&mut self)를 부를 수 없습니다. 시험 peek_shows_what_next_will_return 이 collect() 로 먼저 Vec 에 받아 두는 이유입니다.
