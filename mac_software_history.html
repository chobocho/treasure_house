왜 매킨토시인가?

1984년 1월 24일, 스티브 잡스는 캘리포니아 쿠퍼티노 플린트 센터 무대에서 가방을 열어 작은 베이지색 컴퓨터를 꺼냈습니다.

"Hello, I am Macintosh. It sure is great to get out of that bag."

이날 발표된 매킨토시 128K는 그래픽 사용자 인터페이스(GUI), 마우스, 그리고 무엇보다 소프트웨어 생태계로 컴퓨팅을 바꾸었습니다.

이 프레젠테이션은 그 16년간의 소프트웨어 여정을 따라갑니다.

MacPaint의 기술적 천재성

QuickDraw 라이브러리

Bill Atkinson은 MacPaint를 만들기 위해 먼저 QuickDraw를 만들었습니다. 이 그래픽 라이브러리는 매킨토시 ROM의 핵심이었고, 모든 맥 앱이 사용했습니다.

region (영역) 자료구조

임의 형태의 영역을 효율적으로 표현하는 자료구조. Atkinson이 발명. 모든 창 클리핑, 마우스 히트테스트가 이걸로 동작.

Marching Ants (행진하는 개미)

선택 영역의 점선 테두리가 움직이는 효과. Atkinson이 발명. 오늘날 포토샵까지 동일하게 사용.

MacPaint 소스코드는 2010년 컴퓨터 역사 박물관이 공개. 어셈블리 약 5,000줄 + Pascal 약 2,500줄.
1984 · 도구

MacTerminal

VT100/VT52 터미널 에뮬레이터. 맥을 메인프레임이나 미니컴퓨터에 연결.

  • 모뎀 또는 시리얼 직결 연결
  • XMODEM 파일 전송 지원
  • 대학생들이 학교 VAX에 접속하는 데 사용
  • BBS 시대의 핵심 도구

왜 중요한가

맥은 출시 시점 그래픽 그림장난감으로 폄하되었으나, MacTerminal은 진지한 업무 도구로 쓰일 수 있음을 보였습니다. 비즈니스 사용자가 IBM 메인프레임에 접속하면서 동시에 MacWrite로 문서 작성.

최초의 비주얼 프로젝트 관리 도구.

  • 개발자: Debra Willrett
  • PERT 차트(작업 의존성 그래프)를 마우스로 그림

1984 · 외부 앱

Microsoft Multiplan

맥용 첫 마이크로소프트 앱. Excel의 전신.

  • 출시: 1984년
  • DOS Multiplan의 맥 포팅 — 하지만 마우스/그래픽 활용
  • VisiCalc, Lotus 1-2-3가 PC 시장 지배 중
  • 맥용으로 Multiplan은 GUI 스프레드시트의 첫 출발
빌 게이츠는 매킨토시 출시 전 18개월간 시제품에 접근했고, Multiplan, Word, Chart를 동시 개발 중이었다.

마이크로소프트의 맥용 앱은 PC용보다 먼저 GUI를 익혔고, 이는 훗날 Windows 시대에 큰 자산이 됩니다.

1984 · 외부 앱

Microsoft Word 1.0 (맥용)

1984년 말 — 맥의 첫 본격 상용 워드프로세서.

  • MacWrite와 정면 승부
  • 스타일 시트, 매크로, 각주 — 전문가용 기능
  • 가격 $195

1984 · 외부 앱

Microsoft Chart

스프레드시트 데이터를 그래프로. Excel 차트 기능의 직계 조상.

  • 막대/선/원형/면적/산점도 등 20여 종
  • Multiplan에서 데이터 가져와 차트 그림
  • 흑백 환경에서 패턴 채우기로 구분
  • 출력은 ImageWriter로

왜 분리되어 출시?

당시 PC에서는 차트가 별도 앱이었습니다(VisiPlot 등). 1985년 Excel이 출시되면서 Chart 기능은 Excel에 통합되고, Chart 앱은 단종됩니다.

1984 · 폰트

Susan Kare, 아이콘의 어머니

"나는 픽셀을 자수처럼 다뤘다. 한 픽셀이 1mm짜리 십자수다."

Susan Kare는 매킨토시의 모든 시스템 아이콘을 설계했습니다.

  • 휴지통 (Trash)
  • 해피 맥 (Happy Mac) — 부팅 시 미소
  • 폭탄 (Bomb) — 시스템 에러
  • 시계 커서
  • Command 키 🌐 — 스웨덴 캠핑장 표지에서 영감
  • 도그콥(Dogcow) — 폰트 샘플 캐릭터 "moof!"

이 모든 것이 32×32 또는 16×16 픽셀의 흑백 도트로 그려졌고, 오늘날까지 디지털 아이콘 디자인의 기준이 되었습니다.

1984 · 개발도구

Lisa Workshop (크로스 개발)

맥 자체는 너무 작아 자기 자신의 앱을 개발할 수 없었습니다.

  • 맥 RAM 128KB → 컴파일러 돌릴 수 없음
  • 해결책: Apple Lisa(1MB RAM)에서 크로스 컴파일
  • Lisa Workshop에서 Pascal/어셈블리로 작성
  • 맥에 시리얼로 전송 후 실행
매킨토시 시스템 소프트웨어 자체도 Lisa Workshop으로 만들어졌습니다. 1984년 말 Macintosh Programmer's Workshop(MPW)이 발표되고, 1985년 출시되어 맥에서 직접 개발이 가능해집니다.
1984 · 개발도구

Apple Pascal과 어셈블러

맥의 공식 개발 언어는 Pascal이었습니다.

왜 Pascal?

  • Toolbox API가 Pascal 호출 규약 사용
  • 강한 타입 시스템 — 시스템 크래시 방지
  • Apple Lisa도 Pascal로 개발됨
  • 학계의 표준 언어
PROGRAM HelloMac; USES MemTypes, QuickDraw, OSIntf, ToolIntf; BEGIN InitGraf(@thePort); InitFonts; InitWindows; DrawString('Hello, Mac!'); END.

1986년 THINK Pascal, 1987년 MPW C/Pascal이 주류가 되며 Pascal 시대가 정점을 찍습니다.

1991 · 워드

Microsoft Word 5.0 (맥용)

1994년 Word 6.0이 Windows판과 통합되며 무거워지자 많은 사용자가 5.1로 돌아감.

1992 · 인터넷

Mosaic / Eudora

인터넷이 일반인에게 도달.

  • Eudora (1988-1992) — Steve Dorner, 일리노이 대학. 최초의 그래픽 이메일 클라이언트. 무료.
  • NCSA Mosaic for Mac (1993) — 최초의 그래픽 웹 브라우저.

1993년-1995년 인터넷 사용자가 급증. 맥은 이미 좋은 그래픽 OS여서 웹 콘텐츠 제작자 표준이 됩니다.

1993 · 멀티미디어

Myst

1993년 9월 24일 출시. 게임 역사의 분수령. Cyan(Robyn & Rand Miller 형제) 개발.

  • 전부 HyperCard 스택 + QuickTime 비디오
  • 한 화면 한 카드 — 정적 이미지 + 핫스팟
  • 스토리: 신비한 섬, 책 속 세계들, 형제 갈등
  • 1,200만 장 판매 — 1996년까지 최다 PC 게임

CD-ROM의 살인 앱(killer app). The Sims가 등장하기 전까지 가장 많이 팔린 PC 게임. 게임 깊이 분석은 곧 게임 장에서.

1993 · 시스템

PowerPC 전환과 Mac에뮬레이션

1994년 3월 Power Macintosh 6100 출시. 68K → PowerPC RISC 전환.

  • 10배 빠른 성능
  • 기존 68K 앱은 에뮬레이션으로 실행
  • "FAT 바이너리" — 한 파일에 두 아키텍처
  • 5년에 걸친 점진적 전환

이런 식의 매끄러운 아키텍처 전환은 Apple의 트레이드마크가 됩니다. 2005년 Intel 전환, 2020년 Apple Silicon 전환 모두 비슷한 방식.

1994 · 그래픽

Photoshop 3.0 — 레이어!

1994년 9월 출시. 레이어(Layers) 도입. 이미지 편집의 패러다임 변화.

  • 하나의 이미지가 여러 레이어로
  • 레이어별 투명도, 블렌딩 모드
  • 독립적 편집 가능
  • "되돌리기"가 본질적으로 안전해짐

이전: 한 번의 결정이 영구적이었음. 이후: 어떤 결정도 되돌릴 수 있음. 디지털 이미지 작업의 근본 철학이 바뀜.

레이어 개념은 곧 모든 그래픽 앱에 표준이 됩니다. Illustrator, Director, Premiere, 그리고 결국 비디오 편집까지.

1994 · DTP

Adobe와 Aldus 합병

1994년 8월. Adobe가 Aldus 인수. 출판 소프트웨어 통합.

  • PageMaker — Adobe 산하로

이 합병으로 Adobe는 DTP의 절대 강자가 됩니다. 1999년 Adobe InDesign 1.0 출시 — PageMaker의 후계자. QuarkXPress 추월의 시작.

1994 · 회고

1991-1994년 회고

System 7 + PowerPC + 인터넷 등장으로 맥은 성숙기에 진입.

  • QuickTime으로 멀티미디어 OS화
  • Photoshop 3.0으로 레이어 혁명
  • Myst로 멀티미디어 게임 정점
  • AppleScript로 자동화 시대
  • 인터넷 시대 진입

하지만 1995년 8월 — Microsoft Windows 95가 출시되며 위기가 시작됩니다.

"맥 vs PC" 격차가 좁아지자 비즈니스 사용자가 PC로 이동. Apple의 위기.

1995 · 시스템

System 7.5

1994년 9월. 많은 기능 추가, 하지만 안정성 떨어짐.

  • PowerTalk — 통합 메시징 (실패)

Marathon

1996 · 사건

Copland의 실패와 NeXT 인수

1994-1996년: Apple은 차세대 OS "Copland" 개발 중이었으나 실패.

  • 너무 복잡한 목표 — 보호 메모리, 선점 멀티태스킹, 새 UI 동시
  • 1996년 8월 — Copland 포기 발표
  • Apple은 외부에서 OS를 사야 함

후보:

  • BeOS (Jean-Louis Gassée — 전 Apple 임원)
  • Windows NT (Microsoft)
  • NeXTSTEP (Steve Jobs!)

1996년 12월 20일: Apple이 NeXT 인수 발표. $429M. 잡스 복귀.

1997 · 사건

잡스 복귀와 1997 MacWorld

1997년 8월 보스턴 MacWorld. 잡스가 무대에서:

  • 이사회 개편 (이사 대부분 교체)
  • 제품군 단순화 — 4개로 압축
  • Microsoft와 5년 협정 — $150M 투자, Office 보장
  • "Think Different" 캠페인 시작
"애플의 건강은 우리 산업 전체에 중요하다." — Bill Gates (위성으로 등장)

관객의 야유. 그러나 Apple은 1년 만에 흑자 전환합니다.

1997 · 시스템

Mac OS 8

1997년 7월 26일 출시. $99. 5주 만에 300만 장 판매.

  • Platinum 외관 — 3D 입체감 UI
  • 멀티스레드 Finder — 복사하면서 다른 작업
  • 3D 컬러 아이콘
  • Contextual Menu — 우클릭 (드디어!)
  • Live Scrolling

System 7.7로 출시될 예정이었으나 마케팅상 8.0으로 명명. 클론 제조사와의 라이선스 협약이 7.x에만 적용되어 8.0이 클론을 끝냄.

1998 · 시스템

Mac OS 8.5

1998년 10월. PowerPC 네이티브 (68K 지원 종료).

  • Sherlock — 통합 검색 (파일 + 인터넷)
  • $99
  • HFS+ 파일 시스템 — 더 효율적
  • 전체적으로 빨라짐

같은 해 5월 iMac 출시. 다채로운 사탕 색깔, 일체형, $1,299. Apple의 부활 신호탄.

1998 · iMac

iMac과 USB 표준화

1998년 8월 iMac 출시. 한 가지 큰 결단:

  • 플로피 드라이브 제거
  • SCSI, ADB, 시리얼 포트 제거
  • USB만 — 새 표준

당시 PC 업계는 USB 보급에 미온적. iMac이 USB 주변기기 시장을 활성화. 1999년 말 모든 PC가 USB 표준.

맥용 USB 기기 폭발 — 마우스, 키보드, 프린터, 스캐너, 카메라. iMac의 색상에 맞춘 투명 사탕색 주변기기 유행.

1999 · 시스템

Mac OS 9

1999년 10월. 클래식 Mac OS의 마지막 메이저 버전.

  • Multiple Users — 다중 사용자 (드디어)
  • Keychain — 비밀번호 통합 관리
  • Sherlock 2 — 더 강력한 검색
  • Software Update — 자동 업데이트
  • $99

잡스는 발표 무대에서 Mac OS 9의 관 위에 검은 천을 덮으며 "9는 죽었다. 다음 OS는 OS X"라고 선언.

1999 · 그래픽

Final Cut Pro 1.0

1999년 4월. 비디오 편집 시장 진입.

  • $999 — 당시 표준 Avid는 $50,000
  • DV 비디오 편집 가능
  • FireWire 캠코더 직접 연결
  • 전문가용 NLE(non-linear editor)

독립 영화 제작자, 다큐멘터리 제작자가 맥으로 몰림. 2002년 영화 City of God이 FCP로 편집되어 큰 화제. 2009년 영화 Cold Mountain이 첫 FCP 편집 영화로 아카데미 후보.

1999 · 음악

iTunes의 전신 — SoundJam MP

1999년 출시. Cassidy & Greene 개발. MP3 플레이어.

  • $50
  • MP3 재생, 라이브러리 관리
  • 2000년 Apple이 SoundJam 인수
  • 2001년 1월 — iTunes 1.0으로 변신

2001년 10월 iPod 출시. iTunes + iPod 조합이 음악 산업을 영원히 바꿉니다. 우리 프레젠테이션 범위는 2000년까지지만, 그 시작점은 1999년 SoundJam에 있습니다.

1999 · 회고

1995-1999 회고

Apple은 1996년 적자 8억 달러로 거의 파산 직전이었으나 1999년 흑자 회복.

베이식 · 역사

맥용 BASIC의 험난한 길

맥에는 출시부터 BASIC이 없었습니다. 이는 Apple II와의 큰 차이.

  • Apple II — Integer BASIC, Applesoft BASIC 내장
  • 매킨토시 — BASIC 없음. Pascal 위주
  • 잡스의 결정 — "복잡한 GUI를 BASIC으로 다루기 어렵다"
  • 대안 — Microsoft가 만들어줘야 했음

맥 BASIC을 둘러싼 사건이 1985년 폭발합니다.

베이식 · 역사

Apple의 MacBASIC (사라진 BASIC)

Apple 내부에서 Donn Denman이 1983-1984년 MacBASIC을 개발했습니다.

  • 모던 — 객체, 윈도우, 그래픽 명령
  • 인터프리터 — 즉시 실행
  • 맥 Toolbox 직접 접근
  • 1985년 베타 거의 완성
그러나 Microsoft가 빌 게이츠 명의로 압박. Apple II에 Microsoft BASIC을 계속 라이선스 받으려면 Apple은 MacBASIC을 죽이라는 요구. Apple은 굴복. MacBASIC은 사라짐. 베타 디스크가 일부 유출되어 인터넷 박물관에 남음.
베이식 · 사건

Microsoft BASIC for Macintosh

1984-1985년 Microsoft 출시. $150.

10 PRINT "Hello, Mac!" 20 FOR I = 1 TO 100 30 PRINT "Loop "; I 40 NEXT I 50 INPUT "What's your name? "; NM$ 60 PRINT "Hi, "; NM$
  • 전통 행 번호 BASIC
  • 맥 GUI 거의 활용 못 함
  • 그래픽 명령 일부 있음 (LINE, CIRCLE)
  • 이벤트 처리 약함

실망스러웠습니다. 1986년 새 버전 출시되나 큰 변화 없음. 결국 1991년 단종.

True BASIC

1985년 출시. 누가 만들었을까? — John Kemeny와 Thomas Kurtz, BASIC의 원래 발명자들.

  • 다트머스 대학에서 1964년 BASIC 발명
  • 1985년 자기 회사 True BASIC, Inc 설립
  • 구조적 BASIC — 행 번호 없음
  • 맥, PC, Amiga, Atari ST 지원
  • $80
PROGRAM HelloMac PRINT "Hello, Mac!" FOR i = 1 TO 10 PRINT "Iteration"; i NEXT i CALL Greet("World") END SUB Greet(name$) PRINT "Hi, "; name$ END SUB
베이식 · 명작

True BASIC의 의의

Kemeny와 Kurtz는 자기들이 만든 BASIC이 "Microsoft BASIC 같은 스파게티 언어"로 변질된 데 분노했습니다.

"행 번호와 GOTO는 BASIC의 일부가 아니었다. 우리는 학생들에게 좋은 프로그래밍을 가르치고 싶었다." — Kurtz
  • SUB, FUNCTION — 진짜 부프로그램
  • WHILE, UNTIL — 구조적 루프
  • 그래픽, 사운드 표준 명령
  • 맥의 윈도우/메뉴 작성 가능

현재(2024년)도 살아있음 — True BASIC Bronze Edition 무료. 39년째.

심화 · HyperCard

HyperCard 스택의 구조

Stack ├── Card 1 (배경 + 카드 그래픽 + 필드 + 버튼) │ ├── Background 1 (공통 요소) │ ├── Background Fields │ ├── Card Fields │ ├── Background Buttons │ └── Card Buttons ├── Card 2 └── Card N Each object has a Script: - on mouseUp / mouseDown / mouseEnter - on openCard / closeCard - on idle / arrowKey

객체 계층: Stack > Background > Card > Field/Button. 각 객체는 자기 스크립트를 가질 수 있고, 메시지가 위로 전파됩니다. 1987년에 이미 객체지향 이벤트 모델.

1984년이 우리에게 남긴 것

맺음 · 1

맥이 가르친 것 — 일관성

한 앱에서 배운 것이 다른 앱에서 통한다. 이 단순한 원리가 컴퓨팅을 바꿨습니다.

  • 저장은 ⌘S, 어디서나
  • 실행 취소는 ⌘Z, 어디서나
  • 파일 메뉴는 항상 가장 왼쪽
  • 창 닫기는 항상 같은 자리

오늘날 너무 당연해 보이지만, 1984년 이전에는 모든 앱이 자기만의 키, 자기만의 메뉴 위치를 가졌습니다.

맺음 · 2

맥이 가르친 것 — 직접 조작

"명령을 입력하는 것이 아니라, 사물을 직접 만지듯 다룬다."

파일을 클릭해서 휴지통으로 끌고 간다. 텍스트를 선택해서 다른 곳으로 끌고 간다. 1984년에는 마법이었습니다.

이 패러다임 — "direct manipulation" — 은 모든 GUI의 기초가 되었고, 결국 터치스크린, 그리고 AR/VR로 이어집니다.

맺음 · 3

맥이 가르친 것 — 아름다움이 기능이다

1984년 이전 컴퓨터는 도구였습니다. 아름다워야 할 이유가 없었습니다.

맥은 다음을 가르쳤습니다:

  • 아름다운 폰트는 가독성을 높인다
  • 좋은 아이콘은 빠른 인식을 돕는다
  • 일관된 디자인은 학습 비용을 낮춘다
  • 즐거움이 생산성을 만든다

오늘날 모든 소프트웨어가 디자인을 진지하게 다루는 이유 — 맥이 시작했습니다.

맺음 · 4

맥이 가르친 것 — 비전문가의 컴퓨팅

1984년 이전, 컴퓨터를 쓰려면 전문가가 되어야 했습니다.

맥 이후, 컴퓨터는 누구나 쓸 수 있는 도구가 되었습니다.

  • 매뉴얼 없이 시작
  • 실수 = 되돌리기
  • 아이콘 = 직관
  • HyperCard = 누구나 앱 제작

이것이 가장 큰 유산일지 모릅니다. 컴퓨팅의 민주화. 오늘날 70억 인구가 컴퓨터를 자연스럽게 쓰는 세계의 시작점.

맺음 · 5

오늘의 우리에게

이 프레젠테이션을 보는 당신이 사용하는 기기 — 스마트폰, 노트북, 태블릿 — 는 모두 1984년 매킨토시의 후예입니다.

  • 화면의 폰트는 Chicago의 자손입니다
  • 화면의 아이콘은 Susan Kare의 정신을 잇습니다
