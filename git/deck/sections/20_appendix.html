설명용

이 덱을 다시 만들려면

  • make all — 표·캡처 검사·그림·조립·역검증·범위·상호참조·주장 검사·폭·글꼴.
  • python3 run_all.py — 모든 캡처를 진짜 git 으로 다시 뜬다. sh tools/record.sh --check 는 세 번 떠서 같은지 본다.
  • make test-py · test-go · test-ts · test-java · test-cpp — 다섯 구현의 시험, make parity — 대조표.
  • make golden · make docs · make data — 진짜 git 과 git/git 저장소(mirror)에서 기대 출력·설명서·자료를 다시 만든다.

전부 19부 끝의 Makefile 과 run_all.py 전문에 있습니다.

끝

git 은 내용의 해시로 이름 붙인 바뀌지 않는 객체들과, 그 위를 옮겨 다니는 몇 개의 이름표입니다.

이 덱의 모든 캡처는 git 2.55.0 이 직접 찍은 것이고, 모든 코드는 시험이 통과하는 실물입니다. 틀린 곳을 찾으면 그 캡처를 다시 떠 보는 것이 첫걸음입니다.
