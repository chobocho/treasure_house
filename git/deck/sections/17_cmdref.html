이 부를 읽는 법

git 2.55.0 의 명령 목록(command-list.txt)에 있는 명령 161개를 알파벳순으로 한 장씩 싣습니다.

  • 한 줄 설명 — 그 명령 설명서의 NAME 줄을 옮긴 것, 원문을 아래에 같이 둡니다.
  • 분류 — command-list.txt 의 분류. porcelain(사람용)과 plumbing(스크립트용 배관)의 구분은 2부 7장.
  • 사용법 — 이 기계에서 git 명령 -h 를 돌린 앞 여섯 줄.
  • 실행 예 — 자주 쓰는 명령은 표본 저장소(main·topic, 태그 v1, 커밋 넷)에서 한 번 돌린 캡처.
  • 이 덱에서 돌린 곳 — 다른 부의 캡처 가운데 그 명령을 부른 부.
