# Pinball — 바닐라 JS Canvas 핀볼 게임

외부 라이브러리 없이 HTML5 Canvas와 순수 자바스크립트로 만든 핀볼 게임입니다.
벡터 연산과 삼각함수를 이용한 물리 시뮬레이션을 밑바닥부터 직접 구현했습니다.

## 실행

`pinball.html`을 브라우저에서 열면 바로 실행됩니다. 서버가 필요 없습니다.

## 조작법

| 키 | 동작 |
|---|---|
| SPACE (길게) | 발사 게이지 충전, 떼면 발사 |
| ← 또는 Z | 왼쪽 플리퍼 |
| → 또는 / | 오른쪽 플리퍼 |
| SPACE (게임오버 시) | 재시작 |

공 3개를 모두 잃으면 게임 오버. 범퍼 100~150점, 슬링샷 30점.

## 구현 내용

- **벡터 수학**: `Vec2` 클래스 (내적, 정규화, perp, 회전행렬), 반사 공식 `v' = v − (1+e)(v·n)n`
- **삼각함수**: 플리퍼 끝점 `pivot + L(cosθ, sinθ)`, 상단 아치 벽 22분할 선분 근사, 각속도 기반 표면 속도 `ω·perp(r)`
- **물리**: 반암시적 오일러 적분, 중력·공기저항·속도 상한, 서브스텝 4회 터널링 방지
- **충돌**: 원-원(범퍼), 원-선분(벽), 캡슐(플리퍼), 투영 기반 최근접점, 침투 해소

