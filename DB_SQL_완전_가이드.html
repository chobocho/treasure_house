이 덱을 읽는 법

데이터베이스와 SQL을 처음 배우는 사람부터, 실행 계획을 읽고 동시성 문제를 재현해 보고 싶은 사람까지를 위한 한 권짜리 교재입니다.

이런 사람은여기부터
데이터베이스가 어디서 왔는지 궁금하다1부 · 2부 (역사)
SQL을 처음 써 본다3부 → 4부 → 5부
SQLite 파일 하나가 어떻게 돌아가는지 알고 싶다6부 (SQLite 깊이)
CSV·Parquet 분석을 SQL로 하고 싶다7부 (DuckDB 깊이)
내 언어로 바로 붙여 보고 싶다8~12부 (Python·Go·Java·JS·TS)
느린 쿼리와 잠금 문제를 풀어야 한다13부 · 14부
범위 약속 — 실행 예제는 SQLite와 DuckDB 두 엔진으로만 만듭니다. 둘 다 서버 없이 프로세스 안에서 도는 라이브러리라 어디서든 그대로 따라 할 수 있습니다. PostgreSQL과 MySQL은 역사와 구조를 비교하는 자리에서만 다룹니다.
표기 — SQL 키워드는 대문자, 식별자는 소문자 스네이크 케이스로 씁니다. 화면이 좁은 기기를 위해 결과 표는 필요한 열만 남겼습니다.

모든 코드는 실제로 실행했습니다

이 덱의 코드 블록은 전부 파일로 존재하고, 슬라이드에 실린 출력은 그 파일을 이 환경에서 돌려 받아 적은 것입니다. 손으로 고친 코드는 검증기가 걸러냅니다. 같은 질의를 다섯 언어로 돌린 첫 예제입니다.

examples/p00/hello.py

import sqlite3, duckdb

with sqlite3.connect('data/shop.db') as lite:
    print('sqlite', lite.execute('SELECT count(*) FROM orders').fetchone()[0])

with duckdb.connect('data/shop.duckdb', read_only=True) as duck:
    print('duckdb', duck.execute('SELECT count(*) FROM orders').fetchone()[0])
$ python3 examples/p00/hello.py
