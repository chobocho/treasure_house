정수계획이란

정식화 · 완화 · 정수 껍질 · 난이도

혼합정수 선형계획 (MILP)

minx c⊤x   s.t.   Ax ≤ b,   x ≥ 0,   xj ∈ ℤ (j ∈ I)
실행가능집합이 볼록이 아니다 — ℤn 은 이산 점들의 집합이라 두 점을 잇는 선분이 밖으로 나간다(2부 정의 5.1). 그 순간 2부·5부의 정리들이 모두 무효가 된다: 국소=전역도, KKT 도, 강쌍대성도.

마지막 줄이 유일한 희망이다 — 정수 제약을 버리면(완화하면) LP 가 되고, 그 최적값은 원래 문제의 하한이다. 실행가능집합을 넓혔으니 최솟값은 작아질 수밖에 없다. 이 하한 하나로 탐색을 잘라 내는 것이 이 부 전체의 전략이다.

정수 껍질 — 이론적으로는 이미 끝난 문제

정의 28.1 PI = conv(P ∩ ℤn) — 실행가능한 정수점들의 볼록포.
정리 28.2 P 가 유리수 다면체이면 PI 도 다면체이고, MILP 는 min c⊤x s.t. x ∈ PI 라는 LP 와 같은 최적값을 갖는다.
증명 개요 정수점들의 볼록포가 유한개의 부등식으로 표현된다는 것(Meyer 의 정리)에서 PI 가 다면체임이 나온다. 그러면 6부 정리 23.5 로 최적해가 PI 의 극점에 있고, PI 의 극점은 모두 정수점이므로 원래 MILP 의 실행가능해다.
그런데 왜 어려운가 — PI 를 기술하는 부등식의 개수가 지수적으로 많을 수 있고, 그것을 찾는 것 자체가 원래 문제만큼 어렵다. TSP 의 정수 껍질을 기술하는 부등식은 오늘날에도 완전히 알려져 있지 않다.
세 가지 전략이 여기서 나온다
① 분지 — 격자를 쪼개어 각 조각에서 완화를 푼다 (29장)
② 절단 — PI 의 부등식 일부를 필요할 때 만들어 붙인다 (31장)
③ 구조 활용 — 애초에 P = PI 인 문제를 알아본다 (30장)

29장

분지한정

나무를 만들고, 하한으로 가지를 친다

알고리즘

분지한정 (branch and bound)
  1. 대기 목록에 원문제를 넣는다. incumbent zbest = +∞
  2. 반복: 마디 하나를 꺼내 LP 완화를 푼다 → 하한 zLP
    1. 실행불가능 → 가지치기
    2. zLP ≥ zbest → 가지치기 (한계에 의한)
    3. 해가 전부 정수 → incumbent 갱신, 가지치기
    4. 그 밖 → 분수 변수 xj = v 를 골라 xj ≤ ⌊v⌋ 와 xj ≥ ⌈v⌉ 두 마디로 분지
  3. 대기 목록이 비면 incumbent 가 최적해다
명제 29.1 (정당성) 분지는 실행가능한 정수해를 하나도 잃지 않는다. v 가 정수가 아니면 ⌊v⌋ < xj < ⌈v⌉ 인 정수는 존재하지 않기 때문이다.
명제 29.2 (가지치기의 정당성) 마디의 LP 완화 최적값은 그 마디에 속한 모든 정수해의 목적값의 하한이다. 따라서 그것이 이미 incumbent 이상이면 그 마디에는 더 좋은 해가 없다.

30장

완전단모듈성

어떤 정수 문제는 왜 사실 LP 인가

정의와 핵심 정리

정의 30.1 정수행렬 A 의 모든 정사각 부분행렬의 행렬식이 0, +1, −1 중 하나이면 A 를 완전단모듈(totally unimodular, TU)이라 한다.
정리 30.2 A 가 TU 이고 b 가 정수 벡터이면, 다면체 {x : Ax ≤ b, x ≥ 0} 의 모든 꼭짓점이 정수다.
증명 (크래머 공식 한 줄)
  1. 꼭짓점은 기저 실행가능해다(6부 정리 23.4). 기저 B 에 대해 xB = B−1b.
  2. 크래머 공식으로 (xB)i = det(Bi)/det(B), 여기서 Bi 는 i열을 b 로 바꾼 행렬이다.
  3. B 는 A(슬랙을 붙인 [A | I])의 정칙 정사각 부분행렬이므로 TU 에 의해 det(B) = ±1. A 가 TU 이면 [A|I] 도 TU 라는 사실이 필요하다 — 단위열은 행렬식 전개에서 크기를 바꾸지 않는다.
  4. det(Bi) 는 정수(정수 성분들의 행렬식)이므로 (xB)i 는 정수다.
결론 — TU 문제에서는 LP 를 풀면 그것이 곧 정수 최적해다. 정수 제약을 아예 걸 필요가 없다. 분지도 절단도 필요 없고, 다항 시간에 풀린다.

절단면법

유효 부등식을 만들어 붙인다

유효 부등식과 절단

정의 31.1 부등식 α⊤x ≤ β 가 유효(valid)하다는 것은 모든 정수 실행가능해가 그것을 만족한다는 뜻이다. 게다가 현재 LP 해가 그것을 어기면 그 부등식을 절단(cut)이라 한다.
절단이 하는 일 — 정수해는 하나도 잃지 않으면서 실행가능 영역을 줄인다. 그러면 LP 완화의 최적값(하한)이 올라가고, 분지 나무가 작아진다. 근사가 아니라 같은 정수 문제를 더 조인 것이다.
정리 31.2 (고모리 분수 절단) LP 최적 타블로의 한 행이 xB(i) + ∑j∈N āij xj = b̄i 이고 모든 변수가 정수여야 하면 ∑j∈N f(āij) xj ≥ f(b̄i),    f(v) = v − ⌊v⌋ 는 유효하고, f(b̄i) > 0 이면 현재 LP 해를 자른다.
증명
  1. 모든 xj ≥ 0 이므로 계수를 내림하면 좌변이 작아진다: xB(i) + ∑⌊āij⌋xj ≤ b̄i.
  2. 왼쪽은 정수들의 정수결합이므로 정수다. 정수가 b̄i 이하이면 ⌊b̄i⌋ 이하이기도 하다: xB(i) + ∑⌊āij⌋xj ≤ ⌊b̄i⌋. 여기가 절단이 태어나는 자리다 — 정수성을 딱 한 번 썼다.
  3. 원래 등식에서 이 부등식을 빼면 ∑(āij − ⌊āij⌋)xj ≥ b̄i − ⌊b̄i⌋, 곧 결론이다.
  4. 현재 LP 해에서는 비기저 변수가 모두 0 이므로 좌변이 0 이고 우변은 f(b̄i) > 0 — 어긴다.

돌려 보기 — 절단이 간격을 닫는다

읽는 법 — ① 4라운드에 누적 5개의 절단으로 완화값이 21 → 20 으로 내려와(최소화형 하한으로는 −21 → −20) 정수 최적값과 정확히 같아졌다. ② 각 절단이 실제로 현재 분수해를 자른다(좌변 > 우변). ③ 실행가능한 정수해 13개가 전부 살아남았다 — 절단은 근사가 아니다.

고모리 분수·혼합정수 절단타블로에서 자동 생성범용, 널리 쓰임

조합 최적화 알고리즘

배낭 · 할당 · 흐름 · 근사

배낭 문제와 동적계획

maxx∈{0,1}n ∑ivixi   s.t.   ∑iwixi ≤ W
정리 32.1 (동적계획) D[i][c] = 앞 i 개 물건과 용량 c 에서의 최적값이라 하면 D[i][c] = max(D[i−1][c],   vi + D[i−1][c−wi]) 로 O(nW) 시간에 정확히 풀린다.
증명 최적해가 물건 i 를 포함하지 않으면 나머지는 (i−1, c) 의 최적해여야 하고, 포함하면 나머지는 (i−1, c−wi) 의 최적해여야 한다(그렇지 않으면 그것을 바꿔 더 나은 해를 만들 수 있다 — 최적 부분구조). 두 경우가 전부이므로 최댓값을 취하면 된다.
O(nW) 는 다항 시간이 아니다 — 입력에서 W 를 적는 데 필요한 비트는 logW 이므로, 입력 길이 기준으로는 지수다. 이런 알고리즘을 의사 다항이라 하고, 배낭이 NP-난해라는 사실과 모순되지 않는다.

할당 문제와 헝가리안 알고리즘

minx ∑i,jcijxij   s.t.   ∑jxij = 1,   ∑ixij = 1,   xij ∈ {0,1}
정리 32.2 (Birkhoff–von Neumann) 이중확률행렬(행합·열합이 1 인 비음 행렬)의 극점은 정확히 순열행렬이다. 따라서 할당 문제의 LP 완화는 정수 최적해를 준다.
정리 30.2 의 특수한 경우이기도 하다 — 이분그래프 접속행렬이 TU 이기 때문이다.
헝가리안 알고리즘 = LP 쌍대성의 조합적 구현
잠재값 ui, vj 는 두 등식 제약의 쌍대변수이고, 알고리즘은 쌍대 실행가능성 ui + vj ≤ cij 를 언제나 유지한다. 등호가 성립하는 간선(tight edge)만으로 완전매칭이 만들어지는 순간 상보여유가 성립하고, 그것이 최적성의 증명이다.

근사 알고리즘 — 최적을 포기하고 보장을 얻는다

정의 32.4 알고리즘이 ρ-근사라는 것은, 최소화 문제에서 언제나 ALG ≤ ρ·OPT 를 보장한다는 뜻이다.
정리 32.5 (탐욕 집합 덮기) 집합 덮기 문제에서 “남은 원소를 가장 많이 덮는 집합”을 고르는 탐욕 알고리즘은 Hn ≈ ln n-근사다.
증명
  1. 최적해가 k 개의 집합을 쓴다고 하자. 남은 원소가 r 개일 때, 그 k 개 중 적어도 하나는 r/k 개 이상을 덮는다(비둘기집).
  2. 탐욕은 최선을 고르므로 한 걸음마다 남은 원소가 최소 (1 − 1/k) 배로 줄어든다.
  3. 따라서 t 걸음 뒤 남은 원소는 ≤ n(1−1/k)t < n e−t/k.
  4. t = k ln n 이면 남은 원소가 1 미만, 곧 0 이다. 즉 탐욕은 k ln n 개 이하를 쓴다.
이 보장은 최선이다 P ≠ NP 라면 집합 덮기에 (1−ε)ln n-근사 알고리즘은 존재하지 않는다(Dinur–Steurer, 2014 · 조금 더 강한 가정 아래서는 Feige, 1998). 즉 이 단순한 탐욕이 이론적 한계에 닿아 있다.

Q1. big-M 을 필요보다 크게 잡으면 정답이 달라지는가? 무엇이 나빠지는가?
Q2. 분지한정에서 “좋은 초기 해(incumbent)”가 왜 그렇게 중요한가?

A1. 정수해 집합은 달라지지 않는다 — M 이 충분히 크기만 하면 같은 문제다. 나빠지는 것은 LP 완화다. M 이 크면 z 를 아주 작은 값(예: 10−6)만 켜도 제약이 사실상 사라지므로, 완화의 하한이 형편없어지고 분지 나무가 폭발한다. 정식화의 질 = 완화의 질이다.
A2. 가지치기 규칙이 zLP ≥ zbest 이기 때문이다. zbest = +∞ 인 동안에는 아무 마디도 잘리지 않는다 — 순수 전수 탐색이다. 좋은 incumbent 를 일찍 얻으면 나무의 큰 부분이 통째로 사라진다. 그래서 상용 솔버는 탐색 전에 반올림·국소탐색·feasibility pump 같은 휴리스틱에 상당한 시간을 투자한다.
