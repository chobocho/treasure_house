볼록집합

정의 5.1 C ⊆ ℝn 가 볼록이라는 것은 x, y ∈ C,   t ∈ [0,1]   ⟹   tx + (1−t)y ∈ C 즉 두 점을 잇는 선분이 집합 안에 통째로 들어 있다는 뜻이다.
✔ 볼록인 예
  • 초평면 {x : a⊤x = b}
  • 반공간 {x : a⊤x ≤ b}
  • 공 {x : ‖x−c‖ ≤ r}
  • 다면체 {x : Ax ≤ b, Cx = d}
  • 확률 단체 {x ≥ 0, ∑xi = 1}
  • 양의 반정부호 행렬들 𝕊n+
✘ 볼록이 아닌 예
  • 구면 {x : ‖x‖ = 1} — 안쪽이 비었다
  • 정수격자 ℤn — 7부의 어려움이 여기서 시작
  • 두 공의 합집합
  • {x : ‖x‖ ≥ 1}
  • 랭크가 k 이하인 행렬들
합집합은 볼록성을 깨고, 교집합은 지킨다. 이 비대칭이 “제약을 and 로 붙이면 여전히 쉽고, or 로 붙이면 갑자기 어렵다”는 실무 감각의 정확한 근거다. 배타적 선택(x ∈ {0,1})이 비싼 이유도 같다.

볼록성을 지키는 연산

정리 5.2 Cα 가 (개수와 무관하게) 모두 볼록이면 ⋂αCα 도 볼록이다. 아핀사상 T(x) = Ax+b 에 대해 T(C) 와 T−1(C) 도 볼록이다.
증명
  1. 교집합: x,y ∈ ⋂Cα 이면 모든 α 에서 x,y ∈ Cα 이고, 각 Cα 가 볼록이므로 tx+(1−t)y ∈ Cα. 모든 α 에서 성립하니 교집합에 속한다.
  2. 상(image): u=T(x), v=T(y) 라 하면 tu+(1−t)v = A(tx+(1−t)y) + b = T(tx+(1−t)y) ∈ T(C). 아핀사상이 볼록결합을 볼록결합으로 옮기는 것이 핵심 — t+(1−t)=1 이라서 b 가 딱 한 번만 나온다.
  3. 역상: T(x), T(y) ∈ C 이면 위 계산으로 T(tx+(1−t)y) ∈ C.
실무적 함의 — 다면체 {Ax ≤ b} 가 볼록인 이유는 반공간 m 개의 교집합이기 때문이다. 제약을 아무리 많이 붙여도 각각이 볼록이면 실행가능집합은 볼록으로 남는다.

볼록포와 카라테오도리 정리

정의 5.3 conv(S) 는 S 를 포함하는 가장 작은 볼록집합, 동치로 S 원소들의 모든 볼록결합 ∑θixi (θi ≥ 0, ∑θi = 1) 의 집합이다.
정리 5.4 (카라테오도리) S ⊆ ℝn 이면 conv(S) 의 모든 점은 S 의 많아야 n+1 개 점의 볼록결합으로 쓸 수 있다.
증명
  1. x = ∑i=1k θixi, θi > 0, k > n+1 이라 하자. 이 k 를 줄일 수 있음을 보이면 된다.
  2. k−1 > n 개의 벡터 x2−x1, …, xk−x1 은 ℝn 에서 일차종속이다. n 차원 공간에 n 개 초과의 벡터는 반드시 종속이다.
  3. 따라서 모두 0 은 아닌 μi 로 ∑i≥2μi(xi−x1) = 0. μ1 = −∑i≥2μi 로 두면 ∑μixi = 0, ∑μi = 0.
  4. θi(s) = θi − s μi 로 두면 ∑θi(s) = 1 이고 ∑θi(s)xi = x 가 s 에 무관하게 유지된다.
  5. μi 중 양수가 있으므로 s 를 키우면 어떤 θj(s) 가 먼저 0 이 된다. 그 s 를 잡으면 항이 하나 줄고, 나머지는 여전히 ≥ 0 이다.
  6. k ≤ n+1 이 될 때까지 반복하면 된다.
어디에 쓰이나 — 6부에서 “다면체의 점은 꼭짓점들의 볼록결합”이라는 정리의 뼈대가 이것이다. 또 9부의 군집 기반 방법에서 “후보 몇 개면 충분한가”를 셀 때 등장한다.

투영 정리 — 존재·유일·특징

정리 5.5 C 가 공집합이 아닌 닫힌 볼록집합이면, 임의의 x 에 대해 PC(x) = arg minz ∈ C ‖x − z‖ 가 존재하고 유일하며, 다음 변분 부등식으로 특징지어진다: (x − PC(x))⊤(z − PC(x)) ≤ 0   for all z ∈ C
증명
  1. 존재: C 의 점 하나를 포함할 만큼 큰 R 로 C ∩ B(x, R) 를 잡으면 닫힌 유계 집합이다. z ↦ ‖x−z‖ 는 연속이므로 정리 1.4 로 최소가 달성된다.
  2. 유일: p, q 가 둘 다 최소라 하자. 중점 m = (p+q)/2 는 볼록성으로 C 에 있고, 평행사변형 법칙에서 ‖x−m‖² = ‖x−p‖²+‖x−q‖²2 − ‖p−q‖²4 p ≠ q 라면 ‖x−m‖ 이 최솟값보다 작아져 모순. 따라서 p = q. 유일성은 볼록성과 2-노름 둘 다 필요하다. 1-노름에서는 투영이 유일하지 않을 수 있다.
  3. 변분 부등식: p = PC(x), z ∈ C, t ∈ (0,1] 에 대해 p + t(z−p) ∈ C 이므로 ‖x−p−t(z−p)‖² ≥ ‖x−p‖². 전개하면 −2t(x−p)⊤(z−p) + t²‖z−p‖² ≥ 0. t 로 나누고 t→0 하면 결론.

투영은 거리를 늘리지 않는다

정리 5.6 (비확장성) ‖PC(x) − PC(y)‖ ≤ ‖x − y‖   for all x, y
증명
  1. p=PC(x), q=PC(y) 라 하자. 정리 5.5 의 부등식에 z=q 와 z=p 를 각각 넣으면 (x−p)⊤(q−p) ≤ 0,   (y−q)⊤(p−q) ≤ 0.
  2. 두 식을 더하면 (x−y−(p−q))⊤(q−p) ≤ 0, 즉 ‖p−q‖² ≤ (x−y)⊤(p−q).
  3. 오른쪽에 코시–슈바르츠를 쓰면 ‖p−q‖² ≤ ‖x−y‖‖p−q‖.
  4. ‖p−q‖ = 0 이면 자명하고, 아니면 양변을 그것으로 나누어 결론을 얻는다.
이 성질이 5부·8부를 가능하게 한다 — 투영경사법 xk+1 = PC(xk − α∇f) 는 “자유롭게 한 걸음, 그리고 되돌리기”인데, 되돌리는 연산이 거리를 늘리지 않으므로 무제약 경사하강의 수렴 증명을 거의 그대로 옮길 수 있다.

투영을 실제로 계산하기 — 확률 단체

상자와 공으로의 투영은 한 줄이지만, 단체 {z ≥ 0, ∑zi = 1} 로의 투영은 생각할 거리가 있다.

명제 5.7 P(x)i = max(xi − θ, 0) 이며, θ 는 ∑i max(xi−θ, 0) = 1 을 만족하는 유일한 실수다.
증명 (5부의 KKT 를 미리 쓴다) 문제 min ½‖z−x‖² s.t. ∑zi=1, z ≥ 0 의 라그랑주 함수는 L = ½‖z−x‖² + θ(∑zi−1) − μ⊤z 이다. 정류조건 zi − xi + θ − μi = 0, 상보여유 μizi = 0, μ ≥ 0. zi > 0 이면 μi=0 이라 zi = xi−θ; zi = 0 이면 μi = θ−xi ≥ 0. 둘을 합치면 zi = max(xi−θ, 0). 합은 θ 에 대해 연속이고 순감소하므로 θ 는 유일하다.
정렬이 이분법보다 나은 이유 — θ 는 구간마다 선형이므로, 내림차순으로 훑으며 “활성 성분이 몇 개인가”를 확정하면 θ 가 정확히 나온다. 이분법은 근사값만 준다.

분리 초평면 정리

정리 5.8 (점과 닫힌 볼록집합의 분리) C 가 닫힌 볼록집합이고 y ∉ C 이면, a ≠ 0 과 b 가 존재해 a⊤y > b   이고   a⊤z ≤ b   for all z ∈ C
증명 (투영으로 구성한다)
  1. p = PC(y), a = y − p 라 두자. y ∉ C 이고 p ∈ C 이므로 a ≠ 0.
  2. 정리 5.5 에서 모든 z ∈ C 에 대해 a⊤(z − p) ≤ 0, 즉 a⊤z ≤ a⊤p.
  3. 한편 a⊤y = a⊤p + a⊤(y−p) = a⊤p + ‖a‖² > a⊤p.
  4. b = a⊤p 로 잡으면 원하는 분리를 얻는다.
쌍대성의 씨앗 — 5부에서 강쌍대성(Slater 조건)을 증명할 때, “최적값보다 좋은 실행가능점이 없다”를 어떤 볼록집합과 한 점이 분리된다로 번역한다. 그 분리 초평면의 법선이 곧 라그랑주 승수가 된다.
닫힘이 빠지면? 열린 집합에서는 강한 분리(강부등호)가 실패할 수 있다 — 경계에서 붙기 때문이다. 그래도 지지 초평면(≥ 로 약화한 분리)은 여전히 존재하고, 6부에서 다면체의 면(face)을 다루는 도구가 된다.

원뿔 — 부등식 제약이 만드는 기하

정의 5.9 K 가 원뿔이라는 것은 x ∈ K, t ≥ 0 ⟹ tx ∈ K. 볼록이기도 하면 볼록원뿔이다. K 의 쌍대원뿔은 K∗ = {y : y⊤x ≥ 0 ∀x ∈ K}.

법선원뿔의 뜻 — 정리 5.5 의 변분 부등식은 “x−P(x) 가 P(x) 에서의 법선원뿔에 속한다”와 같은 말이다. 제약 문제의 최적성 조건 전체가 −∇f(x⋆) ∈ NC(x⋆) 라는 한 줄로 요약되며, 5부에서 이것을 KKT 로 풀어 쓴다.

볼록함수와 에피그래프

정의 6.1 정의역이 볼록집합인 f 가 볼록이라는 것은 f(tx + (1−t)y) ≤ t f(x) + (1−t)f(y)    ∀x,y, ∀t ∈ [0,1] 부등호가 x≠y, t∈(0,1) 에서 강부등호면 순볼록(strictly convex)이다.
정의 6.2 (에피그래프) epi f = {(x, s) ∈ ℝn+1 : s ≥ f(x)} — 그래프의 위쪽 영역.
정리 6.3 f 가 볼록 ⟺ epi f 가 볼록집합.
증명
  1. (⟹) (x,s), (y,u) ∈ epi f 이면 s ≥ f(x), u ≥ f(y). 볼록성으로 f(tx+(1−t)y) ≤ tf(x)+(1−t)f(y) ≤ ts+(1−t)u — 즉 볼록결합도 epi 에 든다.
  2. (⟸) (x,f(x)), (y,f(y)) ∈ epi f 의 볼록결합이 epi 에 있다는 것이 곧 정의 6.1 의 부등식이다.
왜 이 동치가 유용한가 — 집합의 언어와 함수의 언어를 오갈 수 있게 된다. 정리 5.2(교집합)를 쓰면 “볼록함수들의 상한(sup)이 볼록”이 즉시 나온다: epi(sup fα) = ⋂ epi fα.

젠센 부등식

정리 6.4 (젠센) f 가 볼록이고 θi ≥ 0, ∑θi = 1 이면 f(∑i θixi) ≤ ∑i θi f(xi) 확률변수 형태로는 f(𝔼[X]) ≤ 𝔼[f(X)].
증명 (항의 개수에 대한 귀납)
  1. k=2 는 정의 6.1 그 자체다.
  2. k−1 에서 성립한다고 가정하고 k 개를 보자. θk = 1 이면 자명하므로 θk < 1 이라 하자.
  3. s = ∑i<kθi = 1−θk > 0 이라 두고 y = ∑i<k(θi/s)xi 라 하자. θi/s 의 합이 1 이므로 y 는 k−1 개의 볼록결합이다.
  4. ∑θixi = s y + θkxk 이므로 2항 볼록성으로 f(∑θixi) ≤ s f(y) + θkf(xk).
  5. 귀납가정으로 f(y) ≤ ∑i<k(θi/s)f(xi) 을 대입하면 결론.
어디서 쓰나 — 8부에서 SGD 의 기댓값 논증이 통째로 젠센이다. 또 산술–기하 평균 부등식, 정보이론의 깁스 부등식이 모두 이 한 줄의 특수화다.

1차 판정 — 접평면이 함수를 아래에서 받친다

정리 6.5 f ∈ C¹ 이 볼록집합 위에서 정의될 때 f 볼록  ⟺  f(y) ≥ f(x) + ∇f(x)⊤(y−x)   ∀x,y
증명
  1. (⟹) 볼록성에서 f(x+t(y−x)) ≤ (1−t)f(x)+tf(y). 정리하면 f(x+t(y−x)) − f(x)t ≤ f(y) − f(x) t→0+ 을 취하면 좌변이 방향도함수 ∇f(x)⊤(y−x) (정리 3.3) 가 된다.
  2. (⟸) z = tx+(1−t)y 라 두고 가정을 (z, x) 와 (z, y) 에 적용한다: f(x) ≥ f(z) + ∇f(z)⊤(x−z),   f(y) ≥ f(z) + ∇f(z)⊤(y−z).
  3. 첫 식에 t, 둘째에 1−t 를 곱해 더하면, t(x−z) + (1−t)(y−z) = 0 이므로 기울기 항이 사라지고 tf(x)+(1−t)f(y) ≥ f(z) — 곧 볼록성이다.
이 한 줄이 볼록 최적화의 전부다 — “접평면은 절대 함수 위로 올라가지 않는다.” 그래서 ∇f(x⋆)=0 이면 f(y) ≥ f(x⋆) 가 모든 y 에서 성립한다 — 전역 최소다. 7장에서 이것을 정식으로 쓴다.

2차 판정 — 헤세가 양의 반정부호

정리 6.6 f ∈ C² 가 열린 볼록집합 위에 있을 때 f 볼록  ⟺  ∇²f(x) ⪰ 0   ∀x 또한 ∇²f(x) ≻ 0 ∀x 이면 순볼록이다 (역은 성립하지 않는다 — x⁴).
증명

  2. 1변수 함수는 φ″ ≥ 0 ⟺ 볼록이다(고교 미적분).
  3. φ″(t) = d⊤∇²f(x+td)d (정리 3.10 의 계산).
  4. 따라서 모든 d 에서 d⊤∇²f d ≥ 0 ⟺ ∇²f ⪰ 0.

단조성 조건을 빠뜨리면 틀린다 — h(u) = −u (볼록이지만 감소), g(x) = x² (볼록) 을 합성하면 −x² 로 오목이 된다. 실무에서 손실함수를 조립할 때 가장 흔한 실수다.
이 표가 도구다 — 새 손실함수의 볼록성을 헤세로 계산하지 말고, 이 연산들의 조합으로 구성해 보면 훨씬 빠르다. 예: 힌지 손실 max(0, 1−y w⊤x) 는 “아핀함수 두 개의 점별 최대” 이므로 볼록이다.

강볼록성 — 아래에서 이차함수가 받친다

정의 6.7 f 가 μ-강볼록이라는 것은 f(x) − (μ/2)‖x‖² 이 볼록이라는 뜻이며, C¹ 이면 다음과 동치다: f(y) ≥ f(x) + ∇f(x)⊤(y−x) + μ2‖y−x‖² C² 이면 ∇²f ⪰ μI 와도 동치다.
보조정리 6.8 (PL 부등식 · 기울기가 곧 최적성 간격) μ-강볼록이면 f(x) − f⋆ ≤ 12μ‖∇f(x)‖²
증명
  1. 정의 6.7 의 부등식 오른쪽을 y 에 대해 최소화한다. 이차함수이므로 최소점은 y = x − ∇f(x)/μ.
  2. 그 값을 넣으면 오른쪽은 f(x) − ‖∇f(x)‖²/(2μ).
  3. 따라서 모든 y 에서 f(y) ≥ f(x) − ‖∇f(x)‖²/(2μ). y=x⋆ 를 넣으면 결론.
왜 대단한가 — 우리가 알고리즘에서 실제로 볼 수 있는 것은 ‖∇f‖ 뿐인데(f⋆ 를 모르니까), 이 부등식이 그것을 최적성 간격의 상한으로 번역해 준다. 3부의 종료 조건이 정당한 이유다.

μ 와 L 사이 — 함수를 위아래로 가두기

f(x) + ∇f(x)⊤p + μ2‖p‖²   ≤   f(x+p)   ≤   f(x) + ∇f(x)⊤p + L2‖p‖²

왼쪽은 강볼록(정의 6.7), 오른쪽은 하강 보조정리(보조정리 3.12)다. 두 이차함수 사이에 f 가 갇힌다.

정의 6.9 κ = L/μ ≥ 1 을 조건수라 한다. 이차함수에서는 정확히 λmax(Q)/λmin(Q) 다 (정리 2.4).

미분이 없는 볼록함수 — 열경사

정의 6.10 g 가 x 에서 f 의 열경사라는 것은 f(y) ≥ f(x) + g⊤(y−x)    ∀y 그런 g 들의 집합을 열미분 ∂f(x) 라 한다.
정리 6.11 볼록함수는 정의역 내부의 모든 점에서 ∂f(x) ≠ ∅ 이다. 또 f 가 x 에서 미분가능하면 ∂f(x) = {∇f(x)} (한 점).

볼록 최적화의 힘

국소가 곧 전역 · 유일성 · 최적성 조건 · 비볼록의 함정

국소 최소가 곧 전역 최소

정리 7.1 f 가 볼록이고 𝒳 가 볼록집합이면, 𝒳 위의 모든 국소 최소점은 전역 최소점이다.
증명 (귀류법)
  1. x⋆ 가 국소 최소인데 전역이 아니라 하자. 그러면 f(y) < f(x⋆) 인 y ∈ 𝒳 가 있다.
  2. 국소 최소이므로 r>0 이 있어 B(x⋆,r) ∩ 𝒳 안에서는 x⋆ 가 최소다.
  3. t ∈ (0,1) 을 아주 작게 잡아 z = (1−t)x⋆ + ty 가 그 공 안에 들어오게 한다. 𝒳 가 볼록이므로 z ∈ 𝒳. 구체적으로 t < r/‖y−x⋆‖ 이면 ‖z−x⋆‖ = t‖y−x⋆‖ < r.
  4. f 의 볼록성으로 f(z) ≤ (1−t)f(x⋆) + tf(y) < (1−t)f(x⋆) + tf(x⋆) = f(x⋆).
  5. 공 안에 x⋆ 보다 나은 점 z 가 있다는 것은 국소 최소라는 가정에 모순이다.
이 한 정리가 볼록 최적화의 값어치 전부다. 알고리즘은 국소적으로만 볼 수 있는데(기울기는 국소 정보다), 볼록성은 그 국소 정보가 전역 결론을 준다고 보증한다.

최적해 집합의 모양

정리 7.2 볼록 문제의 최적해 집합 𝒳⋆ = {x ∈ 𝒳 : f(x) = p⋆} 는 볼록집합이다.
증명 x,y ∈ 𝒳⋆, t∈[0,1] 이면 z=tx+(1−t)y ∈ 𝒳 이고 f(z) ≤ tp⋆+(1−t)p⋆ = p⋆. p⋆ 는 최솟값이므로 f(z) ≥ p⋆, 따라서 등호이고 z ∈ 𝒳⋆.
정리 7.3 (유일성) f 가 순볼록이면 최적해는 많아야 하나다. μ-강볼록이고 𝒳 가 닫힌 볼록집합이면 최적해가 정확히 하나 존재한다.
증명
  1. 유일성: x≠y 가 둘 다 최적이면 중점에서 순볼록성으로 f((x+y)/2) < p⋆ — 모순.
  2. 존재: 강볼록이면 정의 6.7 의 부등식에서 f(y) ≥ f(x0) + ∇f(x0)⊤(y−x0) + (μ/2)‖y−x0‖² 이고 오른쪽은 ‖y‖→∞ 에서 +∞ 로 간다 — 강제적이다(정의 1.5). 정리 1.6 으로 최소가 존재한다.
왜 정칙화를 넣는가 — (λ/2)‖x‖² 를 더하면 문제는 λ-강볼록이 되어 해가 존재하고 유일해진다. 통계적 이유(과적합 억제)와 별개로, 최적화 자체가 잘 정의된다는 이유가 있다.

제약이 있을 때의 1차 최적성 조건

정리 7.4 f ∈ C¹ 볼록, 𝒳 볼록일 때 x⋆ ∈ 𝒳 가 최적  ⟺  ∇f(x⋆)⊤(y − x⋆) ≥ 0   ∀y ∈ 𝒳 즉 실행가능한 어느 방향으로도 값을 낮출 수 없다.
증명
  1. (⟸) 정리 6.5 에서 f(y) ≥ f(x⋆) + ∇f(x⋆)⊤(y−x⋆) ≥ f(x⋆) — 모든 실행가능점에서 최적이다.
  2. (⟹) 어떤 y 에서 ∇f(x⋆)⊤(y−x⋆) < 0 이라 하자. z(t) = x⋆+t(y−x⋆) ∈ 𝒳 이고 d/dt|t=0 f(z(t)) < 0 이므로 작은 t 에서 f(z(t)) < f(x⋆) — 최적성에 모순.
따름정리 7.5 𝒳 = ℝn 이면 조건은 ∇f(x⋆) = 0 으로 줄어든다. 모든 방향 d 와 −d 에서 동시에 ≥ 0 이려면 내적이 0 이어야 하고, 이것이 모든 d 에서 성립하려면 기울기가 0 이다.
정리 7.4 를 투영으로 다시 쓰면 x⋆ = P𝒳(x⋆ − α∇f(x⋆)) (임의의 α>0) 이다 — 정리 5.5 의 변분 부등식과 같은 꼴이기 때문이다. 투영경사법의 고정점이 정확히 최적해라는 뜻이다.

비볼록의 함정 — 무엇을 잃는가

✘ 국소 최소가 여러 개

히멜블라우는 값이 0 인 최소점이 네 개다. 알고리즘은 출발점이 정한 하나로 간다. “수렴했다”가 “옳다”가 아니다.

✘ 안장점

∇f=0 인데 최소가 아닌 점. 고차원에서는 국소 최소보다 안장점이 훨씬 많다 — 헤세의 고윳값 n 개가 모두 양수일 확률이 지수적으로 작기 때문이다.

✘ 평평한 고원

Beale 함수처럼 기울기가 오래 거의 0 인 영역. 종료 조건 ‖∇f‖ ≤ ε 이 거짓 양성을 낸다.

✘ 보장이 사라진다

볼록에서 성립하던 “‖∇f‖ 가 작으면 최적에 가깝다”(보조정리 6.8)가 비볼록에서는 전혀 성립하지 않는다.

그래서 실무의 전략은 둘 중 하나다 — ① 문제를 볼록으로 다시 정식화한다(가능하면 언제나 이쪽). ② 비볼록임을 인정하고 여러 출발점·전역 기법(9부)·좋은 초기화로 대응한다. 셋째 길, “비볼록인데 볼록인 척하기”는 없다.

볼록 최적화 문제의 표준형

정의 7.6 min f0(x)   s.t.   fi(x) ≤ 0,   aj⊤x = bj 에서 f0, …, fm 이 모두 볼록이고 등식 제약이 아핀이면 이 문제를 볼록 최적화 문제라 한다.
명제 7.7 — 등식 제약이 아핀이어야 하는 이유 h 가 볼록이지만 아핀이 아니면 {x : h(x) = 0} 은 일반적으로 볼록집합이 아니다.
증명 (반례와 구조)
  1. h(x) = ‖x‖² − 1 은 볼록이지만 {h=0} 은 단위구면 — 볼록이 아니다(내부가 비었다).
  2. 일반적으로 {h ≤ 0} 은 볼록함수의 하위준위집합이라 항상 볼록이지만, {h = 0} = {h≤0} ∩ {h≥0} 이고 {h≥0} 은 −h 가 오목이라 볼록성이 보장되지 않는다.
  3. 둘 다 볼록이 되려면 h 와 −h 가 모두 볼록, 곧 h 가 아핀이어야 한다.
실무의 요령 — h(x)=0 을 h(x) ≤ 0 으로 완화해도 최적해에서 등호가 성립한다면(목적함수가 그 방향으로 밀어붙인다면) 볼록 문제로 바꿔 풀 수 있다. 13부에서 이 기법을 여러 번 쓴다.

볼록성 점검 체크리스트

  1. 구성으로 확인한다 — 아핀·노름·지수·로그·최대·비음 결합의 조합으로 쓸 수 있는가? 가능하면 헤세를 계산할 필요가 없다.
  2. 합성의 단조성 — h(g(x)) 꼴이라면 h 가 비감소인지 확인했는가?
  3. 등식 제약이 아핀인가 — 아니라면 실행가능집합이 이미 비볼록이다(명제 7.7).
  4. 정의역 — −logx 처럼 정의역 자체가 제약인 함수는 그 정의역이 볼록인지 본다.
  5. 수치로 의심한다 — worst_jensen 으로 무작위 현을 그어 본다. 반례가 나오면 즉시 끝난다.
  6. 헤세의 고윳값 — 표본점에서 λmin 이 음수면 그 자리에서 볼록이 아니다(curvature_range).
  7. 그래도 비볼록이면 — 변수 변환(로그 변환·기하계획법), 볼록 완화, 아니면 9부의 전역 기법으로 간다.
흔한 착각 — “목적함수가 볼록이면 볼록 문제”가 아니다. 제약도 볼록해야 한다. 신경망 학습이 비볼록인 이유는 손실함수가 아니라 매개변수에 대한 합성 구조 때문이다.

돌려 보기 — 볼록성을 기계로 의심하기

읽는 법 — ① 젠센 간격이 음수인 함수는 반례가 실제로 존재한다. 통과는 증명이 아니다. ② 로지스틱 회귀의 μ 가 정칙화 계수 근처인 것에 주목 — 데이터 항의 헤세는 ⪰ 0 일 뿐이고, 강볼록성은 전적으로 (λ/2)‖w‖² 가 만든다. ③ 투영은 20만 개의 무작위 후보 어느 것보다 가깝고, 변분 부등식과 비확장성이 실측으로 확인된다.

확인 문제

Q1. f(x) = ‖Ax − b‖² 는 항상 볼록인가? 순볼록인가? 강볼록인가?
Q2. 볼록함수의 최소값(pointwise minimum) min(f, g) 는 볼록인가?

A1. ∇²f = 2A⊤A ⪰ 0 이므로 항상 볼록. A 의 열이 일차독립(랭크 n)이면 A⊤A ≻ 0 이라 순볼록이자 2λmin(A⊤A)-강볼록. 열이 종속이면(예: m < n) 영공간 방향으로 값이 변하지 않아 순볼록조차 아니다 — 최적해가 아핀 부분공간 전체가 된다(정리 7.2 의 예).
A2. 아니다. f(x)=(x−1)², g(x)=(x+1)² 의 점별 최소는 x=0 근처에서 위로 볼록한 봉우리를 만든다. 최대는 볼록성을 지키지만 최소는 깨진다 — epi(min) = epi f ∪ epi g 이고 합집합은 볼록성을 보존하지 않기 때문이다(정리 5.2 는 교집합에 대한 것이다).
