최적화 문제란 무엇인가

표준형 · 최소점의 종류 · 해가 존재할 조건 · 문제의 분류

표준형

최적화 문제는 언제나 아래 꼴로 적는다. 이 책 전체가 이 다섯 줄 위에 서 있다.

minimizex ∈ ℝn   f0(x)
subject to   fi(x) ≤ 0,   i = 1, …, m
subject to   hj(x) = 0,   j = 1, …, p
용어 x 는 결정변수, f0 는 목적함수, fi ≤ 0 은 부등식 제약, hj = 0 은 등식 제약이다. 제약을 모두 만족하는 점들의 집합 𝒳 = {x : fi(x) ≤ 0 ∀i, hj(x) = 0 ∀j} 을 실행가능집합, 그 원소를 실행가능점이라 한다.
최대화는 따로 다루지 않는다 — max g(x) 는 min −g(x) 와 같은 문제다. 최적값의 부호만 뒤집으면 되고 최적해는 그대로다. 마찬가지로 fi ≥ 0 은 −fi ≤ 0 으로 적는다.
등호의 방향을 마음대로 바꾸지 말 것 — 5부에서 KKT 조건을 유도할 때 승수의 부호가 ≤ 방향에 묶여 있다. 표준형을 지키면 부호 실수가 사라진다.

최적값과 최적해는 다른 것이다

정의 1.1 (최적값) p⋆ = inf { f0(x) : x ∈ 𝒳 } 관례로 𝒳 = ∅ 이면 p⋆ = +∞ (실행불가능), 아래로 유계가 아니면 p⋆ = −∞ (비유계)라 쓴다.
정의 1.2 (최적해) x⋆ ∈ 𝒳 이면서 f0(x⋆) = p⋆ 인 점. 존재하지 않을 수 있고, 여럿일 수도 있다.

셋을 구분해야 하는 이유 — 세 가지 다른 실패

상황예p⋆최적해
실행불가능x ≤ −1, x ≥ 1+∞없음
비유계min x, x ∈ ℝ−∞없음
하한에 도달 못 함min ex, x ∈ ℝ0없음
정상min x², x ∈ ℝ0x⋆ = 0
여러 개min sin x−1무한히 많음
세 번째 줄이 핵심이다 — ex 는 아래로 유계(0)이고 하한도 명확한데 그 값을 얻는 점이 없다. 그래서 “아래로 유계이면 최소가 있다”는 참이 아니다. 이 간극을 메우는 것이 다음 장의 존재성 정리다.

최소점의 종류

정의 1.3 x⋆ ∈ 𝒳 에 대하여
전역 최소f(x⋆) ≤ f(x) for all x ∈ 𝒳
국소 최소∃r > 0 : f(x⋆) ≤ f(x) for all x ∈ 𝒳 ∩ B(x⋆, r)
엄격 국소위에서 부등호가 x ≠ x⋆ 일 때 강부등호
고립 국소어떤 근방 안에 국소 최소점이 그것 하나뿐

여기서 B(x, r) = {y : ‖y − x‖ < r} 는 열린 공이다.

참고 — 엄격하다고 고립된 것은 아니다 반례가 있다. f(x) = x⁴(2 + sin(1/x)), f(0)=0 은 0 에서 엄격 국소 최소이지만, 0 에 수렴하는 국소 최소점들이 무한히 많아 고립되어 있지 않다. 수치 알고리즘의 “수렴했다”는 판정이 왜 미묘한지 보여 주는 예다.
알고리즘이 실제로 찾는 것은 국소 최소다. 전역이라는 보장은 문제의 구조에서만 나온다 — 그 구조가 2부의 볼록성이다.

해가 존재할 조건 — 바이어슈트라스

정리 1.4 (바이어슈트라스 최대·최소 정리) S ⊆ ℝn 가 공집합이 아니고 유계이며 닫혀 있고, f : S → ℝ 가 연속이면 f 는 S 위에서 최솟값과 최댓값을 실제로 얻는다.
증명 (최솟값 쪽)
  1. p⋆ = infS f 라 두자 (−∞ 일 수도 있다고 열어 둔다). 하한은 실수의 완비성으로 항상 정의된다.
  2. 정의에 의해 f(xk) → p⋆ 인 수열 {xk} ⊆ S 가 있다. 하한은 “아무리 가까이 가도 그보다 작은 값이 있다”는 뜻이므로 그런 수열을 뽑을 수 있다.
  3. S 가 유계이므로 볼차노–바이어슈트라스에 의해 수렴하는 부분수열 xkj → x⋆ 가 있다. 유계 수열은 수렴 부분수열을 갖는다 — 유한차원이라서 쓸 수 있는 성질이다.
  4. S 가 닫혀 있으므로 x⋆ ∈ S. 닫힌 집합은 자기 극한점을 포함한다. 이 줄이 “닫혀 있음”을 쓰는 유일한 자리다.
  5. f 가 연속이므로 f(x⋆) = lim f(xkj) = p⋆. 연속성은 “극한과 함수 적용의 순서를 바꿔도 된다”는 말이다.
  6. 따라서 p⋆ 는 유한하고 x⋆ 에서 달성된다.
세 조건이 모두 필요하다 — 유계가 빠지면 min x on ℝ(−∞), 닫힘이 빠지면 min x on (0,1](하한 0 미달성), 연속이 빠지면 계단함수에서 최소가 없다.

유계가 아니어도 되는 경우 — 강제성

실전에서 𝒳 = ℝn 인 무제약 문제가 훨씬 많다. 이때는 유계 조건을 함수의 성질로 대신할 수 있다.

정의 1.5 (강제적 · coercive) ‖x‖ → ∞ 일 때 f(x) → +∞ 이면 f 를 강제적이라 한다.
정리 1.6 f : ℝn → ℝ 가 연속이고 강제적이면 f 는 전역 최소점을 갖는다.
증명
  1. 아무 점 x0 을 잡고 c = f(x0) 라 하자.
  2. 강제성에서, ‖x‖ > R ⇒ f(x) > c 인 R 이 존재한다. “무한대로 간다”의 정의를 c 라는 문턱에 적용한 것이다.
  3. 따라서 최솟값 후보는 전부 K = {x : ‖x‖ ≤ R} 안에 있다. 밖은 값이 c 보다 크므로 x0 에 지고, x0 ∈ K 이다.
  4. K 는 닫혀 있고 유계이므로 정리 1.4 를 적용하면 K 위에서 최소점 x⋆ 가 존재한다.
  5. K 밖의 모든 점은 f > c ≥ f(x⋆) 이므로 x⋆ 는 ℝⁿ 전체의 최소점이다.
실무에서의 쓸모 — 손실함수에 (λ/2)‖x‖² 정칙화 항을 더하면 그 함수는 자동으로 강제적이 된다. “정칙화가 해를 존재하게 만든다”는 말의 정확한 뜻이 이것이다. 4부에서 다시 만난다.

확인 문제

Q. f(x) = x²/(1 + x²) 를 ℝ 에서 최대화하는 문제를 생각하자. 최적값 p⋆ 는? 최적해는 존재하는가? 정리 1.4·1.6 중 어느 것도 쓸 수 없는 이유는?

A. sup f = 1 이지만 어떤 유한한 x 에서도 1 이 되지 않으므로 최적해는 없다(최소화 형태로는 min −f, p⋆ = −1 미달성). ℝ 은 유계가 아니라 정리 1.4 를 못 쓰고, −f 는 ‖x‖→∞ 에서 −1 로 수렴하므로 강제적이지 않아 정리 1.6 도 못 쓴다. 두 정리의 가정이 장식이 아니라는 예다.

코시–슈바르츠 부등식

정리 2.1 모든 x, y ∈ ℝn 에 대하여 |x⊤y| ≤ ‖x‖ ‖y‖ 이고, 등호는 x 와 y 가 평행할 때(한쪽이 다른 쪽의 실수배일 때)에만 성립한다.
증명 (판별식 논법)
  1. y = 0 이면 양변이 0 이므로 자명하다. 이제 y ≠ 0 이라 하자.
  2. 임의의 실수 t 에 대해 g(t) = ‖x − t y‖² ≥ 0 이다. 노름의 제곱은 음이 될 수 없다 — 이것이 유일하게 쓰는 성질이다.
  3. 전개하면 g(t) = ‖y‖²t² − 2(x⊤y)t + ‖x‖² — t 에 대한 이차식이고 최고차항 계수가 양수다.
  4. 모든 t 에서 음이 아니려면 판별식이 0 이하여야 한다: (2x⊤y)² − 4‖y‖²‖x‖² ≤ 0 이차식이 실근을 두 개 가지면 그 사이에서 음수가 된다.
  5. 정리하면 (x⊤y)² ≤ ‖x‖²‖y‖², 양변에 제곱근을 취해 결론을 얻는다.
  6. 등호는 판별식이 0 일 때, 곧 g(t0) = 0 인 t0 가 있을 때다. 그러면 x = t0y.
이 부등식이 이 책에서 하는 일 — “−∇f 가 가장 가파른 하강 방향”이라는 사실(3장)의 증명이 통째로 이것이다. 나중에 수렴 증명에서도 거의 매번 등장한다.

노름 세 가지와 그 관계

‖x‖1 = ∑i|xi|   ·   ‖x‖2 = √∑ixi²   ·   ‖x‖∞ = maxi |xi|
정리 2.2 (노름의 동치성 — 유한차원) 모든 x ∈ ℝn 에 대하여 ‖x‖∞ ≤ ‖x‖2 ≤ √n‖x‖∞,    ‖x‖2 ≤ ‖x‖1 ≤ √n‖x‖2
증명
  1. ‖x‖∞² = max xi² ≤ ∑xi² = ‖x‖2² — 항 하나는 전체 합 이하.
  2. ∑xi² ≤ n·max xi² 이므로 ‖x‖2 ≤ √n‖x‖∞.
  3. ‖x‖1² = (∑|xi|)² = ∑xi² + ∑i≠j|xixj| ≥ ‖x‖2² — 교차항이 음이 아니다.
  4. 마지막은 코시–슈바르츠에 y = (1,…,1) 을 넣은 것이다: ‖x‖1 = ∑|xi|·1 ≤ ‖x‖2·√n.
왜 중요한가 “수렴한다”는 말이 어느 노름을 쓰든 같은 뜻이 된다. 유한차원에서만 참이며, 상수 √n 이 차원에 의존한다는 점이 고차원에서 종종 문제가 된다 — 8부에서 다시 만난다.

노름을 구현할 때의 함정

수식 √(∑xi²) 를 그대로 옮기면 xi = 10200 에서 제곱하는 순간 넘친다. 답은 1.41×10200 으로 멀쩡한 수인데도 inf 가 나온다.

스케일링 — 최대 성분 s 로 나눈 뒤 제곱하고, 마지막에 s 를 곱해 되돌린다. 각 항이 1 이하가 되므로 넘치지 않는다. 언더플로도 같은 이유로 막힌다.
테스트에 test_norm_no_overflow 가 있는 이유다. “교과서 식을 그대로 옮기면 안 되는 자리”를 표시해 두는 것이 테스트의 또 다른 역할이다.

이차형식과 정부호성

정의 2.3 대칭행렬 A ∈ ℝn×n 에 대하여 q(x) = x⊤Ax 를 이차형식이라 한다.
A ≻ 0 양의 정부호x⊤Ax > 0 for all x ≠ 0
A ⪰ 0 양의 반정부호x⊤Ax ≥ 0 for all x
부정부호양수도 되고 음수도 된다
정리 2.4 (레일리 몫의 범위) A 가 대칭이고 고윳값이 λmin ≤ ⋯ ≤ λmax 이면 λmin‖x‖² ≤ x⊤Ax ≤ λmax‖x‖² 따라서 A ≻ 0 ⟺ λmin > 0 이다.
증명
  1. 스펙트럼 정리(정리 2.5)로 A = QΛQ⊤, Q 는 직교, Λ = diag(λi).
  2. y = Q⊤x 로 두면 x⊤Ax = y⊤Λy = ∑λiyi². 직교변환은 좌표를 회전할 뿐 길이를 바꾸지 않는다: ‖y‖ = ‖x‖.
  3. ∑λiyi² ≤ λmax∑yi² = λmax‖x‖². 아래쪽도 같은 방식.
  4. 등호는 x 가 해당 고유벡터일 때 달성되므로 이 한계는 최선이다.
이 정리가 3부의 심장이다 — λmin = μ 는 강볼록 상수가 되고 λmax = L 은 평활 상수가 된다. 경사하강의 수렴 속도는 정확히 κ = L/μ 로 결정된다.

스펙트럼 정리와 야코비 회전

정리 2.5 (스펙트럼 정리) 실대칭행렬 A 는 A = QΛQ⊤ 로 분해된다. Q 의 열은 정규직교 고유벡터, Λ 는 실수 고윳값의 대각행렬이다.

이 책은 이 정리를 구성적으로 쓴다 — 야코비 회전이 실제로 Q 를 만들어 낸다.

명제 2.6 (야코비 회전은 반드시 진전한다) 비대각 성분의 제곱합 off(A) = ∑i≠jaij² 라 하자. (p,q) 성분을 0 으로 만드는 회전 J 을 적용하면 off(J⊤AJ) = off(A) − 2apq²
증명
  1. 직교변환은 프로베니우스 노름을 보존한다: ‖J⊤AJ‖F² = ‖A‖F². ‖M‖F² = tr(M⊤M) 이고 대각합은 순환 성질과 J⊤J = I 로 불변이다.
  2. 회전은 p, q 행·열만 건드리므로 app² + aqq² + 2apq² 가 a′pp² + a′qq² + 0 으로 바뀐다.
  3. 전체 제곱합은 그대로인데 대각 제곱합이 2apq² 만큼 늘었으므로, 비대각 제곱합은 그만큼 줄었다.
  4. 매 회전마다 off 가 단조 감소하고 0 이 하한이므로 수렴한다.

명제 2.7 H = I − 2vv⊤ 는 대칭이고 직교이며 H² = I 다.
증명 H⊤ = I − 2(vv⊤)⊤ = H 이므로 대칭. 또 H⊤H = H² = I − 4vv⊤ + 4v(v⊤v)v⊤ = I — 마지막 등호는 v⊤v = 1 때문이다.

조건수 — 컴퓨터가 잃을 자릿수를 미리 아는 법

정의 2.8 정칙행렬 A 의 2-노름 조건수는 κ2(A) = ‖A‖2‖A−1‖2 = σmax/σmin.
정리 2.9 (섭동 한계) Ax = b 의 우변이 b + Δb 로 바뀌면 해는 x + Δx 로 바뀌고 ‖Δx‖‖x‖ ≤ κ2(A) ‖Δb‖‖b‖
증명
  1. AΔx = Δb 이므로 ‖Δx‖ = ‖A−1Δb‖ ≤ ‖A−1‖‖Δb‖. 유도노름의 정의 ‖My‖ ≤ ‖M‖‖y‖.
  2. 또 ‖b‖ = ‖Ax‖ ≤ ‖A‖‖x‖ 이므로 1/‖x‖ ≤ ‖A‖/‖b‖.
  3. 두 부등식을 곱하면 결론이 나온다.
실용적 읽기 — 입력이 배정밀도(상대오차 ε ≈ 2.2×10−16)로 주어지면 결과의 상대오차는 κ·ε 정도다. 즉 κ = 10k 이면 유효숫자 k 자리를 잃는다. 다음 슬라이드에서 실측한다.

기울기·헤세·테일러 전개 — 그리고 3부 전체를 떠받칠 하강 보조정리

기울기 — 편미분을 모아 놓은 벡터

정의 3.1 f : ℝn → ℝ 의 기울기는 ∇f(x) =
∂f/∂x1
⋮
∂f/∂xn
 ∈ ℝn ∂f/∂xi 는 xi 만 움직이고 나머지를 고정한 1변수 도함수다.
정의 3.2 (미분가능) f 가 x 에서 미분가능하다는 것은, 어떤 벡터 g 가 있어 limh→0 f(x+h) − f(x) − g⊤h‖h‖ = 0 을 만족한다는 뜻이다. 그때 g = ∇f(x).
편미분이 다 있어도 미분가능하지 않을 수 있다 — f(x,y) = xy/(x²+y²), f(0,0)=0 은 원점에서 두 편미분이 모두 0 이지만 대각선 방향으로는 1/2 로 튄다. 이 책의 정리들이 C¹(편미분이 연속)을 요구하는 이유다 — 그러면 미분가능이 따라온다.

방향도함수와 최급강하 방향

정리 3.3 (방향도함수) f 가 x 에서 미분가능하면, 단위벡터 d 에 대해 Ddf(x) = limt→0+ f(x+td) − f(x)t = ∇f(x)⊤d
증명 정의 3.2 에서 h = td 로 두면 ‖h‖ = t 이고 f(x+td) − f(x) = t∇f(x)⊤d + o(t). 양변을 t 로 나누고 t→0 을 취하면 o(t)/t → 0 이므로 결론을 얻는다.
정리 3.4 (가장 가파른 하강 방향) ∇f(x) ≠ 0 일 때, ‖d‖ = 1 인 방향 중 Ddf(x) 를 최소로 만드는 것은 d⋆ = − ∇f(x)‖∇f(x)‖,    그때 값은   −‖∇f(x)‖
증명
  1. 코시–슈바르츠(정리 2.1)에 의해 |∇f⊤d| ≤ ‖∇f‖‖d‖ = ‖∇f‖.
  2. 따라서 ∇f⊤d ≥ −‖∇f‖ — 어떤 방향도 이보다 더 가파르게 내려갈 수 없다.
  3. 등호 조건은 d 가 ∇f 와 평행하고 부호가 반대인 경우이며, 단위벡터 조건까지 붙이면 d⋆ 는 유일하다.
경사하강법의 전부가 이 두 정리다. 다만 “한 걸음 안에서 가장 가파르다”가 “가장 빨리 도착한다”를 뜻하지는 않는다 — 3부에서 지그재그로 확인한다.

직접 해 보기 — 방향도함수

등고선을 눌러 점을 옮기고, 슬라이더로 방향 d 를 돌려 보세요
파랑 ∇f (가장 가파른 상승) · 초록 −∇f (가장 가파른 하강) · 주황 고른 방향 d. 슬라이더를 돌려 ∇f⊤d 가 −‖∇f‖ 에 가장 가까워지는 각도를 찾아보면, 그것이 정확히 초록 화살표 방향이다 — 정리 3.4 의 실측이다.
등고선과 화살표의 관계를 보라 — 화살표는 언제나 등고선에 수직이다(명제 3.5). 로젠브록에서는 골짜기 바닥을 따라가는 방향의 기울기가 거의 0 이라, 초록 화살표가 골짜기를 가로지르는 쪽을 가리킨다. 3부에서 경사하강이 왜 지그재그를 그리는지가 여기 이미 보인다.

기울기는 등위집합에 수직이다

명제 3.5 등위집합 Lc = {x : f(x) = c} 위를 지나는 매끄러운 곡선 γ(t) 에 대해 ∇f(γ(t))⊤γ′(t) = 0 이다.
증명 f(γ(t)) = c 는 t 에 무관한 상수다. 양변을 t 로 미분하고 연쇄법칙을 적용하면 d/dt f(γ(t)) = ∇f(γ)⊤γ′ = 0.
그림으로 — 등고선을 따라 걸으면 높이가 변하지 않는다. 높이가 가장 빨리 변하는 방향은 등고선에 수직이다. 5부의 라그랑주 조건 ∇f = λ∇h 는 “두 등위면이 접한다”는 이 사실의 다른 표현이다.
미리 보는 5부 — 제약 h(x)=0 위에서 최소인 점에서는, f 의 등위면과 h 의 등위면이 접한다. 접한다는 것은 법선이 평행하다는 것이고, 그것이 곧 ∇f = λ∇h 다. 라그랑주 승수는 이 한 줄에서 나온다.

연쇄법칙 — 실제로 기울기를 계산하는 방법

정리 3.6 (연쇄법칙) g : ℝn→ℝm, f : ℝm→ℝ 이 미분가능하면 F = f∘g 에 대해 ∇F(x) = Jg(x)⊤ ∇f(g(x)) 여기서 Jg 는 야코비 행렬 (Jg)ij = ∂gi/∂xj 다.

예 — 로지스틱 손실의 기울기를 이 규칙으로 얻는다

ℓ(w) = log(1 + e−z),   z = y·w⊤x
dℓdz = −e−z1 + e−z = −σ(−z) = −11 + ez,    ∇wz = y x
⟹   ∇wℓ = −σ(−z) · y x
넘침을 피하는 법 — z 가 크게 음수면 e−z 가 넘친다. 그래서 코드는 1/(1+ez) 꼴로 쓴다. 수식이 같아도 어느 꼴로 계산하느냐가 다르다.

헤세 행렬 — 곡률

정의 3.7 (∇²f(x))ij = ∂²f∂xi∂xj(x)
정리 3.8 (슈바르츠·클레로) 2차 편미분이 x 근방에서 연속이면 ∂²f/∂xi∂xj = ∂²f/∂xj∂xi — 즉 ∇²f 는 대칭이다.
연속성이 빠지면 깨진다 f(x,y) = xy(x²−y²)/(x²+y²) (원점에서 0)은 fxy(0,0) = −1, fyx(0,0) = +1 이다. 그래서 정리에 “연속”이 붙어 있다.
헤세가 알려 주는 것조건뜻
국소 최소∇f=0, ∇²f ≻ 0모든 방향으로 위로 휜다
국소 최대∇f=0, ∇²f ≺ 0모든 방향으로 아래로 휜다
안장점∇f=0, 부정부호어떤 방향은 오르고 어떤 방향은 내린다
판정 불가∇²f ⪰ 0 이고 특이3차 이상을 봐야 한다 (x⁴ vs −x⁴)
이 표의 정확한 증명은 3부 1장(최적성 조건)에서, 테일러 2차 전개를 세운 뒤에 한다.

다변수 테일러 전개

정리 3.9 (1차 · 평균값 형태) f ∈ C¹ 이면 x 와 x+p 를 잇는 선분 위의 어떤 ξ 에 대해 f(x+p) = f(x) + ∇f(ξ)⊤p
정리 3.10 (2차 · 적분 형태와 나머지 형태) f ∈ C² 이면 f(x+p) = f(x) + ∇f(x)⊤p + 12p⊤∇²f(ξ)p 인 ξ 가 선분 위에 있고, 또한 ∇f(x+p) = ∇f(x) + 1∫0 ∇²f(x+tp) p dt
증명 (1변수로 환원하는 표준 수법)
  1. φ(t) = f(x + tp), t ∈ [0,1] 이라 두자. φ 는 1변수 함수다. 다변수 정리를 1변수 정리로 끌어내리는 이 치환이 앞으로 계속 쓰인다.
  2. 연쇄법칙: φ′(t) = ∇f(x+tp)⊤p,   φ″(t) = p⊤∇²f(x+tp)p.
  3. 1변수 평균값 정리 φ(1) = φ(0) + φ′(θ) 를 쓰면 정리 3.9 가 나온다 (ξ = x+θp).
  4. 1변수 테일러 φ(1) = φ(0) + φ′(0) + ½φ″(θ) 를 쓰면 정리 3.10 의 첫 식이 나온다.
  5. 미적분의 기본정리를 ∇f(x+tp) 에 성분별로 적용하면 적분 형태를 얻는다.
2차 전개가 최적화의 세계관이다 — 모든 매끄러운 함수는 국소적으로 이차형식이다. 그래서 “이차함수에서 어떻게 동작하는가”가 알고리즘의 성격을 거의 결정한다.

하강 보조정리 — 이 책에서 가장 많이 쓰이는 부등식

정의 3.11 (L-평활) ‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖ 가 모든 x,y 에서 성립하면 f 를 L-평활하다고 한다. (기울기가 립시츠 연속)
보조정리 3.12 (하강 보조정리 · descent lemma) f 가 L-평활이면 모든 x, y 에 대해 f(y) ≤ f(x) + ∇f(x)⊤(y−x) + L2‖y−x‖²
증명
  1. p = y − x 라 두고 정리 3.10 의 적분 형태를 스칼라 버전으로 쓴다: f(y) − f(x) = ∫₀¹ ∇f(x+tp)⊤p dt.
  2. 양변에서 ∇f(x)⊤p 를 빼면 f(y) − f(x) − ∇f(x)⊤p = ∫₀¹ [∇f(x+tp) − ∇f(x)]⊤p dt.
  3. 코시–슈바르츠로 피적분함수를 위로 누른다: [·]⊤p ≤ ‖∇f(x+tp) − ∇f(x)‖·‖p‖.
  4. 립시츠 조건으로 ‖∇f(x+tp) − ∇f(x)‖ ≤ L‖tp‖ = Lt‖p‖.
  5. 따라서 적분은 ≤ ∫₀¹ Lt‖p‖² dt = (L/2)‖p‖². 정리하면 결론.
읽는 법 — “함수는 그 접평면 위로 (L/2)‖·‖² 이상 솟아오르지 않는다.” 즉 함수를 위에서 덮는 이차함수가 항상 있다. 그 이차함수를 최소화하는 것이 곧 α = 1/L 의 경사하강이다 — 3부 2장에서 이 한 줄로 수렴을 증명한다.

수치미분 — 손으로 유도한 식을 채점하는 장치

최적화 코드에서 가장 흔한 버그는 알고리즘이 아니라 기울기 식의 오타다. 증상도 고약하다 — 알고리즘은 멀쩡히 돌고, 조용히 엉뚱한 점으로 간다.

헤세는 ∇f 의 야코비다 — 그러니 헤세 검사를 따로 만들 필요가 없다. 기울기 함수에 야코비 수치미분을 걸면 그대로 검사가 된다. 두 번 미분하지 않으므로 정밀도도 더 낫다.
이 책의 모든 시험함수는 tests/test_numdiff.py 에서 이 검사를 통과한다. 통과하지 못한 도함수는 싣지 않았다.

확인 문제

Q. f(x) = ½x⊤Qx, Q ⪰ 0 의 립시츠 상수 L 은 얼마인가? 하강 보조정리는 이 함수에서 등호가 되는가?

A. ∇f(x) = Qx 이므로 ‖∇f(x)−∇f(y)‖ = ‖Q(x−y)‖ ≤ λmax(Q)‖x−y‖ (정리 2.4). 따라서 L = λmax(Q) 이고 이것이 최선이다 — 최대 고유벡터 방향에서 등호가 성립하므로.
하강 보조정리는 f(y) = f(x) + ∇f(x)⊤p + ½p⊤Qp 라는 정확한 등식과 비교되는데, ½p⊤Qp ≤ (L/2)‖p‖² 이므로 부등식이며, p 가 최대 고유벡터일 때만 등호다. 다른 방향에서는 헐거운 한계라는 뜻이고, 그 헐거움이 곧 경사하강이 느린 이유다.

상쇄 — 뺄셈이 유효숫자를 지운다

가까운 두 수를 빼면 앞자리가 사라지고 뒷자리의 반올림 오차만 남는다. 차분 미분이 딱 이 모양이다.

f(x+h) − f(x)h  — 분자는 h→0 일수록 서로 가까운 두 수의 차
정리 4.1 (최적 차분 스텝) f 의 값에 상대오차 ε 이 있을 때, 전진차분의 전체 오차는 E(h) ≈ h2|f″| + 2ε|f|h 이고, 이를 최소화하는 h 는 h⋆ = 2√ε|f|/|f″| ≈ 2√ε ≈ 3×10−8, 그때 오차는 O(√ε) ≈ 10−8.
증명
  1. 테일러: f(x+h) = f + hf′ + (h²/2)f″ + … 이므로 절단오차는 (h/2)|f″|.
  2. f 값 각각에 최대 ε|f| 의 오차가 있고 둘을 빼서 h 로 나누므로 반올림오차는 2ε|f|/h.
  3. E′(h) = |f″|/2 − 2ε|f|/h² = 0 을 풀면 h⋆ = 2√(ε|f|/|f″|). E 는 볼록(두 항 모두 볼록)이므로 이 정류점이 최소다.
  4. h⋆ 을 대입하면 E(h⋆) = 2√(ε|f||f″|) — √ε 규모다.
따름정리 4.2 (중심차분) 절단오차가 (h²/6)|f‴| 로 줄어드므로, 반올림 항을 ε|f|/h 로 잡으면 h⋆ ≈ (3ε)1/3 ≈ 9×10−6, 오차는 O(ε2/3) ≈ 4×10−11. 함수 호출 두 배로 정밀도 세 자리를 산다.

복소 스텝 미분 — 뺄셈을 없애면 상쇄도 없다

정리 4.3 f 가 실수축 근방에서 해석적이고 실수축 위에서 실수값을 가지면 f′(x) = Im f(x + ih)h + O(h²)
증명
  1. 해석적이므로 복소 테일러 전개가 성립한다: f(x+ih) = f(x) + ihf′(x) − h²2f″(x) − ih³6f‴(x) + ⋯
  2. 실수축 위에서 f, f′, f″ 가 모두 실수이므로 허수부만 모으면 Im f(x+ih) = hf′(x) − (h³/6)f‴(x) + ⋯
  3. h 로 나누면 f′(x) − (h²/6)f‴ + ⋯ — 오차는 O(h²).
  4. 결정적으로, 어디에도 뺄셈이 없다. 그래서 h 를 10−30 까지 줄여도 반올림오차가 커지지 않고, 절단오차만 사라진다.
공짜는 아니다 — f 가 복소수를 받아 해석적으로 계산되어야 한다. abs, max, 비교 분기, math.*(복소수를 거부) 가 하나라도 있으면 쓸 수 없다. 그래서 검증 도구로는 훌륭하지만 범용은 아니다.

돌려 보기 — 이론이 예측한 자리에 최솟값이 있다

읽는 법 — ① 전진차분은 h≈10−8, 중심차분은 h≈10−6 근처에서 가장 정확하다. 정리 4.1·4.2 가 예측한 자리다. ② 복소 스텝은 h=10−8 이하에서 오차가 정확히 0 이 된다. ③ 0.1% 만 틀린 기울기도 검사에 걸린다.
