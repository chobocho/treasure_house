15장

선형 최소제곱

정사영 · 정규방정식 · QR · SVD

문제와 그 기하학

minx∈ℝn   f(x) = 12‖Ax − b‖²,    A ∈ ℝm×n, m ≥ n

Ax 는 A 의 열공간 range(A) 안을 움직인다. 그러니 이 문제는 “b 에 가장 가까운 열공간의 점을 찾아라”다 — 곧 정사영이다.

정리 15.1 (정규방정식) x 가 최소해 ⟺ A⊤(Ax − b) = 0 ⟺ A⊤Ax = A⊤b
증명 (두 가지 길)
  1. 미분으로: f(x) = ½(x⊤A⊤Ax − 2b⊤Ax + b⊤b) 이므로 ∇f = A⊤Ax − A⊤b. ∇²f = A⊤A ⪰ 0 이라 f 는 볼록이고, 정리 7.4·따름정리 7.5 로 ∇f=0 이 필요충분이다.
  2. 기하로: 임의의 y 에 대해 r = Ax−b 라 두면 ‖Ay−b‖² = ‖r + A(y−x)‖² = ‖r‖² + 2r⊤A(y−x) + ‖A(y−x)‖². A⊤r=0 이면 가운데 항이 사라져 ‖Ay−b‖ ≥ ‖r‖. 역도 같은 계산으로 나온다. 두 번째 줄이 정리 5.5(투영)의 변분 부등식과 같은 모양임에 주목 — 실제로 Ax 는 b 의 열공간 위 투영이다.
따름정리 15.2 (유일성) A 의 열이 일차독립(랭크 n)이면 A⊤A ≻ 0 이므로 해가 유일하다. 랭크가 부족하면 해집합은 null(A) 만큼의 아핀 부분공간이다(정리 7.2 의 예).

세 가지 해법과 그 안정성

해법비용정확도랭크 부족쓸 때
정규방정식 + 촐레스키mn² + n³/3κ(A)²·ε실패잘 조건 지어졌고 속도가 급할 때
QR (하우스홀더)2mn² − 2n³/3κ(A)·ε피벗팅 필요기본값
SVD≈ 4mn² + 8n³κ(A)·ε최소노름 해랭크가 의심스러울 때
정리 15.3 (조건수 제곱) A 의 열이 독립일 때 κ2(A⊤A) = κ2(A)².
증명 A = UΣV⊤ 이면 A⊤A = VΣ²V⊤ 이므로 A⊤A 의 고윳값은 σi² 다. 따라서 κ(A⊤A) = σmax²/σmin² = κ(A)².
실무적 함의 — κ(A)=108 이면 정규방정식은 유효숫자를 전부 잃지만 QR 은 8자리를 남긴다. 그리고 1 + ε² 이 반올림되어 A⊤A 가 특이해지는 일도 실제로 일어난다 — 다음 슬라이드의 실측.

SVD 해법 — 최소노름 해와 의사역행렬

정리 15.4 A = UΣV⊤ (랭크 r) 일 때 x+ = r∑i=1 ui⊤bσi vi = A+b 는 최소제곱 해 중 노름이 가장 작은 유일한 해다.
증명
  1. 임의의 최소제곱 해는 x = x+ + z, z ∈ null(A) 꼴이다(따름정리 15.2).
  2. x+ 는 v1,…,vr 의 결합이고 null(A) = span(vr+1,…,vn) 이므로 x+ ⊥ z.
  3. 피타고라스: ‖x‖² = ‖x+‖² + ‖z‖² ≥ ‖x+‖², 등호는 z=0 일 때만.
잘라내기(truncation)가 곧 정칙화다 σi 가 아주 작은 항은 ui⊤b 의 잡음을 1/σi 배로 증폭한다. 그래서 rcond 아래의 항을 버린다. 이것이 절단 SVD이고, 다음 장의 릿지는 같은 일을 부드럽게 한다.
정리 15.5 (에카르트–영 · 진술) 랭크 k 이하의 행렬 중 A 에 가장 가까운 것은 특잇값 앞 k 개만 남긴 Ak 이고, 그 오차는 ‖A−Ak‖2 = σk+1 이다. (PCA·저랭크 근사·추천 시스템의 근거)

돌려 보기 — 해법 셋과 반데르몽드의 저주

읽는 법 — ① 정규방정식은 ε=10−3 에서 이미 QR 보다 다섯 자리 나쁘고 10−8 부터는 아예 풀 수 없다. ② 다항식 차수를 올리면 조건수가 30배씩 뛰고, 차수 12 부터는 더 좋은 모형인데 정규방정식의 잔차가 오히려 커진다. ③ 릿지의 필터 인자가 작은 특잇값 방향만 골라 누른다. ④ 잔차가 0 이 아닌 문제에서 GN 은 마지막 자릿수를 못 내리고, LM 은 7회 만에 끝낸다.

16장

정칙화

릿지와 라쏘 — 무엇을 왜 누르는가

릿지 회귀

minx   ‖Ax − b‖² + λ‖x‖²,    λ > 0
정리 16.1 해는 xλ = (A⊤A + λI)−1A⊤b 이고, λ>0 이면 A 의 랭크와 무관하게 존재하고 유일하다.
증명 목적함수의 헤세는 2(A⊤A + λI) ⪰ 2λI ≻ 0 이므로 2λ-강볼록이다. 정리 7.3 으로 최소점이 정확히 하나 존재하고, ∇=0 을 풀면 위 식이다.
정리 16.2 (SVD 로 본 릿지 = 스펙트럼 필터) xλ = ∑i σiσi² + λ (ui⊤b) vi = ∑i σi²σi²+λ필터 인자 · ui⊤bσi vi
증명 A=UΣV⊤ 를 대입하면 A⊤A+λI = V(Σ²+λI)V⊤ 이고 A⊤b = VΣU⊤b. 따라서 xλ = V(Σ²+λI)−1ΣU⊤b 이고 성분별로 쓰면 위 식이다.
읽는 법 — σi ≫ √λ 이면 필터가 1 에 가까워 그대로 두고, σi ≪ √λ 이면 필터가 0 에 가까워 지운다. 절단 SVD 의 계단 함수를 부드러운 S자로 바꾼 것이다. 릿지가 “작은 방향을 버린다”는 말의 정확한 뜻이 이것이다.

라쏘 — 왜 계수가 정확히 0 이 되는가

minx   12‖Ax − b‖² + λ‖x‖1
정리 16.3 (희소성의 조건) x⋆ 가 최적 ⟺ 각 성분에서
(A⊤(Ax⋆−b))j = −λ sign(xj⋆)if xj⋆ ≠ 0
|(A⊤(Ax⋆−b))j| ≤ λif xj⋆ = 0
증명 목적은 볼록이고 비평활이므로 최적성 조건은 0 ∈ ∂F(x⋆) (2부 정의 6.10)이다. ∂(λ‖x‖1)j = λ sign(xj) (xj≠0), = λ[−1,1] (xj=0) 이므로 (A⊤(Ax⋆−b))j + λ·(그 열경사) = 0 을 두 경우로 나누어 쓰면 위와 같다.
0 이 되는 것이 λ 만큼 '쉬워진다' — xj=0 을 유지하는 데 필요한 조건이 등식이 아니라 폭 2λ 짜리 부등식이다. 반면 릿지에서는 ∂(λxj²)/∂xj = 2λxj 가 0 에서 0 이라 아무 여유도 주지 않는다. 그래서 릿지는 0 에 가까이 보낼 뿐 정확히 0 으로 보내지 못한다.
기하로 보면

‖x‖1 ≤ t 는 마름모다. 꼭짓점이 축 위에 있어, 등고선 타원이 제약집합에 처음 닿는 곳이 꼭짓점(= 어떤 좌표가 0) 이기 쉽다.

릿지는

‖x‖2 ≤ t 는 원이다. 매끄러워서 어느 점에서 닿아도 좌표가 정확히 0 이 될 확률은 0 이다.

라쏘를 푸는 알고리즘(ISTA·FISTA·좌표하강)은 8부에서 다룬다. 여기서는 “왜 그런 해가 나오는가”만 밝혔다.

17장

비선형 최소제곱

가우스–뉴턴과 Levenberg–Marquardt

구조 — 헤세가 거의 공짜다

f(x) = 12‖r(x)‖² = 12m∑i=1 ri(x)²
명제 17.1 J(x) 를 r 의 야코비라 할 때 ∇f = J⊤r,    ∇²f = J⊤J + ∑i ri ∇²ri
증명 ∂f/∂xj = ∑i ri ∂ri/∂xj 이 첫 식이다. 한 번 더 미분하면 곱의 미분으로 ∂²f/∂xj∂xk = ∑i(∂ri/∂xj)(∂ri/∂xk) + ∑iri ∂²ri/∂xj∂xk.
이 한 줄이 4부 전체의 아이디어다 — 헤세의 첫 항 J⊤J 는 1차 도함수만으로 얻어지고, 언제나 ⪰ 0 이다. 둘째 항은 잔차 ri 에 비례하므로, 모형이 자료를 잘 설명하면(잔차가 작으면) 무시할 수 있다.

가우스–뉴턴법

가우스–뉴턴
  1. Jk = J(xk), rk = r(xk)
  2. (Jk⊤Jk) pk = −Jk⊤rk 를 푼다  — 선형 최소제곱 한 번이다
  3. xk+1 = xk + αkpk (Armijo 라인서치)
명제 17.2 (하강 방향 보장) Jk 의 랭크가 n 이고 Jk⊤rk ≠ 0 이면 pk 는 하강 방향이다.
증명 ∇f⊤p = (J⊤r)⊤(−(J⊤J)−1J⊤r) = −‖·‖²(J⊤J)−1 < 0, 랭크 조건에서 J⊤J ≻ 0 이므로 (명제 8.6).
상황가우스–뉴턴의 거동이유
잔차가 0 에 가깝다거의 이차수렴버린 항 ∑ri∇²ri 이 작다
모형이 거의 선형한 걸음에 수렴∇²ri ≈ 0
잔차가 크다선형 수렴, 느리다버린 항이 지배한다

Levenberg–Marquardt — 감쇠로 표현한 신뢰영역

(J⊤J + λ diag(J⊤J)) p = −J⊤r
명제 17.3 (신뢰영역과의 동치) λ ≥ 0 로 감쇠한 해 p(λ) 는, 어떤 반경 Δ(λ) 에 대한 신뢰영역 부분문제 min ‖Jp+r‖² s.t. ‖Dp‖ ≤ Δ 의 해와 같다. λ 가 커지면 Δ 는 작아진다.
증명 개요 제약 문제의 KKT 조건(5부)을 쓰면 (J⊤J + λD⊤D)p = −J⊤r 이고 λ 가 제약의 승수다. 상보여유 조건에서 제약이 활성일 때만 λ>0 이고, ‖p(λ)‖ 가 λ 에 대해 순감소하므로 대응이 일대일이다.
λ방향보폭성격
→ 0가우스–뉴턴길다모형을 믿는다
→ ∞−J⊤r/λ = 경사하강짧다모형을 못 믿는다
왜 I 가 아니라 diag(J⊤J) 인가 — 변수마다 단위가 다르면(예: 미터와 라디안) λI 는 스케일에 의존해 한쪽만 심하게 누른다. 대각으로 스케일하면 각 변수의 곡률에 비례해 감쇠가 걸려 단위 변환에 둔감해진다. Marquardt 의 기여가 정확히 이 한 줄이다.

18장

실전에서 부딪히는 것들

기저 선택 · 가중 · 이상치 · 행렬 없는 해법

기저를 바꾸면 조건수가 바뀐다

같은 k차 다항식 공간을 표현하는 기저는 무수히 많다. 어느 것을 쓰든 표현력은 같지만 설계행렬의 조건수는 하늘과 땅이다.

기저정의[0,1] 20차 조건수
단항1, x, x², …≈ 3×1015 — 배정밀도의 한계
체비쇼프T0=1, T1=t, Tk+1=2tTk−Tk−1≈ 56
왜 단항 기저가 나쁜가 [0,1] 위에서 x18 과 x20 의 그래프는 거의 구별되지 않는다. 즉 설계행렬의 열들이 거의 평행하다. 열이 평행하면 σmin 이 0 에 가까워지고, 그것이 곧 조건수 폭발이다.
일반 원칙 — “같은 문제를 다르게 적는다”가 수치 최적화에서 가장 값싼 개선책이다. 변수 스케일링, 기저 변경, 중심화(centering)가 모두 여기 속한다. 알고리즘을 바꾸기 전에 문제부터 다시 적어 보라.

가중 최소제곱과 로버스트 회귀

정의 18.1 (가중 최소제곱) min ∑wi(ai⊤x − bi)². 행을 √wi 로 스케일하면 보통 최소제곱이 된다. wi = 1/σi² 로 두면 가우스 잡음 가정 아래 최대가능도 추정이다.
정의 18.2 (후버 손실) ρδ(r) =
½r²if |r| ≤ δ
δ|r| − ½δ²otherwise
 볼록이고 C¹ 이지만 C² 는 아니다(|r|=δ 에서 2차 도함수가 튄다).
명제 18.3 (IRLS 가 하는 일) ∑ρδ(ri) 의 정류조건은 ∑ ρ′(ri) ai = 0 인데, wi = ρ′(ri)/ri 로 두면 이것이 가중 최소제곱의 정규방정식과 같은 꼴이 된다. 그래서 “가중치를 고정하고 풀기 → 가중치 갱신”을 반복하면 된다.
증명 ∑ρ′(ri)ai = ∑ (ρ′(ri)/ri) ri ai = ∑ wi ri ai = A⊤W(Ax−b). 후버에서는 wi = 1 (|r|≤δ), = δ/|ri| (그 밖) — 큰 잔차일수록 가중치가 반비례로 줄어든다.
δ 를 어떻게 고르나 — 잔차의 척도에 맞춰야 한다. 관례는 δ = 1.345·σ̂(정규 잡음에서 95% 효율), σ̂ 는 중앙절대편차(MAD)로 추정한다. δ 가 너무 크면 최소제곱과 같아지고, 너무 작으면 ‖·‖1 회귀에 가까워진다.

행렬을 만들지 않는 최소제곱 — CGLS

m = 107, n = 105 이면 A 를 저장할 수 없다. 그런데 A·v 와 A⊤·w 는 계산할 수 있는 경우가 많다(희소행렬, 합성곱, 푸리에 변환 등).

CGLS — 정규방정식에 CG 를 걸되 A⊤A 를 만들지 않는다
  1. r = b − Ax,   s = A⊤r,   p = s,   γ = ‖s‖²
  2. 반복: q = Ap,   α = γ/‖q‖²
  3. x ← x + αp,   r ← r − αq,   s = A⊤r
  4. β = ‖s‖²/γ,   p ← s + βp,   γ ← ‖s‖²
세 가지 이득 — ① 메모리가 O(m+n) 이다. ② A⊤A 를 만들지 않으므로 정리 15.3 의 정보 손실을 겪지 않는다. ③ 언제든 멈출 수 있고, 일찍 멈추는 것 자체가 정칙화 효과를 낸다(반복 정칙화 — 작은 특잇값 방향은 늦게 수렴하므로).

돌려 보기 — 기저·가중·이상치·CGLS

Q2. 잔차가 큰 문제에서 가우스–뉴턴 대신 BFGS(3부)를 쓰면 어떻게 되는가?

A1. 정리 15.3 의 조건수 제곱을 피하기 때문이다. 확대 행렬의 조건수는 √((σ1²+λ)/(σn²+λ)) 로 A⊤A+λI 의 제곱근이다. λ 가 아주 작을 때 차이가 결정적이다.
A2. BFGS 는 ∑ri∇²ri 항까지 포함한 진짜 헤세를 근사하므로, 잔차가 큰 문제에서는 오히려 가우스–뉴턴보다 나을 수 있다. 실제로 잔차가 큰 문제의 실무 권장은 LM 이 아니라 준뉴턴이거나, 둘을 섞은 방법이다. 다만 잔차가 작은 문제에서는 J⊤J 라는 공짜 2차 정보가 있는 GN/LM 이 압도적으로 유리하다.
