19장

등식 제약과 라그랑주 승수

기하학적 직관에서 정리까지

기하학적 착상 — 등위면이 접한다

minx f(x)   s.t.   h(x) = 0

제약 곡면 {h=0} 위를 걸으면서 f 를 낮춘다고 하자. 더 낮출 수 없는 지점은 어떤 모습일까?

명제 19.1 x⋆ 가 제약 위의 국소 최소점이고 곡면이 매끄러우면, ∇f(x⋆) 는 곡면의 접공간에 수직이다.
증명
  1. 곡면 위를 지나는 임의의 매끄러운 곡선 γ(t), γ(0)=x⋆ 를 잡자. φ(t) = f(γ(t)) 는 t=0 에서 국소 최소다.
  2. 1변수 최적성 조건으로 φ′(0) = ∇f(x⋆)⊤γ′(0) = 0.
  3. γ′(0) 은 접공간의 임의의 벡터가 될 수 있으므로, ∇f(x⋆) 는 접공간 전체에 수직이다.

한편 명제 3.5 에서 ∇h(x⋆) 도 같은 접공간에 수직이다. 접공간의 직교여공간이 1차원이면(제약이 하나이고 ∇h ≠ 0 이면) 두 벡터는 평행해야 한다.

∇f(x⋆) = −λ ∇h(x⋆)    ⟺    ∇f(x⋆) + λ ∇h(x⋆) = 0
라그랑주 승수의 정체 — λ 는 마법의 상수가 아니라, 두 법선벡터의 비례상수다. 그리고 곧 보겠지만 그 값은 “제약을 한 단위 풀었을 때 목적값이 얼마나 좋아지는가”와 정확히 같다.

제약 자격 — 왜 조건이 필요한가

정의 19.2 (LICQ) x⋆ 에서 활성 제약들의 기울기 {∇hj(x⋆)} 가 일차독립이면 그 점이 정칙(regular)하다고 한다. (Linear Independence Constraint Qualification)
정칙성이 없으면 라그랑주 조건이 성립하지 않는다 — 유명한 반례: min x   s.t.   h(x,y) = x³ − y² = 0 실행가능집합은 원점에서 뾰족한 첨점을 갖는 곡선이고, 최소점은 (0,0) 이다. 그런데 ∇h(0,0) = (0,0) 이라 ∇f = (1,0) = −λ·(0,0) 을 만족하는 λ 가 존재하지 않는다.
무엇이 잘못된 것인가 — 문제가 아니라 제약을 적는 방식이 문제다. 같은 집합을 y = x3/2, x ≥ 0 로 적으면 정칙이 된다. 이런 이유로 제약 자격 조건은 여러 종류가 있고(LICQ, MFCQ, Slater), 그중 어느 것이든 하나만 만족하면 KKT 가 필요조건이 된다.
실무에서는 — 선형 제약만 있으면 제약 자격이 자동으로 성립한다(아벨 조건). 그래서 LP·QP 에서는 이 문제를 걱정할 필요가 없다. 6·7부가 마음 편한 이유다.

라그랑주 함수와 1차 조건

정의 19.3 L(x, ν) = f(x) + p∑j=1 νj hj(x) = f(x) + ν⊤h(x)
정리 19.4 (등식 제약의 1차 필요조건) f, h ∈ C¹ 이고 x⋆ 가 정칙한 국소 최소점이면, 유일한 ν⋆ 가 존재해 ∇xL(x⋆, ν⋆) = ∇f(x⋆) + Jh(x⋆)⊤ν⋆ = 0,    h(x⋆) = 0
증명 (음함수 정리를 쓴다)
  1. 정칙성에서 Jh(x⋆) 의 랭크는 p 다. 좌표를 재배열해 x = (u, v), u∈ℝp 로 두어 ∂h/∂u 가 가역이 되게 한다.
  2. 음함수 정리로 v 근방에서 u = u(v) 인 매끄러운 함수가 존재하고 h(u(v), v) = 0 이 유지된다. 즉 제약 곡면을 v 만의 무제약 문제로 국소적으로 바꿔 쓸 수 있다.
  3. F(v) = f(u(v), v) 는 v⋆ 에서 무제약 국소 최소이므로 ∇F(v⋆) = 0. 연쇄법칙으로 ∇vf + (∂u/∂v)⊤∇uf = 0.
  4. 제약을 미분하면 ∂h/∂u·(∂u/∂v) + ∂h/∂v = 0, 곧 ∂u/∂v = −(∂h/∂u)−1(∂h/∂v).
  5. ν⋆ = −(∂h/∂u)−⊤∇uf 로 정의하면 u 성분은 정의상, v 성분은 3·4번을 대입해 모두 0 이 된다. 유일성은 Jh 의 랭크가 p 이기 때문이다.
읽는 법 — 라그랑주 함수는 “제약을 위반한 만큼 벌금을 매긴 목적함수”이고, 승수는 그 벌금의 단가다. 최적점에서는 그 단가가 딱 맞아떨어져 제약이 없는 것처럼 정류점이 된다.

2차 조건 — 접공간 위에서만 본다

정의 19.5 x⋆ 에서의 접공간은 T = {d : Jh(x⋆)d = 0} — 제약을 1차까지 지키며 움직일 수 있는 방향들이다.
정리 19.6 (2차 조건) (x⋆, ν⋆) 가 정리 19.4 를 만족한다고 하자. 그러면
필요d⊤∇²xxL(x⋆,ν⋆)d ≥ 0 for all d ∈ T
충분d⊤∇²xxL d > 0 for all 0 ≠ d ∈ T ⟹ 엄격 국소 최소
∇²f 가 아니라 ∇²L 이다 — 제약이 휘어 있으면 그 곡률이 목적함수의 곡률에 더해진다. ∇²xxL = ∇²f + ∑νj∇²hj. 예를 들어 min x² − y² s.t. x²+y²=1 에서 ∇²f 는 부정부호지만 ∇²L 은 접방향에서 양수일 수 있다.
전체 공간이 아니라 접공간 — ∇²L 이 전체에서 양의 정부호일 필요가 없다. 제약을 벗어나는 방향의 곡률은 애초에 갈 수 없는 방향이므로 상관없다.

감도 정리 — 승수는 그림자 가격이다

정리 19.8 (감도) 제약을 h(x) = u 로 섭동한 문제의 최적값을 p⋆(u) 라 하면, 적당한 정칙 조건 아래 ∇u p⋆(0) = −ν⋆
증명
  1. 음함수 정리로 u 근방에서 최적해 x⋆(u) 와 승수 ν⋆(u) 가 매끄럽게 존재한다고 하자.
  2. p⋆(u) = f(x⋆(u)) 를 미분하면 ∇p⋆ = (∂x⋆/∂u)⊤∇f(x⋆).
  3. 정류조건 ∇f = −Jh⊤ν⋆ 를 대입하면 ∇p⋆ = −(∂x⋆/∂u)⊤Jh⊤ν⋆.
  4. 제약 h(x⋆(u)) = u 를 u 로 미분하면 Jh(∂x⋆/∂u) = I.
  5. 따라서 ∇p⋆ = −I⊤ν⋆ = −ν⋆.
경제학적 읽기 — 제약이 자원 한도(예: 예산 b)라면, 승수는 그 자원 한 단위의 한계 가치다. “예산을 1 늘리면 이익이 얼마나 늘어나는가”가 곧 |ν| 다. 그래서 그림자 가격이라 부르고, 6부의 LP 쌍대변수가 정확히 이것이다.
실무의 쓰임 — 승수가 큰 제약이 병목이다. 어디에 투자해야 하는지를 최적화가 알려 준다. 12부의 프로세스 병목 분석이 같은 원리를 쓴다.

돌려 보기 — 승수가 정말 민감도인가

읽는 법 — ① 승수와 −∂p⋆/∂b 가 소수 여덟 자리까지 같다(정리 19.8). ② KKT 잔차 넷이 모두 0 인 후보는 하나뿐이다. ③ 같은 μ에서 증강 라그랑주가 페널티보다 108배 정확하다. ④ 페널티의 조건수가 μ 에 비례하고 경사하강 반복 수의 실측(69085)과 이론(69084)이 한 걸음 차이다. ⑤ 쌍대 간격이 ν=1/‖a‖² 에서 정확히 0 이 된다. ⑥ 배리어의 실제 간격이 보장치 m/t 와 거의 같다.

부등식 제약과 KKT 조건

활성 집합 · 상보여유 · Farkas 보조정리

활성 제약이라는 개념

minx f(x)   s.t.   gi(x) ≤ 0 (i=1..m),   hj(x) = 0 (j=1..p)
정의 20.1 x 에서 gi(x) = 0 인 부등식 제약을 활성(active), < 0 인 것을 비활성이라 한다. 활성 집합 𝒜(x) = {i : gi(x)=0}.
핵심 관찰 — 최적점에서 비활성 제약은 없는 것과 같다. 경계에서 떨어져 있으므로 작은 이동으로는 그 제약을 어길 수 없기 때문이다. 그래서 부등식 문제는 “어느 제약이 활성인지만 알면 등식 문제”가 된다.
그런데 그것을 모른다 — 활성 집합을 미리 알 수 없다는 것이 부등식 제약의 유일한 어려움이자 전부다. 후보가 2m 개이므로 전부 시도하는 것은 불가능하다. 상보여유 조건이 이 조합적 성질을 대수적으로 표현한 장치다.

KKT 조건

정의 20.2 L(x, λ, ν) = f(x) + λ⊤g(x) + ν⊤h(x)
정리 20.3 (KKT 필요조건) x⋆ 가 국소 최소점이고 제약 자격(LICQ)이 성립하면, (λ⋆, ν⋆) 가 존재해
① 정류성∇f(x⋆) + ∑λi⋆∇gi(x⋆) + ∑νj⋆∇hj(x⋆) = 0
② 원문제 실행가능gi(x⋆) ≤ 0,   hj(x⋆) = 0
③ 쌍대 실행가능λi⋆ ≥ 0
④ 상보여유λi⋆ gi(x⋆) = 0   for all i
④ 를 읽는 법 — “제약이 비활성이면(gi<0) 승수가 0 이고, 승수가 양수이면 제약이 활성이다.” 곧 느슨한 제약에는 값을 매기지 않는다. 그림자 가격의 언어로는 “남아도는 자원의 한계가치는 0”이다.
③ 의 부호가 왜 ≥ 0 인가 — gi ≤ 0 방향으로 표준형을 잡았기 때문이다. 최적점에서 −∇f 는 실행가능영역 바깥쪽을 향해야 하고(안쪽이면 더 내려갈 수 있으니까), ∇gi 가 바깥 방향이므로 계수가 음이 아니어야 한다. 등식 제약의 ν 에 부호 제한이 없는 이유도 같다 — 양쪽 어디로도 못 가기 때문이다.

Farkas 보조정리 — KKT 증명의 열쇠

정리 20.4 (Farkas) A ∈ ℝm×n, c ∈ ℝn 에 대해 다음 둘 중 정확히 하나가 성립한다. (Ⅰ)   ∃y ≥ 0 :   A⊤y = c
(Ⅱ)   ∃d :   Ad ≤ 0  이고  c⊤d > 0
증명 (분리 정리로)
  1. 두 조건이 동시에 성립할 수는 없다: c⊤d = y⊤Ad ≤ 0 (∵ y≥0, Ad≤0) 이므로 (Ⅱ)의 >0 과 모순.
  2. (Ⅰ)이 거짓이라 하자. K = {A⊤y : y ≥ 0} 는 닫힌 볼록 원뿔이다(유한생성 원뿔은 닫혀 있다).
  3. c ∉ K 이므로 분리 정리(정리 5.8)로 d 와 b 가 있어 d⊤c > b 이고 d⊤z ≤ b for all z∈K.
  4. 0 ∈ K 이므로 b ≥ 0, 따라서 c⊤d > 0.
  5. K 가 원뿔이므로 z∈K ⟹ tz∈K (t>0). d⊤(tz) ≤ b 가 모든 t 에서 성립하려면 d⊤z ≤ 0 이어야 한다. 그렇지 않으면 t→∞ 에서 좌변이 b 를 넘는다. 원뿔의 분리가 동차가 되는 이유다.
  6. z = A⊤ei 를 넣으면 (Ad)i = d⊤A⊤ei ≤ 0 — 곧 Ad ≤ 0. (Ⅱ)가 성립한다.
기하학적 읽기 — “c 가 ai 들이 만드는 원뿔 안에 있거나, 아니면 ai 전부와는 둔각이면서 c 와는 예각인 방향이 있다.” 택일 정리(theorem of the alternative)라 부르며, 6부의 LP 쌍대성 증명도 이것 하나로 끝난다.

KKT 필요조건의 증명

정리 20.3 의 증명 (부등식만 있는 경우)
  1. 𝒜 = 𝒜(x⋆) 를 활성 집합이라 하자. 주장: 다음을 만족하는 d 는 존재하지 않는다. ∇gi(x⋆)⊤d ≤ 0  (∀i∈𝒜)   이고   ∇f(x⋆)⊤d < 0
  2. 왜냐하면 그런 d 가 있으면, LICQ 아래에서 x⋆ 에서 d 방향으로 실행가능하게 움직이는 곡선이 존재하고(선형화된 접원뿔 = 실제 접원뿔), 그 위에서 f 가 감소해 국소 최소성에 모순이기 때문이다.
  3. 1번의 부존재를 Farkas 의 언어로 옮긴다. A 의 행을 ∇gi(x⋆)⊤ (i∈𝒜), c = −∇f(x⋆) 로 두면 1번은 정확히 “(Ⅱ)가 거짓”이다.
  4. Farkas 정리에 의해 (Ⅰ)이 참이다: ∃λ𝒜 ≥ 0 로 ∑i∈𝒜 λi∇gi(x⋆) = −∇f(x⋆).
  5. 비활성 제약에는 λi = 0 을 주면 ① 정류성과 ④ 상보여유가 동시에 성립한다. ②는 x⋆ 가 실행가능하므로, ③은 Farkas 가 준 λ ≥ 0 이므로 성립한다.

등식 제약이 있으면 hj 를 hj ≤ 0 과 −hj ≤ 0 두 부등식으로 쪼갠 뒤, 두 승수의 차 νj 가 부호 제한 없는 승수가 된다. ∎

증명의 구조를 기억하자 — “좋아지는 실행가능 방향이 없다” → Farkas → “기울기가 제약 기울기들의 음이 아닌 결합이다”. 부호 조건 λ≥0 이 Farkas 에서 나온다는 것이 요점이다.

볼록 문제에서는 KKT 가 충분조건이다

정리 20.5 f, gi 가 볼록이고 hj 가 아핀이라 하자. (x⋆,λ⋆,ν⋆) 가 KKT 조건을 만족하면 x⋆ 는 전역 최소점이다.
증명
  1. λ⋆ ≥ 0 이고 gi 가 볼록이므로 L(·, λ⋆, ν⋆) 는 x 에 대해 볼록이다(비음 결합 + 아핀 항).
  2. 정류성 ∇xL(x⋆)=0 과 정리 7.1·따름정리 7.5 로 x⋆ 는 L 의 전역 최소점이다.
  3. 따라서 임의의 실행가능 x 에 대해 f(x⋆) = L(x⋆,λ⋆,ν⋆) ≤ L(x,λ⋆,ν⋆) = f(x) + λ⋆⊤g(x) + ν⋆⊤h(x) ≤ f(x). 첫 등호는 상보여유(λ⋆⊤g(x⋆)=0)와 h(x⋆)=0, 마지막 부등호는 λ⋆≥0, g(x)≤0, h(x)=0 때문이다.
볼록 최적화의 실무적 결론 — KKT 조건이 필요충분이 된다. 그래서 “최적해를 찾는 문제”가 “연립방정식·부등식을 푸는 문제”로 바뀐다. 내부점법이 바로 그 방정식계를 뉴턴법으로 푸는 방법이다.

예제 — 단체 투영을 KKT 로 유도한다

2부 명제 5.7 에서 미리 빌려 썼던 유도를 이제 정식으로 한다.

minz 12‖z−x‖²   s.t.   ∑izi = 1,   −zi ≤ 0
KKT 를 적고 푼다
  1. L = ½‖z−x‖² + θ(∑zi−1) − ∑μizi  (μi ≥ 0 은 −zi≤0 의 승수)
  2. 정류성: zi − xi + θ − μi = 0
  3. 상보여유: μizi = 0
  4. zi > 0 이면 μi=0 이므로 zi = xi − θ. zi = 0 이면 μi = θ − xi ≥ 0, 곧 xi ≤ θ.
  5. 두 경우를 하나로 묶으면 zi = max(xi − θ, 0).
  6. θ 는 등식 제약 ∑max(xi−θ,0) = 1 로 결정된다. 좌변이 θ 에 대해 연속·순감소하므로 해는 유일하다.
이 패턴을 기억하라 — “정류성으로 z 를 승수의 함수로 푼다 → 상보여유로 경우를 나눈다 → 남은 등식으로 승수를 결정한다.” 근접연산자(8부)와 SVM 의 쌍대(13부)가 전부 이 패턴이다.

21장

쌍대성

모든 최소화 문제 뒤에는 최대화 문제가 숨어 있다

라그랑주 쌍대 함수

정의 21.1 q(λ, ν) = infx L(x, λ, ν) = infx ( f(x) + λ⊤g(x) + ν⊤h(x) ) 쌍대 문제는 max q(λ,ν) s.t. λ ≥ 0 이며, 그 최적값을 d⋆ 라 쓴다.
정리 21.2 (약쌍대성) 모든 λ ≥ 0 와 모든 ν 에 대해 q(λ,ν) ≤ p⋆. 따라서 d⋆ ≤ p⋆.
증명 (세 줄) 임의의 실행가능 x̃ 에 대해 g(x̃) ≤ 0, h(x̃)=0, λ≥0 이므로 L(x̃,λ,ν) = f(x̃) + λ⊤g(x̃) + ν⊤h(x̃) ≤ f(x̃). 따라서 q(λ,ν) = infxL ≤ L(x̃,λ,ν) ≤ f(x̃). 모든 실행가능 x̃ 에서 성립하므로 q ≤ p⋆.
정리 21.3 (쌍대 함수는 언제나 오목) 원문제가 볼록이든 아니든 q 는 (λ,ν) 에 대해 오목이다.
증명 각 x 를 고정하면 (λ,ν) ↦ L(x,λ,ν) 는 아핀이다. q 는 아핀함수들의 점별 하한이고, 아핀함수의 하한은 오목이다(2부 6장 보존 연산의 오목 버전).
이것이 쌍대성의 실용적 가치다 — 원문제가 아무리 흉악해도(정수 제약, 비볼록) 쌍대 문제는 언제나 볼록(오목 최대화)이다. 그래서 어떤 문제에서든 하한을 값싸게 얻을 수 있다. 7부의 분지한정이 이 하한으로 살아간다.

강쌍대성과 Slater 조건

정의 21.4 (쌍대 간격) p⋆ − d⋆ ≥ 0. 이것이 0 이면 강쌍대성이 성립한다고 한다.
정의 21.5 (Slater 조건) 볼록 문제에서 gi(x̃) < 0 (모든 비아핀 i) 이고 h(x̃)=0 인 엄격 내부점 x̃ 가 존재한다.
정리 21.6 (강쌍대성) 볼록 문제가 Slater 조건을 만족하면 p⋆ = d⋆ 이고, p⋆ 가 유한하면 쌍대 최적해가 달성된다.
증명 (분리 정리로 — 부등식만 있는 경우)
  1. 집합 𝒜 = {(u, t) ∈ ℝm+1 : ∃x, gi(x) ≤ ui, f(x) ≤ t} 를 생각하자. f, g 가 볼록이므로 𝒜 는 볼록집합이다.
  2. ℬ = {(0, s) : s < p⋆} 역시 볼록이고, 정의상 𝒜 ∩ ℬ = ∅ 이다. 교집합이 있으면 p⋆ 보다 작은 값을 내는 실행가능점이 있다는 뜻이라 모순.
  3. 두 볼록집합이 만나지 않으므로 분리 초평면이 존재한다: (λ, μ) ≠ 0 과 α 가 있어 λ⊤u + μt ≥ α for (u,t)∈𝒜,   μs ≤ α for s<p⋆.
  4. 𝒜 는 u, t 를 키우는 방향으로 닫혀 있으므로 λ ≥ 0, μ ≥ 0. 그리고 둘째 부등식에서 μp⋆ ≤ α.
  5. μ > 0 임을 보인다. μ=0 이면 λ⊤u ≥ α ≥ 0 이 모든 (u,t)∈𝒜 에서 성립하는데, Slater 점 x̃ 를 넣으면 λ⊤g(x̃) ≥ 0 이다. 그런데 g(x̃) < 0 이고 λ ≥ 0 이므로 λ = 0 이어야 하고, 그러면 (λ,μ) = 0 이라 모순이다. Slater 조건이 쓰이는 유일한 자리가 여기다. 엄격 내부점이 없으면 수직 분리 초평면(μ=0)이 생겨 쌍대 정보가 사라진다.
  6. μ>0 이므로 λ̃ = λ/μ 로 두면 모든 x 에서 f(x) + λ̃⊤g(x) ≥ α/μ ≥ p⋆, 곧 q(λ̃) ≥ p⋆.
  7. 약쌍대성과 합치면 q(λ̃) = p⋆ = d⋆ 이고 λ̃ 가 쌍대 최적해다.

안장점 해석 — min max 와 max min

명제 21.7 p⋆ = infx supλ≥0,ν L(x,λ,ν),    d⋆ = supλ≥0,ν infx L(x,λ,ν)
증명 x 가 실행가능하면 supλ≥0 λ⊤g(x) = 0 (g≤0 이므로 λ=0 이 최적), 실행불가능하면 그 sup 은 +∞ 다(위반한 성분의 승수를 무한히 키우면 된다). 등식 제약도 같은 논리다. 따라서 안쪽 sup 은 실행가능집합의 지시함수 역할을 하고, 바깥 inf 가 곧 p⋆ 다.
약쌍대성 = max-min ≤ min-max — 언제나 참인 부등식이다(“나중에 두는 쪽이 유리하다”). 강쌍대성은 순서를 바꿔도 같다는 뜻이고, 그때 (x⋆,λ⋆) 는 L 의 안장점이다: L(x⋆,λ) ≤ L(x⋆,λ⋆) ≤ L(x,λ⋆).
게임으로 읽기 — x 를 고르는 최소화 참가자와 λ 를 고르는 최대화 참가자의 2인 영합게임이다. 강쌍대성은 이 게임에 내시 균형(안장점)이 있다는 말이고, 폰 노이만의 최소최대 정리가 그 특수한 경우다.

쌍대 문제 세 가지 예

① 최소노름 문제
min ½‖x‖²  s.t.  Ax = b

L = ½‖x‖² + ν⊤(Ax−b), ∇xL=0 ⟹ x = −A⊤ν.

q(ν) = −½‖A⊤ν‖² − b⊤ν

무제약 오목 최대화 — 훨씬 쉽다

② 선형계획 (6부에서 다시)
min c⊤x  s.t.  Ax=b, x≥0

q(ν) = infx≥0 (c+A⊤ν)⊤x − b⊤ν. 괄호 안이 음수 성분을 하나라도 가지면 −∞ 다.

max −b⊤ν  s.t.  A⊤ν + c ≥ 0

쌍대도 LP 다 — 자기쌍대적 구조

③ 하드마진 SVM (13부에서 다시)
min ½‖w‖²  s.t.  yi(w⊤xi+b) ≥ 1

정류조건에서 w = ∑αiyixi — 해가 자료의 결합으로 나온다. 상보여유에 의해 αi>0 인 것은 경계에 놓인 점들뿐이고, 그것이 서포트 벡터다.

max ∑iαi − ½∑i,jαiαjyiyj(xi⊤xj)  s.t.  α≥0, ∑αiyi=0

자료가 내적으로만 등장한다 — 커널 기법이 여기서 나온다

쌍대 문제를 보는 세 가지 이유 — ① 변수 수가 확 줄기도 한다(제약 수 ↔ 변수 수가 뒤바뀐다). ② 구조가 드러난다(서포트 벡터, 그림자 가격). ③ 언제나 하한을 준다 — 계산을 중간에 멈춰도 “얼마나 더 좋아질 수 있는가”를 안다.

쌍대성의 실용

쓰임어떻게어디
정지 기준쌍대 간격 f(x) − q(λ) ≤ ε 이면 ε-최적이 증명된다내부점법 (6부)
하한정수 문제를 완화해 쌍대 하한을 얻는다분지한정 (7부)
분해결합 제약을 승수로 떼어 내면 부분문제가 독립이 된다ADMM (8부), 스케줄링 (13부)
민감도승수 = 그림자 가격 → 병목 식별12부 프로세스 병목
알고리즘 설계쌍대 문제가 더 쉬우면 그쪽을 푼다SVM, 최소비용흐름 (7부)
라그랑주 완화 — 7부의 뼈대를 미리 본다
  1. 어려운 제약 Ax ≤ b 를 골라 승수 λ 로 목적함수에 흡수한다
  2. 남은 문제는 (구조가 좋아서) 쉽게 풀린다 → q(λ) 를 계산
  3. q 는 오목이므로 열경사 상승으로 최대화 → 최선의 하한
  4. 그 하한을 분지한정의 가지치기에 쓴다
쌍대 간격이 0 이 아닐 수 있다 — 비볼록·정수 문제에서는 강쌍대성이 깨진다. 그 간격을 쌍대성 간격(duality gap)이라 부르며, 7부에서 그 크기를 실제로 잰다.

22장

제약 문제를 푸는 알고리즘

투영 · 페널티 · 증강 라그랑주 · 배리어

투영경사법

투영경사 (projected gradient)
  1. xk+1 = PC(xk − α∇f(xk))
정리 22.1 (수렴) f 가 볼록·L-평활, C 가 닫힌 볼록집합, α = 1/L 이면 f(xk) − f⋆ ≤ L‖x0−x⋆‖²2k — 무제약 경우(정리 9.4)와 똑같은 속도다.
증명 개요
  1. 투영의 변분 부등식(정리 5.5)에서 (xk − α∇f(xk) − xk+1)⊤(z − xk+1) ≤ 0 for all z∈C.
  2. 이 부등식을 하강 보조정리(3.12)와 결합하면, 무제약 증명의 각 단계에서 등장하던 항이 그대로 재현된다. 핵심은 비확장성(정리 5.6)이 오차 ‖xk−x⋆‖ 를 늘리지 않는다는 것이다.
  3. 결과적으로 정리 9.4 의 망원 합 논증이 그대로 통과한다.
종료 판정을 바꿔야 한다 — 제약 위에서는 ∇f ≠ 0 이 정상이다. 대신 사상의 이동량 G(x) = (x − PC(x − α∇f(x)))/α 를 본다. G(x)=0 ⟺ x 가 최적(정리 7.4). 이것을 경사 사상(gradient mapping)이라 하며 무제약의 ∇f 자리를 대신한다.
투영이 싸야 쓸 수 있다 — 상자·공·단체·아핀 부분공간은 닫힌 꼴이 있어 O(n)~O(nlogn) 이지만, 일반 다면체 {Ax≤b} 로의 투영은 그 자체가 QP 다. 그때는 다른 방법을 써야 한다.

페널티법과 그 한계

Q(x; μ) = f(x) + μ2‖h(x)‖²
정리 22.2 (페널티의 편향) x(μ) 가 Q(·;μ) 의 최소점이면 μ h(x(μ)) → −ν⋆    (μ→∞) 따라서 ‖h(x(μ))‖ ≈ ‖ν⋆‖/μ — 유한한 μ 로는 결코 실행가능해지지 않는다.
증명 ∇Q = ∇f(x(μ)) + μ Jh⊤h(x(μ)) = 0 이다. 이것을 KKT 정류조건 ∇f(x⋆) + Jh⊤ν⋆ = 0 과 비교하면, μh(x(μ)) 가 ν⋆ 의 역할을 대신하고 있음을 알 수 있다. x(μ)→x⋆ 이면 연속성으로 μh → ν⋆(부호는 규약에 따름).
✘ 결함 1 — 정확히 실행가능해지지 않는다

승수의 역할을 μh 가 대신하므로 위반이 ν⋆/μ 만큼 남아야만 한다.

✘ 결함 2 — 병조건화

헤세가 ∇²f + μ J⊤J 이라 조건수가 μ 에 비례해 커진다. 정확도를 사려면 계산량을 지불해야 한다.

증강 라그랑주 — 두 결함을 한 번에 고친다

LA(x, ν; μ) = f(x) + ν⊤h(x) + μ2‖h(x)‖²
증강 라그랑주 (ALM · 승수법)
  1. xk+1 = arg minx LA(x, νk; μk)  — 무제약 문제 하나
  2. νk+1 = νk + μk h(xk+1)  — 승수 갱신
  3. 위반이 충분히 줄지 않았으면 μ 를 키운다
정리 22.3 (승수 갱신의 근거) 하위 문제의 정류조건은 ∇f(xk+1) + Jh⊤(νk + μkh(xk+1)) = 0 이다. 즉 νk+1 은 정확히 xk+1 에서 정류성을 성립시키는 승수다.
증명 (선형 제약 이차 문제에서 수렴률까지)
  1. f = ½x⊤Gx, h = Ax−b 라 하자. 하위 문제의 해는 (G + μA⊤A)x = μA⊤b − A⊤νk.
  2. 이것과 KKT 조건 Gx⋆ + A⊤ν⋆ = 0, Ax⋆=b 를 빼면 νk+1 − ν⋆ = M(μ)(νk − ν⋆) 꼴이 되고, ‖M(μ)‖ = O(1/μ) 임을 계산할 수 있다. 1차원 예 min x²+y² s.t. x+y=2 에서는 정확히 νk+1−ν⋆ = (νk−ν⋆)/(1+μ) 다.
  3. 따라서 μ 를 고정해도 승수가 선형 수렴하고, 그와 함께 h(xk) → 0 이 된다. μ→∞ 가 필요 없다는 것이 결론이다.
ADMM 의 뿌리 — 8부의 ADMM 은 증강 라그랑주에서 x 를 두 블록으로 나눠 번갈아 최소화하는 변형이다. 승수 갱신식은 똑같다.

로그 배리어와 중심 경로

B(x; t) = t f(x) − m∑i=1 log(−gi(x))

실행가능 영역 안쪽에서만 정의되고 경계에 다가가면 +∞ 로 튄다. 그래서 최소점이 자동으로 내부에 머문다.

정리 22.4 (중심 경로의 최적성 간격) x⋆(t) 가 B(·;t) 의 최소점이면 f(x⋆(t)) − p⋆ ≤ mt
증명
  1. 정류조건: t∇f(x⋆(t)) + ∑ (−1/gi)∇gi = 0.
  2. λi = −1/(t gi(x⋆(t))) > 0 으로 두면 ∇f + ∑λi∇gi = 0 — 정확한 쌍대 실행가능점이다.
  3. 그 λ 에서 쌍대값은 q(λ) = f(x⋆(t)) + ∑λigi = f(x⋆(t)) − m/t. λigi = −1/t 가 모든 i 에서 같다 — 근사 상보여유다.
  4. 약쌍대성 q(λ) ≤ p⋆ 에서 결론이 나온다.
이 정리가 내부점법의 전부다 — t 를 알면 계산 없이 최적성 간격의 상한을 안다. ε-정확도를 원하면 t = m/ε 까지만 키우면 되고, t 를 μ배씩 키우면 O(log(m/(ε t0))) 번의 바깥 반복이면 충분하다. 6부에서 LP 에 적용한다.

확인 문제

Q1. min x s.t. x² ≤ 0 의 최적해는 x=0 이다. KKT 조건이 성립하는가?
Q2. 어떤 알고리즘이 f(xk) = 12.34 를 보고했고 쌍대값 q(λk) = 12.30 을 함께 계산했다. 이 정보로 무엇을 증명할 수 있는가?

A1. 성립하지 않는다. ∇f = 1, ∇g(0) = 2·0 = 0 이므로 1 + λ·0 = 0 을 만족하는 λ 가 없다. 원인은 제약 자격의 실패다 — 실행가능집합이 {0} 한 점뿐이라 Slater 조건도, LICQ 도 성립하지 않는다. 정리 20.3 이 “제약 자격이 성립하면”이라는 단서를 붙인 이유가 이것이다.
A2. xk 가 실행가능하다면 q(λk) ≤ p⋆ ≤ f(xk) (정리 21.2)이므로 p⋆ ∈ [12.30, 12.34] 다. 즉 현재 해가 0.04 이내로 최적임이 증명된다 — 상대오차 0.33%. 이것이 “수렴한 것 같다”와 “ε-최적임을 증명했다”의 차이이며, 쌍대값을 함께 계산하는 값어치다.
