알고리즘 카드

한 장에 하나씩 — 문제·아이디어·한 걸음·비용·보장

이 카드를 쓰는 법

“어떤 문제”와 “보장”만 봐도 절반은 정해진다 — 새 문제를 만나면 먼저 그 문제가 어느 칸에 들어가는지 찾고, 그 알고리즘의 보장이 내 문제의 가정과 맞는지 확인한다. 맞지 않으면 가정을 만족시키도록 문제를 다시 적을 수 있는지를 묻는다(13부 51장).
비용은 반복당 비용이다 — 총 비용은 “반복당 비용 × 반복 수”이고, 반복 수는 대개 조건수와 정확도가 정한다(3부 따름정리 9.6). 반복 수가 적다고 빠른 것이 아니다.

경사하강법

항목내용
어떤 문제매끄러운 무제약
아이디어가장 가파른 하강 방향으로 간다
한 걸음x ← x − α∇f(x)
비용O(n) / 반복
보장볼록: O(1/k) · 강볼록: (1−μ/L)^k · 비볼록: min‖∇f‖ = O(1/√k)

모멘텀 · 네스테로프 가속

항목내용
어떤 문제매끄러운 무제약
아이디어관성을 주어 진동을 상쇄하고 일관된 방향을 누적
한 걸음v ← βv − α∇f; x ← x + v (가속은 앞질러 간 점에서 기울기)
비용O(n) / 반복
보장κ → √κ, 볼록에서 O(1/k²) — 1차 방법의 이론적 하한
언제 쓰나거의 언제나 켠다. 비단조이므로 재시작 기법과 함께

뉴턴법

항목내용
어떤 문제매끄러운 무제약, n 이 작을 때
아이디어2차 테일러 모형의 최소점으로 간다
한 걸음x ← x − (∇²f)⁻¹∇f (부정부호면 τI 를 더한다)
비용O(n³) 분해 / 반복
보장국소 이차수렴 (정리 11.2)
언제 쓰나헤세를 싸게 얻을 수 있고 n ≲ 10³ 일 때
본문3부 11장

BFGS · L-BFGS

항목내용
어떤 문제매끄러운 무제약
아이디어기울기 이력으로 역헤세를 근사 (할선 조건 + 최소 변화)
한 걸음d = −H∇f; Wolfe 라인서치; H 를 랭크-2 갱신
비용O(n²) / O(mn) 반복
보장초선형 수렴, 양의 정부호 유지 → 하강 보장 (정리 12.5)
언제 쓰나대규모의 사실상 표준. L-BFGS 의 m 은 5~20
본문3부 12장

켤레기울기 (선형)

항목내용
어떤 문제Ax = b, A ≻ 0
아이디어서로 간섭하지 않는 켤레방향을 그때그때 만든다
한 걸음α = rᵀr/pᵀAp; x += αp; r −= αAp; p = r + βp
비용O(nnz) / 반복, 메모리 O(n)
보장정확 산술에서 n 걸음 유한 종료, 수렴률 √κ
언제 쓰나행렬을 만들 수 없고 곱만 가능할 때
본문3부 13장

신뢰영역 (Steihaug)

항목내용
어떤 문제매끄러운, 비볼록 포함
아이디어믿을 반경을 먼저 정하고 그 안에서 2차 모형을 최소화
한 걸음부분문제를 CG 로 풀되 경계·음의 곡률에서 멈춤; ρ 로 반경 갱신
비용O(n³) 또는 CG 반복
보장전역수렴, 음의 곡률을 활용
언제 쓰나안장점이 많은 비볼록 문제
본문3부 13장

가우스–뉴턴 · LM

항목내용
어떤 문제비선형 최소제곱
아이디어헤세를 JᵀJ 로 근사 (잔차가 작으면 정확)
한 걸음(JᵀJ + λ diag(JᵀJ)) p = −Jᵀr
비용O(mn²) / 반복
보장잔차가 작으면 거의 이차수렴
언제 쓰나곡선 맞추기·보정·SLAM 등 잔차 구조가 있을 때

투영경사법

항목내용
어떤 문제제약이 단순한 볼록 문제
아이디어자유롭게 한 걸음 간 뒤 실행가능집합으로 되돌린다
한 걸음x ← P_C(x − α∇f(x))
비용O(n) + 투영 비용
보장무제약과 같은 O(1/k), 비확장성 덕분 (정리 5.6)

증강 라그랑주 (ALM)

항목내용
어떤 문제등식 제약
아이디어페널티에 승수 추정을 더해 유한 μ 로 정확해진다
한 걸음x ← min L_A(x, ν; μ); ν ← ν + μh(x)
비용하위 무제약 문제 1개 / 바깥 반복
보장유한 μ 로 선형 수렴, 병조건화 없음 (정리 22.3)
언제 쓰나페널티법이 필요한 모든 자리 — 페널티 대신 이것을 쓴다

내부점법 (배리어)

항목내용
어떤 문제볼록·LP·QP·SOCP
아이디어경계에서 튀는 배리어를 더하고 중심 경로를 따라간다
한 걸음KKT 를 xᵢsᵢ = σμ 로 완화하고 뉴턴 한 걸음

보장간격 = m/t 보장, O(√n log 1/ε) 반복 (정리 26.3)
언제 쓰나대규모 볼록·LP. 반복 수가 크기에 거의 무관

심플렉스법

항목내용

근접경사 · FISTA

항목내용
어떤 문제f = 매끄러움 + 비평활(prox 가능)
아이디어매끄러운 부분은 경사, 비평활 부분은 prox 로 정확히
한 걸음x ← prox_{αh}(x − α∇g(x)); FISTA 는 앞질러 간 점에서
비용O(n) + prox
보장O(1/k) → 가속하면 O(1/k²)
언제 쓰나라쏘·제약·정칙화. 희소성이 필요하면 반드시 이것
