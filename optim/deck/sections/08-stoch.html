확률적 경사하강

불편추정량 · 잡음의 공 · 보폭 규칙

유한합 구조 — 기계학습 목적함수의 모양

f(x) = 1N N∑i=1 fi(x)

fi 는 i번째 자료의 손실이다. 전체 기울기 한 번에 N 번의 계산이 드는데, N = 107 이면 한 걸음이 이미 비싸다.

명제 33.1 (불편성) i 를 균등하게 무작위로 뽑으면 𝔼i[∇fi(x)] = 1N∑i∇fi(x) = ∇f(x)
이 한 줄이 SGD 의 전부다 — 표본 하나의 기울기는 방향은 맞고 잡음만 섞인 추정량이다. 잡음을 견디는 방식으로 걸으면 된다. 대가는 명확하다: 잡음이 있는 한 정확히 도달하지 못한다.
SGD
  1. 반복 k = 0, 1, 2, …
    1. 표본(또는 미니배치) Bk 를 뽑는다
    2. gk = (1/|Bk|) ∑i∈Bk ∇fi(xk)
    3. xk+1 = xk − αk gk

고정 보폭은 최적해에 도달하지 못한다

정리 33.2 (고정 보폭 SGD) f 가 μ-강볼록·L-평활이고 𝔼‖gk − ∇f(xk)‖² ≤ σ², α ≤ 1/L 이면 𝔼‖xk − x⋆‖² ≤ (1−αμ)k‖x0−x⋆‖² + ασ²μ
증명
  1. xk+1 − x⋆ = xk − x⋆ − αgk 의 제곱 노름을 취하고 기댓값을 씌운다: 𝔼‖xk+1−x⋆‖² = ‖xk−x⋆‖² − 2α∇f(xk)⊤(xk−x⋆) + α²𝔼‖gk‖². 교차항에 명제 33.1(불편성)을 써서 𝔼[gk] = ∇f(xk) 로 바꾼 것이 핵심이다.
  2. 강볼록성에서 ∇f(xk)⊤(xk−x⋆) ≥ μ‖xk−x⋆‖² (정의 6.7 의 두 점 버전).
  3. 𝔼‖gk‖² = ‖∇f(xk)‖² + 𝔼‖gk−∇f‖² ≤ L²‖xk−x⋆‖² + σ².
  4. 정리하면 ek+1 ≤ (1−αμ)ek + α²σ² 꼴의 점화식이 되고, 이것을 풀면 결론이다. 기하급수의 합 ∑α²σ²(1−αμ)j = ασ²/μ 가 남는 항이다.
두 항을 읽자 — 첫 항은 지수적으로 사라지고(초기 오차를 잊는다), 둘째 항 ασ²/μ 는 남는다. 즉 SGD 는 최적해를 중심으로 반지름 O(√α) 인 공 안을 맴돈다. σ=0(잡음 없음)이면 이 항이 사라져 경사하강의 선형 수렴이 된다.

보폭 규칙 — 도달하려면 줄여야 한다

정리 33.3 (Robbins–Monro 조건) ∑kαk = ∞   그리고   ∑kαk² < ∞ 이면 (적절한 정칙 조건 아래) xk → x⋆ 가 확률 1 로 성립한다.
두 조건의 뜻 첫째 ∑αk = ∞ 는 “아무리 멀리서 출발해도 닿을 수 있을 만큼 총 이동거리가 무한해야 한다”. 둘째 ∑αk² < ∞ 는 “잡음의 누적이 유한해야 한다” — 정리 33.2 의 남는 항이 α² 에 비례했음을 떠올리면 된다.

미니배치 — 잡음과 계산량의 거래

명제 33.4 크기 B 의 미니배치 기울기는 여전히 불편이고, 그 분산은 σ²/B 다.
증명 독립 표본 B 개의 평균이므로 기댓값은 그대로이고 분산은 1/B 배가 된다(복원추출 가정).
수확 체감 — 계산량은 B 에 비례해 늘고, 잡음(표준편차)은 √B 에 반비례해 준다. 배치를 4배로 키우면 비용은 4배, 잡음은 2배만 줄어든다. 그래서 “배치를 무조건 키우는 것”은 계산 효율 면에서 손해다.
그런데 실무에서는 배치를 키운다 — 이유는 최적화가 아니라 하드웨어다. GPU 는 병렬 처리가 가능해 B=1 과 B=256 의 실제 시간이 비슷하다. 최적화 이론과 시스템 현실이 다른 답을 주는 대표적인 자리다.
큰 배치의 함정 — 배치가 커지면 보폭도 키워야 같은 진행을 얻는데, 보폭에는 2/L 상한이 있다(3부 따름정리 9.2). 그래서 배치를 무한정 키워도 에폭당 진행이 포화된다. “선형 스케일링 규칙”과 워밍업이 이 문제를 다루는 실무 기법이다.

34장

모멘텀과 가속

관성이 아니라 수학 — 왜 √κ 가 되는가

무거운 공 방법

vk+1 = βvk − α∇f(xk),    xk+1 = xk + vk+1
정리 34.1 (이차함수에서의 수렴 인자) f = ½x⊤Qx, 고윳값 λ ∈ [μ, L] 일 때, 최적 매개변수 α = (2√L + √μ)²,    β = (√L − √μ√L + √μ)² 에서 수렴 인자는 (√κ−1)/(√κ+1) 이다.
증명 개요
  1. 고유기저에서 각 좌표가 독립적으로 2차 선형 점화식을 따른다: yk+1 = (1 + β − αλ)yk − βyk−1.
  2. 이 점화식의 수렴 속도는 특성방정식 z² − (1+β−αλ)z + β = 0 의 근의 크기로 정해진다.
  3. 두 근이 복소수가 되면 크기가 √β 로 λ 에 무관해진다. 모든 λ∈[μ,L] 에서 복소가 되도록 α, β 를 잡고 √β 를 최소화하면 위 값이 나온다. 여기가 요점이다 — 경사하강은 최악의 λ 에 발목이 잡히지만, 모멘텀은 모든 λ 를 같은 속도로 다룬다.
κ → √κ — 반복 수가 O(κ log 1/ε) 에서 O(√κ log 1/ε) 로 줄어든다. κ = 104 이면 100배다. 켤레기울기(3부 정리 13.3)와 같은 차수이고, 1차 방법의 이론적 하한이다.

네스테로프 가속

yk = xk + k−1k+2(xk − xk−1),    xk+1 = yk − 1L∇f(yk)
모멘텀과의 차이는 한 곳뿐 — 기울기를 현재 점 xk 가 아니라 앞질러 간 점 yk 에서 잰다. “이대로 가면 어디에 도착할지”를 먼저 보고 방향을 고치는 셈이라, 지나치는 것을 미리 교정한다.
정리 34.2 (수렴률) f 가 볼록·L-평활이면 f(xk) − f⋆ ≤ 2L‖x0 − x⋆‖²(k+1)² 경사하강의 O(1/k)(정리 9.4)보다 한 차수 빠르다.
정리 34.3 (하한 · Nesterov) k ≤ (n−1)/2 인 동안, 1차 정보만 쓰는 어떤 방법도 f(xk) − f⋆ ≥ 3L‖x0−x⋆‖²/(32(k+1)²) 인 문제가 존재한다.
따라서 O(1/k²) 는 최선이다 — 네스테로프 가속은 상한과 하한이 만나는 최적 1차 방법이다. 더 빠르려면 2차 정보(뉴턴)나 문제 구조(유한합 → SVRG)를 써야 한다.

돌려 보기 — 가속의 이득과 비단조성

읽는 법 — ① 반복 수의 비율이 √κ 를 따라간다: κ=104 에서 138,156회 → 1,791회. ② 두 방법 모두 각자의 이론 상한 아래에 있다. ③ 가속법은 단조 감소하지 않는다 — 60회 중 12회가 직전보다 커졌다. 관성으로 최소점을 지나쳤다 돌아오기 때문이며, “목적값이 줄지 않으면 버그”라는 직관이 여기서는 틀린다.
재시작(restart) — 목적값이 늘어나면 모멘텀을 0 으로 초기화하는 간단한 기법이 있다. 강볼록성 상수를 몰라도 적응적으로 선형 수렴을 얻어 실무에서 널리 쓰인다.

AdaGrad — 좌표마다 다른 보폭

Gk(i) = k∑t=1 (gt(i))²,    xk+1(i) = xk(i) − α√Gk(i) + ε gk(i)
무엇을 적응시키는가 — 지금까지 기울기가 크게 움직인 좌표는 보폭을 줄이고, 거의 안 움직인 좌표는 큰 보폭을 유지한다. 자연어 처리처럼 희소한 특징이 많은 문제에서 특히 강하다 — 드물게 나타나는 특징이 나올 때마다 크게 배울 수 있기 때문이다.

Adam 과 편향 보정

mk = β1mk−1 + (1−β1)gk,    vk = β2vk−1 + (1−β2)gk²
m̂k = mk/(1−β1k),    v̂k = vk/(1−β2k),    xk+1 = xk − α m̂k/(√v̂k + ε)
명제 35.1 (편향 보정의 근거) 기울기가 정상(stationary)이고 𝔼[gt] = g 이면 𝔼[mk] = (1 − β1k) g 따라서 (1−β1k) 로 나누면 𝔼[m̂k] = g 가 되어 편향이 정확히 사라진다.
증명 m0=0 에서 펼치면 mk = (1−β1)∑t=1kβ1k−tgt. 기댓값을 취하면 (1−β1)g∑j=0k−1β1j = (1−β1k)g — 등비급수의 합이다.
Adam 이 만능은 아니다 — 볼록 문제에서도 수렴하지 않는 예가 있다(Reddi et al., 2018 — AMSGrad 논문). 또 일반화 성능이 SGD+모멘텀보다 나쁠 수 있다는 보고가 많다. “기본값으로 잘 도는 방법”이지 “최선의 방법”이 아니다.

분산 감소 — SVRG

정리 33.2 의 남는 항 ασ²/μ 를 없애려면 α 를 줄이거나 σ 를 줄여야 한다. SVRG 는 σ 를 줄인다.

SVRG (stochastic variance reduced gradient)
  1. 주기 시작: x̃ = x, 전체 기울기 μ̃ = ∇f(x̃) 를 한 번 계산
  2. 안쪽 반복 m 회: i 를 뽑아 g = ∇fi(x) − ∇fi(x̃) + μ̃,   x ← x − αg
명제 35.2 (여전히 불편이다) 𝔼i[g] = ∇f(x) − ∇f(x̃) + ∇f(x̃) = ∇f(x).
명제 35.3 (분산이 사라진다) x → x̃ 이면 ∇fi(x) − ∇fi(x̃) → 0 이므로 g → μ̃ = ∇f(x̃) — 잡음이 0 으로 간다. 정량적으로는 𝔼‖g − ∇f(x)‖² ≤ 4L(f(x) − f⋆ + f(x̃) − f⋆) 로, 최적해에 다가갈수록 함께 0 이 된다.
정리 35.4 (선형 수렴 · 진술) μ-강볼록·L-평활 유한합에서, 적절한 α, m 으로 SVRG 는 고정 보폭으로 선형 수렴한다. 총 기울기 계산 횟수는 O((N + κ) log(1/ε)) — 전체 경사하강의 O(Nκ log(1/ε)) 보다 훨씬 낫다.

FISTA 와 좌표하강

가속은 비평활 항이 있어도 작동한다 — 구조가 34장의 accelerated 와 완전히 같다. 앞질러 간 점에서 기울기를 재고 prox 를 건다. 비용도 같다(기울기 1회 + prox 1회).
정리 36.3 (좌표하강의 수렴) F(x) = g(x) + ∑jhj(xj) 꼴로 비평활 항이 좌표별로 분리되면, 좌표하강은 최적해로 수렴한다.
분리되지 않으면 갇힌다 — F(x) = |x1 − x2| 같은 함수에서는 어느 한 좌표만 움직여서는 값을 줄일 수 없는 점이 있다. 좌표하강이 최적이 아닌 점에서 멈춘다. 라쏘가 좌표하강으로 잘 풀리는 것은 ‖·‖1 이 좌표별로 분리되기 때문이다 — 우연이 아니다.

ADMM — 문제를 쪼개어 번갈아 푼다

minx,z g(x) + h(z)   s.t.   Ax + Bz = c
ADMM (교대방향 승수법)
  1. x+ = arg minx Lρ(x, z, u)
  2. z+ = arg minz Lρ(x+, z, u)
  3. u+ = u + Ax+ + Bz+ − c  — 승수 갱신 (5부 22장과 같다)
증강 라그랑주의 블록 버전 — 5부 22장의 ALM 은 x 전체를 한꺼번에 최소화했다. ADMM 은 x 와 z 를 번갈아 최소화한다. 두 부분문제가 각각 쉬우면 전체가 쉬워진다 — 그것이 이 방법의 존재 이유다.

라쏘를 ADMM 으로: min ½‖Xx−y‖² + λ‖z‖1 s.t. x−z=0

ADMM 이 빛나는 자리왜
합의 최적화 (consensus)자료를 기계별로 나누고 xi = z 제약 — 분산 학습
제약 + 정칙화 결합각 항의 prox 만 알면 된다
희소 + 저랭크 분해두 정칙화를 각각 다른 블록에
전역 변수 + 국소 변수부분문제가 병렬로 풀린다
수렴은 하지만 느릴 수 있다 — 볼록 문제에서 ADMM 은 수렴이 보장되지만 속도는 ρ 선택에 민감하고, 높은 정확도가 필요하면 다른 방법이 낫다. 실무의 강점은 정확도가 아니라 분해 가능성이다.

돌려 보기 — 라쏘를 네 가지로 푼다

읽는 법 — ① λ 를 키우면 계수가 하나씩 정확히 0 이 되고, 적당한 λ 에서 진짜 0 이 아닌 세 계수만 살아남는다. ② 네 알고리즘이 같은 해로 모인다 — 볼록이므로 최적해가 유일하다. ③ 조건수 175 인 문제에서 k=4000 일 때 FISTA 의 오차가 ISTA 의 1/188,000 이다. 두 방법의 반복당 비용은 같다.

확인 문제

Q1. SGD 의 보폭을 αk = c/k 로 두면 Robbins–Monro 조건을 만족한다. 그런데 실무에서 잘 안 쓰는 이유는?
Q2. 라쏘를 경사하강으로 풀면 왜 계수가 정확히 0 이 되지 않는가?

A1. ∑αk = c∑1/k 는 발산하지만 아주 느리게(≈ c ln k) 발산한다. 출발점이 최적해에서 거리 D 만큼 떨어져 있으면 c ln k ≳ D, 곧 k ≳ eD/c 번은 지나야 도달 가능성이 생긴다. 즉 초반에 사실상 움직이지 못한다. c/(1+γk) 나 단계적 감소는 초반 보폭을 크게 유지하면서 나중에 줄여 이 문제를 피한다.
A2. ‖x‖1 은 xj=0 에서 미분 불가능하다. 열경사를 아무거나 골라 쓰면 xj 가 0 을 지나쳐 반대 부호로 넘어가고, 다음 걸음에서 다시 넘어오며 0 근처를 진동한다. 근접경사법은 그 대신 부분문제를 정확히 풀어 0 을 정확히 맞힌다 — 연성 문턱이 |v| ≤ t 인 구간을 통째로 0 으로 보내기 때문이다. 비평활 항을 근사하지 않고 그대로 다루는 것이 요점이다.
