테스트가 함께 있다 — optim/tests/ 에 모듈마다 대응하는 파일이 있고, 전체 309개가 통과해야 이 덱이 만들어진다. 응용(13부)은 모두 전수 조사 기준 구현과 대조한다.

직접 돌려 보는 법

전체 테스트

$ cd optim $ python3 -m unittest discover -s tests -t . -v # 309 tests, 0 failures

데모 하나 돌리기

$ PYTHONPATH=. python3 py/demo_gd.py $ PYTHONPATH=. python3 py/demo_pm_conf.py

덱 다시 만들기 (소스를 고쳤다면)

$ python3 run_all.py # 모든 데모 실행 → out/manifest.json $ python3 deck/build_deck.py # 조각 + 소스 + 출력 → 단일 HTML $ python3 deck/verify_deck.py # 덱 ↔ 소스 역검증
덱을 직접 고치지 말 것 — 수학적_최적화_완전_가이드.html 은 산출물이다. 고칠 곳은 optim/deck/sections/*.html(글)과 optim/py/(코드)이며, 빌더가 둘을 합친다. verify_deck.py 가 덱과 소스가 어긋났는지 매번 다시 확인한다.
