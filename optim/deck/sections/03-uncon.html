3부

무제약 최적화

기울기만으로 어디까지 갈 수 있는가 — 그리고 2차 정보를 쓰면 무엇이 달라지는가

8장

최적성 조건

무엇을 찾고 있는지 정확히 하기

1차 필요조건

정리 8.1 f ∈ C¹ 이고 x⋆ 가 국소 최소점이면 ∇f(x⋆) = 0.
증명
  1. ∇f(x⋆) ≠ 0 이라 가정하고 d = −∇f(x⋆) 를 잡자.
  2. 방향도함수는 ∇f(x⋆)⊤d = −‖∇f(x⋆)‖² < 0 (정리 3.3).
  3. 정의에 의해 충분히 작은 t>0 에서 f(x⋆+td) − f(x⋆) = t∇f(x⋆)⊤d + o(t) < 0. o(t)/t→0 이므로 1차항의 음수 부호가 이긴다.
  4. 어떤 근방에도 x⋆ 보다 나은 점이 있다는 뜻이므로 국소 최소가 아니다 — 모순.
정의 8.2 ∇f(x) = 0 인 점을 정류점(stationary point)이라 한다. 알고리즘이 실제로 찾는 것은 최소점이 아니라 정류점이다.
필요조건일 뿐이다 — f(x)=x³ 은 x=0 에서 정류점이지만 최소도 최대도 아니다. f(x,y)=x²−y² 는 원점이 안장점이다.

2차 조건 — 필요와 충분

정리 8.3 (2차 필요조건) f ∈ C², x⋆ 가 국소 최소점이면 ∇f(x⋆)=0 이고 ∇²f(x⋆) ⪰ 0.
증명
  1. 어떤 d 에서 d⊤∇²f(x⋆)d < 0 이라 하자.
  2. 테일러 2차(정리 3.10)와 ∇f(x⋆)=0 에서 f(x⋆+td) = f(x⋆) + ½t²d⊤∇²f(ξt)d, ξt → x⋆.
  3. ∇²f 가 연속이므로 작은 t 에서 d⊤∇²f(ξt)d < 0 이 유지된다.
  4. 따라서 f(x⋆+td) < f(x⋆) — 국소 최소에 모순.
정리 8.4 (2차 충분조건) ∇f(x⋆)=0 이고 ∇²f(x⋆) ≻ 0 이면 x⋆ 는 엄격 국소 최소점이다.
증명
  1. λ = λmin(∇²f(x⋆)) > 0 이라 하자.
  2. ∇²f 가 연속이므로 어떤 반지름 r 안에서 ∇²f(y) ⪰ (λ/2)I 가 유지된다.
  3. 그 공 안의 x = x⋆+p 에 대해 테일러 2차와 정리 2.4 로 f(x) = f(x⋆) + ½p⊤∇²f(ξ)p ≥ f(x⋆) + (λ/4)‖p‖².
  4. p ≠ 0 이면 강부등호이므로 엄격 국소 최소다.
틈이 남는다 필요조건은 ⪰, 충분조건은 ≻. ∇²f 가 특이하면 어느 쪽도 결론을 못 낸다 — x⁴(최소)와 −x⁴(최대)가 둘 다 f″(0)=0 이다.

하강 방향과 종료 조건

정의 8.5 ∇f(x)⊤d < 0 이면 d 를 x 에서의 하강 방향이라 한다. 그러면 충분히 작은 α>0 에서 f(x+αd) < f(x) 가 보장된다.
명제 8.6 B ≻ 0 이면 d = −B∇f(x) 는 항상 하강 방향이다.
증명 ∇f⊤d = −∇f⊤B∇f < 0 (∇f ≠ 0 이고 B 가 양의 정부호이므로).
이 명제가 설계 지침이다 — 경사하강은 B=I, 뉴턴은 B=(∇²f)−1, BFGS 는 B=Hk. 양의 정부호만 유지하면 하강은 공짜다. 그래서 뉴턴법은 헤세를 수정하고, BFGS 는 갱신식이 정부호를 지키도록 설계된다.
종료 조건식주의
기울기 노름‖∇f(xk)‖ ≤ ε스케일 의존 — ε(1+|f|) 로 상대화하는 것이 낫다
함수값 변화|fk − fk−1| ≤ ε고원에서 거짓 양성
점 변화‖xk − xk−1‖ ≤ ε보폭이 작아졌을 뿐일 수 있다
최적성 간격f−f⋆ ≤ ‖∇f‖²/2μ강볼록에서만 — 보조정리 6.8
실무에서는 세 가지를 함께 쓴다 — 기울기 노름을 주 조건으로 두고, 변화량 조건과 최대 반복 수를 안전판으로 둔다. 이 책의 minimize 도 그렇게 되어 있다.

9장

경사하강법

가장 단순한 방법의 수렴을 끝까지 증명한다

알고리즘

경사하강법 (gradient descent)
  1. x0 를 고른다
  2. 반복 k=0,1,2,…
    1. gk = ∇f(xk),   ‖gk‖ ≤ ε 이면 종료
    2. xk+1 = xk − αk gk

구현은 이 책의 공통 드라이버 안에 “방향은 −g”라는 한 줄로 들어 있다.

보폭 αk 를 정하는 세 가지 방식 — ① 고정 α = 1/L (이론이 가장 깔끔) ② 라인서치(실무의 기본) ③ 감소 수열 αk = c/√k (확률적 환경, 8부). 아래에서 ①을 기준으로 정리를 세운다.

한 걸음의 보장 — 얼마나 줄어드는가

보조정리 9.1 f 가 L-평활이고 α ≤ 1/L 이면 f(xk+1) ≤ f(xk) − α2‖∇f(xk)‖²
증명
  1. 하강 보조정리(보조정리 3.12)에 y = xk − α gk 를 넣는다: f(y) ≤ f(xk) − α‖gk‖² + (L/2)α²‖gk‖².
  2. 묶으면 f(y) ≤ f(xk) − α(1 − Lα/2)‖gk‖².
  3. α ≤ 1/L 이면 1 − Lα/2 ≥ 1/2 이므로 결론. 여기서 α ≤ 1/L 이라는 조건이 처음이자 유일하게 쓰인다.
따름정리 9.2 (발산의 경계) 이차함수 f = ½x⊤Qx 에서 고정보폭 경사하강은 xk+1 = (I − αQ)xk 이므로, 수렴 ⟺ 모든 고윳값에서 |1 − αλi| < 1 ⟺ 0 < α < 2/L.
1/L 은 안전판, 2/L 이 진짜 경계 — 정리에서 1/L 을 요구하는 것은 증명을 깔끔하게 하려는 것이지, 그보다 크면 반드시 터진다는 뜻이 아니다. 실측은 다음 슬라이드에 있다.

비볼록에서도 무언가는 보장된다

정리 9.3 f 가 L-평활이고 아래로 유계(f ≥ f⋆)이며 α = 1/L 이면 min0≤i≤k ‖∇f(xi)‖ ≤ √2L(f(x0) − f⋆)k+1 즉 O(1/√k) 속도로 정류점에 다가간다.
증명
  1. 보조정리 9.1 을 i=0..k 에 대해 더한다(망원 합): ∑i=0k (1/2L)‖∇f(xi)‖² ≤ f(x0) − f(xk+1) ≤ f(x0) − f⋆.
  2. 왼쪽의 각 항은 최솟값 이상이므로 (k+1)·mini‖∇f(xi)‖² ≤ 2L(f(x0)−f⋆).
  3. 양변을 k+1 로 나누고 제곱근을 취한다.
보장의 정확한 내용을 읽자 — 이것은 “최소점에 간다”가 아니라 “기울기가 작은 점을 지나간다”는 보장이다. 비볼록에서는 이것이 1차 방법이 줄 수 있는 전부다. 안장점일 수도, 국소 최대일 수도 있다.

볼록이면 O(1/k)

정리 9.4 f 가 볼록이고 L-평활, α = 1/L 이면 f(xk) − f⋆ ≤ L‖x0 − x⋆‖²2k
증명
  1. 볼록성(정리 6.5)으로 f(xk) − f⋆ ≤ gk⊤(xk − x⋆).
  2. 한편 갱신식에서 ‖xk+1 − x⋆‖² = ‖xk − x⋆‖² − 2α gk⊤(xk−x⋆) + α²‖gk‖²
  3. 1번을 대입하면 ‖xk+1−x⋆‖² ≤ ‖xk−x⋆‖² − 2α(f(xk)−f⋆) + α²‖gk‖².
  4. 보조정리 9.1 에서 α²‖gk‖² ≤ 2α(f(xk) − f(xk+1)) 이므로 ‖xk+1−x⋆‖² ≤ ‖xk−x⋆‖² − 2α(f(xk+1)−f⋆).
  5. i=0..k−1 로 더하면(망원) 2α∑(f(xi+1)−f⋆) ≤ ‖x0−x⋆‖².
  6. f(xi) 가 단조 감소하므로 k(f(xk)−f⋆) ≤ ∑(f(xi+1)−f⋆). 정리하면 결론.
속도의 뜻 — 오차를 10−6 로 줄이려면 k ≈ 106 이 필요하다. 8부의 가속(Nesterov)이 이것을 O(1/k²) 로 바꾼다.

강볼록이면 선형수렴

정리 9.5 f 가 μ-강볼록·L-평활이고 α = 1/L 이면 f(xk) − f⋆ ≤ (1 − μL)k (f(x0) − f⋆)
증명 (두 줄이면 된다)
  1. 보조정리 9.1: f(xk+1) − f⋆ ≤ f(xk) − f⋆ − (1/2L)‖gk‖².
  2. PL 부등식(보조정리 6.8): ‖gk‖² ≥ 2μ(f(xk)−f⋆).
  3. 대입하면 f(xk+1)−f⋆ ≤ (1 − μ/L)(f(xk)−f⋆).
  4. 귀납으로 k 제곱이 나온다.
따름정리 9.6 (반복 수) f−f⋆ ≤ ε 에 도달하려면 k ≥ κ log f(x0)−f⋆ε,    κ = L/μ (1−1/κ)k ≤ e−k/κ 를 쓰면 바로 나온다.
κ 가 비용이다 — 정확도 ε 은 로그로만 들어오고(값싸다), 조건수는 선형으로 들어온다(비싸다). 그래서 실무의 승부는 정확도가 아니라 조건수를 낮추는 것에서 난다.

이차함수에서의 최적 보폭과 지그재그

정리 9.7 f = ½x⊤Qx, 0 ≺ μI ⪯ Q ⪯ LI 일 때 고정보폭 경사하강의 최악 수렴 인자는 minα maxλ∈[μ,L] |1 − αλ| = L − μL + μ = κ − 1κ + 1 이고 최적 보폭은 α⋆ = 2/(L+μ) 다.
증명
  1. Q = VΛV⊤ 로 대각화하고 y = V⊤x 로 두면 각 좌표가 독립적으로 yi(k+1) = (1−αλi)yi(k) 로 움직인다.
  2. 전체 수렴 인자는 maxi|1−αλi| 이고, 최악의 경우 λ 는 양 끝 μ, L 에서 나온다.
  3. α ↦ max(|1−αμ|, |1−αL|) 는 α 에 대해 조각별 선형이고 볼록이다. 최소는 두 조각이 만나는 곳, 곧 1−αμ = αL−1 에서 달성된다.
  4. 풀면 α⋆ = 2/(L+μ) 이고 그때 값은 (L−μ)/(L+μ).
지그재그의 정체 최적 보폭에서 가장 큰 고윳값 좌표의 인자는 1−α⋆L = −(κ−1)/(κ+1) — 음수다. 즉 그 좌표는 매 반복 부호가 뒤집히며 줄어든다. 이것이 좁은 계곡을 가로지르며 튀는 지그재그의 수학적 정체다.

돌려 보기 — 보폭과 조건수

읽는 법 — 위 표에서 발산의 경계가 정확히 α = 2/L = 0.5 다(따름정리 9.2). α=0.25 = 1/L 에서는 |1−αL|=0 이라 그 좌표가 한 걸음에 0 이 된다. 아래 표에서는 실측 수렴 인자가 (κ−1)/(κ+1) 과 소수점 여덟 자리까지 일치한다 — 정리 9.7 의 확인이다.

직접 해 보기 — 경사하강 궤적

보라 — 이차함수에서 α 를 키우면 어느 순간 궤적이 지그재그로 튀기 시작하고, 2/L 을 넘으면 밖으로 날아간다. 히멜블라우에서는 출발점을 옮길 때마다 다른 최소점으로 간다 — 비볼록 문제에서 “수렴했다”가 “옳다”가 아니라는 것을 눈으로 확인할 수 있다.

10장

라인서치

보폭을 자동으로 정하기 — Armijo · Wolfe · Zoutendijk

왜 고정 보폭으로는 부족한가

✘ L 을 모른다

보조정리 9.1 은 α ≤ 1/L 을 요구하는데, 실제 문제에서 L 을 계산하는 것은 대개 최적화 자체만큼 어렵다.

✘ L 은 최악의 값이다

전역 립시츠 상수는 함수의 가장 험한 곳에서 정해진다. 평탄한 영역에서도 그 보폭을 쓰면 필요 이상으로 느리다.

해법: 매 반복 φ(α) = f(xk + αdk) 라는 1변수 함수를 잠깐 들여다보고 쓸 만한 α 를 고른다.

φ 를 정확히 최소화하지 않는다 — 그것은 비싸고, 사실 필요도 없다. 필요한 것은 “충분히 줄었는가”와 “충분히 나아갔는가” 두 가지뿐이다. 그 두 요구를 수식으로 적은 것이 Armijo 와 곡률조건이다.

Armijo 조건 — 충분히 줄었는가

정의 10.1 f(x + αd) ≤ f(x) + c1 α ∇f(x)⊤d,    c1 ∈ (0,1) 관례적으로 c1 = 10−4.

오른쪽은 기울기 c1φ′(0) 인 직선이다. 접선(φ′(0))보다 완만한 직선 아래로 내려오라는 요구다.

명제 10.2 (되추적은 반드시 끝난다) d 가 하강 방향이면, α ← ρα (ρ∈(0,1)) 로 줄이는 되추적은 유한 번에 Armijo 조건을 만족한다.
증명
  1. φ(α) = φ(0) + αφ′(0) + o(α) 이고 φ′(0) < 0.
  2. Armijo 조건은 αφ′(0) + o(α) ≤ c1αφ′(0), 곧 o(α)/α ≤ (c1−1)φ′(0) 과 같다.
  3. 오른쪽은 (c1−1) < 0 이고 φ′(0) < 0 이라 양의 상수이고, 왼쪽은 α→0 에서 0 으로 간다.
  4. 따라서 어떤 ᾱ 아래의 모든 α 에서 조건이 성립하고, 되추적은 그 안에 반드시 들어간다.

Wolfe 조건 — 충분히 나아갔는가

정의 10.3 (Wolfe 조건) ① Armijo:   φ(α) ≤ φ(0) + c1αφ′(0)
② 곡률조건:   φ′(α) ≥ c2φ′(0),    0 < c1 < c2 < 1 ②를 |φ′(α)| ≤ c2|φ′(0)| 로 강화한 것이 강 Wolfe 조건이다.
정리 10.4 (존재성) φ 가 연속미분가능하고 아래로 유계이며 φ′(0)<0 이면, Wolfe 조건을 만족하는 구간 (α1, α2) 가 존재한다.
증명
  1. ℓ(α) = φ(0) + c1αφ′(0) 은 기울기가 음수인 직선이므로 α→∞ 에서 −∞ 로 간다. φ 는 아래로 유계이므로 두 그래프가 만나는 가장 작은 α′ > 0 이 존재한다: φ(α′) = ℓ(α′).
  2. (0, α′) 에서는 φ < ℓ 이므로 Armijo 가 성립한다.
  3. 평균값 정리로 φ′(α″) = (φ(α′)−φ(0))/α′ = c1φ′(0) 인 α″ ∈ (0,α′) 가 있다.
  4. c1 < c2 이고 φ′(0)<0 이므로 c1φ′(0) > c2φ′(0) — 곧 φ′(α″) ≥ c2φ′(0) 로 곡률조건도 성립한다.
  5. φ′ 이 연속이므로 α″ 의 작은 근방 전체에서 두 조건이 함께 성립한다.
곡률조건이 사는 이유 — Armijo 만으로는 α→0 이 언제나 통과한다. 곡률조건은 “기울기의 크기가 c2 배 이하로 평평해질 때까지 나아가라”고 요구해 그 퇴화를 막는다. 그리고 이것이 s⊤y > 0 을 보장해 BFGS 를 살린다(정리 12.3).

강 Wolfe 라인서치 구현

Zoutendijk 조건 — 전역수렴의 기둥

정리 10.5 (Zoutendijk) f 가 아래로 유계·L-평활이고, 매 반복이 Wolfe 조건을 만족하는 보폭을 쓰면 ∞∑k=0 cos²θk ‖∇f(xk)‖² < ∞,    cos θk = −∇f(xk)⊤dk‖∇f(xk)‖‖dk‖
증명
  1. 곡률조건에서 (∇f(xk+1) − ∇f(xk))⊤dk ≥ (c2−1)∇f(xk)⊤dk.
  2. 립시츠 조건에서 왼쪽 ≤ Lαk‖dk‖². 두 부등식을 합치면 αk ≥ (c2−1)∇f(xk)⊤dk / (L‖dk‖²) — 보폭의 하한을 얻는다.
  3. 이것을 Armijo 조건에 대입하면 f(xk+1) ≤ f(xk) − c·cos²θk‖∇f(xk)‖², c = c1(1−c2)/L.
  4. 모든 k 에 대해 더하면 좌변은 망원 합이 되어 f(x0) − f⋆ < ∞ 로 눌린다.
따름정리 10.6 방향이 기울기와 너무 직각에 가까워지지 않으면(cos θk ≥ δ > 0) ‖∇f(xk)‖ → 0.
이 따름정리가 설계 규칙을 준다 — 경사하강은 cos θ = 1 로 항상 안전하다. 뉴턴·준뉴턴은 B 의 조건수가 유계이면 안전하다. 그래서 실무 구현이 근사 헤세의 조건수를 감시하고 필요하면 초기화하는 것이다 — 이 책의 minimize 도 ∇f⊤d ≥ 0 이면 B=I 로 되돌린다.

11장

뉴턴법

2차 모형을 그대로 믿는다 — 그 대가와 보상

아이디어 — 2차 모형의 최소점으로 간다

xk 근처에서 테일러 2차 전개(정리 3.10)로 함수를 근사한다.

mk(p) = f(xk) + ∇f(xk)⊤p + 12p⊤∇²f(xk)p

∇²f ≻ 0 이면 mk 는 강볼록 이차함수이므로 유일한 최소점이 있고, ∇mk(p)=0 에서

pk = −(∇²f(xk))−1 ∇f(xk)   ⟸   뉴턴 방향
명제 11.1 (아핀 불변성) 가역 변환 x = Ty 로 좌표를 바꿔도 뉴턴법의 궤적은 같은 점들을 지난다.
증명 h(y) = f(Ty) 라 하면 ∇h = T⊤∇f, ∇²h = T⊤∇²f T. 따라서 py = −(T⊤∇²f T)−1T⊤∇f = −T−1(∇²f)−1∇f = T−1px, 곧 Tpy = px 로 같은 이동이다.
왜 이것이 중요한가 — 경사하강은 좌표 스케일을 바꾸면 성능이 완전히 달라진다(조건수가 바뀌므로). 뉴턴법은 스케일에 무관하다. 그래서 “특징 정규화가 필요 없다”는 성질을 갖는다.

이차수렴 정리

정리 11.2 f ∈ C², x⋆ 에서 ∇f(x⋆)=0, ∇²f(x⋆) ≻ 0 이고 ∇²f 가 x⋆ 근방에서 M-립시츠라 하자. 그러면 x0 가 충분히 가까울 때 보폭 α=1 의 뉴턴법은 ‖xk+1 − x⋆‖ ≤ C ‖xk − x⋆‖²,    C = Mλmin(∇²f(x⋆))
증명
  1. ek = xk − x⋆, Hk = ∇²f(xk) 라 두자. 갱신식에서 ek+1 = ek − Hk−1∇f(xk) = Hk−1[Hkek − ∇f(xk) + ∇f(x⋆)]. ∇f(x⋆)=0 을 더해 넣은 것이 요령이다.
  2. 테일러 적분형(정리 3.10)에서 ∇f(xk) − ∇f(x⋆) = ∫₀¹ ∇²f(x⋆+tek) ek dt.
  3. 따라서 대괄호 안은 ∫₀¹ [Hk − ∇²f(x⋆+tek)] ek dt 이고, 립시츠 조건으로 ‖Hk − ∇²f(x⋆+tek)‖ ≤ M(1−t)‖ek‖.
  4. 적분하면 ‖대괄호‖ ≤ M‖ek‖²∫₀¹(1−t)dt = (M/2)‖ek‖².
  5. 연속성으로 x⋆ 근방에서 ‖Hk−1‖ ≤ 2/λmin 이 유지되므로(헤세가 연속이라 고윳값이 λmin/2 아래로 내려가지 않는 근방이 있다) ‖ek+1‖ ≤ (M/λmin)‖ek‖².
  6. C‖e0‖ < 1 이면 오차가 단조 감소하며 제곱 속도로 사라진다.
“유효 자릿수가 매 걸음 두 배” — ‖ek+1‖ ≈ C‖ek‖² 에 로그를 취하면 log(1/‖e‖) 가 매 반복 두 배가 된다. 실측이 다음 슬라이드에 있다.

헤세가 양의 정부호가 아닐 때

순수 뉴턴은 위험하다 — ∇²f 가 부정부호면 −H−1g 가 오르막일 수 있고, 특이하면 아예 정의되지 않는다. 게다가 멀리서 출발하면 α=1 이 발산을 부른다.
수정 뉴턴 (modified Newton)
  1. τ ← 0
  2. 반복: H + τI 에 촐레스키를 시도한다
    1. 성공하고 g⊤d < 0 이면 그 d 를 쓴다
    2. 실패하면 τ 를 10배로 키운다
  3. 보폭은 Armijo 라인서치로 정한다 (α0=1 에서 시작 — 수렴 영역에서는 곧바로 통과한다)
τ 를 키우면 뉴턴에서 경사하강으로 연속적으로 옮겨간다 — τ→∞ 이면 d → −g/τ. 즉 “믿을 수 있을 때는 2차 정보를, 믿을 수 없을 때는 1차 정보를”이라는 절충이 τ 하나에 담긴다. 13장의 신뢰영역은 같은 절충을 반경으로 표현한다.

돌려 보기 — 이차수렴의 지문

읽는 법 — 앞의 스무 걸음은 ‖g‖ 가 오르내린다. 멀리서는 2차 모형이 함수를 대변하지 못하기 때문이다(정리 11.2 는 국소 정리다). 그러다 k=19 부터 3.9×10−3 → 1.2×10−4 → 4.5×10−10 → 0 으로 떨어진다. log10 열의 감소폭이 −2.4 → −3.9 → −9.4 로 커지는 것이 이차수렴의 지문이다.

돌려 보기 — 두 라인서치의 차이

읽는 법 — 이차함수 한 점에서 Armijo 는 α=0.5 에 만족하고 멈추지만(곡률조건은 불만족), Wolfe 는 α=0.25 로 정확한 최소점 0.2615 에 훨씬 가깝게 간다. 반면 로젠브록 전체 실행에서는 반복 수가 같고 기울기 호출만 두 배다 — Wolfe 가 언제나 이기는 것은 아니다. Wolfe 를 쓰는 진짜 이유는 다음 장의 s⊤y > 0 보장이다.

12장

준뉴턴법

헤세를 계산하지 않고 헤세처럼 쓰기 — BFGS 와 L-BFGS

할선 조건 — 기울기 변화에서 곡률을 읽는다

연속한 두 점의 기울기 차이가 곡률 정보를 담고 있다. 테일러 전개에서

∇f(xk+1) − ∇f(xk) ≈ ∇²f(xk+1) (xk+1 − xk)
정의 12.1 (할선 조건) sk = xk+1−xk, yk = ∇f(xk+1)−∇f(xk) 라 할 때 근사 헤세 Bk+1 과 그 역 Hk+1 은 Bk+1 sk = yk   ⟺   Hk+1 yk = sk 를 만족해야 한다.
명제 12.2 Bk+1 ≻ 0 이 가능하려면 sk⊤yk > 0 이어야 한다 (곡률 조건).
증명 s⊤y = s⊤Bk+1s 인데 B ≻ 0 이고 s ≠ 0 이면 이 값은 양수다.
정리 12.3 (Wolfe 가 곡률 조건을 준다) Wolfe 곡률조건 ∇f(xk+1)⊤dk ≥ c2∇f(xk)⊤dk 를 만족하는 보폭을 쓰면 sk⊤yk > 0 이다.
증명 sk = αkdk 이므로 s⊤y = αk(∇f(xk+1) − ∇f(xk))⊤dk ≥ αk(c2−1)∇f(xk)⊤dk > 0, 마지막 부등호는 c2<1 이고 dk 가 하강 방향(∇f⊤d<0)이기 때문이다.
이제 10장의 곡률조건이 왜 필요했는지 답이 나왔다 — Armijo 만 쓰면 s⊤y ≤ 0 이 생길 수 있고, 그러면 BFGS 근사가 양의 정부호를 잃어 방향이 오르막이 된다.

BFGS 갱신식은 어디서 오는가

정리 12.4 (최소 변화 원리) Hk+1 = arg minH ‖H − Hk‖W   s.t.   H = H⊤,   Hyk = sk (적절한 가중 노름 ‖·‖W 에서) 의 해가 BFGS 갱신식 Hk+1 = (I − ρkskyk⊤) Hk (I − ρkyksk⊤) + ρksksk⊤,    ρk = 1/sk⊤yk 이다.
읽는 법 “할선 조건을 만족하는 대칭행렬 중에서, 지금 갖고 있는 근사에서 가장 적게 바뀌는 것을 고른다.” 새 정보 하나((s,y) 한 쌍)만 들어왔으니 그만큼만 고치겠다는 것이다.
정리 12.5 (양의 정부호 유지) Hk ≻ 0 이고 sk⊤yk > 0 이면 Hk+1 ≻ 0 이다.
증명
  1. 임의의 z ≠ 0 에 대해 w = (I − ρkyksk⊤)z 라 두면 z⊤Hk+1z = w⊤Hkw + ρk(sk⊤z)².
  2. 두 항 모두 음이 아니다: 첫째는 Hk ≻ 0, 둘째는 ρk > 0.
  3. 합이 0 이 되려면 w = 0 이고 sk⊤z = 0 이어야 한다. 그런데 sk⊤z=0 이면 w = z 이므로 z=0 — 가정에 모순.
  4. 따라서 z⊤Hk+1z > 0.
왜 이것이 결정적인가 — 명제 8.6 과 합치면 BFGS 방향은 언제나 하강 방향이다. 헤세를 한 번도 계산하지 않고 이 보장을 얻는다는 것이 준뉴턴법의 존재 이유다.

BFGS 구현 — 랭크-2 갱신 한 덩어리

수렴 성질내용
전역수렴볼록·Wolfe 라인서치에서 ‖∇f‖→0 (Zoutendijk, 정리 10.5)
국소 수렴 속도초선형 — ‖ek+1‖/‖ek‖ → 0. 이차는 아니지만 선형보다 훨씬 빠르다
이차함수에서n 번 반복 뒤 Hn = Q−1 — 켤레기울기와 같은 유한 종료
실패 모드s⊤y ≤ 0 이면 갱신을 건너뛴다(코드의 조건). 비볼록에서 실제로 일어난다
구현 관례 — H0 = I 로 시작하지만, 첫 갱신 뒤 H0 ← (s⊤y/y⊤y)I 로 스케일을 맞추면 초기 몇 걸음이 크게 개선된다. L-BFGS 는 매 반복 이 스케일링을 다시 한다(다음 슬라이드의 gamma).

L-BFGS — 행렬을 만들지 않는다

n = 106 이면 H 는 1012 개의 수다. 담을 수 없다. 그런데 우리가 필요한 것은 행렬이 아니라 곱 H∇f 하나뿐이다.

명제 12.6 BFGS 갱신을 m 번 펼치면 Hk∇f 는 저장된 (si, yi) 쌍들과의 내적만으로 계산된다 — O(mn) 시간, O(mn) 공간.
두 루프의 뜻 — 첫 루프는 최근 정보부터 거꾸로 벗겨 내며 계수 αi 를 기록하고, 가운데서 초기 근사(γI)를 적용한 뒤, 둘째 루프에서 다시 입힌다. 행렬곱을 전개해 보면 정확히 BFGS 를 m 번 적용한 결과와 같다.

13장

켤레기울기와 신뢰영역

행렬을 분해하지 않는 2차 방법, 그리고 모형을 얼마나 믿을 것인가

켤레방향 — 서로 간섭하지 않는 방향들

정의 13.1 Q ≻ 0 에 대해 di⊤Q dj = 0 (i≠j) 이면 {di} 를 Q-켤레라 한다.
정리 13.2 (유한 종료) f = ½x⊤Qx − b⊤x 에 대해, 서로 Q-켤레인 n 개의 방향을 따라 각각 정확한 라인서치를 하면 n 걸음 안에 정확한 최소점에 도달한다.
증명
  1. {d0,…,dn−1} 은 일차독립이다. ∑cidi = 0 에 dj⊤Q 를 곱하면 켤레성으로 cjdj⊤Qdj = 0 이고 Q≻0 이라 cj=0.
  2. 따라서 x⋆ − x0 = ∑i σidi 로 유일하게 전개된다.
  3. dj⊤Q 를 곱하면 σj = dj⊤Q(x⋆−x0)/(dj⊤Qdj).
  4. 한편 알고리즘의 k번째 정확한 라인서치는 αk = −gk⊤dk/(dk⊤Qdk) 를 준다. xk − x0 이 d0,…,dk−1 의 결합이고 켤레성으로 dk⊤Q(xk−x0)=0 이므로 αk = σk.
  5. 즉 각 걸음이 그 방향의 정확한 성분을 한 번에 완전히 채운다. n 걸음이면 전개가 완성된다.
이것이 “간섭하지 않는다”의 뜻이다 — 보통의 경사하강은 나중 걸음이 앞선 걸음의 성과를 망친다(지그재그). 켤레방향은 그 간섭을 정확히 0 으로 만든다.

뉴턴–CG (truncated Newton) — 뉴턴 방정식 ∇²f p = −∇f 를 CG 로 대충 푸는 방법. 헤세를 만들지 않고 ∇²f·v 곱만 쓰며(자동미분이나 (∇f(x+hv)−∇f(x))/h 로 근사), 음의 곡률을 만나면 그 자리에서 멈춘다. 대규모 문제의 표준 2차 방법이다.

신뢰영역 — 모형을 어디까지 믿을 것인가

라인서치는 방향을 먼저 정하고 거리를 정한다. 신뢰영역은 순서를 뒤집는다 — 거리를 먼저 정하고 그 안에서 방향을 정한다.

minp   mk(p) = fk + gk⊤p + 12p⊤Bkp    s.t.   ‖p‖ ≤ Δk
반경 갱신 규칙
  1. 실제 감소 ared = f(xk) − f(xk+p), 예측 감소 pred = mk(0) − mk(p)
  2. ρ = ared / pred  — 모형이 얼마나 맞았는가
  3. ρ < 0.25 → 반경을 1/4 로 줄인다 (모형을 과신했다)
  4. ρ > 0.75 이고 경계에 닿았다 → 반경을 2배로 (더 믿어도 되겠다)
  5. ρ > 0.1 → 걸음을 받아들인다. 아니면 제자리에서 반경만 줄여 다시 푼다
라인서치가 못 하는 일 — Bk 가 부정부호여도 신뢰영역은 그대로 쓸 수 있다. 오히려 음의 곡률 방향은 경계까지 멀리 가라는 신호로 해석된다. 안장점을 빠져나오는 데 유리한 이유가 이것이다.

부분문제를 푸는 법 — Steihaug–CG

부분문제를 정확히 푸는 것도 가능하지만(신뢰영역 부분문제는 λ 하나짜리 방정식으로 환원된다), 큰 문제에서는 CG 를 반경에서 잘라 쓰는 편이 훨씬 싸다.

명제 13.4 Steihaug–CG 의 반복점 ‖zj‖ 는 단조 증가한다. 따라서 “경계를 넘는 순간”이 잘 정의되고, 그 지점에서 멈추면 안전하다.
첫 걸음은 언제나 최급강하 방향 — z0=0 에서 시작하므로 첫 CG 방향은 −g 다. 그래서 반경이 아주 작으면 신뢰영역은 자동으로 경사하강이 되고, 반경이 크고 모형이 좋으면 뉴턴이 된다. 11장의 τ 와 같은 절충을 반경으로 표현한 것이다.

돌려 보기 — 여섯 방법 비교

읽는 법 — 반복 수는 뉴턴·신뢰영역이 압도적이지만, 기울기 호출 수로 보면 BFGS 가 매우 효율적이다. 경사하강은 같은 정확도에 19,435 번이 필요하다 — 로젠브록 최소점의 κ=2508 이 만든 결과다(정리 9.5·9.7). “어느 방법이 가장 빠른가”라는 질문은 “무엇을 세느냐”를 먼저 정해야 답할 수 있다.

미분을 얻는 세 가지 길

① 손으로 유도

정확하고 빠르다. 그러나 사람이 틀린다. 모형을 고칠 때마다 다시 유도해야 한다.

② 수치미분

어떤 함수에나 쓸 수 있다. 그러나 정확도가 8자리에서 멈추고(정리 4.1), n+1 번 평가가 필요하다.

③ 자동미분

연쇄법칙을 기계가 적용한다. 근사가 아니므로 절단오차가 없고, 코드를 고치면 도함수가 따라온다.

자동미분은 기호미분이 아니다 기호미분(SymPy 류)은 수식을 수식으로 바꾸며, 식이 지수적으로 부풀 수 있다. 자동미분은 수를 수로 계산한다 — 특정 점에서의 도함수 값만 얻지만, 그것이 최적화에 필요한 전부다.

전방 모드 — 이중수 하나면 된다

정의 14.1 (이중수) a + bε, 단 ε² = 0 (ε ≠ 0). 실수 위의 다항식환을 ε² 로 나눈 몫환이다.
정리 14.2 f 가 a 근방에서 해석적이면 f(a + bε) = f(a) + b f′(a) ε
증명 테일러 전개 f(a+h) = ∑k≥0 f(k)(a)hk/k! 에 h = bε 를 넣으면 h² = b²ε² = 0 이므로 k ≥ 2 항이 모두 사라진다. 남는 것은 f(a) + b f′(a)ε 뿐이다. 근사가 아니다 — ε²=0 은 대수적 항등식이므로 잘려 나간 항은 애초에 0 이다. 복소 스텝(정리 4.3)이 O(h²) 를 남기는 것과 대비된다.

따라서 곱셈·나눗셈·초등함수의 규칙이 곧 미분 공식이 된다.

역방 모드 — 한 번 계산하고 거꾸로 훑는다

손실함수는 출력이 하나이고 입력이 수백만이다. 전방 모드로는 수백만 번 훑어야 한다. 역방 모드는 순서를 뒤집는다.

역전파
  1. 순전파: 값을 계산하면서, 마디마다 “내가 각 부모에 대해 얼마나 민감한가”(∂n/∂p)를 기록한다
  2. 출력 마디의 adjoint 를 ∂f/∂f = 1 로 둔다
  3. 역전파: 위상 역순으로 훑으며 ∂f/∂p += ∂f/∂n · ∂n/∂p 를 누적한다
  4. 입력 마디에 쌓인 값이 곧 기울기다
왜 += 인가 — 한 마디가 여러 곳에서 쓰이면(공유 부분식) 경로마다 기여가 생긴다. 다변수 연쇄법칙이 경로의 합이라는 사실이 이 한 글자에 들어 있다. = 로 쓰면 마지막 경로만 남아 조용히 틀린 기울기가 나온다.
재귀 대신 스택 — 위상 정렬을 재귀로 짜면 깊은 그래프에서 파이썬의 재귀 한도(기본 1000)에 걸린다. 층이 깊은 모형에서 실제로 부딪히는 문제라 명시적 스택으로 구현했다.

확인 문제

Q1. L-평활 볼록함수에 α = 1.9/L 을 쓰면 정리 9.4 의 증명이 어디서 깨지는가? 그래도 수렴하는가?
Q2. BFGS 를 이차함수 ½x⊤Qx 에 H0=I 로 돌리면 몇 걸음 만에 끝나는가?

A1. 보조정리 9.1 의 1 − Lα/2 ≥ 1/2 가 깨진다 — α=1.9/L 이면 계수가 0.05 로 작아진다. 그래도 양수이므로 감소 자체는 보장되고, 정리 9.4 의 결론은 상수만 나빠진 채로 살아남는다. 실제 발산 경계는 2/L 이다(따름정리 9.2). 다만 상수가 나빠지므로 “더 큰 보폭이 항상 더 빠르다”는 아니다 — 이차함수에서 최적은 2/(L+μ) 다.
A2. 많아야 n 걸음. 정확한 라인서치를 쓰면 BFGS 가 생성하는 방향이 Q-켤레가 되어 정리 13.2 가 그대로 적용되고, 동시에 Hn = Q−1 이 된다. 실제 구현은 라인서치가 부정확해 조금 더 걸린다.
