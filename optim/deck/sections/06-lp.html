다면체와 극점

정의 23.1 P = {x : Ax ≤ b} 를 다면체라 한다. 유한하고 유계이면 폴리토프다.
정의 23.2 (극점) x ∈ P 가 극점이라는 것은, x = ½(y+z), y,z ∈ P 이면 반드시 y=z=x 라는 뜻이다. 곧 다른 두 점의 중점으로 쓸 수 없는 점이다.
정의 23.3 (기저 실행가능해) 표준형 Ax=b, x≥0 (A 는 m×n, 랭크 m)에서, 열 m 개를 골라 만든 정칙 부분행렬 B 에 대해 xB = B−1b ≥ 0, 나머지 xN = 0 인 점을 기저 실행가능해(BFS)라 한다.
정리 23.4 (극점 = 기저 실행가능해) 표준형에서 x 가 극점 ⟺ x 가 기저 실행가능해.
증명
  1. (⟸) x 가 BFS 이고 x = ½(y+z) 라 하자. xN=0 이고 y,z ≥ 0 이므로 yN=zN=0. 음이 아닌 두 수의 평균이 0 이면 둘 다 0 이다.
  2. 그러면 ByB = b = BzB 이고 B 가 정칙이므로 yB=zB=B−1b. 따라서 y=z=x.
  3. (⟹) x 가 극점이고 S = {j : xj > 0} 라 하자. S 에 해당하는 열들이 일차종속이라 가정하면 모순이 나옴을 보인다.
  4. 종속이면 d ≠ 0 이 있어 Ad = 0 이고 dj=0 for j∉S. 충분히 작은 ε>0 에 대해 x ± εd ≥ 0 이고 A(x±εd) = b 이므로 둘 다 실행가능하다. xj > 0 인 성분만 움직이므로 작은 ε 에서는 음수가 되지 않는다.
  5. x = ½((x+εd) + (x−εd)) 이므로 극점이 아니다 — 모순. 따라서 S 의 열은 독립이고, 필요하면 열을 더 넣어 m 개의 기저를 만들 수 있다.
이 정리가 심플렉스를 가능하게 한다 — 무한히 많은 점 중에서 유한한 조합적 대상(기저)만 보면 된다. 기하 문제가 대수 문제로 바뀐 것이다.

선형계획의 기본 정리

정리 23.5 표준형 LP 에서 실행가능집합이 비어 있지 않고 최적값이 유한하면, 최적해 중 적어도 하나는 극점이다.
증명
  1. x⋆ 를 최적해 중 0 이 아닌 성분 수가 가장 적은 것으로 고르고, S = {j: xj⋆>0} 이라 하자.
  2. S 의 열이 독립이면 정리 23.4 에 의해 x⋆ 는 극점이고 증명이 끝난다.
  3. 종속이라 하자. Ad=0, dj=0 (j∉S) 인 d≠0 이 있다. c⊤d ≠ 0 이면 d 또는 −d 방향으로 목적값이 개선되므로 최적성에 모순 → c⊤d=0.
  4. x⋆ + td 를 t 를 키우며(또는 줄이며) 따라가면 어떤 성분이 처음으로 0 이 되는 t0 가 있다(d 에 음의 성분이 있거나, 없으면 −d 를 쓴다). d 의 모든 성분이 같은 부호이고 그 방향으로 유계가 아니면 최적값이 유한하다는 가정에 모순이다.
  5. 그 점도 최적해인데 0 인 성분이 하나 더 많다 — x⋆ 를 고른 방식에 모순.
LP 의 결말은 셋뿐이다뜻심플렉스가 알아내는 방법
최적해 존재유한한 최적값축소비용이 모두 ≥ 0
비유계p⋆ = −∞개선 열의 계수가 모두 ≤ 0 (비율검정 실패)
실행불가능𝒳 = ∅1단계 최적값이 > 0
비볼록·비선형과의 대비 — 3부에서는 “국소해로 수렴했다”가 최선이었다. LP 에서는 세 결말 중 무엇인지 유한 시간에 판정되고, 최적해면 그 사실이 증명된다.

24장

심플렉스법

축소비용 · 비율검정 · 퇴화 · 유한성

축소비용 — 어느 방향이 이득인가

기저 B 와 비기저 N 으로 나누면 Ax=b 는 BxB + NxN = b, 곧 xB = B−1(b − NxN).

정리 24.1 (축소비용) 목적함수를 비기저 변수만의 함수로 쓰면 c⊤x = cB⊤B−1b + ∑j∈N c̄j xj,    c̄j = cj − cB⊤B−1aj c̄j 를 j 열의 축소비용이라 한다.
증명 c⊤x = cB⊤xB + cN⊤xN 에 xB 를 대입하면 = cB⊤B−1b + (cN⊤ − cB⊤B−1N)xN. 성분별로 쓰면 위 식이다.
정리 24.2 (최적성 판정) 기저 실행가능해에서 모든 j∈N 에 대해 c̄j ≥ 0 이면 그 해는 최적이다.
증명 임의의 실행가능 x 는 xN ≥ 0 이므로 정리 24.1 에서 c⊤x = cB⊤B−1b + ∑c̄jxj ≥ cB⊤B−1b = 현재 기저해의 목적값.
축소비용의 뜻 — “비기저 변수 xj 를 1 만큼 늘리면(그리고 기저를 조정해 등식을 지키면) 목적값이 c̄j 만큼 변한다.” 음수면 이득이므로 그 열을 들여보낸다. cB⊤B−1 이 곧 쌍대변수 π 이고, c̄j = cj − π⊤aj 는 쌍대 실행가능성 위반량이다 — 25장에서 이 연결을 정식으로 다룬다.

비율검정 — 얼마나 멀리 갈 수 있는가

xq 를 0 → t 로 늘리면 기저 변수는 xB = B−1b − t B−1aq 로 변한다. 음수가 되면 안 되므로

t⋆ = mini : (B−1aq)i > 0 (B−1b)i(B−1aq)i
명제 24.3 (비유계 판정) (B−1aq)i ≤ 0 이 모든 i 에서 성립하면 t 를 무한히 키워도 실행가능하므로, c̄q < 0 과 함께 목적값이 −∞ 임을 증명한다.
정의 24.4 (퇴화) 어떤 기저 변수의 값이 0 이면 그 기저해를 퇴화했다고 한다. 그러면 비율 t⋆=0 이 되어, 기저가 바뀌어도 점이 움직이지 않는다.
퇴화가 순환을 부른다 — 목적값이 줄지 않는 반복이 이어지면 같은 기저로 돌아올 수 있다. 실제 문제(특히 조합 최적화에서 나오는 LP)는 퇴화가 매우 흔하다.

알고리즘과 구현

심플렉스 한 반복
  1. 축소비용 c̄j 를 계산한다
  2. 모두 ≥ 0 이면 종료 — 최적 (정리 24.2)
  3. c̄q < 0 인 열 q 를 고른다  — Dantzig: 가장 음수 / Bland: 첨자 최소
  4. 비율검정으로 나갈 행 r 을 고른다. 후보가 없으면 종료 — 비유계
  5. (r, q) 를 축으로 가우스 소거 → 기저 갱신
전체 타블로 vs 개정 심플렉스 — 여기서는 (m+1)×(n+1) 타블로를 통째로 갱신한다(O(mn)/반복). 실무 구현은 B−1 만 갱신하고 필요한 열만 계산하는 개정 심플렉스를 쓴다 — 희소성을 살릴 수 있고, 누적 오차도 주기적 재분해로 관리한다.

2단계법 — 출발점을 만드는 법

슬랙만으로 실행가능 기저를 만들 수 있으면 좋지만, 등식 제약이나 ≥ 제약이 있으면 불가능하다. 그때 인공변수를 쓴다.

1단계 (feasibility)
  1. 기저 열이 없는 행에만 인공변수 ai ≥ 0 을 붙인다
  2. min ∑ai 를 심플렉스로 푼다 (인공변수 기저에서 시작 — 자명하게 실행가능)
  3. 최적값 > 0 이면 원문제가 실행불가능하다 (증명: 인공변수를 모두 0 으로 만들 수 없다는 것은 Ax=b, x≥0 의 해가 없다는 뜻)
  4. 최적값 = 0 이면 그 기저가 원문제의 실행가능 기저다 → 2단계로
왜 “필요한 행에만” 붙이는가 — 모든 행에 붙여도 정답은 같지만, 1단계가 사실상 최적화를 대신 해 버려 2단계에서 아무 일도 일어나지 않는다. 실무 구현도 슬랙 열을 재활용한다.

돌려 보기 — 심플렉스의 발자국

읽는 법 — 기저가 {s1,s2,s3} → {x2,s1,s3} → {x1,x2,s1} 로 바뀌며 목적값이 0 → −30 → −36 으로 내려간다. 좌표로는 (0,0) → (0,6) → (2,6) 이고, 1번 표의 꼭짓점 목록에 전부 들어 있다. 심플렉스는 다면체의 모서리를 따라 걷는다.

Bland 규칙과 유한성

정리 24.5 (Bland) 들어올 열과 나갈 행을 모두 첨자가 가장 작은 것으로 고르면 심플렉스는 순환하지 않으며, 유한 번에 종료한다.
증명 개요 (귀류법)
  1. 순환이 있다고 하자. 순환 동안 목적값은 변하지 않으므로 그 사이 들어오고 나간 변수들은 모두 값이 0 인 퇴화 변수다.
  2. 순환에 등장하는 변수 중 첨자가 가장 큰 것을 q 라 하자. q 가 들어오는 반복과 나가는 반복이 각각 존재한다.
  3. 두 반복의 타블로를 비교하면, Bland 규칙이 강제하는 첨자 순서 때문에 어떤 성분의 부호가 동시에 양수이고 음수여야 한다는 결론이 나온다 — 모순.
  4. 따라서 순환은 없고, 기저의 개수가 C(n,m) 로 유한하므로 알고리즘은 끝난다.
규칙순환 방지실전 속도쓰임
Dantzig (최대 음수)보장 없음빠르다기본값
Bland (최소 첨자)보장느리다순환 의심 시 전환
최대 감소량보장 없음반복 수 적음, 반복당 비쌈드묾

실무의 관행 — 평소 Dantzig/Devex 로 돌리다가 목적값이 일정 횟수 이상 개선되지 않으면 Bland 로 전환한다. 이 책의 구현도 rule 인자로 둘을 고를 수 있다.

심플렉스는 얼마나 빠른가

정리 24.6 (Klee–Minty, 1972 · 진술) Dantzig 규칙을 쓰는 심플렉스가 2n − 1 번의 반복을 요구하는 LP 가 존재한다 — 최악의 경우 지수 시간이다.
Klee–Minty 입방체 — 단위입방체를 살짝 찌그러뜨려 모든 꼭짓점을 순서대로 방문하게 만든 예다. n=30 이면 10억 번이 넘는다.
관점결론
최악의 경우지수 시간 (Klee–Minty)
실무 관찰반복 수가 대략 2m ~ 3m — 놀랍도록 빠르다
평활 분석 (Spielman–Teng, 2004)입력을 미세하게 무작위 섭동하면 기대 다항 시간
내부점법O(√n log(1/ε)) 반복 — 다항 시간 보장
미해결 문제강다항 시간 LP 알고리즘의 존재 여부 (Smale 의 9번 문제)
이론과 실무의 간극 — 심플렉스는 “최악은 지수, 실전은 선형에 가깝다”의 대표적인 예다. 알고리즘을 최악 복잡도만으로 판단하면 안 된다는 교훈이기도 하다.

돌려 보기 — 퇴화와 축 선택 규칙

읽는 법 — Beale 의 퇴화 예제다. 이 구현에서는 두 규칙 모두 순환 없이 끝났지만(순환은 동률 처리 방식까지 특정해야 재현된다), Dantzig 규칙으로 순환하는 예가 존재한다는 사실과 Bland 규칙이 순환하지 않음이 증명되어 있다는 사실은 그대로다. 그래서 실무 솔버는 순환이 의심되면 규칙을 바꾼다.

선형계획의 쌍대성

완벽하게 대칭인 쌍 · 상보여유 · 민감도

쌍대 LP 를 유도한다

원문제 (P)
min c⊤x
s.t. Ax ≥ b
     x ≥ 0
쌍대 (D)
max b⊤y
s.t. A⊤y ≤ c
     y ≥ 0
유도 (5부 정의 21.1 을 적용한다)
  1. L(x,y) = c⊤x + y⊤(b − Ax) = b⊤y + (c − A⊤y)⊤x,  y ≥ 0
  2. q(y) = infx≥0 L. 괄호 안 (c−A⊤y) 에 음수 성분이 하나라도 있으면 그 xj 를 무한히 키워 −∞ 가 된다.
  3. 따라서 q(y) = b⊤y if A⊤y ≤ c, else −∞. 쌍대 문제는 max q 이므로 위 (D) 가 나온다.

변수 xj 부호 자유제약 j: = cj
제약 i: ≥ bi변수 yi ≥ 0
제약 i: = bi변수 yi 부호 자유
제약 m 개, 변수 n 개변수 m 개, 제약 n 개
쌍대의 쌍대는 원문제다 — 위 표를 두 번 적용하면 확인된다. LP 의 쌍대성은 완벽히 대칭이며, 이것이 일반 볼록 문제와 다른 점이다.

강쌍대성 — LP 에서는 언제나 성립한다

정리 25.1 (약쌍대성) x 가 (P) 에, y 가 (D) 에 실행가능하면 b⊤y ≤ c⊤x.
증명 (한 줄) b⊤y ≤ (Ax)⊤y = x⊤(A⊤y) ≤ x⊤c. 첫 부등호는 Ax ≥ b, y ≥ 0, 둘째는 A⊤y ≤ c, x ≥ 0 때문이다.
정리 25.2 (강쌍대성) (P) 와 (D) 중 하나가 유한 최적값을 가지면 다른 쪽도 그렇고, 두 최적값이 같다.
증명 (심플렉스의 종료 조건에서 바로 나온다)
  1. 심플렉스가 최적 기저 B 에서 멈췄다고 하자. y⊤ = cB⊤B−1 로 두자.
  2. 최적성 조건 c̄j = cj − y⊤aj ≥ 0 (모든 j) 는 정확히 A⊤y ≤ c, 곧 y 의 쌍대 실행가능성이다.
  3. 목적값은 c⊤x = cB⊤B−1b = y⊤b — 두 값이 같다.
  4. 약쌍대성에 의해 이 y 는 쌍대 최적해다.

실행불가능·비유계 경우는 Farkas 정리(5부 정리 20.4)로 처리한다. ∎

심플렉스는 원문제와 쌍대문제를 동시에 푼다 — 최적 기저 하나가 원해 x 와 쌍대해 y 를 함께 준다. 그래서 최적성의 증명서가 공짜로 나온다.

상보여유 정리

정리 25.3 실행가능한 x, y 가 각각 최적 ⟺ yi · ((Ax)i − bi) = 0   ∀i   그리고   xj · (cj − (A⊤y)j) = 0   ∀j
증명
  1. 약쌍대성 증명의 두 부등식을 다시 본다: c⊤x − b⊤y = x⊤(c − A⊤y) + y⊤(Ax − b).
  2. 두 항 모두 음이 아닌 수들의 곱의 합이다(x≥0, c−A⊤y≥0, y≥0, Ax−b≥0).
  3. 강쌍대성으로 좌변이 0 ⟺ 각 항이 0 ⟺ 각 곱이 하나하나 0.
경제학적 읽기 — “남는 자원에는 값을 매기지 않고, 값이 매겨진 자원은 남지 않는다.” 그리고 “쓰이는 활동은 정확히 손익분기이고, 손해 보는 활동은 쓰지 않는다.” 이 두 문장이 정리 25.3 의 전부다.
알고리즘적 쓸모 — 상보여유는 “최적성을 어떻게 확인할 것인가”에 대한 답이다. 내부점법은 xjsj = μ 로 완화한 뒤 μ→0 으로 보낸다. 7부의 최소비용흐름 알고리즘도 상보여유를 조합적으로 유지하는 방식이다.

내부점법

경계를 걷는 대신 안쪽을 가로지른다

KKT 계를 푸는 문제로 바꾼다

표준형 LP 의 KKT 조건(5부 정리 20.3)은 다음과 같다.

Ax = b,    A⊤y + s = c,    x ≥ 0,   s ≥ 0,    xisi = 0

앞의 두 줄은 선형이다. 어려움은 마지막 줄의 조합적 성질(각 쌍마다 하나는 0)에 있다.

정의 26.1 (중심 경로) xisi = μ > 0 으로 완화한 계의 해 (x(μ), y(μ), s(μ)) 들이 그리는 곡선.
정리 26.2 중심 경로 위의 점에서 쌍대 간격은 정확히 n μ 다.
증명 c⊤x − b⊤y = (A⊤y+s)⊤x − (Ax)⊤y = s⊤x = ∑xisi = nμ.
5부 정리 22.4 와 같은 이야기다 — 로그 배리어의 m/t 가 여기서는 nμ 다. 실제로 μ = 1/t 로 두면 두 관점이 정확히 일치한다. μ 를 보면 얼마나 최적에 가까운지 계산 없이 안다.

보폭과 중심화

원-쌍대 경로 추종 한 반복
  1. μ = x⊤s/n 을 계산한다
  2. 중심화 계수 σ ∈ (0,1) 를 고른다  — 작으면 공격적, 크면 안전
  3. 뉴턴 방향 (Δx, Δy, Δs) 를 푼다
  4. x, s > 0 을 유지하는 최대 보폭의 99% 만 간다

① 배합 문제 (diet)
min c⊤x  s.t.  Nx ≥ r, x ≥ 0

영양소 요구 r 를 최소 비용으로 채운다. 쌍대변수는 영양소 1단위의 잠재 가격이다.

공급지 → 수요지 배분. 제약행렬이 완전단모듈이라 LP 해가 자동으로 정수다 (7부 정리 30.3).

③ 최대흐름
max v  s.t.  유량 보존, 0 ≤ fe ≤ ue

쌍대 문제가 정확히 최소 컷이 된다 — 최대흐름–최소컷 정리가 LP 쌍대성의 특수한 경우다.

④ 2인 영합 게임
maxp minj (p⊤A)j  s.t.  p ∈ 단체

폰 노이만의 최소최대 정리가 LP 강쌍대성과 동치다. 원문제는 내가 고르는 혼합전략, 쌍대는 상대의 혼합전략이다.

왜 이 넷인가 — 각각이 LP 의 서로 다른 얼굴을 보여 준다: 쌍대변수의 경제적 해석(①), 정수성(②), 그래프 이론과의 연결(③), 게임 이론과의 동치(④). 7부와 13부에서 각각을 다시 만난다.

목적함수의 방향을 돌리면 최적 꼭짓점이 어떻게 옮겨 가는가
보라 — ① 각도를 연속으로 돌려도 최적해는 꼭짓점에서 꼭짓점으로 뛴다(정리 23.5). ② 어떤 각도에서는 목적 등위선이 모서리와 평행해져 그 모서리 전체가 최적이 된다 — 최적해가 유일하지 않은 경우다. ③ 주황색 선이 심플렉스가 걷는 경로다. 언제나 모서리를 따라가고, 목적값이 좋아지는 쪽으로만 간다.

확인 문제

Q1. LP 의 최적해가 유일하지 않은 경우는 어떤 때인가? 그때 심플렉스는 무엇을 반환하는가?
Q2. 제약이 m 개인 LP 에서 최적해의 0 이 아닌 성분은 최대 몇 개인가? 왜 중요한가?

A1. 최적 기저에서 어떤 비기저 변수의 축소비용이 0 일 때다. 그 변수를 들여보내도 목적값이 변하지 않으므로, 두 꼭짓점을 잇는 모서리 전체가 최적해다(정리 7.2 — 최적해 집합은 볼록). 심플렉스는 그중 꼭짓점 하나만 반환한다. 내부점법은 반대로 최적면의 상대적 내부(중심)로 수렴한다 — 같은 문제에서 두 방법이 다른 해를 주는 이유다.
A2. 최대 m 개다(기저 변수의 수). 이것이 희소성 보장이다: 수송 문제에서 “m 개 이하의 경로만 쓰면 된다”, 포트폴리오에서 “제약 수만큼의 자산만 보유하면 된다”가 여기서 나온다. 8부의 ℓ1 정칙화가 희소성을 유도하는 것과 달리, LP 는 구조적으로 희소한 해를 보장한다.
