부록 — 돌려 보지 못한 것

macOS term/termios_darwin.go 는 GOOS=darwin GOARCH=arm64 go build 로 컴파일만 확인했다. 실행해 본 적이 없다. 상수는 Go 소스에서 읽어 적었고, 논리는 리눅스와 공유하는 makeRawTermios 가 시험으로 확인된다.
윈도우 term/term_windows.go 는 ErrUnsupported 를 돌려주는 스텁이다. 컴파일은 되고, 터미널을 만지려는 순간 정직하게 거절한다. 콘솔 API 로 같은 일을 하려면 무엇이 필요한지는 4부에 적어 두었다.
경합 검출기 -race 는 이 기계(android/arm64)에서 지원하지 않는다 (-race is not supported on android/arm64). 동시성은 설계와 타이밍 시험으로만 논증했다 — 다른 기계에서 go test -race ./... 를 돌려 보는 것이 이 덱의 마지막 연습문제다.

이 셋을 여기 적어 두는 이유: 문서가 거짓말하는 가장 흔한 방식이 "안 해 본 것을 안 적는 것" 이기 때문이다.

부록 — 이 덱을 다시 만들려면

cd boricha

make test                # 전 패키지 시험
make cross               # macOS·윈도우 교차 컴파일 확인
make gen-width           # 글자 폭 표 다시 굽기 (결과가 같아야 한다)
make record              # 화면 기록 (두 번 돌려 git diff 가 비어야 한다)
make tmux-smoke          # 진짜 PTY 캡처 (tmux 필요)
make html                # 기록·캡처를 덱이 읽는 HTML 로
make logs                # go test·vec·loc·bench 출력 저장
make deck                # 덱 조립 → ../나만의_Bubble_Tea_만들기.html
make deck-check          # 브라우저 없이 점검
필요한 것 Go 1.27 이상 · tmux · python3(fontTools · brotli) · node · D2Coding 글꼴 파일. 네트워크는 필요 없다 — 모듈 의존성이 없기 때문이다.

make deck 은 커버리지를 세고 "오류 N건" 을 찍는다. 0이 아니면 그 덱은 내보내지 않는다.
