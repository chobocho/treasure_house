설명용

1장

궤적 — 시간의 함수로 적은 위치

멈춤에서 멈춤으로 · 정규화한 모양 β(u)

왜 매끄러워야 하나

8부의 평탄성(T12)은 궤적의 미분이 곧 드론의 입력이라고 말합니다. 가속도는 총추력과 기울기를, 가가속도는 몸체 각속도를, 스냅(가가속도의 미분)은 각가속도 — 곧 토크 — 를 정합니다.

  • 가속도가 끊기면 기울기가 순간 이동해야 하고, 가가속도가 끊기면 각속도가 순간 이동해야 합니다.
  • 그래서 궤적은 스냅까지 유계(가능하면 연속)여야 모터가 따라갈 수 있습니다.
  • 동시에 빨라야 합니다 — 쇼의 전환 시간은 곧 관객이 기다리는 시간입니다.
설명용

정규화한 모양 β(u)

점 a 에서 b 로 직선을 따라 T 초에 갈 때, 위치는 a + β(t/T)(b − a) 로 쓸 수 있습니다. β 는 0 에서 1 로 가는 함수 하나 — 이 부의 궤적은 모두 β 를 고르는 문제입니다.

사다리꼴은 β″ 가 계단처럼 뛰고(가속도 불연속), 최소 저크는 β″ 까지, 최소 스냅은 β‴ 까지 양 끝에서 0 입니다. 쇼 파일은 전환마다 이 셋 가운데 하나를 고릅니다(SPEC §9.1).

실행 검증

1장 퀴즈

Q. 거리가 다른 두 드론이 같은 β 와 같은 T 로 움직입니다. 둘의 최고 속도는 어떤 관계인가요?

A. 속도는 β′(u)·|b−a|/T 라 거리에 비례합니다. 가장 먼 드론이 가장 빠르고, 전환 시간은 그 드론이 한계를 넘지 않도록 정합니다(9장).
설명용

2장

다항식 궤적 — 최소 저크와 최소 스냅

7차 다항식은 왜 특별한가

멈춤 → 멈춤 다항식

β(0) = 0, β(1) = 1 이고, 양 끝에서 속도·가속도(최소 저크) 또는 가가속도까지(최소 스냅) 0 인 가장 낮은 차수의 다항식을 찾습니다. 조건이 6개면 5차, 8개면 7차 — 미지수 수와 조건 수가 같습니다.

최소 저크 β = 10u³ − 15u⁴ + 6u⁵    최소 스냅 β = 35u⁴ − 84u⁵ + 70u⁶ − 20u⁷
실행 검증

그런 다항식은 하나뿐이다

쓰는 도구: 다항식의 계수와 도함수의 관계(0 에서의 k계 도함수 = k!·ck).

증명
  1. 7차 이하 p 가 0 에서 값과 1~3계 도함수가 0 이면 c₀ = c₁ = c₂ = c₃ = 0, 곧 p = t⁴q(t), q 는 3차 이하.
  2. 1 에서도 같은 조건이므로 t ↦ 1 − t 로 바꿔 같은 논리를 쓰면 p 는 (1 − t)⁴ 로도 나누어집니다. 그래서 t⁴(1−t)⁴(8차)이 p 를 나눕니다.
  3. 7차 이하가 8차로 나누어지면 0 뿐입니다. 두 멈춤→멈춤 다항식의 차가 이런 p 이므로 둘은 같습니다.
실행 검증

무엇을 가장 작게 하나 — 스냅 제곱의 적분

J(x) = ∫0T (x⁗(t))² dt

스냅은 토크(각가속도)와 이어지므로(T12), J 가 작다는 것은 모터를 덜 흔든다는 뜻입니다. 조건을 지키는 모든 곡선 가운데 J 가 가장 작은 것을 찾습니다 — 답이 7차 다항식이라는 것이 이 장의 정리입니다.

실행 검증

교차항은 0 이다 — 부분적분 네 번

쓰는 도구: M12. 가정: h 와 h′, h″, h‴ 가 양 끝에서 0, x 는 7차 이하(그래서 x(8) = 0).

증명
  1. ∫x⁗h⁗ = [x⁗h‴] − ∫x(5)h‴. M12
  2. 같은 일을 세 번 더 하면 끝값 항 [x⁗h‴ − x(5)h″ + x(6)h′ − x(7)h] 과 ∫x(8)h 가 남습니다.
  3. 끝값 항은 h 의 0~3계 도함수가 양 끝에서 0 이라 모두 0. h 의 가정을 여기서 쓴다
  4. 남은 적분은 x(8) = 0 이라 0. 7차라는 가정을 여기서 쓴다
실행 검증

최소 스냅 정리

쓰는 도구: L11, L12. 가정: 비교하는 곡선 y 는 네 번 미분할 수 있고 x 와 같은 끝 조건을 지킨다.

증명
  1. x 를 L11 의 7차 다항식, y 를 끝 조건을 지키는 아무 곡선이라 하고 h = y − x. 끝 조건이 같으므로 h 와 h′, h″, h‴ 는 양 끝에서 0.
  2. J(y) = J(x) + 2∫x⁗h⁗ + J(h) — 제곱을 펼친 것.
  3. L12 로 가운데 항이 0 이므로 J(y) = J(x) + J(h) ≥ J(x).
  4. 등호는 J(h) = 0, 곧 h⁗ ≡ 0 — h 는 3차 이하이고 0 에서 네 조건이 0 이므로 h ≡ 0. 최소점은 x 하나입니다.

여러 구간의 경우(경유점에서 6계 도함수까지 이어짐)는 같은 논리를 구간마다 쓰면 되지만, 이 덱은 스케치로 둡니다. 원래의 결과는 Mellinger·Kumar 입니다.

실행 검증

섭동을 더하면 — 비용은 늘기만 한다

200번 가운데 가장 작은 증가도 양수입니다. 증가량이 정확히 J(h) 라는 것(교차항 0)은 증인 시험이 섭동마다 확인합니다.

실행 검증

경유점 여러 개 — 구간마다 7차, 6계까지 이어 붙이기

경유점 N+1 개를 지나는 궤적은 구간마다 7차 다항식 N 개입니다. 미지수 8N 개에 조건도 8N 개(양 끝 8개, 가운데 경유점마다 위치 2개와 1~6계 연속 6개) — 연립방정식 하나로 풉니다.

실행 검증

경유점에서의 이음새

0~6계는 반올림 오차(10⁻¹³ 대)만큼만 다르고, 7계에서 처음으로 크게 뜁니다. 최소 스냅 궤적은 C⁶ — 스냅의 미분(스냅 변화율)까지 이어집니다.

실행 검증

손으로 풀어 보기 — 2장

Q. 최소 저크 β = 10u³ − 15u⁴ + 6u⁵ 의 가운데(u = ½) 속도 β′ 를 구하세요.

A. β′ = 30u² − 60u³ + 30u⁴, u = ½ 에서 30/4 − 60/8 + 30/16 = 1.875. 평균 속도(1)의 1.875 배입니다.
실행 검증

2장 퀴즈

Q. T27 의 증명에서 "끝 조건이 같다" 는 가정이 없으면 어느 단계가 무너지나요?

A. L12 의 3단계 — 끝값 항이 0 이 아니게 되어 교차항이 사라지지 않습니다. 그러면 J(y) 가 J(x) 보다 작을 수도 있습니다. 실제로 끝에서 멈추지 않아도 되는 곡선(예: 속도를 남기고 끝나는 직선)은 스냅이 0 이라 비용이 더 작습니다.
설명용

3장

속도 프로파일 — 한계 안의 최단 시간

가속 · 등속 · 감속 · 삼각형이 되는 조건

사다리꼴 프로파일

속도 한계 vmax 와 가속도 한계 amax 만 있고 매끄러움을 따지지 않는다면, 가장 빠른 길은 "최대로 가속 → 최대 속도로 순항 → 최대로 감속" 입니다. 거리가 짧으면 순항 전에 감속해야 해 삼각형이 됩니다.

실행 검증

속도의 천장

증명
  1. 멈춘 채 출발하고 가속도가 amax 이하이면, 속도는 t 초 동안 amaxt 넘게 늘 수 없습니다. 가속도를 0 부터 적분 — 작은 것의 적분은 작다
  2. 멈춘 채 도착하므로 끝에서 거꾸로 봐도 같습니다: v(t) ≤ amax(T − t). 여기에 한계 vmax 가 더해집니다.
실행 검증

삼각형이 되는 조건

증명
  1. 멈춘 채 최고 속도까지 가속하고 다시 멈추는 데만, 천장(L14)의 삼각형 넓이 vmax²/amax 만큼의 거리가 듭니다.
  2. 거리가 그보다 짧으면 최고 속도에 닿기 전에 줄여야 합니다 — 순항 구간이 없는 삼각형입니다.
실행 검증

사다리꼴이 가장 빠르다

쓰는 도구: L13, L14. 가정: 멈춤→멈춤, |v| ≤ vmax, |a| ≤ amax.

증명
  1. 간 거리는 속도의 적분이고, L14 로 속도는 천장 c(t) = min(amaxt, amax(T−t), vmax) 아래에 있습니다. 그래서 d ≤ ∫c.
  2. T ≤ 2vmax/amax 이면 천장은 삼각형이라 ∫c = amaxT²/4, 곧 T ≥ 2√(d/amax).
  3. 그보다 길면 사다리꼴이라 ∫c = vmaxT − vmax²/amax, 곧 T ≥ d/vmax + vmax/amax.
  4. 사다리꼴 프로파일은 천장을 그대로 따라가므로 등호를 이룹니다. 어느 경우인지는 L13 이 정합니다.
실행 검증

매끄러움의 값 — 같은 한계에서 걸리는 시간

최소 스냅은 사다리꼴보다 1.4–1.9 배 오래 걸립니다. 매끄러움(모터가 따라갈 수 있음)과 빠르기를 맞바꾼 것입니다. 쇼 설계에서는 이 둘 사이에서 고릅니다 — 이 덱의 기본은 가속 구간을 ¼ 로 둔 사다리꼴입니다(SPEC §9).

실행 검증

같은 시간에 가면 — 모양이 어떻게 다른가

  • 사다리꼴의 속도는 꺾인 선입니다. 꺾이는 자리에서 가속도가 한순간에 바뀌고, 모터는 그만큼 추력을 한순간에 바꿔야 합니다.
  • 최소 스냅의 속도는 종 모양이라 꺾임이 없습니다. 대신 같은 시간에 가려면 최고 속도가 4 에서 약 4.9 m/s 로 올라갑니다 — 앞 표에서 한계를 지키면 더 오래 걸린 까닭입니다.
실행 검증

손으로 풀어 보기 — 3장

Q. 거리 6 m, vmax 3 m/s, amax 2 m/s² 의 최단 시간은?

A. 6 > 3²/2 = 4.5 라 사다리꼴, T = 6/3 + 3/2 = 3.5 초.
실행 검증

3장 퀴즈

Q. 사다리꼴이 가장 빠른데 왜 쇼는 늘 사다리꼴을 쓰지 않나요?

A. 사다리꼴은 가속도가 계단처럼 뛰어 가가속도가 순간적으로 무한대입니다. 평탄성(T12)에 따라 그 순간 드론은 각속도를 순간적으로 바꿔야 해 궤적을 놓칩니다. 여러 대가 가까이 날수록 그 오차가 충돌 여유를 깎습니다. 그래서 여유가 좁은 전환은 최소 스냅을, 넉넉한 전환은 사다리꼴을 씁니다(16부의 물리 모드 추적 오차표).
설명용

4장

곡선과 경로 계획 — 개념만

베지어 · 스플라인 · A* · RRT

다항식 조각을 잇는 다른 방법들

  • 베지어 곡선 — 조정점 몇 개의 가중 평균으로 곡선을 만듭니다. 곡선이 조정점들의 볼록 껍질 안에 머무는 성질이 있어 "이 상자 밖으로 안 나간다" 를 보장하기 쉽습니다.
  • 스플라인 — 경유점마다 다항식 조각을 잇되 이음새에서 몇 계 도함수까지 연속이게 합니다. 최소 스냅의 여러 구간 궤적(2장)이 7차 스플라인입니다.
  • 쇼의 전환은 대개 장애물이 없는 하늘에서 직선이면 충분합니다. 곡선이 필요한 것은 모양 안에서 도는 움직임(13부의 회전·파동) 같은 경우입니다.
설명용

장애물이 있으면 — 격자 탐색과 무작위 나무

  • A* — 공간을 격자로 나누고, "지금까지 온 거리 + 남은 거리의 어림" 이 작은 칸부터 넓혀 가며 최단 경로를 찾습니다. 어림이 실제 거리를 넘지 않으면 찾은 경로가 최단입니다.
  • RRT — 무작위로 점을 뽑아 이미 만든 나무에서 가장 가까운 가지를 그쪽으로 조금 늘립니다. 차원이 높고 모양이 복잡한 공간에서 "일단 길을 하나 찾는" 데 강합니다.
  • 이 덱의 시뮬레이터는 둘 다 구현하지 않습니다. 쇼는 미리 계획한 궤적만 날고, 계획 단계에서 할당(6장)과 간격 검사(7장)가 충돌을 막기 때문입니다.
설명용

5장

편대와 충돌 회피 — 개념만

합의 · 그래프 라플라시안 · 속도 장애물 · 포텐셜

합의 — 이웃만 보고 모두가 같은 값에

드론마다 자기 값(예: 원하는 높이)을 이웃의 평균 쪽으로 조금씩 옮기면, 연결된 무리는 모두 같은 값으로 모입니다. 식으로는 ẋ = −Lx, L 은 "누가 누구의 이웃인가" 를 적은 그래프 라플라시안입니다.

  • L 의 각 행의 합은 0 이라 모두 같은 값인 상태는 움직이지 않습니다(평형).
  • 그래프가 연결되어 있으면 L 의 다른 고윳값은 모두 양수이고, 그래서 차이가 지수적으로 줄어듭니다(7부 M19 의 여러 차원 판 — 이 덱은 증명하지 않습니다).
  • 쇼 드론은 서로 통신하며 합의하지 않고 지상국의 계획을 각자 따릅니다. 합의는 계획이 없는 편대(탐색·수색)에서 씁니다.
설명용

실시간 충돌 회피 — 쇼가 기대지 않는 까닭

  • 속도 장애물 — 상대의 속도를 알면 "이 속도로 가면 부딪친다" 는 속도의 집합을 계산해 피합니다.
  • 포텐셜 장 — 목표는 끌어당기고 다른 드론은 밀어내는 가상의 힘을 더해 움직입니다. 두 힘이 비기는 자리에 갇힐 수 있습니다.
  • 둘 다 서로의 위치를 실시간으로 알아야 하고, 수백 대가 동시에 피하면 계획한 모양이 무너집니다. 쇼는 반대로 계획 단계에서 충돌이 없음을 증명하고 그대로 납니다 — 7장의 CAPT 가 그 증명입니다.

누가 어디로 — 할당 문제와 헝가리안

n! 을 n³ 으로

할당 문제

지금 자리 n 개와 다음 모양의 자리 n 개가 있습니다. 드론 i 가 자리 π(i) 로 가는 비용을 ci,π(i) 라 하면, 비용의 합이 가장 작은 짝짓기 π 를 찾습니다.

  • 경우의 수는 n! — 10 대면 약 360 만, 20 대면 1018 이 넘습니다. 모두 볼 수는 없습니다.
  • 헝가리안 방법은 n³ 에 비례하는 걸음으로 최적을 찾습니다.
  • 비용을 무엇으로 하느냐 — 그냥 거리인가 제곱 거리인가 — 가 7장의 주제입니다. 이 덱의 쇼는 제곱 거리를 씁니다.

증명 스케치

최적성의 핵심(증명서)은 끝까지 보이고, 알고리즘이 그 증명서를 n³ 걸음 안에 만든다는 부분은 스케치로 둡니다.

  1. 잠재값 ui, vj 가 모든 칸에서 ui + vj ≤ cij 를 지킨다고 합시다.
  2. 어떤 할당 π 의 비용도 Σci,π(i) ≥ Σ(ui + vπ(i)) = Σu + Σv. π 는 순열이라 모든 v 를 한 번씩 더한다
  3. 그래서 줄인 비용이 0 인 칸(등호인 칸)만으로 완전한 짝짓기를 찾으면, 그 비용이 Σu + Σv 로 하한과 같아 최적입니다.
  4. 알고리즘은 행을 하나씩 더하며, 막히면 잠재값을 고쳐 0 인 칸을 늘립니다. 한 번 고치는 데 n, 한 행에 최대 n 번 — 합해 n³ 에 비례합니다(스케치).

쓰는 도구: M1(내적의 분배).

증명
  1. |a−b|² = |a|² − 2a·b + |b|² 를 네 쌍에 쓰면 |a|², |b|² 항은 맞바꿔도 같습니다.
  2. 남는 것은 내적 항: (그대로) − (맞바꿈) = −2a₁·b₁ − 2a₂·b₂ + 2a₁·b₂ + 2a₂·b₁ = −2(a₁ − a₂)·(b₁ − b₂).

무교차 보조정리 — 그냥 거리의 합

쓰는 도구: M5(삼각 부등식과 등호 조건). 가정: 평면, 두 경로가 한 직선 위에 있지 않은 채 안쪽에서 엇갈린다.

증명
  1. a₁→b₁ 과 a₂→b₂ 가 점 X 에서 엇갈린다고 합시다. X 는 두 선분 위에 있으므로 |a₁b₁| = |a₁X| + |Xb₁|, |a₂b₂| = |a₂X| + |Xb₂|.
  2. M5 로 |a₁b₂| ≤ |a₁X| + |Xb₂|, |a₂b₁| ≤ |a₂X| + |Xb₁|. 더하면 맞바꾼 쪽이 1단계의 합보다 크지 않습니다.
  3. 두 등호가 모두 성립하려면 a₁, X, b₂ 와 a₂, X, b₁ 이 각각 한 직선 위여야 하고, 그러면 네 점이 X 를 지나는 한 직선 위에 놓여 두 경로가 한 직선 위에 있게 됩니다. 가정에 어긋난다
  4. 그래서 맞바꾸면 합이 엄격히 줄어듭니다. 합이 가장 작은 할당에는 엇갈린 쌍이 없습니다.

증명

증명

증명

  2. 제곱은 0 이상이므로 ½ 이상이고, 등호는 β = ½.
실행 검증

동기 직선 이동의 안전 — CAPT 의 핵심

쓰는 도구: L9, L10, L21. 가정: 모두 같은 β 로 동시에 출발·도착(동기), 제곱 거리 최적 할당, 출발·도착 간격 ≥ δ.

증명
  1. L9 로 두 대 사이 거리의 제곱은 (1−β)²|Δa|² + β²|Δb|² + 2β(1−β)Δa·Δb.
  2. L21 로 Δa·Δb ≥ 0 이고, 0 ≤ β ≤ 1 이라 마지막 항은 0 이상. 최적 할당이라는 가정
  3. 간격 가정으로 |Δa|, |Δb| ≥ δ, 그래서 거리² ≥ δ²((1−β)² + β²) ≥ δ²/2. L10
  4. 제곱근을 취하면 이동 내내 거리 ≥ δ/√2 — 몇 대이든, 몇 차원이든.

Turpin·Michael·Kumar 의 CAPT 는 이것을 반지름 R 인 로봇에 대해 "간격 2√2R 이면 부딪치지 않는다" 로 적었습니다. 쇼 설계의 규칙으로 옮기면: 최소 간격 d 를 지키려면 모양 안의 간격을 √2·d 로 둔다.
