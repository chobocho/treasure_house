벡터 — 방향이 있는 수

내적 · 외적 · 코시-슈바르츠 · 삼각 부등식

벡터는 수 셋

드론의 위치·속도·힘·각속도는 모두 크기와 방향이 있습니다. 이 덱은 그것을 수 셋의 목록 a = (a₁, a₂, a₃) 으로 적습니다 — 세계 좌표에서는 (동, 북, 위) 차례입니다.

a + b = (a₁+b₁, a₂+b₂, a₃+b₃)  ·  ka = (ka₁, ka₂, ka₃)

클래스를 만들지 않고 리스트를 쓴 까닭은 자바스크립트 판의 배열과 모양을 같게 하기 위해서입니다(15부).

실행 검증

크기와 거리

벡터의 크기는 피타고라스 정리를 두 번 쓴 것 |a| = √(a₁² + a₂² + a₃²) 이고, 두 점 사이 거리는 차의 크기 |a − b| 입니다. 쇼의 안전은 결국 이 거리 하나로 요약됩니다(10부).

실행 검증

한 판 계산해 보기

a = (3, 0, 4), b = (1, 2, 2) 로 이 장의 도구를 한 번씩 씁니다. 손으로 먼저 해 보고 출력과 맞춰 보세요.

외적은 두 벡터에 모두 수직이고(내적 0), 순서를 바꾸면 부호가 바뀝니다. 마지막 줄이 이 장에서 증명할 라그랑주 항등식입니다.

실행 검증

내적 — 성분의 곱의 합, 그리고 코사인

내적은 성분끼리 곱해 더한 수 a·b = a₁b₁ + a₂b₂ + a₃b₃ 입니다. 정의는 대수인데, 뜻은 기하입니다.

쓰는 도구: 고등학교 코사인 법칙. 가정: 두 벡터가 0 이 아니어야 사이각 θ 가 정해집니다.

증명
  1. 교환·분배는 정의에서 바로 나옵니다: Σaᵢbᵢ = Σbᵢaᵢ, Σaᵢ(bᵢ+cᵢ) = Σaᵢbᵢ + Σaᵢcᵢ. 실수의 곱과 합의 법칙
  2. 그러면 |a−b|² = (a−b)·(a−b) = |a|² − 2a·b + |b|². 1단계를 두 번
  3. 두 벡터를 변으로 하는 삼각형의 셋째 변이 a−b 이므로 코사인 법칙이 |a−b|² = |a|² + |b|² − 2|a||b| cos θ 를 줍니다. 여기서 0 이 아니라는 가정을 쓴다 — 삼각형이 있어야 한다
  4. 2와 3을 비교하면 a·b = |a||b| cos θ.

어디에 썼나: 두 방향이 수직인지(내적 0), 한 방향으로의 성분이 얼마인지(투영) — 9부의 총추력 계산.

실행 검증

내적의 쓰임 — 수직 판정과 투영

  • 수직 — a·b = 0 이면 cos θ = 0, 곧 90°. 이 장 끝의 연습 문제(손으로 풀어 보기)가 그 예입니다.
  • 투영 — 단위벡터 u 방향의 성분은 a·u = |a| cos θ. 방향만 남기고 싶으면 (a·u)u.
  • 드론에서 — 제어기가 원하는 추력 벡터 f 가 기울어진 드론의 몸체 z 축 zB 와 어긋나 있을 때, 실제로 낼 수 있는 총추력은 투영 f·zB 입니다(9부).
  • 일 — 힘 F 가 변위 d 만큼 한 일은 F·d. 4부의 호버 일률이 그 연장입니다.
설명용

외적 — 두 벡터에 수직인 벡터

a × b = (a₂b₃ − a₃b₂,  a₃b₁ − a₁b₃,  a₁b₂ − a₂b₁)

기저로 보면 e₁×e₂ = e₃, e₂×e₃ = e₁, e₃×e₁ = e₂ — 오른손 법칙입니다. 세계 좌표(동·북·위)와 몸체 좌표(앞·왼쪽·위)가 둘 다 오른손 좌표계라서 이 식을 그대로 씁니다.

실행 검증

외적은 두 벡터에 수직이고, 순서를 바꾸면 뒤집힌다

쓰는 도구: 외적의 성분식, 내적의 정의.

증명
  1. (a×b)·a = a₁(a₂b₃ − a₃b₂) + a₂(a₃b₁ − a₁b₃) + a₃(a₁b₂ − a₂b₁). 정의대로 전개
  2. 여섯 항이 a₁a₂b₃ 와 −a₂a₁b₃ 처럼 둘씩 짝지어 지워지므로 0. 같은 계산이 (a×b)·b = 0 도 줍니다. 실수의 곱은 교환된다
  3. 성분식에서 a 와 b 를 바꾸면 세 성분 모두 두 항의 차례가 바뀌어 부호가 뒤집힙니다: b×a = −a×b.

어디에 썼나: 로터 추력이 만드는 토크 r×F(8부의 믹서), 추력 방향과 요 방향으로 몸체 축 세우기(9부).

실행 검증

라그랑주 항등식 — 외적의 크기는 사인

쓰는 도구: M1, M2의 성분식.

증명
  1. 외적의 성분은 세 쌍 (i, j) = (2,3), (3,1), (1,2) 의 aᵢbⱼ − aⱼbᵢ 이므로 |a×b|² = Σi<j (aᵢbⱼ − aⱼbᵢ)². 부호는 제곱에서 사라진다
  2. 펼치면 Σi<j (aᵢ²bⱼ² + aⱼ²bᵢ²) − 2Σi<j aᵢbᵢaⱼbⱼ.
  3. (a·b)² = Σᵢ aᵢ²bᵢ² + 2Σi<j aᵢbᵢaⱼbⱼ. 합의 제곱
  4. 2와 3을 더하면 교차항이 지워지고 Σi≠j aᵢ²bⱼ² + Σᵢ aᵢ²bᵢ² = (Σᵢaᵢ²)(Σⱼbⱼ²) = |a|²|b|².
  5. M1 을 넣으면 |a×b|² = |a|²|b|²(1 − cos²θ) = |a|²|b|² sin²θ, 그리고 0 ≤ θ ≤ π 에서 sin θ ≥ 0.
실행 검증

코시-슈바르츠 부등식

쓰는 도구: M3.

증명
  1. M3 에서 (a·b)² = |a|²|b|² − |a×b|² ≤ |a|²|b|². 크기의 제곱은 0 이상
  2. 양변은 음이 아니므로 제곱근을 취해 |a·b| ≤ |a||b|.
  3. 등호는 a×b = 0 일 때, 곧 한쪽이 0 이거나 sin θ = 0(나란함)일 때뿐입니다.

어디에 썼나: 바로 다음의 삼각 부등식, 그리고 10부의 할당 증명.

행렬 — 벡터를 바꾸는 표

곱 · 행렬식 · 가우스 소거 · 계수 · 직교 행렬

행렬은 벡터를 벡터로 보내는 규칙

3×3 행렬 A 에 벡터를 곱하면 각 행과 벡터의 내적이 새 성분이 됩니다: (Ax)ᵢ = Σⱼ Aᵢⱼxⱼ. 회전, 좌표 바꾸기, 추력 넷을 힘·토크로 바꾸는 믹서가 모두 이 꼴입니다.

실행 검증

행렬 곱 — 변환 둘을 잇기

(AB)ᵢₖ = Σⱼ AᵢⱼBⱼₖ — A 의 i 행과 B 의 k 열의 내적입니다. 코드는 B 를 전치해 열을 행처럼 꺼냅니다.

순서가 중요합니다. 일반적으로 AB ≠ BA. 먼저 롤로 돌리고 피치로 돌린 것과 그 반대는 다른 자세입니다(8부).
실행 검증

곱은 결합된다 — 그래서 변환을 이을 수 있다

쓰는 도구: 합의 순서 바꾸기(유한 합).

증명
  1. ((AB)x)ᵢ = Σₖ (AB)ᵢₖxₖ = Σₖ Σⱼ AᵢⱼBⱼₖxₖ. 곱의 정의 두 번
  2. 유한 합은 순서를 바꿔도 되므로 = Σⱼ Aᵢⱼ (Σₖ Bⱼₖxₖ) = Σⱼ Aᵢⱼ (Bx)ⱼ = (A(Bx))ᵢ.

뜻: "먼저 B, 다음 A" 를 한 번에 하는 행렬이 AB 입니다. 8부의 회전 합성이 이것입니다.

실행 검증

3×3 행렬식 — 첫 행으로 펼치기

det A = A₁₁(A₂₂A₃₃ − A₂₃A₃₂) − A₁₂(A₂₁A₃₃ − A₂₃A₃₁) + A₁₃(A₂₁A₃₂ − A₂₂A₃₁)

기하학적 뜻은 다음 장의 정리가 줍니다 — 세 열벡터가 만드는 평행육면체의 부피(부호 포함)입니다.

실행 검증

행렬식은 세 열의 삼중곱이다

쓰는 도구: M2 의 외적 성분식. 가정 없음 — 모든 3×3 행렬에서 성립합니다.

증명
  1. 열이 a, b, c 이면 A₁₁ = a₁, A₁₂ = b₁, A₁₃ = c₁, 둘째 행은 a₂, b₂, c₂ … 를 앞 장의 식에 넣습니다.
  2. det = a₁(b₂c₃ − c₂b₃) − b₁(a₂c₃ − c₂a₃) + c₁(a₂b₃ − b₂a₃).
  3. a₂ 와 a₃ 로 묶어 다시 쓰면 a₁(b₂c₃ − b₃c₂) + a₂(b₃c₁ − b₁c₃) + a₃(b₁c₂ − b₂c₁).
  4. 괄호 셋이 바로 b×c 의 세 성분이므로 det = a·(b×c).
실행 검증

행렬식의 부호와 크기

  • 크기 — |b×c| 는 밑면의 넓이(M3), a 와의 내적은 그 위의 높이를 곱합니다. 그래서 |det| 는 세 열이 만드는 상자의 부피입니다.
  • 0 — 세 열이 한 평면에 누우면 부피가 0 입니다. 그런 행렬은 어떤 방향을 지워 버리므로 거꾸로 풀 수 없습니다.
  • 음수 — 오른손 좌표계를 왼손으로 뒤집는 거울입니다. 두 축을 맞바꾸는 행렬의 det 가 −1 인 것이 그 예입니다.
  • 드론에서 — 회전은 부피도 방향도 지키므로 det = +1(5부 T4), 오일러각의 비율 행렬은 피치 ±90° 에서 det = 0 이 되어 짐벌 락이 생깁니다(T5).
설명용

가우스 소거 — 손으로 한 번

연립방정식 두 개를 풉니다. 한 식의 배를 다른 식에서 빼 미지수를 하나씩 없앤 뒤, 뒤에서부터 대입합니다.

2x + y = 3   (1)
x + 3y = 5   (2)
(2) − ½·(1):  2.5y = 3.5  →  y = 1.4
(1) 에 대입:  2x = 3 − 1.4  →  x = 0.8

첫 식의 x 계수 2 를 피벗이라 부릅니다. 피벗으로 나눈 배(여기서는 ½)를 아래 식에서 빼는 것이 소거 한 걸음입니다. 3×3 이상도 같은 걸음을 열마다 되풀이할 뿐입니다.

같은 문제가 시뮬레이터의 시험(test_linalg.test_solve_small)에 그대로 들어 있습니다.

설명용

실행 검증

피벗이 0 이면 — 줄을 바꾼다

y = 2,  x + y = 3 을 적힌 차례대로 소거하면 첫 피벗(첫 식의 x 계수)이 0 이라 나눌 수 없습니다. 해는 멀쩡히 있는데 방법이 막힌 것입니다.

그래서 코드는 열마다 절댓값이 가장 큰 행을 피벗으로 끌어올립니다. 0 을 피할 뿐 아니라, 0 에 가까운 수로 나눠 반올림 오차가 커지는 것도 막습니다.

도함수 — 순간의 변화율

f′(t) = limh→0 (f(t+h) − f(t))/h. 위치의 도함수가 속도, 속도의 도함수가 가속도입니다. 이 덱은 위치를 네 번 미분한 스냅까지 씁니다(10부).

다항식은 규칙 하나로 미분합니다: (tn)′ = ntn−1. 시뮬레이터는 다항식을 계수 목록으로 들고, 미분은 계수에 차수를 곱해 한 칸 당기는 것이고, 값은 호너 법으로 셉니다.

곱의 미분과 연쇄 법칙

증명 스케치

스케치입니다 — 극한의 엄밀한 정의(ε–δ)는 쓰지 않습니다.

  1. 곱: f(t+h)g(t+h) − f(t)g(t) = [f(t+h) − f(t)]g(t+h) + f(t)[g(t+h) − g(t)] 을 h 로 나누고 h → 0.
  2. 연쇄: [f(g(t+h)) − f(g(t))]/h 를 [f(g+Δg) − f(g)]/Δg · Δg/h 로 쪼갭니다(Δg = 0 인 경우는 따로 다뤄야 합니다 — 이 덱에서는 생략).

예: d/dt sin(ωt) = ω cos(ωt) — 진동수가 ω 인 신호를 미분하면 크기가 ω 배가 됩니다. 9부에서 D항이 고주파 잡음을 키우는 까닭이 이 한 줄입니다(T22).

작은 각 근사 — 오차가 얼마나 작은가

쓰는 도구: 적분의 단조성(작은 함수의 적분이 작다), (sin)′ = cos, (cos)′ = −sin, (tan)′ = 1 + tan². 가정: 0 ≤ θ ≤ 1(라디안) — 음수 쪽은 홀짝성으로 같습니다.

증명
  1. cos t ≤ 1 을 0 부터 θ 까지 적분하면 sin θ ≤ θ.
  2. sin t ≤ t 를 적분하면 1 − cos θ ≤ θ²/2 — cos 의 오차가 O(θ²).
  3. 1 − cos t ≤ t²/2 를 적분하면 θ − sin θ ≤ θ³/6 — sin 의 오차가 O(θ³).
  4. tan 은 [0, 1] 에서 아래로 볼록(tan″ = 2 tan·sec² ≥ 0)하고 tan 1 < 2 이므로 현 아래에 있습니다: tan t ≤ 2t. 가정 θ ≤ 1 을 여기서 쓴다
  5. tan θ − θ = ∫0θ tan²t dt ≤ ∫ 4t² dt = 4θ³/3 — tan 의 오차도 O(θ³).

  4. 그래서 y 는 상수 y(0) = x₀ 이고 x = x₀eat.

복소 평면 · eiθ · 감쇠 진동 · 회전으로서의 곱

복소수 — 평면 위의 점

i² = −1 인 수 i 를 들이면 모든 2차방정식이 근을 가집니다. z = a + bi 는 평면의 점 (a, b) 이고, 크기 |z| = √(a² + b²), 켤레 z̄ = a − bi, zz̄ = |z|².

  • 덧셈은 벡터처럼 성분끼리.
  • 곱은 (a+bi)(c+di) = (ac − bd) + (ad + bc)i — 크기는 곱하고, 각은 더합니다(다음 장).
  • 실수 계수 다항식의 복소 근은 켤레 쌍으로 나옵니다: s² + 2s + 5 의 근은 −1 ± 2i.
설명용

오일러 공식

증명 스케치

스케치입니다 — 급수의 수렴은 따지지 않습니다.

  1. ex = Σ xn/n! 에 x = iθ 를 넣으면 i 의 거듭제곱이 1, i, −1, −i 로 돕니다.
  2. 짝수 차 항을 모으면 cos θ 의 급수, 홀수 차 항을 모으면 i sin θ 의 급수입니다.
  3. 그래서 |eiθ| = 1, 그리고 s = σ + iω 이면 est = eσt(cos ωt + i sin ωt), 크기는 eσt.
설명용

복소 근은 흔들림, 실수부는 줄어듦

근이 σ ± iω 이면 두 복소 해를 더하고 빼서 실수 해 둘을 얻습니다.

x(t) = eσt(A cos ωt + B sin ωt)
  • ω — 흔들림의 각진동수. 한 번 흔들리는 데 2π/ω 초.
  • σ — 흔들림의 크기가 줄어드는(σ < 0) 빠르기. 시상수 1/|σ|.
  • 9부의 초과량 공식 e−πζ/√(1−ζ²) 은 반 주기(π/ω) 동안 eσt 가 얼마나 줄었는지를 적은 것입니다.
설명용

복소수의 곱은 평면의 회전 — 쿼터니언의 예고

eiθ 를 곱하면 크기는 그대로, 각만 θ 더해집니다. 평면의 회전을 수의 곱 하나로 적은 것입니다.

  • 두 회전을 잇기: eiαeiβ = ei(α+β) — 곱이 곧 합성입니다.
  • 되돌리기: 켤레를 곱합니다.
  • 3차원 회전을 같은 방식으로 적으려면 허수 단위가 셋(i, j, k) 필요합니다. 그것이 쿼터니언이고, 곱의 순서가 중요해진다는 점(ij = −ji)만 다릅니다 — 5부 T6.

뉴턴의 법칙 · 토크 · 각운동량

힘이 가속도를, 토크가 각가속도를 만든다

힘은 더해지고, 합이 가속도를 만든다

드론 한 대에 걸리는 힘은 넷입니다: 로터의 추력(몸체 위쪽), 중력(세계 아래쪽), 공기 저항(속도 반대쪽), 바람. 벡터로 더한 합을 질량으로 나눈 것이 가속도입니다.

mv̇ = R(q)(0, 0, F) − mge₃ − cv + f바람

호버는 합이 0 인 상태 — 추력이 중력과 같고(F = mg) 몸체가 수평입니다(L19). 모터를 끄면 추력이 0 이 되어 가속도는 −g 입니다. 이때 가속도계는 0 을 읽습니다(L20, 5부).

설명용

토크 — 힘이 비트는 정도

원점에서 r 만큼 떨어진 곳에 힘 F 가 걸리면 토크는 τ = r × F 입니다. 크기는 |r||F| sin θ(M3) — 팔이 길수록, 힘이 팔에 수직일수록 셉니다.

쿼드로터의 팔 끝 로터가 위로 미는 추력 (0, 0, T) 가 자리 (x, y, 0) 에서 만드는 토크는 (yT, −xT, 0) — 롤과 피치만 비틀고 요는 못 비틉니다. 요는 로터의 반토크가 맡습니다(4부 T3).

설명용

각운동량 — 토크가 없으면 변하지 않는다

쓰는 도구: M11(곱의 미분 — 외적에도 성립), M2(평행한 벡터의 외적은 0), M20.

증명
  1. L′ = r′ × mv + r × mv′. 외적의 곱의 미분(순서를 지킨다)
  2. r′ = v 이므로 첫 항은 v × mv = 0. M2: 자기 자신과의 외적
  3. mv′ = F 이므로 둘째 항은 r × F. M20

점 질량을 여럿 묶은 강체로 옮기면 8부의 회전 방정식 Jω̇ = τ − ω × Jω 가 됩니다(T8). 증인 시험은 토크 없이 도는 강체의 각운동량이 세계 좌표에서 멈춰 있는 것을 봅니다.

질량이 가속을 버티듯 관성 모멘트는 각가속을 버팁니다. 점 질량 m 이 축에서 r 떨어져 있으면 그 축의 관성은 mr² 이고, 강체는 그 합입니다.

  • 쿼드로터의 무거운 부분(모터 넷)은 팔 끝에 있습니다. 그래서 요 축(수직) 관성이 가장 크고, 롤·피치 축 관성은 X 배치의 대칭 때문에 같습니다.

오일러 · RK4 · 오차의 차수

오일러 방법 — 지금의 기울기로 한 걸음

해를 식으로 못 쓰는 비선형 방정식(드론 전체)은 작은 걸음 dt 로 나눠 나아갑니다. 가장 단순한 것은 지금의 기울기를 걸음 내내 쓰는 것입니다: xn+1 = xn + dt·f(xn).

기울기가 걸음 동안 변하면 그만큼 어긋납니다. 걸음당 어긋남은 dt² 에 비례하고, 걸음이 1/dt 개이므로 끝의 오차는 dt 에 비례합니다(1차).

실행 검증

RK4 — 기울기 넷을 섞는다

걸음의 처음, 가운데 두 번, 끝에서 기울기를 재어 1 : 2 : 2 : 1 로 섞습니다. 한 걸음에 계산이 네 배 들지만 오차는 dt⁴ 에 비례해, 같은 정확도를 훨씬 큰 걸음으로 얻습니다.

실행 검증

오차의 차수를 수로 확인하기

걸음을 반으로 줄이면 오일러의 오차는 2배, RK4 는 16배 줄어듭니다 — 1차와 4차입니다. dt 가 클 때(0.2) RK4 의 비가 17 을 넘는 것은 "차수" 가 dt 가 작을 때의 이야기이기 때문입니다.

실행 검증

증명 스케치

RK4 의 한 걸음을 dt 로 테일러 전개하면(M13) 참 해의 전개와 dt⁴ 항까지 같습니다. 해가 3차 이하 다항식이면 4계 이상 도함수가 0 이라 남는 차이가 없습니다. 네 단계의 전개를 모두 적는 것은 길어서 이 덱은 생략합니다.

실행 검증

  • 가장 빠른 부분은 모터입니다(τm = 0.03 s). 걸음 0.002 s 면 시상수 하나에 15 걸음 — 앞 장의 표에서 모델과 식의 차이는 10⁻⁷ 대였습니다.
  • 제어기는 250 Hz(4 ms)로 돕니다. 물리 걸음이 그 반이라 제어 한 번에 물리 두 걸음이 딱 맞습니다(SPEC §5).
  • 쿼터니언은 걸음마다 다시 정규화합니다. 적분이 크기를 조금씩 바꾸기 때문입니다 — 5부 T7 이 그 크기를 정확히 셉니다.

최소와 분산 — 추정의 도구

이차함수의 최소 · 분산의 규칙 · 정규분포

이차함수는 꼭짓점에서 가장 작다

쓰는 도구: 완전제곱. 가정: a > 0.

증명
  1. ak² − 2bk + c = a(k − b/a)² + c − b²/a. 전개해 확인
  2. 제곱은 0 이상이고 a > 0 이므로 첫 항은 k = b/a 에서만 0, 다른 곳에서는 양수입니다. 가정 a > 0 을 여기서 쓴다 — a < 0 이면 꼭짓점은 최대

어디에 썼나: 5부의 칼만 이득(T24) — 두 추정을 섞는 비율 K 에 대한 분산이 K 의 이차함수입니다.

실행 검증

분산의 규칙

증명 스케치

분산의 정의 Var Z = E[(Z − EZ)²] 에 Z = aX + bY 를 넣어 펼치면 교차항 2ab E[(X−EX)(Y−EY)] 이 남는데, 독립이면 이 기댓값이 0 입니다. 독립에서 그 기댓값이 0 이라는 사실은 확률론의 정리로 두고 증명하지 않습니다.

예: 분산 1 인 독립 측정 둘을 평균하면 Var((X+Y)/2) = ¼ + ¼ = ½ — 측정을 늘리면 떨림이 줍니다. 떨림(표준편차)은 √N 으로 줄어듭니다.

설명용

정규분포 난수 — 두 언어가 같은 수를 뽑는다

센서 잡음은 정규분포로 흉내 냅니다. 균등 난수 둘을 박스-뮬러 변환으로 바꿉니다. 난수 생성기는 파이썬과 자바스크립트가 비트까지 같은 수를 내도록 손으로 만들었습니다(15부).

실행 검증

두 추정을 섞기 — 칼만의 예고

분산 P 인 예측과 분산 R 인 측정이 있습니다. 둘을 (1−K)·예측 + K·측정 으로 섞으면 분산은 (서로 독립일 때) M24 로

(1 − K)²P + K²R

이고, 이것은 K 의 이차함수라 M23 이 가장 좋은 K 를 줍니다. 그 답 K = P/(P+R) 이 칼만 이득입니다 — 5부 T24 가 이 계산을 끝까지 합니다.

실제로 일어난 일 — 이 덱의 작업 지시서는 처음에 "제곱 거리 합이 가장 작은 할당은 경로가 엇갈리지 않는다" 를 정리로 적었습니다. 증인 시험을 쓰다가 엇갈린 채로 두는 편이 제곱 거리 합이 더 작은 반례가 나왔습니다. 그래서 정리를 참인 문장으로 고쳤습니다 — 엇갈리지 않는 것은 그냥 거리의 합이고(T30), 제곱 거리는 대신 충돌 회피를 보장합니다(T31). 반례는 L24 로 남겼습니다.
