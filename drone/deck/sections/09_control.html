피드백 — 재고, 비교하고, 고친다

열린 루프 · 닫힌 루프 · 오차

열린 루프와 닫힌 루프

열린 루프는 "호버 회전수를 내라" 처럼 결과를 보지 않고 명령합니다. 조금만 어긋나도(모터 1 %) 어긋남이 쌓입니다. 닫힌 루프는 결과(자세·위치)를 재어 목표와 비교하고, 그 차이 — 오차 — 로 다음 명령을 정합니다.

오차 e = 목표 r − 측정 y  →  명령 u = C(e)  →  기체  →  새 측정 y
  • 제어기 C 가 할 일은 오차를 0 으로 몰고 가는 것, 그리고 몰고 가는 동안 넘치거나 흔들리지 않는 것입니다.
  • 측정에는 잡음이 있고(5부), 명령에는 한계가 있고(8부의 포화), 기체는 늦게 반응합니다(모터 지연). 이 부의 모든 어려움이 이 셋에서 나옵니다.
설명용

가장 단순한 피드백 — 1차 계에 P 제어

x′ = −x + u 인 계에 u = k(1 − x) 를 걸면 x′ = −(1+k)x + k. M16 으로 x 는 k/(1+k) 에 시상수 1/(1+k) 로 다가갑니다.

이득을 키우면 빨라지고 오차가 줄지만, 0 은 되지 않습니다. 오차가 있어야 명령이 나오는 구조이기 때문입니다. 이 오차를 지우는 것이 4장의 적분항입니다.

실행 검증

1장 퀴즈

A. (1) 명령에 한계가 있습니다 — 큰 이득은 작은 오차에도 모터 한계를 넘는 명령을 내 포화됩니다. (2) 드론은 1차 계가 아닙니다 — 모터 지연과 적분기 사슬 때문에 이득을 키우면 넘치고 흔들리다 불안정해집니다(5장, 12장의 실패 사례). 측정 잡음도 이득만큼 커져 모터를 흔듭니다.

1차 계 — 시상수 하나로 요약되는 느림

계단 응답 · 모터 지연 · 닫은 뒤의 시상수

1차 계의 계단 응답

쓰는 도구: M16. 이 정리는 M16 을 드론의 말로 다시 읽은 것입니다 — 모터 회전수, 1차 저역 통과 필터, P 로 닫은 1차 계가 모두 이 꼴입니다.

증명
  1. τx′ = u − x, x(0) = 0, u 일정 — M16 의 가정 그대로입니다.
  2. M16 이 x = u(1 − e−t/τ) 를 줍니다. 목표에 63 % 닿는 시각이 τ, 95 % 가 약 3τ.
  3. P 로 닫은 앞 장의 계는 x′ = −(1+k)x + k — 같은 꼴에 τ 만 1/(1+k) 로 줄었습니다. 피드백이 느린 계를 빠르게 만듭니다.

2차 계와 PD — 초과량 공식

감쇠비 ζ · 고유 진동수 ωn · 초과량 · 정착 시간

관성이 있으면 넘친다 — 이중 적분기에 PD

8부의 선형 모델에서 각 축은 이중 적분기입니다(힘 → 가속도 → 속도 → 위치). 위치만 보고 밀면(P) 목표를 지나쳐 영원히 흔들립니다(7부의 x″ + 4x = 0). 속도로 브레이크를 걸면(D) 흔들림이 줄어듭니다.

ẍ = kp(r − x) − kdẋ   ⟹   s² + kds + kp = 0

이름을 붙이면 kp = ωn², kd = 2ζωn. ωn 은 빠르기, ζ(감쇠비)는 흔들림의 정도입니다. ζ < 1 이면 복소 근 — 흔들리며 다가가고(7부 5장), ζ ≥ 1 이면 넘치지 않습니다.

설명용

초과량 공식

쓰는 도구: M18(해의 꼴), M19, M11. 가정: 0 < ζ < 1, 계단 목표 r = 1, 정지에서 출발.

증명
  1. 오차 e = x − 1 은 ë + kdė + kpe = 0, e(0) = −1, ė(0) = 0.
  2. 근은 σ ± iωd, σ = −ζωn, ωd = ωn√(1−ζ²). 가정 ζ < 1 — 판별식이 음수
  3. M18 로 e = eσt(A cos ωdt + B sin ωdt). 초기값에서 A = −1, B = σ/ωd.
  4. 미분하면 cos 항의 계수 σA + ωdB 가 0 이고 ė = (ωn²/ωd)eσt sin ωdt. M11. σ² + ωd² = ωn²
  5. ė 는 t = π/ωd 에서 처음으로 부호를 바꾸므로 그때가 최고점입니다.
  6. e(π/ωd) = eσπ/ωd·(−1)·cos π = e−πζ/√(1−ζ²) — 이것이 초과량입니다.
실행 검증

초과량을 수로 — 공식과 측정

  • 측정과 공식이 다섯째 자리까지 같습니다.
  • ζ 가 작으면 크게 넘치고 오래 흔들립니다(ζ = 0.2 에서 53 %, 9.8 초).
  • ζ = 1 이면 넘치지 않지만 느리게 다가갑니다. 2 % 정착이 가장 빠른 것은 ζ = 0.8 근처 — 조금 넘치게 두는 편이 빨리 끝납니다.
실행 검증

  • ζ = 0.707 은 4 % 남짓 넘치고 곧 가라앉습니다. ζ = 1 은 넘치지 않지만 끝이 느립니다.

적분항은 일정한 외란을 지운다

쓰는 도구: M19, T14. 가정: 외란 d 는 일정, 닫은 계가 안정(정상상태에 닿는다).

증명
  1. PD: ẍ = kp(1 − x) − kdẋ + d. 정상상태(ẍ = ẋ = 0)에서 0 = kp(1 − x) + d, 곧 오차 1 − x = −d/kp.
  2. PID: 상태에 z = ∫(1 − x) 를 더하면 ż = 1 − x.
  3. 안정하다는 가정으로 모든 상태가 멈추면 ż = 0, 곧 x = 1 — d 가 무엇이든. 안정성 가정을 여기서 쓴다
  4. 그때 적분항 kiz 가 −d 를 맡아 외란을 떠받칩니다.
실행 검증

외란 아래 PD 와 PID — 그리고 포화

이중 적분기에 외란 d = −0.5(아래로 끄는 힘)를 걸고 kp = 4, kd = 3 으로 목표 1 에 세웁니다.

  • PD 는 0.875 에 멈춥니다 — 1 − 0.5/4 = 0.875, 정리대로입니다.
  • PID 는 1 에 닿지만 24 % 넘칩니다. 적분이 쌓이는 동안 넘칠 힘도 쌓입니다.

적분 포화(wind-up)

증명
  1. 출력이 한계에 붙어 있는 동안 기체는 한계만큼만 반응하고, 오차는 줄지 않습니다.
  2. 그동안 적분은 계속 오차를 더합니다 — 필요한 것보다 훨씬 큰 값이 쌓입니다.
  3. 목표에 닿아 오차가 부호를 바꿔도, 쌓인 적분이 풀릴 때까지 출력은 여전히 한쪽으로 밀립니다 — 그만큼 지나칩니다.
실행 검증

막는 법 — 적분에 한계를

증명
  1. 코드는 매 걸음 I ← clamp(I + edt, −Imax, Imax) 로 자릅니다.
  2. 그래서 늘 |I| ≤ Imax 이고 적분항은 kiImax 를 넘지 않습니다.

안정 판정 — 3차 라우스

근을 구하지 않고 계수만 보고

이중 적분기에 PID 를 걸면 3차

PD 는 2차였지만 적분을 더하면 상태가 하나 늘어 특성다항식이 3차가 됩니다.

ẍ = −kpx − kdẋ − ki∫x  ⟹  s³ + kds² + kps + ki = 0

3차 방정식의 근의 공식은 손으로 쓰기 어렵습니다. 그런데 안정 여부만 알고 싶다면 계수만 보면 됩니다.

설명용

라우스 판정 (3차)

쓰는 도구: M18, M19, 중간값 정리(연속함수가 부호를 바꾸면 그 사이에 근 — 증명 없이 씀).

증명 — 인수분해
  1. 계수가 모두 양수이면 s ≥ 0 에서 p(s) > 0 이라 0 이상의 실근은 없습니다. s → −∞ 에서 p → −∞, p(0) = a₀ > 0 이므로 음의 실근 −c(c > 0)가 있습니다.
  2. 나누면 p(s) = (s + c)(s² + bs + e), 펼치면 a₂ = b + c, a₁ = e + bc, a₀ = ce.
  3. 2차 인수의 근이 모두 왼쪽에 있을 필요충분조건은 b > 0 이고 e > 0 (근의 공식과 M19).
  4. e = a₀/c > 0 은 늘 성립합니다. 남은 조건은 b > 0 하나입니다.

증명은 다음 장에 이어집니다.

라우스 판정 — b 의 부호가 곧 a₂a₁ − a₀ 의 부호

증명 — 계산
  1. a₂a₁ − a₀ = (b + c)(e + bc) − ce = b(e + bc + c²) = b(a₁ + c²).
  2. a₁ + c² > 0 이므로 a₂a₁ > a₀ ⟺ b > 0 — 앞 장과 합치면 "안정 ⟺ a₂a₁ > a₀". 계수가 양수라는 가정
  3. 거꾸로, 근이 모두 왼쪽이면 p 는 c, b, e 가 모두 양수인 꼴로 나뉘고, 2단계의 펼친 식에서 계수가 모두 양수이며 1단계의 식이 a₂a₁ − a₀ > 0 을 줍니다.

4차 이상의 일반 라우스-후르비츠 판정은 이 덱에서 쓰지도 증명하지도 않습니다.

Q. PID 의 적분 이득을 키우면 정상 오차가 더 빨리 지워집니다. 라우스 판정은 여기에 어떤 한계를 긋나요?

설명용

왜 겹치나 — 바깥은 안쪽을 "명령대로 되는 것" 으로 본다

안쪽 루프가 충분히 빠르면, 바깥 루프가 보기에 "각속도를 이만큼 내라" 는 명령은 곧장 이루어집니다. 그러면 바깥 루프는 복잡한 안쪽을 잊고 단순한 계(적분기 하나)를 제어하면 됩니다. 이 가정이 성립하는 조건을 정리로 적은 것이 T17 입니다.

  • 장점: 루프마다 따로 튜닝할 수 있고, 각 층에서 한계(기울기, 각속도, 속도)를 따로 걸 수 있습니다.
  • 대가: 안쪽이 바깥보다 확실히 빨라야 합니다. 그렇지 않으면 가정이 깨져 넘치고 흔들립니다.
설명용

시간 척도 분리 — 1차 루프 두 개로 좁혀 증명

쓰는 도구: M18, √(1−ε) 의 두 부등식(아래 3단계에서 증명). 가정: 안쪽을 1차 계 ẏ = b(u − y), 바깥을 ẋ = y, u = k(r − x) 로 좁힘, b ≥ 4k > 0.

증명
  1. 합치면 ẍ = b(k(r−x) − ẋ), 특성다항식 s² + bs + bk, 근 (−b ± b√(1−ε))/2, ε = 4k/b ≤ 1. b ≥ 4k 라서 실근
  2. 느린 근은 s = −(b/2)(1 − √(1−ε)).
  3. 0 ≤ ε ≤ 1 에서 1 − ε/2 − ε²/2 ≤ √(1−ε) ≤ 1 − ε/2: 오른쪽은 (1−ε/2)² = 1 − ε + ε²/4 ≥ 1 − ε, 왼쪽은 제곱해 정리하면 (ε+3)(ε−1) ≤ 0.
  4. 그래서 ε/2 ≤ 1 − √(1−ε) ≤ ε/2 + ε²/2, 곱하면 k ≤ |s| ≤ k(1 + 4k/b).
  5. 안쪽을 1 로 본 바깥 루프 ẋ = k(r − x) 의 극은 −k. 차이는 상대적으로 4k/b 이하 — b ≫ k 이면 사라집니다.

쿼터니언 자세 제어

오차 쿼터니언 · P 법칙 · 닫힌 해 · 감소 자세 · SE(3)

자세 오차를 쿼터니언 하나로

지금 자세 q, 원하는 자세 qd. 둘의 차이는 "지금에서 원하는 곳까지 몸체 좌표로 얼마나 돌아야 하나" 이고, 그것이 qe = q−1 ⊗ qd 입니다(T6: 곱은 합성, 역은 되돌림).

  • qe 의 벡터 부분은 sin(θ/2)·축, 스칼라 부분은 cos(θ/2) — θ 는 돌아야 할 각입니다.
  • q 와 −q 는 같은 회전이라, qe 의 스칼라가 음수면 부호를 뒤집어 "짧은 쪽" 으로 돌게 합니다(canonical).
  • P 법칙: ω명령 = 2k·sign(qe,w)·qe,xyz — 축 방향으로, 남은 각에 비례해 돌린다.
설명용

쿼터니언 P 법칙은 오차각을 단조롭게 줄인다

쓰는 도구: L2, T6, M11, M15 의 논법. 가정: 각속도가 명령을 곧장 따른다(운동학 모델 — T17 의 시간 척도 분리가 이것을 정당화), qd 는 일정, θ < π.

증명
  1. q̇ = ½q ⊗ (0, ω) 의 켤레를 취하면 q̇e = −½(0, ω) ⊗ qe. T6 — 켤레는 곱의 차례를 뒤집는다
  2. qe = (w, v), ω = 2k sign(w)v 를 넣으면 ω ∥ v 라 외적이 사라지고 v̇ = −k|w|v. 가정 "곧장 따른다"
  3. v 는 방향을 그대로 둔 채 크기만 줄어듭니다 — 축이 변하지 않습니다.
  4. |w| = cos(θ/2), |v| = sin(θ/2) 이므로 ½cos(θ/2)θ̇ = −k cos(θ/2) sin(θ/2), 곧 θ̇ = −2k sin(θ/2) < 0. θ < π 라 cos(θ/2) ≠ 0
  5. g = ln tan(θ/4) 를 미분하면 ġ = θ̇/(2 sin(θ/2)) = −k. 그래서 tan(θ/4) = tan(θ₀/4)e−kt. M11 — 연쇄 법칙과 배각 공식
실행 검증

닫힌 해와 적분 — 오차각 2.5 rad 에서

차이가 10⁻¹² 대 — 증명한 식이 시뮬레이터의 적분과 끝자리까지 맞습니다. 큰 오차에서는 sin(θ/2) 가 θ/2 보다 작아 선형 법칙보다 느리게, 작은 오차에서는 거의 e−kt 로 줄어듭니다.

D항과 필터 — 미분은 잡음을 키운다

주파수에 비례하는 이득 · 1차 저역 통과 · 펌웨어의 D항 필터

D항은 주파수만큼 키우고, 필터가 누른다

쓰는 도구: M11, M16, M17(복소 지수로 정상 진동 풀기).

증명
  1. d/dt A sin(ωt) = Aω cos(ωt) — 진폭이 ω 배. 느린 신호(비행)는 작게, 빠른 잡음(진동·센서)은 크게 키웁니다. M11
  2. 필터 τẏ = u − y 에 u = eiωt 를 넣고 y = Yeiωt 를 찾으면 Y(1 + iωτ) = 1. M17 — 복소 지수는 미분해도 모양이 같다
  3. 그래서 진폭비 |Y| = 1/√(1 + (ωτ)²). 실수 신호 sin 은 이 복소 해의 허수 부분입니다.
  4. ω ≪ 1/τ 이면 거의 1, ω ≫ 1/τ 이면 약 1/(ωτ) — D 와 합치면 높은 주파수의 이득이 1/τ 에서 멈춥니다.
실행 검증

필터를 단 D — 주파수마다의 이득

1/τ = 200 rad/s 에서 필터 이득이 1/√2 가 됩니다. 필터가 없으면 1000 rad/s 잡음이 1000 배로 커지는데, 필터를 달면 196 배에서 멈춥니다. 그 대신 필터는 D항을 조금 늦춥니다 — 필터 시상수를 루프보다 충분히 짧게 잡는 까닭입니다.

실행 검증

잡음 섞인 측정의 D — 필터의 효과

0.5 Hz 사인(비행)에 표준편차 0.01 의 잡음(센서)을 섞고, 250 Hz 로 D 를 계산합니다. 신호만의 몫과 잡음의 몫을 나눠 봅니다.

잡음 0.01 은 신호 크기 1 의 1 % 에 불과한데, 필터가 없으면 D 출력의 흔들림 가운데 잡음의 몫(3.6)이 신호의 몫(2.2)보다 큽니다. τ = 5 ms 필터가 그것을 3 분의 1 로 줄이고 신호는 거의 건드리지 않습니다.

실행 검증

레이싱 펌웨어는 D항을 어떻게 거르나 — 발췌

Betaflight 는 D항에 쓸 자이로 값을 노치 필터 하나와 저역 통과 필터 둘에 차례로 통과시킵니다. 측정값(자이로)을 미분한다는 점(L5)도 같습니다.

Q. τ = 0.01 s 필터는 100 rad/s 잡음을 얼마로 줄이나요?

A. ωτ = 1 이라 1/√2 ≈ 0.707.

9장 퀴즈

Q. D 필터의 시상수를 크게 할수록 잡음은 줄어듭니다. 그런데 왜 무한히 키우지 않나요?

A. 필터가 D항을 늦춥니다. 시상수가 루프의 흔들림 주기와 비슷해지면 D 가 "지금의 속도" 가 아니라 "조금 전의 속도" 로 브레이크를 걸어, 감쇠 대신 지연을 더하게 됩니다 — 흔들림이 오히려 늘 수 있습니다. 필터 시상수는 제어하려는 흔들림보다 확실히 빠르게, 잡음보다는 느리게 둡니다.

1 m 계단 — 위치 · 속도 · 기울기

2 초 뒤 목표를 1.4 % 넘었다가 돌아옵니다. 위치 루프가 속도를 요구하고, 속도 루프가 기울기를 요구하는 차례가 수에 보입니다 — 기울기가 먼저 커졌다 줄고, 속도가 뒤따르고, 위치가 마지막입니다. 표는 0.5 초 간격이라 기울기의 봉우리를 놓칩니다 — 다음 장의 그림.

실행 검증

같은 계단을 20 ms 간격으로

  • 기울기의 봉우리는 0.28 초의 약 20° 입니다. 표의 0.5 초 7° 는 이미 내려오는 중입니다.
  • 0.6 초에 기울기가 0 을 지납니다 — 반대쪽으로 기울어 브레이크를 걸기 시작한 순간입니다. 그래서 1 초의 5° 는 미는 기울기가 아니라 멈추는 기울기입니다.
실행 검증

요 90° — 제자리에서 돌기

요는 1.5 초에 84°, 3 초에 90° 에 닿습니다. 요 이득이 롤·피치의 절반이고 요 토크 자체가 약해서(8부의 포화 표) 기울기보다 한참 느립니다. 도는 동안 제자리에서 2 cm 안쪽으로만 벗어납니다.

실행 검증

일정한 바람 — 3차원에서 본 T15

동쪽으로 0.3 N 의 힘을 계속 주는 바람 속에서 제자리를 지킵니다. 속도 루프의 적분항이 있을 때와 없을 때.

적분항이 없으면 17 cm 밀려난 채 멈춥니다(PD 의 정상 오차). 있으면 20 초 뒤 4 mm 까지 되돌아옵니다 — 적분이 바람을 떠받칠 만큼 쌓이는 데 시간이 듭니다.

실행 검증

10 m 계단 — 한계가 모양을 정한다

위치 오차가 크면 위치 루프가 요구하는 속도가 한계(5 m/s)에 붙어 거의 일정한 속도로 갑니다. 목표 근처에서야 속도 요구가 줄어 기울기를 풀고 멈춥니다. 선형 분석(초과량 공식)은 이런 한계 구간을 모릅니다 — 한계는 설계의 일부입니다.

10장 퀴즈

Q. 계단 표에서 기울기가 가장 큰 시각(0.5 초)과 속도가 가장 큰 시각이 다릅니다. 캐스케이드의 구조로 설명해 보세요.

A. 속도는 기울기(가속도)를 적분한 것이라, 기울기가 양수인 동안 속도는 계속 늘어납니다. 기울기가 0 으로 돌아오는 순간이 속도가 가장 큰 순간이고, 그 뒤 기울기가 반대로 서며 감속합니다. 적분기 사슬에서 한 단계 바깥의 양은 늘 한 박자 늦게 최대에 닿습니다.

  • 안쪽이 빨라야 한다 — 주기가 아니라 대역폭(이득)으로.
