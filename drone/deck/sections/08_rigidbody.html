문서 근거

자세 = 몸체 축을 세계에서 본 것

회전행렬 R 의 세 열은 몸체의 x·y·z 축을 세계 좌표로 적은 것입니다. 몸체 좌표의 벡터 vB 는 vW = RvB 로 세계로 옵니다.

  • R 은 직교하고 det = 1(T4)이라 거꾸로는 전치 RT 입니다. 가속도계가 재는 비력을 몸체로 옮길 때 씁니다(L20).
  • 시뮬레이터는 R 대신 단위 쿼터니언 q 를 상태로 들고, 필요할 때 vW = q ⊗ vB ⊗ q* 로 돌립니다(T6).

각속도 — 몸체 좌표로 잰다

자이로스코프는 드론에 붙어 있으므로 각속도를 몸체 좌표로 잽니다: ω = (p, q, r), 롤·피치·요 축 둘레의 빠르기(rad/s)입니다.

자세는 이 각속도로 변합니다. 몸체에 붙은 어떤 벡터 u 가 세계에서 보면 u̇ = ωW × u 로 돌고, 쿼터니언은 q̇ = ½ q ⊗ (0, ω) 로 변합니다(T7). 몸체 좌표의 ω 를 쿼터니언의 오른쪽에 곱하는 것이 요점입니다 — 세계 좌표의 ω 라면 왼쪽입니다.

뉴턴-오일러 회전 방정식

쓰는 도구: M21(각운동량과 토크), L3, M2. 가정: J 는 몸체에 고정된 대각 행렬(주축 좌표) — 모양이 변하지 않는 강체.

증명 — 방정식
  1. 세계에서 본 각운동량 H = RJω 의 변화율은 세계 토크입니다: Ḣ = Rτ. M21 을 점 질량마다 더함 — 내부의 힘은 짝지어 지워진다고 둔다
  2. L3 에서 Ḣ = R(Jω̇ + ω × Jω). J 가 몸체에 고정이라는 가정 — 몸체에서 본 J 의 변화율은 0
  3. 두 식에서 R 을 떼면(R 은 가역, T4) Jω̇ = τ − ω × Jω.

증명은 다음 장에 이어집니다 — 보존 법칙.

토크가 없으면 무엇이 보존되나

쓰는 도구: M2(외적은 두 벡터에 수직), M1, M11.

증명 — 보존
  1. 에너지 E = ½ω·Jω. J 가 대각이므로 Ė = ω·Jω̇. 대각 가정을 여기서 쓴다 — 대칭이면 충분
  2. 토크가 0 이면 Jω̇ = −ω × Jω, 그리고 ω·(ω × Jω) = 0. 그래서 Ė = 0. M2
  3. d/dt |Jω|² = 2Jω·Jω̇ = −2Jω·(ω × Jω) = 0. M2 — Jω 에도 수직
  4. 세계에서 본 H 는 1단계에서 τ = 0 이므로 벡터째로 멈춰 있습니다 — 몸체에서 보면 도는데, 세계에서 보면 가만히 있습니다.

가운데 축은 불안정하다 — 테니스 라켓 정리

가장 작은 관성 축이나 가장 큰 관성 축 둘레의 회전은 조금 흔들어도 그대로입니다. 가운데 축 둘레의 회전은 작은 흔들림이 자라 몸체가 뒤집힙니다.

가운데 축(y)으로 던진 것만 다른 축 각속도가 2 까지 자라고, 원래 축의 각속도가 −2 까지 뒤집힙니다. 방정식에 이미 들어 있는 성질이라 시뮬레이터가 따로 가르쳐 주지 않아도 나옵니다. 쿼드로터는 요 축 관성이 가장 커서 요 둘레 회전은 안정한 쪽입니다.

실행 검증

드론에서 자이로 항은 얼마나 큰가

  • 쿼드로터는 롤과 피치 관성이 같습니다(Jxx = Jyy). 그래서 ω × Jω 의 z 성분 (Jyy − Jxx)pq 가 정확히 0 입니다.
  • 롤·피치 성분은 요 각속도가 있을 때만 생깁니다: (Jzz − Jyy)qr 꼴. 쇼 드론은 요를 천천히 돌리므로 작습니다.
  • 그래서 이 덱의 제어기는 자이로 항을 앞먹임하지 않습니다(SPEC §5.5). 빠르게 뒤집는 레이싱 드론이라면 이야기가 다릅니다.

호버 회전수와 추력 대 중량비

twr ≈ 3.9 는 "무게의 네 배 가까이 밀 수 있다" 는 뜻입니다. 남는 추력이 기울기와 가속에 쓰이고, 바람을 버티는 여유가 됩니다.

믹서 — 추력 넷이 만드는 것

총추력은 합, 롤·피치 토크는 7부의 r × (0, 0, T) = (yT, −xT, 0), 요 토크는 반토크의 합입니다.

F = T₁ + T₂ + T₃ + T₄
τx = a(T₁ + T₂ − T₃ − T₄)
τy = a(−T₁ + T₂ + T₃ − T₄)
τz = c(−T₁ + T₂ − T₃ + T₄),   c = kQ/kT
실행 검증

기준 쿼드로터의 믹서 행렬

요 줄의 계수(c ≈ 0.01)가 롤·피치 줄(a ≈ 0.08)보다 여덟 배쯤 작습니다. 같은 추력 차이로 요는 훨씬 약하게 돕니다 — 반토크는 추력보다 작은 효과이기 때문입니다. 이 차이가 곧 "요는 가장 먼저 포기한다" 는 설계로 이어집니다(몇 장 뒤).

제어가 없으면 — 모터 하나가 1 % 셀 때

호버 상태에서 로터 1 만 회전수를 1 % 올리고, 나머지는 호버 회전수 그대로 둡니다. 제어기는 없습니다.

1 % 의 추력 차이가 롤·피치 토크를 만들고, 토크는 각가속도, 각속도, 기울기를 차례로 키웁니다. 기울면 추력이 옆으로 새어 옆으로 미끄러지고, 높이도 잃습니다. 멀티로터는 스스로 서 있지 못하는 기계입니다 — 그래서 9부가 있습니다.

실행 검증

기울기에서 위치까지 — 적분기 넷

토크를 넣으면 무엇이 몇 번 적분되어 위치가 되는지 세어 봅니다.

토크 → (÷J) 각가속도 → ∫ 각속도 → ∫ 기울기 → (×g) 수평 가속도 → ∫ 속도 → ∫ 위치

적분이 네 번입니다. 적분 하나마다 반응이 한 박자 늦어지므로, 위치를 곧장 토크로 잡으려 하면 느리고 불안정합니다. 그래서 제어기는 이 사슬을 안쪽부터 한 고리씩 닫습니다 — 각속도, 자세, 속도, 위치(9부 캐스케이드).

호버 선형화

쓰는 도구: M14(작은 각), T4(회전행렬의 열). 가정: 총추력 mg, 요 0, 기울기는 롤 또는 피치 하나.

증명

미분 평탄성 — 궤적이 입력을 정한다

가속도가 추력을, 요가 자세를, 가가속도가 각속도를

궤적을 알면 나머지가 다 정해진다

위치의 궤적 p(t) 와 요 ψ(t) 를 (충분히 매끄럽게) 정하면, 그것을 따라 나는 데 필요한 총추력·자세·각속도가 미분만으로 정해집니다. 이 성질을 미분 평탄성이라 부르고, 네 수 (x, y, z, ψ)를 평탄 출력이라 합니다.

  • 가속도 a = p̈ → 추력의 크기와 방향.
  • 추력 방향 + 요 → 자세.
  • 가가속도 j = p⃛ + 요 변화율 → 몸체 각속도.

이 성질 덕분에 10부는 궤적을 위치만으로 설계하고(최소 스냅), 9부의 제어기는 그 미분을 앞먹임합니다. 이 결과는 Mellinger·Kumar 가 쿼드로터에 대해 보였습니다.

문서 근거

추력 방향과 요가 자세를 하나로 정한다

쓰는 도구: M2, M3. 가정: zB 가 요 방향 수평벡터 xC 와 나란하지 않다(드론이 옆으로 90° 눕지 않는다).

증명
  1. yB = zB × xC / |zB × xC| 는 둘에 수직인 단위벡터입니다. M2. 분모가 0 이 아니라는 가정을 여기서 쓴다
  2. xB = yB × zB 는 두 단위벡터의 외적으로 둘에 수직이고, 사이각이 90° 라 크기 1 입니다. M3
  3. 세 벡터는 서로 수직인 단위벡터이고 xB × yB = zB(오른손)라 이들을 열로 둔 행렬이 회전행렬입니다.
  4. xB 는 xC 와 zB 가 펼치는 평면에 있으므로(yB 에 수직), 기수를 수평면에 내린 방향이 ψ 입니다.

미분 평탄성 — 추력과 자세

쓰는 도구: M20, L26, M11, L3. 가정: 항력과 바람을 뺀 모델, a + ge₃ ≠ 0(자유낙하가 아니다), L26 의 가정.

증명 — 추력과 자세
  1. 힘은 추력(몸체 z)과 중력뿐이므로 ma = FzB − mge₃, 곧 FzB = m(a + ge₃). M20, 항력을 뺀다는 가정
  2. zB 는 단위벡터이고 추력은 위로만 미므로(F > 0) F = m|a + ge₃|, zB = (a + ge₃)/|…|. 0 이 아니라는 가정 — 나눌 수 있다
  3. zB 와 ψ 가 정해졌으니 L26 이 자세 전체를 정합니다.

각속도는 다음 장에서 — 이 식을 한 번 더 미분합니다.

미분 평탄성 — 각속도는 가가속도에서

쓰는 도구: M11(몫의 미분), L3(몸체에 붙은 벡터의 미분 żB = ω × zB, 세계 성분으로), M2.

증명 — 각속도
  1. f = a + ge₃ 이면 ḟ = j. 단위벡터 zB = f/|f| 를 미분하면 h ≡ żB = (j − (zB·j)zB)/|f|. M11 — 크기가 변하는 몫을 빼면 수직 성분만 남는다
  2. 한편 ω = pxB + qyB + rzB 이면 żB = ω × zB = qxB − pyB. x×z = −y, y×z = x
  3. 두 식을 맞추면 p = −h·yB, q = h·xB — r 은 zB 만 봐서는 안 보입니다.
  4. r 은 L26 의 구성 yB·xC = 0 을 미분해 얻습니다: ẏB·xC + yB·ẋC = 0, ẋC = ψ̇yC.
  5. xC = αxB + βzB(yB 에 수직이므로)로 쓰면 ẏB·xC = (ω×yB)·xC = −αr + βp. M2 의 성분 계산
  6. 그래서 r = (βp + ψ̇ yB·yC)/α. α ≠ 0 — L26 의 가정에서 xB 는 xC 쪽을 본다

평탄성을 코드로 — 그리고 수치 미분과 대조

흔히 인용되는 간단한 식 r = ψ̇·(e₃·zB) 는 이 구성에서 정확하지 않습니다 — 원 궤적의 표에서 r 이 요 변화율 0.3 과 조금씩 다른 것이 보입니다. 이 덱은 증명한 식만 씁니다.

궤적의 미분을 제어기에 미리 알려 주면(앞먹임), 제어기는 오차가 생긴 뒤에야 반응하지 않아도 됩니다. 반지름 2 m·0.8 rad/s 의 원을 네 단계로 따라 납니다.

  • 속도 앞먹임으로 1.28 m → 0.36 m, 가속도까지 넣으면 0.09 m.
  • 가가속도(각속도) 앞먹임은 항력이 있을 때 오히려 조금 나빠졌습니다. 항력이 없으면 약간 좋아집니다 — 남은 오차의 주인은 제어기가 모르는 항력이지 가가속도가 아닙니다.

예상과 다른 결과도 그대로 싣습니다. 무엇이 남은 오차를 만드는지 가르는 실험(항력 0)을 함께 둔 것이 요점입니다.

Q. 반지름 2 m 의 원을 0.8 rad/s 로 도는 드론은 얼마나 기울어야 하나요? T12 의 1–2단계로 구하세요.

A. 구심 가속도 rω² = 2·0.64 = 1.28 m/s² 가 수평, 중력 보상 g 가 수직이라 기울기는 atan(1.28/9.81) ≈ 7.4°.

7장 퀴즈

Q. 평탄성으로 궤적을 설계할 때 가가속도가 불연속인 궤적(예: 가속도가 계단처럼 바뀌는 사다리꼴)은 무엇이 문제인가요?

A. 가가속도가 순간적으로 무한대가 되어, T12 가 요구하는 몸체 각속도(p, q)가 무한대가 됩니다. 실제 드론은 자세를 순간 이동할 수 없으므로 그 구간에서 궤적을 놓칩니다. 10부의 최소 스냅 궤적이 가가속도와 스냅까지 연속인 까닭입니다.

Q. 이 부의 모델에 없는 것 셋을 대고, 각각이 시뮬레이션 결과를 어느 쪽으로 틀리게 할지 말해 보세요.

A. (1) 로터끼리·지면과의 공기 간섭(다운워시, 지면 효과) — 쇼처럼 여러 대가 가까이 날 때 추력이 모델보다 약하거나 흔들립니다(13부 T35). (2) 배터리 전압이 떨어지는 것 — 같은 명령에서 추력이 줄어 끝으로 갈수록 느려집니다. (3) 프로펠러의 비틀림·진동 — 센서 잡음이 늘어 D항이 더 흔들립니다(9부). 모델은 이런 것을 모른다고 알고 써야 합니다.
