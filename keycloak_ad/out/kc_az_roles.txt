$ 역할을 하나 만든다: lunch-admin
  name         "lunch-admin"
  description  "학식 메뉴를 고칠 수 있다"
  composite    false
  clientRole   false

$ 그룹 lunch-admins 에 그 역할을 붙인다
  (붙였다 — 이제 그 그룹의 사람은 자동으로 그 역할을 갖는다)

$ 소희 — ID 토큰과 액세스 토큰을 나란히
  [ID 토큰]
  preferred_username admin.lee
  groups             ["campus-all", "lunch-admins", "lunch-users"]
  realm_access.roles []
  토큰 길이           1167글자 (내용 534바이트)

  [액세스 토큰]
  preferred_username admin.lee
  groups             ["campus-all", "lunch-admins", "lunch-users"]
  realm_access.roles ["default-roles-campus", "lunch-admin", "offline_access", "uma_authorization"]
  토큰 길이           1521글자 (내용 799바이트)

$ 민지 — 액세스 토큰
  [액세스 토큰]
  preferred_username minji
  groups             ["campus-all", "lunch-users"]
  realm_access.roles ["default-roles-campus", "offline_access", "uma_authorization"]
  토큰 길이           1471글자 (내용 762바이트)

**역할은 ID 토큰에 없다.** 기본 client scope 인 roles 가
액세스 토큰에만 싣기 때문이다. ID 토큰에도 넣으려면
그 매퍼의 "Add to ID token" 을 켜야 한다.
