시작과 계보부터 "2026-09 기준" 의 모습까지

이 부의 날짜는 모두 기계로 모은 것입니다 — 저장소의 첫 커밋, GitHub 릴리스, 위키의 첫 리비전, 공지 글. 사건 하나가 data/timeline.tsv 의 한 줄이고, 줄마다 출처가 붙어 있습니다(전체 표는 17부 부록). 누가 무엇을 했는지는 파일에 적힌 이름만 씁니다.

2025년 이후의 일은 모두 2026-09 기준입니다 — 이 덱을 만든 때의 모습이고, 그 뒤에 바뀌었을 수 있습니다.

1장

2015 — 시작

패키지 빌드 스크립트(termux-packages)가 6월에 먼저, 앱(termux-app)은 10월에 첫 커밋과 첫 릴리스 v0.17 을 같은 날 냈습니다. 그해가 가기 전에 API·Styling·Widget 이 붙었습니다. 여러 저장소의 첫 커밋 작성자는 같은 사람입니다.

출처: 각 저장소의 첫 커밋(git) · GitHub 릴리스 API · data/people.tsv

계보 — Android Terminal Emulator

termux-app 의 README 와 LICENSE 는 터미널 처리가 jackpal 의 Android Terminal Emulator 에 기반하고 그 Apache-2.0 코드를 쓴다고 적습니다. 4부에서 본 터미널 에뮬레이터 모듈의 뿌리입니다.

출처: termux-app README · LICENSE.md

2장

2016~2017 — 플러그인과 위키

7부의 플러그인 대부분이 이때 태어났고, 셔뱅 문제를 푸는 termux-exec 가 2017-09 에 나왔습니다(5부). 위키는 2017-07-04 의 첫 리비전에서 시작해 "Differences from Linux" 같은 이 덱이 자주 인용한 문서들이 그해에 생겼습니다.

역사 자료

termux-app 의 릴리스 — 해마다

2016~2021 에 몰려 있고, 0.118 이후로는 드뭅니다. 최신 안정판은 v0.118.3(2025-05-22, 2026-09 기준)입니다.

역사 자료

3장

2019~2020 — targetSdk 28 에 멈추다

2019-01 의 v0.66 부터 targetSdk 는 28 에 멈췄습니다. 29 이상은 앱 홈의 파일을 execve() 할 수 없기 때문입니다(5부). Google Play 는 더 높은 targetSdk 를 요구하므로, Play 판은 v0.101 에서 멈추고 F-Droid·GitHub 가 주 배포처가 됐습니다.

역사 자료

minSdk 와 targetSdk 의 걸음

minSdk 는 v0.76(2019-10-20)에 21 → 24(Android 7) 로 올랐습니다 — README 의 "Android 7 이상" 이 여기서 옵니다.

역사 자료

4장

2021~2022 — 팬텀 프로세스와 0.118

2021-10 의 이슈 #2366 이 "signal 9" 의 시작입니다(8부). 2022-01 의 v0.118.0 은 모든 파일을 누구나 읽던 취약점을 고쳤고, 30일 뒤 세 취약점이 함께 공개됐습니다(14부). 같은 해 7월, 공식 저장소에 없는 패키지를 모으는 TUR 이 termux-packages 를 포크해 시작했습니다(6부).

역사 자료

5장

2023~2024 — glibc, Play 복귀, 보조금

2023-09 에 glibc 로 지은 패키지를 위한 저장소(glibc-packages)가 생겼고, 2024-06 에 Termux 가 Android 11 이상용으로 Google Play 에 돌아왔습니다 — 이번에는 별도 저장소에서, sharedUserId 없이(1부). 2024-11 에는 NLnet 의 NGI Mobifree 보조금 선정이 공지됐습니다.

역사 자료

6장

2025~2026 — 지금(2026-09 기준)

앱의 최신 안정판은 여전히 v0.118.3(2025-05) 이고, 플러그인들은 2025-09 에 판을 올렸습니다. termux-exec 2.5.0 과 proot-distro 5.8.0 은 2026 년 여름에 나왔습니다. 2026-08-31 부터 Google Play 는 새 앱·업데이트에 API 36 이상을 요구합니다 — targetSdk 28 에 머문 F-Droid 판과의 거리는 더 벌어졌습니다(2026-09 기준).

2부 퀴즈

Q. "Termux 는 왜 Google Play 에서 오래 업데이트되지 않았나?" 를 이 부의 사건 셋으로 설명해 보세요.

A. ① Android 10 부터 targetSdk 29 이상 앱은 앱 홈의 파일을 실행할 수 없다(W^X). ② Termux 는 그래서 v0.66 부터 targetSdk 28 에 머물렀다. ③ Google Play 는 더 높은 targetSdk 를 요구해 Play 판은 v0.101 에서 멈췄고, 2024-06 에야 정책에 맞춰 크게 고친 별도 빌드로 돌아왔다.
