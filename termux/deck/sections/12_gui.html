활용 III: GUI 와 데스크톱

터미널 너머 — 창이 뜨는 리눅스

Termux 는 터미널 앱이지만 X 윈도 프로그램도 돌립니다. 화면에 그리려면 X 서버가 따로 있어야 하고, 그 자리를 Termux:X11 앱이나 VNC 가 채웁니다.

이 기기에는 X11 관련 패키지가 하나도 없고, 이 덱은 새로 깔지 않았습니다. 그래서 이 부는 문서와 소스, 그리고 "없다" 는 캡처로 씁니다. 화면을 찍은 그림은 없습니다.

1장

이 기기의 출발점

X11 패키지는 별도 저장소에 있습니다. 위키: pkg install x11-repo 가 sources.list 파일과 PGP 키를 더하고, 그 패키지를 지우면 저장소도 빠진다. 이 기기의 목록에는 main 과 TUR 만 있습니다(6부).

출처: 캡처 · 위키 Graphical Environment 1절

이 기기 캡처

2장

Termux:X11 — NDK 로 지은 X 서버

README: "완전한 X 서버이고, 안드로이드 NDK 로 지어 Termux 에 맞췄다." 어떻게 동작하나 — "다른 X 서버와 똑같이." Android 8 이상, 안드로이드 앱(nightly 릴리스의 APK)과 x11-repo 의 termux-x11-nightly 패키지를 둘 다 깔아야 합니다(7부). 처음이라면 README 는 XFCE 데스크톱(pkg i xfce)부터 권합니다.

출처: termux-x11 README 1.1·1.3·1.4

문서

띄우는 법

README 의 기본형:

  • termux-x11 :1 -xstartup "dbus-launch --exit-with-session xfce4-session"
  • 또는 termux-x11 :1 & 뒤 env DISPLAY=:1 dbus-launch --exit-with-session xfce4-session
  • TERMUX_X11_XSTARTUP 을 .bashrc 에 두면 매번 적지 않아도 된다.

기기 탓의 문제 두 가지에 옵션이 있습니다: 검은 화면에 커서만 보이면 -legacy-drawing, 색이 뒤바뀌면 -force-bgra. 알림의 "Exit" 로 창을 닫아도 termux-x11 명령은 계속 돈다는 점도 README 가 짚습니다.

출처: termux-x11 README 1.5

문서

화면 밖의 앱은 느려진다 — sharedUid APK

README 의 경고: 안드로이드는 화면에 없는 앱에 CPU 시간을 덜 준다. Termux:X11 이 열리면 Termux 자신은 "화면에 없는 앱" 이 되어 그 안의 데스크톱 프로그램이 느려질 수 있다. 그래서 …-sharedUid-debug.apk 판이 있다 — Termux 의 일부로 돌아 한 앱으로 취급된다. 단 GitHub 에서 받은 Termux 에서만 된다. F-Droid·Google Play 판은 서명 키가 달라 공유 uid 를 쓸 수 없다(4부의 sharedUserId 와 같은 규칙).

출처: termux-x11 README 1.4.1

문서

3장

proot 배포판에서 쓰려면 — /tmp 를 나눠야 한다

README 1.6: proot 로 쓸 거라면 proot-distro 를 --shared-tmp 로 띄워야 한다(안 되면 TMPDIR 을 컨테이너의 /tmp 에 맞춰라). X 서버와 프로그램이 소켓을 같은 /tmp 에서 찾기 때문입니다.

소스 발췌

이 세션의 /tmp 는 따로다

9부의 명령줄에는 $PREFIX/tmp:/tmp 바인드가 없었고, 두 /tmp 의 inode 도 다릅니다. 이 세션은 --shared-tmp 없이 떴습니다. 여기서 X 프로그램을 띄워 Termux:X11 에 그리려면 세션을 다시 띄우거나 README 의 TMPDIR 우회를 써야 합니다.

이 기기 캡처

4장

VNC — 오래된 길

위키 "Graphical Environment" 의 방법: tigervnc 를 깔고 vncserver -localhost. 처음에 비밀번호(최대 8자)를 묻고, 디스플레이 :1 이 생기면 DISPLAY=":1". 안드로이드의 VNC 뷰어로 127.0.0.1:5901 에 붙는다 — 포트는 5900 + 디스플레이 번호.

-localhost 는 같은 폰 안에서만 붙게 하는 옵션입니다. 11부의 웹 서버처럼 바깥에 열지 않는 쪽이 기본입니다.

출처: 위키 Graphical Environment 2절

문서

창 관리자와 데스크톱

위키가 꼽는 창 관리자는 Fluxbox·Openbox, 데스크톱 환경은 XFCE·LXQt·MATE 입니다. 소리는 Termux 의 PulseAudio 패키지가 맡고(그래서 앱이 권하는 PULSE_SERVER 를 따로 둘 필요가 없다고 위키는 적는다), proot-distro 는 Termux 에서 PULSE_SERVER=127.0.0.1 을 손님 환경에 기본으로 넣습니다.

출처: 위키 Graphical Environment 4·5·6절 · proot-distro README 1.3.5.2

그래픽 가속

위키(Graphical Environment)는 "하드웨어 가속은 기본으로 지원되지 않는다" 고 적습니다. 이 문서가 언제 쓰였는지와 그 뒤의 변화(GPU 가속 드라이버들)는 이 덱이 출처를 확보하지 못해 다루지 않습니다 — 미확인.

12부 퀴즈

Q. F-Droid 에서 받은 Termux 를 쓰는 사람이 데스크톱이 느리다며 termux-x11-universal-sharedUid-debug.apk 를 깔려고 합니다. 무슨 일이 생기고, 대신 무엇을 해야 할까요?

A. 공유 uid 는 같은 서명 키를 요구하는데 F-Droid 판 Termux 는 F-Droid 의 키로 서명되어 있어 함께 쓸 수 없습니다(README 1.4.1 · 4부). sharedUid 판을 쓰려면 Termux 와 플러그인을 모두 지우고 GitHub 판으로 다시 깔아야 하고 — 이때 $HOME 도 지워지니 8부의 백업이 먼저입니다 — 아니면 일반 APK 를 그대로 쓰고 느림을 받아들입니다.
