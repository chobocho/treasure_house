CHAPTER 1

B+트리란 무엇인가?

모든 데이터를 잎에 모으고, 잎을 연결 리스트로 이은 B-트리의 진화형

B-트리는 키와 데이터를 모든 노드에 흩어 두지만, B+트리는 실제 데이터(값)를 잎 노드에만 둡니다. 내부 노드는 길을 안내하는 라우터(분리 키)만 가집니다.

  • 모든 값은 리프에 존재 (내부 키는 잎에 중복 등장 가능)
  • 리프들은 연결 리스트로 이어져 있어 범위 검색이 매우 빠름
  • 내부 노드는 키만 담아 한 블록에 더 많은 가지를 → 더 납작
  • 모든 검색은 항상 리프까지 내려감 (경로 길이 일정)
예시 — 차수 m=4 (잎끼리 주황 점선으로 연결)
맨 아래 줄이 리프(데이터), 위쪽은 라우터. 주황 점선이 리프를 잇는 next 포인터입니다.
CHAPTER 2

B-트리 vs B+트리

왜 데이터베이스는 대부분 B+트리를 쓰는가
항목B-트리B+트리
데이터 위치모든 노드리프에만
내부 노드키+데이터라우터 키만
키 중복없음분리 키가 리프에 중복
리프 연결없음연결 리스트(next)
범위 검색중위 순회 필요리프 따라가기 (빠름)
분기 수보통더 큼(더 납작)
  • 범위 질의 (BETWEEN, ORDER BY): 시작 리프를 찾고 next로 쭉 훑으면 끝
  • 전체 스캔: 가장 왼쪽 리프 → next → ... 한 줄로 순회
  • 캐시/디스크 효율: 내부 노드가 키만 담아 한 페이지에 가지가 더 많음
  • 일관된 성능: 모든 조회가 같은 깊이(리프)에서 끝남
그래서 MySQL(InnoDB), PostgreSQL, Oracle, SQLite의 인덱스와 대부분의 파일시스템이 B+트리(또는 변형)를 채택합니다.
CHAPTER 3

구조와 규칙

차수 m 으로 정의되는 B+트리의 약속
차수(order) m
  • 모든 노드는 키가 최대 m-1개
  • 루트가 아닌 노드는 키가 최소 ⌈m/2⌉-1개
  • 내부 노드의 분리 키 s: 왼쪽 자식 < s ≤ 오른쪽 자식
  • 모든 리프는 같은 깊이, 그리고 next로 연결
  • 값(value)은 리프에만 저장
키 ∈ [⌈m/2⌉-1, m-1]  ·  자식 ∈ [⌈m/2⌉, m]
검색은 분리 키로 길을 찾는다
내부 노드에서 찾는 키 k가 분리 키 s에 대해 k < s면 왼쪽, k ≥ s면 오른쪽으로 내려갑니다. 분리 키와 같은 값은 오른쪽 잎에 실제로 들어 있습니다.
CHAPTER 4 · 검색

검색 (Search)

반드시 리프까지 내려가서 값을 찾는다

내부 노드에서는 분리 키로 자식을 고르고, 리프에 도착하면 그 안에서 키를 찾습니다. 값이 잎에만 있으므로 검색은 항상 리프까지 내려갑니다.

  • 내부: k ≥ key[i] 인 동안 i 증가 → child[i]
  • 리프 도착 후 키 일치하면 값 반환 (초록=경로, 빨강=도착)
  • 없으면 실패 — 그래도 리프까지는 내려감
위 입력칸에 키를 넣고 검색을 눌러보세요.
CHAPTER 5 · 삽입 & 삭제

삽입과 삭제

잎에서 시작 — 넘치면 쪼개고, 모자라면 빌리거나 합친다
삽입 (Insert)
  • 알맞은 리프에 키-값 삽입 (이미 있으면 값 갱신)
  • 리프가 넘치면(m개) 분할: 오른쪽 절반을 새 잎으로, 첫 키를 복사해 위로
  • 새 잎을 next 사슬에 끼워 넣음
  • 내부 노드가 넘치면 가운데 키를 위로 올리며(복사 아님) 분할
삭제 (Delete)
  • 리프에서 키 제거 (라우터의 같은 키는 그대로 둬도 OK)
  • 리프가 모자라면(<최소) 형제에게서 빌리기
  • 양쪽 형제가 빠듯하면 형제와 병합 + next 사슬 보수
  • 루트가 비면 자식이 새 루트 → 높이 감소
B+트리 삭제는 리프 병합 시 next 포인터를 잊지 않고 이어주는 것이 포인트입니다.
CHAPTER 6 · 범위 검색

B+트리의 필살기 — 범위 검색

시작 잎을 찾고 next를 따라 쭉 — 이것이 B+트리를 쓰는 이유

SELECT * WHERE key BETWEEN lo AND hi 같은 질의는 lo가 있는 리프를 찾은 뒤 next 포인터를 따라가며 hi를 넘을 때까지 값을 줍습니다. 트리를 다시 오르내릴 필요가 없어 매우 빠릅니다.

범위 ~
lo ~ hi 를 넣고 범위 검색을 눌러보세요. 해당 잎 키가 초록으로 칠해집니다.
