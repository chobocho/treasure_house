왜 테트리스를 Rust 로?

✔ 잘 맞는 점

GC 멈춤이 없어 프레임이 고르다. 같은 코드가 네이티브와 WASM 으로 다 나간다. enum+match 가 게임 상태를 빠짐없이 다루게 강제한다.

✘ 각오할 점

빌림 검사기와의 첫 몇 주. 컴파일이 Go 보다 느리다. GUI 생태계가 아직 "정답 하나"로 모이지 않았다(3부에서 비교).

이 덱의 전략 — 규칙은 의존성 0 의 순수 Rust 로, 바깥(터미널·창·브라우저)만 얇게. 빌림 검사기와 싸울 일이 거의 없는 구조를 먼저 고르는 것이 Rust 다운 설계입니다.

코드를 읽기 전에 — 소유권 세 줄

  1. 값마다 주인이 하나 — 주인 변수가 범위를 벗어나면 값이 해제된다.
  2. 대입·인자 전달은 "이동" — 옛 변수는 더는 못 쓴다. 단, Copy 타입(정수, 작은 구조체)은 복사된다.
  3. 빌려 쓰기 — &T 는 여럿이 동시에 읽기, &mut T 는 한 명만 쓰기. 둘을 동시에 가질 수는 없다.

/// `Copy` 라서 함수에 넘겨도 "이동"되지 않고 복사된다.

    O,
    T,
    S,
    Z,
    J,

Rust 의 enum 은 닫혀 있다 — Kind 값은 일곱 중 하나뿐이고 다른 정수를 끼워 넣을 수 없습니다. 크기는 1바이트(아래 "크기 재기" 슬라이드).

#[derive(...)] — 손으로 안 쓰는 구현들

트레이트얻는 것다른 언어의 자리
Clone.clone() 으로 명시적 복제Java clone()
Copy대입·인자 전달이 이동이 아니라 비트 복사Go 의 값 타입, Java 의 int
Debug{:?} 로 찍기 (Kind::T → T)Java toString(), Python __repr__
PartialEq, Eq== 비교Java equals(), Python __eq__
HashHashMap 키로 쓰기Java hashCode()
derive 는 매크로 — 컴파일 시점에 impl Clone for Kind { ... } 같은 코드를 만들어 붙입니다. 런타임 리플렉션이 아닙니다. Java 의 Lombok, Python 의 @dataclass 와 같은 일을 컴파일러가 합니다.

    [(0, 1), (1, 1), (2, 1), (3, 1)], // I  ....
    [(0, 0), (1, 0), (0, 1), (1, 1)], // O  (2×2 상자)
    [(1, 0), (0, 1), (1, 1), (2, 1)], // T  .T. / TTT
    [(1, 0), (2, 0), (0, 1), (1, 1)], // S  .SS / SS.
    [(0, 0), (1, 0), (1, 1), (2, 1)], // Z  ZZ. / .ZZ
    [(0, 0), (0, 1), (1, 1), (2, 1)], // J  J.. / JJJ
    [(2, 0), (0, 1), (1, 1), (2, 1)], // L  ..L / LLL
];

impl Kind — 메서드

core/src/piece.rs

impl Kind {
    pub const ALL: [Kind; 7] = [
        Kind::I,
        Kind::O,
        Kind::T,
        Kind::S,
        Kind::Z,
        Kind::J,
        Kind::L,
    ];

    /// 표(배열)를 찾아볼 때 쓰는 번호. `as usize` 는 선언 순서.
    pub fn index(self) -> usize {
        self as usize
    }

    /// 회전 상자 한 변의 길이.
    pub fn box_size(self) -> i32 {
        match self {
            Kind::I => 4,
            Kind::O => 2,
            _ => 3,
        }
    }

    pub fn spawn_cells(self) -> [(i32, i32); 4] {
        SHAPES[self.index()]
    }

    /// 시험용 판 그림(`"..TT.."`)을 읽을 때 쓴다.
    pub fn from_char(c: char) -> Option<Kind> {
        Kind::ALL.into_iter().find(|k| k.to_char() == c)
    }

    pub fn to_char(self) -> char {
        b"IOTSZJL"[self.index()] as char
    }
}

회전 상태 — enum Rot

/// 회전 상태. SRS 의 0 · R · 2 · L 에 차례로 대응한다.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Rot {
    R0,
    R1,
    R2,
    R3,
}

impl Rot {
    const ORDER: [Rot; 4] = [Rot::R0, Rot::R1, Rot::R2, Rot::R3];

    pub fn cw(self) -> Rot {
        Rot::ORDER[(self.index() + 1) % 4]
    }

    pub fn ccw(self) -> Rot {
        Rot::ORDER[(self.index() + 3) % 4]
    }

    pub fn index(self) -> usize {
        self as usize
    }
}
R0·R1·R2·R3 은 SRS 문서의 0·R·2·L 입니다. 시계 방향은 +1, 반시계는 +3 (≡ −1 mod 4) — 음수 나머지를 피하는 흔한 요령입니다. const ORDER 처럼 impl 블록 안에 둔 상수를 연관 상수라고 부릅니다(Java 의 static final).

impl Piece {
    /// 가이드라인대로 3·4열 가운데, 맨 윗줄에서 나온다.
    pub fn spawn(kind: Kind) -> Piece {
        let x = if kind == Kind::O { 4 } else { 3 };
        Piece {
            kind,
            rot: Rot::R0,
            x,
            y: 0,
        }
    }

    /// 판 좌표로 바꾼 네 칸.
    ///
    /// 회전은 표를 따로 두지 않고 상자 안에서 계산한다.
    /// 시계 방향 90°: (x, y) → (n−1−y, x). SRS 의 상태와 정확히 같다.
    pub fn cells(&self) -> [(i32, i32); 4] {
        let n = self.kind.box_size();
        let mut out = self.kind.spawn_cells();
        for c in out.iter_mut() {
            for _ in 0..self.rot.index() {
                *c = (n - 1 - c.1, c.0);
            }
            *c = (c.0 + self.x, c.1 + self.y);
        }
        out
    }

    /// 옮긴 사본을 돌려준다. `self` 를 값으로 받으므로 원본은 그대로.
    pub fn moved(self, dx: i32, dy: i32) -> Piece {
        Piece {
            x: self.x + dx,
            y: self.y + dy,
            ..self
        }
    }
}

/// `from` 상태에서 돌릴 때 차례로 시험할 다섯 가지 이동(y 아래로).
pub fn kicks(kind: Kind, from: Rot, cw: bool) -> [(i32, i32); 5] {
    let table = match (kind, cw) {
        (Kind::O, _) => return [(0, 0); 5],
        (Kind::I, true) => &I_CW,
        (Kind::I, false) => &I_CCW,
        (_, true) => &JLSTZ_CW,
        (_, false) => &JLSTZ_CCW,
    };
    table[from.index()].map(|(dx, dy)| (dx, -dy))
}

fn reverse_rotation_kicks_are_negated() {
    // SRS 의 성질: A→B 킥 = −(B→A 킥)
    for k in [Kind::I, Kind::T, Kind::J] {
        for r in [Rot::R0, Rot::R1, Rot::R2, Rot::R3] {

            }
        }
    }
}

/// 판 그림으로 만든다. 줄들은 **바닥에 붙여** 놓는다.
///
/// ```
/// use tetris_core::{Board, Kind};
/// let b = Board::from_rows(&["T.........", "IIII......"]);
/// assert_eq!(b.get(0, 19), Some(Kind::I));
/// ```
///
/// 그림이 잘못되면 패닉한다 — 시험·예제 전용이라 `Result` 보다
/// 바로 터지는 쪽이 원인을 찾기 쉽다.
pub fn from_rows(text: &[&str]) -> Board {
    assert!(text.len() <= HEIGHT, "판은 {HEIGHT}줄까지");
    let mut b = Board::new();
    let top = HEIGHT - text.len();
    for (i, line) in text.iter().enumerate() {
        let n = line.chars().count();
        assert_eq!(n, WIDTH, "줄마다 {WIDTH}칸: {line:?}");
        for (x, c) in line.chars().enumerate() {
            let cell =
                match c {
                    '.' => None,
                    _ => Some(Kind::from_char(c).unwrap_or_else(
                        || panic!("모르는 칸 {c:?}"),
                    )),
                };
            b.rows[top + i][x] = cell;
        }
    }
    b
}

/// 조각을 판에 굳힌다. 네 칸이 모두 판 안에 들어왔으면 `true`,
/// 하나라도 위로 삐져나왔으면 `false`(lock out — 게임 오버).
pub fn lock(&mut self, p: &Piece) -> bool {
    let mut inside = true;
    for (x, y) in p.cells() {
        if y < 0 {
            inside = false;
        } else {
            self.rows[y as usize][x as usize] = Some(p.kind);
        }
    }
    inside
}

/// 꽉 찬 줄을 지우고 위를 내려 채운 뒤, 지운 줄 수를 돌려준다.
///
/// 아래에서 위로 한 번 훑으며 "남길 줄"을 `write` 위치로 복사한다.
/// O(WIDTH × HEIGHT) 시간, 추가 메모리 O(1).
pub fn clear_lines(&mut self) -> u32 {
    let mut write = HEIGHT;
    for read in (0..HEIGHT).rev() {
        let full = self.rows[read].iter().all(Option::is_some);
        if !full {
            write -= 1;
            self.rows[write] = self.rows[read];
        }
    }
    // write 위쪽은 지운 줄 수만큼 빈 줄로
    for row in &mut self.rows[..write] {
        *row = [None; WIDTH];
    }
    write as u32
}

clear_lines — 한 번 훑어 당겨 쓰기

바닥(y=19)부터 위로 읽으며, 꽉 차지 않은 줄만 write 자리에 복사합니다. 다 읽고 나면 write 위쪽이 지운 줄 수만큼 남고, 그 자리를 빈 줄로 채웁니다.

코드설명
(0..HEIGHT).rev()19, 18, … 0. 범위도 반복자

self.rows[write] = self.rows[read]줄(10바이트 배열)이 Copy 라 그냥 대입

/// xorshift64* — 상태 8바이트, 곱셈 한 번. 게임용으로 충분하다.
#[derive(Clone, Debug)]
pub struct Rng {
    state: u64,
}

impl Rng {
    pub fn new(seed: u64) -> Rng {
        // splitmix64 로 씨앗을 한 번 섞는다. 0·1·2 처럼 비슷한 씨앗도
        // 전혀 다른 수열이 되고, xorshift 가 갇히는 상태 0 을 피한다.
        let mut z = seed.wrapping_add(0x9E37_79B9_7F4A_7C15);
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        z ^= z >> 31;
        Rng {
            state: if z == 0 { 1 } else { z },
        }
    }

    pub fn next_u64(&mut self) -> u64 {
        let mut x = self.state;
        x ^= x >> 12;
        x ^= x << 25;
        x ^= x >> 27;
        self.state = x;
        x.wrapping_mul(0x2545_F491_4F6C_DD1D)
    }

    /// 0 이상 n 미만. 상위 32비트에 n 을 곱해 자른다(나눗셈 없음).
    /// 편향은 n/2³² 이하 — n ≤ 7 인 이 게임에서는 무시해도 된다.
    pub fn below(&mut self, n: u32) -> u32 {
        assert!(n > 0, "below(n) 는 n > 0 이어야 한다");
        (((self.next_u64() >> 32) * n as u64) >> 32) as u32
    }
}

/// 일곱 조각을 한 봉지에 넣고 섞어 차례로 꺼낸다. 같은 조각이
/// 오래 안 나오는 "가뭄"이 최대 12개로 묶인다.
#[derive(Clone, Debug)]
pub struct Bag {
    rng: Rng,
    queue: VecDeque<Kind>,
}

impl Bag {
    pub fn new(seed: u64) -> Bag {
        Bag::with_prefix(seed, &[])
    }

    /// `prefix` 를 먼저 내놓고 그다음부터 봉지. 시험에서 첫 조각을
    /// 정해 두는 데 쓴다.
    pub fn with_prefix(seed: u64, prefix: &[Kind]) -> Bag {
        let mut bag = Bag {
            rng: Rng::new(seed),
            queue: prefix.iter().copied().collect(),
        };
        bag.refill();
        bag
    }

/// 미리보기가 모자라지 않도록 큐를 언제나 7개 이상으로 유지한다.
fn refill(&mut self) {
    while self.queue.len() < 7 {
        let mut b = Kind::ALL;
        // 피셔–예이츠 셔플: O(n), 모든 순열이 같은 확률
        for i in (1..b.len()).rev() {
            let j = self.rng.below(i as u32 + 1) as usize;
            b.swap(i, j);
        }
        self.queue.extend(b);
    }
}

pub fn draw(&mut self) -> Kind {
    let k = self.queue.pop_front().expect("refill 이 큐를 채운다");
    self.refill();
    k
}

/// 다음에 나올 조각들(7개 이상). `&self` 라서 꺼내지 않고

}

/// 입력 하나를 처리한다. 실제로 무언가 바뀌었으면 `true`.
pub fn apply(&mut self, a: Action) -> bool {
    if self.over {
        return false;
    }
    if a == Action::Pause {
        self.paused = !self.paused;
        return true;
    }
    if self.paused {
        return false;
    }
    let ok = match a {
        Action::Left => self.try_move(-1, 0),
        Action::Right => self.try_move(1, 0),
        Action::SoftDrop => {
            let ok = self.try_move(0, 1);
            if ok {
                self.score += 1;
                self.fall_ms = 0;
            }
            ok
        }
        Action::HardDrop => {
            let dist = self.ghost().y - self.cur.y;
            self.score += 2 * dist as u32;
            self.cur = self.ghost();
            self.lock_piece();
            return true;
        }
        Action::RotateCw => self.rotate(true),
        Action::RotateCcw => self.rotate(false),
        Action::Hold => return self.swap_hold(),
        Action::Pause => unreachable!("위에서 처리했다"),
    };
    if ok && self.lock_ms > 0 && self.resets < MAX_LOCK_RESETS {
        // 바닥에서 움직이면 고정을 미뤄 준다 — 단, 무한히는 아니다
        self.lock_ms = 0;
        self.resets += 1;
    }
    ok
}

시간 흘리기 — tick

core/src/game.rs

/// 시간을 흘려보낸다. 바닥에 닿아 있으면 고정 지연을, 아니면
/// 중력을 센다. 큰 값이 와도 넘치지 않게 포화 덧셈을 쓴다.
pub fn tick(&mut self, dt_ms: u32) {
    if self.over || self.paused {
        return;
    }
    if self.grounded() {
        self.lock_ms = self.lock_ms.saturating_add(dt_ms);
        if self.lock_ms >= LOCK_DELAY_MS {
            self.lock_piece();
        }
        return;
    }
    self.lock_ms = 0;
    self.fall_ms = self.fall_ms.saturating_add(dt_ms);
    let g = Game::gravity_ms(self.level);
    while self.fall_ms >= g {
        self.fall_ms -= g;
        if !self.try_move(0, 1) {
            // 바닥에 닿았다. 남은 시간은 버리고 다음 tick 부터
            // 고정 지연을 센다.
            self.fall_ms = 0;
            break;
        }
    }
}

fn spawn(&mut self, kind: Kind) {
    self.cur = Piece::spawn(kind);
    self.fall_ms = 0;
    self.lock_ms = 0;
    self.resets = 0;
    if !self.board.fits(&self.cur) {
        self.over = true; // block out: 나올 자리가 막혔다
    }
}

fn lock_piece(&mut self) {
    let inside = self.board.lock(&self.cur);
    let n = self.board.clear_lines();
    self.last_clear = n;
    // 시험용 판은 처음부터 꽉 찬 줄을 여럿 가질 수 있다 → min(4)
    self.score += LINE_SCORE[n.min(4) as usize] * self.level;
    self.lines += n;
    self.level = self.lines / 10 + 1;
    self.hold_used = false;
    if !inside {
        self.over = true; // lock out: 판 위로 삐져나와 굳었다
        return;
    }
    let k = self.bag.draw();
    self.spawn(k);
}

fn swap_hold(&mut self) -> bool {
    if self.hold_used {
        return false;
    }
    // Option::replace — 새 값을 넣고 옛 값을 돌려받는다
    let next = match self.hold.replace(self.cur.kind) {
        Some(k) => k,
        None => self.bag.draw(),
    };
    self.spawn(next);
    self.hold_used = true;
    true
}

/// 게임 상태 → 글자 격자. 색 표는 픽셀 렌더러의 것을 같이 쓴다.
pub fn compose(game: &Game) -> Screen {
    use tetris_render::{BOARD_BG, OVERLAY, color};
    let mut s = Screen::new();
    let (board_bg, dot) = (rgb(BOARD_BG), rgb(0x3A_4258));

    // 판: 한 칸 = 글자 2개. 정사각형에 가깝게 보이려고.
    for y in 0..HEIGHT {
        s.put_str(0, y, "|", Color::Reset, Color::Reset);
        for x in 0..WIDTH {
            let cell = game.board().get(x as i32, y as i32);
            match cell {
                Some(k) => s.put_str(
                    1 + x * 2,
                    y,
                    "  ",
                    board_bg,
                    rgb(color(k)),
                ),
                None => s.put_str(1 + x * 2, y, " .", dot, board_bg),
            }
        }
        s.put_str(1 + WIDTH * 2, y, "|", Color::Reset, Color::Reset);
    }
    let bottom = format!("+{}+", "-".repeat(WIDTH * 2));
    s.put_str(0, HEIGHT, &bottom, Color::Reset, Color::Reset);

/// 패널에 조각 모양 하나. I 처럼 상자 둘째 줄에서 시작하는 모양도
/// 맨 윗줄에 붙도록 가장 작은 y 를 뺀다.
fn mini(s: &mut Screen, x: usize, y: usize, kind: Kind) {
    let cells = kind.spawn_cells();
    let top = cells.iter().map(|c| c.1).min().unwrap_or(0);
    let bg = rgb(tetris_render::color(kind));
    for (cx, cy) in cells {
        s.put_str(
            x + cx as usize * 2,
            y + (cy - top) as usize,
            "  ",
            Color::Reset,
            bg,
        );
    }
}

fn panel(game: &Game, s: &mut Screen) {
    let label = |s: &mut Screen, y, t: &str| {
        s.put_str(PANEL_X, y, t, Color::DarkGrey, Color::Reset);

/// 터미널에 쓴다. `prev` 가 없으면(첫 화면·창 크기 변경) 전부 그린다.
///
/// 커서가 이미 그 자리에 있으면 `MoveTo` 를, 색이 같으면 `SetColors` 를
/// 생략한다. `queue!` 는 버퍼에 쌓기만 하고 `flush` 때 한 번에 나간다.
pub fn present(
    out: &mut impl Write,
    prev: Option<&Screen>,
    next: &Screen,
) -> io::Result<()> {
    let changed: Vec<usize> = match prev {
        Some(p) => diff(p, next),
        None => {
            queue!(out, Clear(ClearType::All))?;
            (0..W * H).collect()
        }
    };
    if changed.is_empty() {
        return out.flush();
    }
    let mut cursor: Option<usize> = None;
    let mut colors: Option<(Color, Color)> = None;
    for i in changed {
        let c = next.cells[i];
        if cursor != Some(i) {
            queue!(out, MoveTo((i % W) as u16, (i / W) as u16))?;
        }
        if colors != Some((c.fg, c.bg)) {
            queue!(out, SetColors(Colors::new(c.fg, c.bg)))?;
            colors = Some((c.fg, c.bg));
        }
        queue!(out, Print(c.ch))?;
        // 행 끝에서는 커서가 다음 행으로 가지 않는다(터미널이 더 넓다)
        cursor = if i % W + 1 < W { Some(i + 1) } else { None };
    }
    queue!(out, ResetColor)?;
    out.flush()
}

pub fn key_to_command(key: KeyEvent) -> Option<Command> {
    // 윈도 콘솔은 누를 때와 뗄 때 두 번 보낸다. 뗄 때는 버린다.
    if key.kind == KeyEventKind::Release {
        return None;
    }
    // raw 모드에서는 Ctrl+C 가 시그널이 아니라 그냥 키로 온다
    let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
    if ctrl && key.code == KeyCode::Char('c') {
        return Some(Command::Quit);
    }
    let a = match key.code {
        KeyCode::Left => Action::Left,
        KeyCode::Right => Action::Right,
        KeyCode::Down => Action::SoftDrop,
        KeyCode::Up => Action::RotateCw,
        KeyCode::Char(' ') => Action::HardDrop,
        KeyCode::Esc => Action::Pause,
        KeyCode::Char(c) => match c.to_ascii_lowercase() {
            'x' => Action::RotateCw,
            'z' => Action::RotateCcw,
            'c' => Action::Hold,
            'p' => Action::Pause,
            'r' => return Some(Command::Restart),
            'q' => return Some(Command::Quit),
            _ => return None,
        },
        _ => return None,
    };
    Some(Command::Play(a))
}

/// 터미널을 되돌리는 경비원. 만들 때 raw 모드·대체 화면에 들어가고,
/// 버려질 때(`Drop`) 원래대로 돌린다 — `?` 로 일찍 빠져나가도, 패닉으로
/// 스택이 풀려도. Go 의 `defer`, Java 의 try-with-resources 자리다.
struct TerminalGuard;

impl TerminalGuard {
    fn enter() -> io::Result<TerminalGuard> {
        terminal::enable_raw_mode()?;
        execute!(
            stdout(),
            terminal::EnterAlternateScreen,
            cursor::Hide
        )?;
        Ok(TerminalGuard)
    }
}

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        // drop 은 실패를 돌려줄 수 없다. 되돌리기는 최선을 다할 뿐.
        let _ = execute!(
            stdout(),
            cursor::Show,
            terminal::LeaveAlternateScreen
        );
        let _ = terminal::disable_raw_mode();
    }
}

    let mut wait = frame;

                _ => {}

}

/// 채널마다 (a×wa + b×wb) / (wa+wb).
fn mix(a: u32, b: u32, wa: u32, wb: u32) -> u32 {
    let ch = |s: u32| {
        let (x, y) = ((a >> s) & 0xFF, (b >> s) & 0xFF);
        ((x * wa + y * wb) / (wa + wb)) << s
    };
    ch(16) | ch(8) | ch(0)
}

#[derive(Clone, Debug)]
pub struct Frame {
    pub cell: usize,
    pub w: usize,
    pub h: usize,
    pub px: Vec<u32>,
}

impl Frame {
    /// 여백 = 반 칸. 가로: 여백·판 10칸·여백·패널 5칸·여백.
    pub fn new(cell: usize) -> Frame {
        assert!(cell >= 8, "cell >= 8 이어야 글자가 보인다");
        let pad = cell / 2;
        let w = pad * 3 + (WIDTH + 5) * cell;
        let h = pad * 2 + HEIGHT * cell;
        Frame {
            cell,
            w,
            h,
            px: vec![BG; w * h],
        }
    }

    pub fn board_origin(&self) -> (usize, usize) {
        (self.cell / 2, self.cell / 2)
    }

    /// 판 칸 (x, y) 한가운데 픽셀의 버퍼 번호(시험용).
    pub fn cell_center(&self, x: usize, y: usize) -> usize {
        let (ox, oy) = self.board_origin();
        let c = self.cell;
        (oy + y * c + c / 2) * self.w + ox + x * c + c / 2
    }

/// 사각형 채우기. 버퍼 밖으로 나가는 부분은 잘라 낸다.
fn rect(&mut self, x: usize, y: usize, w: usize, h: usize, c: u32) {
    let (x1, y1) = ((x + w).min(self.w), (y + h).min(self.h));
    for yy in y.min(y1)..y1 {
        self.px[yy * self.w + x.min(x1)..yy * self.w + x1].fill(c);
    }
}

/// 오른쪽 패널: 다음 조각 3개, 홀드, 점수·줄·레벨.
fn panel(game: &Game, f: &mut Frame) {
    let c = f.cell;
    let pad = c / 2;
    let x = pad * 2 + WIDTH * c;
    let scale = (c / 12).max(1);
    let line = 7 * scale + pad / 2; // 글자 한 줄 높이 + 사이
    let ms = c * 3 / 5; // 미리보기 칸 크기
    let mut y = pad;

    text(f, x, y, "NEXT", scale, LABEL);
    y += line;
    for k in game.next_kinds().take(3) {
        mini(f, x, y, k, ms);
        y += ms * 2 + pad;
    }

    y += pad;
    text(f, x, y, "HOLD", scale, LABEL);
    y += line;
    if let Some(k) = game.hold() {
        mini(f, x, y, k, ms);
    }
    y += ms * 2 + pad * 2;

    let stats = [
        ("SCORE", game.score()),
        ("LINES", game.lines()),
        ("LEVEL", game.level()),
    ];
    for (label, value) in stats {
        text(f, x, y, label, scale, LABEL);
        y += line;
        text(f, x, y, &value.to_string(), scale, TEXT);
        y += line + pad;
    }
}

캔버스용 변환 — as_chunks_mut

/// 캔버스 `ImageData` 는 바이트 R·G·B·A 순서다.
pub fn write_rgba(&self, out: &mut [u8]) {
    assert_eq!(out.len(), self.px.len() * 4, "RGBA 버퍼 크기");
    // as_chunks_mut: &mut [u8] → &mut [[u8; 4]] (길이가 상수인 조각)
    let (quads, _) = out.as_chunks_mut::<4>();
    for (p, o) in self.px.iter().zip(quads) {
        *o = [(p >> 16) as u8, (p >> 8) as u8, *p as u8, 0xFF];
    }
}
코드설명
out: &mut [u8]바깥(WASM 메모리)이 준 버퍼에 쓴다. 이 함수는 할당하지 않는다
as_chunks_mut::<4>()&mut [u8] 를 &mut [[u8; 4]] 로 본다(Rust 1.88+). 나머지 조각은 _
*o = [r, g, b, 0xFF]네 바이트를 배열 하나로 대입

왜 변환이 필요한가 — minifb 는 0RGB u32, 캔버스 ImageData 는 바이트 R·G·B·A 순서입니다. 리틀 엔디언 u32 를 그대로 넘기면 B·G·R·0 이 되어 색이 뒤집히고 투명해집니다.

pub fn actions(

fn main() {
    let seed = seed_from_args();
    let mut game = Game::new(seed);
    let mut frame = Frame::new(28); // 칸 28px → 창 462×588

    let opts = WindowOptions::default();
    let mut win = Window::new("Rust 테트리스", frame.w, frame.h, opts)
        .unwrap_or_else(|e| {
            eprintln!("창을 열 수 없다: {e}");
            std::process::exit(1);
        });
    win.set_target_fps(60); // update_with_buffer 가 알아서 쉬어 준다
    win.set_key_repeat_delay(0.17); // 첫 반복까지 170ms
    win.set_key_repeat_rate(0.05); //  그 뒤 50ms 마다

    let mut last = Instant::now();
    while win.is_open() && !win.is_key_down(Key::Q) {
        for a in actions(|k, r| win.is_key_pressed(k, r)) {
            game.apply(a);
        }
        if game.is_over() && win.is_key_pressed(Key::R, KeyRepeat::No) {
            game = Game::new(seed.wrapping_add(1));
        }

        let ms = last.elapsed().as_millis() as u32;
        last += Duration::from_millis(ms as u64);
        game.tick(ms);

        draw(&game, &mut frame);
        // 버퍼를 창에 올리고, 그동안 들어온 키·마우스 이벤트를 모은다
        if let Err(e) =
            win.update_with_buffer(&frame.px, frame.w, frame.h)
        {
            eprintln!("그리기 실패: {e}");
            break;
        }
    }
}

/// 새 판. 씨앗은 u64 인데 JS 의 Number 는 2⁵³ 까지만 정확하므로 32비트
/// 두 개로 받는다. `cell` 은 칸 한 변의 픽셀 수(8~64). 성공하면 1.
#[unsafe(no_mangle)]
pub extern "C" fn tt_init(
    seed_lo: u32,
    seed_hi: u32,
    cell: u32,
) -> u32 {
    if !(8..=64).contains(&cell) {
        return 0; // 패닉 대신 실패 값(extern "C" 밖 패닉은 abort)
    }
    let seed = (seed_hi as u64) << 32 | seed_lo as u64;
    let frame = Frame::new(cell as usize);
    let rgba = vec![0; frame.w * frame.h * 4];
    let app = App {
        game: Game::new(seed),
        frame,
        rgba,
        seed,
    };
    APP.with_borrow_mut(|slot| *slot = Some(app));
    1
}

/**
 * 캔버스에 게임을 붙이고 돌린다. 돌려주는 조종기:
 *   press(name)  동작 하나
 *   stats()      {score, lines, level, over, paused}
 *   sleep()      프레임 루프만 멈춤(상태 유지) · wake()  다시 돌림
 *   stop()       완전히 정지 ·  running  루프가 도는 중인가
 */
function mount(canvas, ex, opts = {}) {
  const cell = opts.cell || 24;
  const seed = opts.seed ?? Date.now();
  // u64 씨앗을 32비트 둘로. >>> 0 은 "부호 없는 32비트로" 관용구
  const lo = seed >>> 0, hi = Math.floor(seed / 2 ** 32) >>> 0;
  if (!ex.tt_init(lo, hi, cell)) {
    throw new Error('tt_init 실패: cell=' + cell);
  }
  const w = ex.tt_width(), h = ex.tt_height();
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext('2d');

  let last = performance.now(), carry = 0, raf = 0;
  const ctl = {
    running: true,
    press(name) {
      return name in CODE ? ex.tt_input(CODE[name]) === 1 : false;
    },
    stats() {
      return { score: ex.tt_stat(0), lines: ex.tt_stat(1),
               level: ex.tt_stat(2), over: ex.tt_stat(3) === 1,
               paused: ex.tt_stat(4) === 1 };
    },
    sleep() {
      cancelAnimationFrame(raf);
      raf = 0;
      ctl.running = false;
    },
    wake() {
      if (raf) return;
      ctl.running = true;
      last = performance.now(); // 자는 동안의 시간은 버린다
      raf = requestAnimationFrame(frame);
    },
    stop() { ctl.sleep(); },
  };
opts.seed ?? Date.now() — ?? 는 null/undefined 일 때만 오른쪽. seed: 0 을 넘겨도 0 이 살아남습니다(|| 였다면 시각으로 바뀐다).

function frame(now) {
  raf = 0;
  if (!ctl.running) return;
  // 탭이 쉬다 돌아오면 수 초가 한꺼번에 온다 → 한 번에 100ms 까지만
  carry += Math.min(100, now - last);
  last = now;
  const ms = Math.floor(carry);
  carry -= ms;
  ex.tt_tick(ms);
  if (opts.onFrame) opts.onFrame(now);
  // onFrame 안에서 sleep() 했으면 다음 프레임을 예약하지 않는다
  if (!ctl.running) return;

  // 매번 새 뷰: 메모리가 늘면 옛 memory.buffer 는 길이 0 이 된다
  const px = new Uint8ClampedArray(

Rust 의 Vec 이 더 큰 메모리를 요청하면 WASM 은 memory.grow 를 하고, 그 순간 JS 가 들고 있던 memory.buffer 는 길이 0 짜리 떨어진(detached) 버퍼가 됩니다. 뷰를 한 번 만들어 두고 재사용하면 언젠가 빈 화면이나 TypeError 를 봅니다.

이 게임은 tt_init 뒤로 할당이 거의 없어 실제로는 잘 안 일어나지만(점수 문자열 정도), 싸게 막을 수 있으니 막아 둡니다. wasm-bindgen 이 만든 글루도 같은 이유로 매번 뷰를 확인합니다.

/**
 * 게임패드 → 동작. 매 프레임 불러 준다. 버튼은 "눌리는 순간"만,
 * 십자키 좌우·아래는 170ms 뒤 50ms 간격으로 반복한다.
 * 표준 배치: 0=A 1=B 2=X 3=Y 4=LB 5=RB 9=Start 12~15=십자키.
 */
function padReader() {
  const held = {}, next = {};
  const MAP = [
    [0, 'cw'], [1, 'ccw'], [2, 'hold'], [3, 'hard'], [4, 'hold'],
    [5, 'hold'], [9, 'pause'], [12, 'hard'], [13, 'soft'],
    [14, 'left'], [15, 'right'],
  ];
  return function poll(now, press) {
    const pads = navigator.getGamepads ? navigator.getGamepads() : [];
    const down = {};
    for (const g of pads) {
      if (!g) continue;
      for (const [i, name] of MAP) {
        const b = g.buttons[i];
        if (b && (b.pressed || b.value > 0.5)) down[name] = true;
      }
      if ((g.axes[0] || 0) < -0.5) down.left = true;
      if ((g.axes[0] || 0) > 0.5) down.right = true;
      if ((g.axes[1] || 0) > 0.5) down.soft = true;
    }
    for (const name of Object.keys(CODE)) {
      if (!down[name]) { held[name] = false; continue; }
      if (!held[name]) {
        held[name] = true;
        next[name] = now + 170;
        press(name);
      } else if (REPEATS.has(name) && now >= next[name]) {
        next[name] = now + 50;
        press(name);
      }
    }
    return Object.keys(down).length > 0;
  };
}

연습 1 — T-스핀 판정

할 일힌트
마지막 동작이 회전이었나 기억하기Game 에 bool 필드 하나. rotate 성공 시 켜고, 이동·낙하 성공 시 끈다. 구조체 리터럴(with_setup)이 빠진 필드를 컴파일 오류로 알려 준다
