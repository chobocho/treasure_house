> 🕹️ 모든 PPT형 슬라이드 덱(76종)과 🏰 포털(`index.html`)은 **키보드 방향키**와 **게임패드**로 조작할 수 있습니다!

### 📊 슬라이드 덱 📖

| 🎮 입력 | 📝 동작 |
|--------|---------|
| ⬆️ ⬇️ | 📜 현재 슬라이드 스크롤 |
| ⬅️ ➡️ | 📄 이전 / 다음 페이지 |
| ␣ Space · PageDown | ➡️ 다음 페이지 |
| 🏠 Home · End | ⏮️ 첫 장 / ⏭️ 마지막 장 *(71종 중 66종)* |
| 🇹 T | 📑 목차 열기 *(71종 중 55종)* |
| 👉 스와이프 | 📄 이전 / 다음 페이지 (모바일) *(71종 중 65종)* |
| 🕹️ 좌스틱 · D-pad ⬆️⬇️ | 📜 부드러운 연속 스크롤 |
| 🕹️ 좌스틱 · D-pad ⬅️➡️ | 📄 이전 / 다음 페이지 |
| 🅰️ A · RB · RT | ➡️ 다음 페이지 |
| 🅱️ B · LB · LT | ⬅️ 이전 페이지 |
| ❎ X · Start | 📑 목차 |
| ⏪ Back | ⏮️ 첫 장 |

### 🏰 포털 (`index.html`) 🗺️

| 🎮 입력 | 📝 동작 |
|--------|---------|
| ⬆️ ⬇️ | 📜 페이지 스크롤 |
| ⬅️ ➡️ | 🃏 이전 / 다음 카드로 이동 |
| ↩️ Enter | 📂 선택한 카드 열기 |
| 🕹️ 좌스틱 · D-pad ⬆️⬇️ | 📜 연속 스크롤 |
| 🕹️ 좌스틱 · D-pad ⬅️➡️ | 🃏 이전 / 다음 카드 |
| 🅰️ A | 📂 카드 열기 |
| 🅱️ B | 🔝 맨 위로 |
| 🎚️ LB · RB | 📚 이전 / 다음 섹션으로 점프 |
| ❎ X · Start | 🔍 검색창으로 |

> 💡 게임패드는 아무 버튼이나 한 번 눌러야 브라우저가 인식합니다 🎮
> 💡 검색창·입력창에 커서가 있거나 🕹️ 슬라이드 안 인터랙티브 데모가 방향키를 쓰는 중이면, 방향키는 그쪽에 양보합니다 🤝

## 🔖 책갈피 (읽던 위치 이어보기) 📑

> 📚 문서를 읽던 위치가 **브라우저 IndexedDB**(`treasure-house` DB · `bookmarks` 저장소)에 자동으로 저장됩니다. 서버 전송 없이 기기 안에만 남습니다 🔒

| 📍 상황 | 📝 동작 |
|--------|---------|
| 📖 문서를 읽는 중 | 🔄 현재 페이지(슬라이드 덱) 또는 스크롤 위치(긴 문서)를 1.2초마다 자동 저장 |
| 🔙 같은 문서를 다시 열면 | 🔖 “지난번 42 / 310 쪽까지 읽었어요” 안내가 아래에 뜨고 **이어보기** 버튼으로 그 자리로 이동 (15초 후 자동 사라짐) |
| 🏰 포털(`index.html`) | 📋 상단 **🔖 이어서 읽기** 목록에 최근 12개가 진행률 막대와 함께 표시 — 클릭하면 바로 그 페이지로 |
| 🃏 문서 카드 | 🏷️ 읽던 문서 카드에 `🔖 42 / 310 쪽` 배지 표시 |
| 🗑️ 지우기 | ✕ 항목별 삭제, **전체 지우기** 버튼으로 일괄 삭제 |

> 💡 URL에 `#해시`를 직접 달아 열면(딥링크) 안내가 뜨지 않습니다 🔗
> 💡 지원 범위: 슬라이드 덱은 `쪽 번호`, 긴 가이드 문서는 `스크롤 위치(%)` — 게임·데모 페이지(`art.html`, `jsdoom.html`, 테트리스 등)는 제외 🎮
