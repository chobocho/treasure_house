## 🎮 조작법 ⌨️

> 🕹️ 모든 PPT형 슬라이드 덱(58종)과 🏰 포털(`index.html`)은 **키보드 방향키**와 **게임패드**로 조작할 수 있습니다!

### 📊 슬라이드 덱 📖

| 🎮 입력 | 📝 동작 |
|--------|---------|
| ⬆️ ⬇️ | 📜 현재 슬라이드 스크롤 |
| ⬅️ ➡️ | 📄 이전 / 다음 페이지 |
| ␣ Space · PageDown | ➡️ 다음 페이지 |
| 🏠 Home · End | ⏮️ 첫 장 / ⏭️ 마지막 장 *(58종 중 50종)* |
| 🇹 T | 📑 목차 열기 *(58종 중 41종)* |
| 👉 스와이프 | 📄 이전 / 다음 페이지 (모바일) *(58종 중 52종)* |
| 🕹️ 좌스틱 · D-pad ⬆️⬇️ | 📜 부드러운 연속 스크롤 |
| 🕹️ 좌스틱 · D-pad ⬅️➡️ | 📄 이전 / 다음 페이지 |
| 🅰️ A · RB · RT | ➡️ 다음 페이지 |
| 🅱️ B · LB · LT | ⬅️ 이전 페이지 |
| ❎ X · Start | 📑 목차 |
| ⏪ Back | ⏮️ 첫 장 |

### 🏰 포털 (`index.html`) 🗺️

| 🎮 입력 | 📝 동작 |
|--------|---------|
| ⬆️ ⬇️ | 📜 페이지 스크롤 |
| ⬅️ ➡️ | 🃏 이전 / 다음 카드로 이동 |
| ↩️ Enter | 📂 선택한 카드 열기 |
| 🕹️ 좌스틱 · D-pad ⬆️⬇️ | 📜 연속 스크롤 |
| 🕹️ 좌스틱 · D-pad ⬅️➡️ | 🃏 이전 / 다음 카드 |
| 🅰️ A | 📂 카드 열기 |
| 🅱️ B | 🔝 맨 위로 |
| 🎚️ LB · RB | 📚 이전 / 다음 섹션으로 점프 |
| ❎ X · Start | 🔍 검색창으로 |

> 💡 게임패드는 아무 버튼이나 한 번 눌러야 브라우저가 인식합니다 🎮
> 💡 검색창·입력창에 커서가 있거나 🕹️ 슬라이드 안 인터랙티브 데모가 방향키를 쓰는 중이면, 방향키는 그쪽에 양보합니다 🤝
