한 줄 요약

1964년 프랑스 수학자 외젠 에르하르트(Eugène Ehrhart)가 제기한 뒤 62년간 미해결이던 부피 추측을, 2026년 8월 1일 OpenAI의 차세대 모델 Astra가 증명했다. 증명은 사람 수학자의 검토를 거쳐 논문으로 정리되었고, Lean 4 증명 보조기로 기계 검증까지 마쳤다.
  • 추측의 내용: "무게중심이 유일한 내부 격자점인 볼록체의 부피는 (n+1)ⁿ/n! 을 넘을 수 없다."
  • 지금은 이 문장이 낯설어도 괜찮다 — 6장이 끝나면 한 단어씩 전부 이해된다.
  • 이 덱의 진짜 목표는 "이 수학이 컴퓨터과학 어디에 스며들어 있는가"를 보여주는 것이다.

OpenAI의 발표 — "Ten advances in mathematics"

  • 2026년 8월 1일, OpenAI는 "Ten advances in mathematics and theoretical computer science"를 발표했다.
  • 수학·이론전산학의 미해결 문제 10개에 대한 새로운 결과 — 증명 또는 반례.
  • 함께 공개된 것: 249쪽 분량의 논문(PDF), 추론 과정 기록(reasoning walkthroughs), 그리고 GitHub 저장소 openai/ten-proofs.
  • 저장소에는 10개 결과 각각의 Lean 4 형식화 파일이 들어 있다 — 기계가 검사 가능한 증명 인증서.

Astra는 어떤 모델인가

  • OpenAI의 차기 주력 모델의 내부 버전 코드명. GPT-6가 될지, GPT-5 계열 버전이 될지는 발표 시점에 미정이었다.
  • 범용 추론(reasoning) 모델이다 — 수학 전용으로 훈련된 특수 모델이 아니라는 점이 발표의 핵심 주장.
  • 보도에 따르면 "AI가 한 분야의 중심적인 미해결 문제를 자율적으로 해결한 첫 사례"라는 표현을 썼다.
  • 이 표현의 타당성 논쟁은 12장에서 다룬다 — 인간 개입이 실제로 어느 단계에 있었는지가 관건
  • 중요한 것: 주장 방식이 과거와 달라졌다. "모델이 풀었다고 말했다"가 아니라 "기계 검증 가능한 인증서를 첨부했다".

10개 결과 전체 목록 (1~5번)

  • ① 고차원 구 채우기 — 구 채우기 밀도의 점근적 상한 개선, Cohn–Elkies 문턱값 도달.
  • ② 이진·구면 부호 — 모든 최소 거리에서 이진 부호의 상한을 지수적으로 강화.
  • ③ 비-sofic 군 — "모든 군은 유한 순열로 근사 가능한가"에 반례가 되는 군의 구성.
  • ④ Connes 강성 추측 — 폰 노이만 대수 관련 추측에 대한 반례.
  • ⑤ 산술 회로 복잡도 — permanent 계산의 회로·식 하한. n⁴/log n 식 하한 포함.

①②는 10장(부호 이론)에서, ⑤는 복잡도 이론과 직결 — 컴공과 무관한 발표가 아니다.

10개 결과 전체 목록 (6~10번)

  • ⑥ 양자 병렬 반복 — 2인 양자 게임의 지수적 병렬 반복 정리.
  • ⑦ 최근접 벡터 문제(CVP) — 다항 인자 근사가 어렵다는 경도(hardness) 증명. 격자 암호와 직결.
  • ⑧ 에르하르트 부피 추측 — 오늘의 주인공. 아래에서 계속.
  • ⑨ 다색 램지 수 — 삼각형 램지 수의 초지수적 하한. 에르되시 문제 183 해결.
  • ⑩ 극값 그래프 이론 — compactness·degeneracy 추측의 반례. 에르되시 문제 146, 180 해결.

⑦은 9장(격자 암호)에서 다시 만난다. 10개 중 3개(①⑦⑧)가 "격자와 부피"의 수학이다.

그중 8번: 에르하르트 부피 추측

"The sharp maximum volume in every dimension for a convex body
whose centroid is its only interior lattice point"
  • 공식 설명문 그대로: "무게중심(centroid)이 유일한 내부 격자점인 볼록체의, 모든 차원에서의 정확한 최대 부피".
  • Lean 형식화 파일 이름: EhrhartVolumeInequality.lean
  • "sharp(정확한)"가 핵심이다 — 상한을 구했을 뿐 아니라, 그 상한이 실제로 달성됨(등호 도형 존재)까지 확정했다는 뜻.
  • 62년간 2차원과 특수한 경우만 알려져 있었고, 일반 차원은 완전히 열려 있었다.

에르하르트 vs 에르되시 — 이름 혼동 주의

  • 에르하르트(Ehrhart): 프랑스 수학자 외젠 에르하르트(1906–2000). 오늘의 부피 추측과 '에르하르트 다항식'의 주인공.
  • 에르되시(Erdős): 헝가리 수학자 폴 에르되시. 1,500편 이상의 논문과 수백 개의 미해결 문제를 남긴 전설.
  • 한국어 표기가 비슷해 뉴스에서 자주 섞인다. 이번 발표에는 두 사람의 문제가 모두 포함되어 더 헷갈리기 쉽다.

발표에 포함된 에르되시 문제들

  • ⑨ 다색 램지 수 하한 — 에르되시 문제 183 해결.
  • ⑩ 극값 그래프 이론 반례 — 에르되시 문제 146, 180 해결.
  • 에르되시 문제란: 에르되시가 생전에 제시한 미해결 문제들로, 현재 Thomas Bloom이 운영하는 erdosproblems.com에 목록화되어 있다.
  • 즉 이번 발표에서 "에르되시 문제 3개 + 에르하르트 추측 1개"가 각각 별도로 해결됐다.
  • "에르하르트 부피 추측 = 에르되시 문제"라고 쓴 기사가 있다면 그 기사가 틀린 것

검증 방식: 249쪽 논문 + Lean 4 인증서

  • 발표의 3단 구성:
  • ① 모델(Astra)이 증명 아이디어와 논증을 생성
  • ② 인간 수학자들이 논증을 검토하고 정식 논문 원고(249쪽)로 집필
  • ③ 모델이 각 증명을 Lean 4 코드로 형식화 — 기계가 한 줄씩 검사
  • GitHub의 openai/ten-proofs에서 누구나 lake build 명령으로 전체 증명을 직접 재검증할 수 있다.
  • "저를 믿으세요"가 아니라 "직접 컴파일해 보세요" — 소프트웨어 엔지니어에게 매우 익숙한 신뢰 모델이다.

격자란 무엇인가 — Zⁿ

  • 정수 격자 Zⁿ = 모든 좌표가 정수인 점들의 집합. Z² = {(0,0), (1,0), (0,1), (−3,7), …}
  • 모눈종이의 교차점, 바둑판의 교점을 무한히 펼친 것이라 생각하면 된다.
  • 격자점(lattice point) = 격자에 속하는 점. 이 덱 전체의 주인공.

격자의 일반 정의

L = { a₁b₁ + a₂b₂ + … + aₙbₙ : aᵢ ∈ Z }
b₁…bₙ은 선형독립인 기저 벡터
  • 일반적으로 격자란: 선형독립인 벡터 n개의 정수 계수 선형결합 전체.
  • 기저를 열벡터로 모은 행렬 B에 대해 L = B·Zⁿ 이라고도 쓴다.
  • 같은 격자를 만드는 기저는 무한히 많다 — "좋은 기저"와 "나쁜 기저"의 구분이 격자 암호의 핵심이 된다(9장).
  • 이 덱의 수학은 대부분 Zⁿ으로 설명하지만, 선형변환 하나면 일반 격자로 옮겨진다.

왜 컴퓨터과학은 격자를 사랑하는가

  • 컴퓨터가 다루는 양은 본질적으로 이산적이다 — 사람 수, 서버 수, 반복 횟수, 비트.
  • "제약을 만족하는 정수 해"를 찾는 문제 = 격자점이 어떤 영역 안에 있는지 묻는 문제.
  • 스케줄링: 몇 명을 어느 근무조에? — 정수 벡터
  • 메모리 접근: A[i][j]의 (i,j) — 격자점
  • 암호 키: 격자 위의 비밀 벡터
  • 연속 수학(부피, 볼록성)으로 이산 문제(격자점 개수)를 공략하는 것 — 그것이 이 덱의 수학이 하는 일이다.

격자점 세기 문제의 원형: 가우스 원 문제

  • 반지름 r인 원 안의 격자점 수 N(r)은 대략 원의 넓이 πr²와 같다.
  • 오차 N(r) − πr² 가 얼마나 작은지는 1800년대 가우스 이래 아직도 미해결(가우스 원 문제).
  • 핵심 직관: 격자점 개수 ≈ 부피. 이 근사가 언제 정확하고 언제 깨지는가가 이 분야 전체의 테마다.

예제: 두 제곱수 정리

  • "n = x² + y² 인 정수 x, y가 존재하는가?" = "반지름 √n인 원이 격자점을 지나는가?"
  • 정수론 문제가 기하 문제로 번역되는 전형적인 예.
  • 5장에서 민코프스키 정리로 이런 유형(네 제곱수 정리)을 실제로 증명하는 스케치를 본다.

기본 영역과 행렬식

  • 기본 영역(fundamental domain): 기저 벡터들이 만드는 평행육면체. 격자의 "단위 타일".
  • 격자 행렬식 det(L) = 기본 영역의 부피 = |det B|.
  • Zⁿ의 행렬식은 1 — 단위 정육면체가 타일이다.
  • 공간 전체는 이 타일로 빈틈없이 채워진다. 따라서 "부피 V인 영역에는 대략 V/det(L)개의 격자점" — 가우스 원 문제 직관의 일반화.
  • det(L)은 기저 선택과 무관한 격자 고유의 양이다.

unimodular 변환 — 격자를 보존하는 사상

  • 정수 행렬 U의 행렬식이 ±1이면 U를 unimodular라 한다.
  • 이런 U는 Zⁿ을 정확히 Zⁿ으로 보낸다 — 격자점은 격자점으로, 비격자점은 비격자점으로.
  • 게다가 |det U| = 1이므로 부피도 보존한다.
  • 따라서 "격자점 개수"와 "부피"에 관한 모든 명제는 unimodular 변환을 해도 그대로 성립한다.
  • 6장에서 "등호는 unimodular 동치인 도형뿐"이라는 문장이 나올 때 이 개념이 쓰인다.

격자 = 반복문의 인덱스 공간

// 이 이중 루프가 도는 (i, j)들의 집합은?
for (int i = 0; i <= N; i++)
  for (int j = 0; j <= i; j++)
    sum += A[i][j];
// 답: 삼각형 { 0 ≤ j ≤ i ≤ N } 안의 격자점 전부
  • 중첩 반복문의 인덱스 (i, j, k, …)는 부등식으로 잘린 영역(다포체) 안의 격자점이다.
  • "이 루프는 몇 번 도는가?" = "이 다포체 안에 격자점이 몇 개인가?"
  • 이 관점이 컴파일러 최적화의 한 분야 전체를 만들었다.

polyhedral 컴파일러 이야기

  • polyhedral model: 루프 중첩을 다포체+격자로 모델링해 변환(타일링, 교환, 병렬화)하는 컴파일러 기법.
  • LLVM의 Polly, GCC의 Graphite가 이 모델의 구현체다.
  • 루프 횟수 세기, 캐시 접근 패턴 분석에 에르하르트 다항식(4장)이 그대로 쓰인다.
  • 즉 "격자점 세기"는 순수수학이 아니라, 여러분이 매일 쓰는 컴파일러 안에서 돌아가는 코드다.
  • 11장에서 barvinok/isl 라이브러리로 다시 만난다

  • 다음 장에서 볼록성, 단체(simplex), 무게중심을 정리한다.

2장 요약

  • 격자 = 기저 벡터의 정수 계수 결합 전체. 기본은 정수 격자 Zⁿ.
  • 격자점 개수 ≈ 부피 / det(L) — 이 근사의 정밀화가 분야 전체의 테마.
  • unimodular 변환(정수 행렬, det ±1)은 격자와 부피를 동시에 보존한다.
  • 반복문 인덱스, 정수 해, 암호 키 — CS의 곳곳이 격자점이다.
  • 차원이 고정이냐 변수냐가 격자 문제의 난이도를 가른다.

볼록 집합의 정의

x, y ∈ K 이면 선분 xy ⊂ K
  • 집합 안의 어떤 두 점을 잡아도, 잇는 선분이 통째로 집합 안에 있으면 볼록(convex).
  • 볼록체(convex body) = 볼록하고, 유계이고, 내부가 비어 있지 않은 집합.
  • 원, 타원, 삼각형, 정육면체: 볼록. 별 모양, 도넛, 초승달: 볼록 아님.
  • 볼록성이 좋은 이유: 국소 최적 = 전역 최적(최적화), 분리 초평면 존재(ML의 SVM), 그리고 격자점 논증이 먹힌다(5장).

볼록 껍질 (convex hull)

  • conv(S) = S를 포함하는 가장 작은 볼록 집합.
  • 계산기하학의 첫 알고리즘(Graham scan 등)으로 익숙할 것이다.
  • 유한 개 점의 볼록 껍질 = (볼록) 다포체(polytope). 꼭짓점·모서리·면을 가진다.

단체(simplex) — 가장 단순한 다포체

  • n차원 단체 = 일반 위치의 점 n+1개의 볼록 껍질.
  • 1차원: 선분(점 2개), 2차원: 삼각형(3개), 3차원: 사면체(4개).
  • "n차원에서 만들 수 있는 가장 마른 도형" — 그런데 에르하르트 추측의 주인공(최대 부피 도형)이 바로 단체다. 6장에서 이 아이러니를 본다.

표준 단체 Δₙ과 부피 1/n!

Δₙ = { x ∈ Rⁿ : xᵢ ≥ 0, x₁+…+xₙ ≤ 1 }
Vol(Δₙ) = 1/n!
  • 표준 단체 = 원점과 각 좌표축의 단위점 e₁…eₙ의 볼록 껍질.
  • n=2: 넓이 1/2 직각삼각형. n=3: 부피 1/6 사면체.
  • 단위 정육면체를 좌표 순서(x₁ ≥ x₂ ≥ …)로 n!등분하면 각 조각이 단체와 합동 — 그래서 1/n!.
  • 추측의 상한 (n+1)ⁿ/n! 에 들어 있는 n!의 정체가 바로 이것이다.

초입방체와 다른 다포체들

  • 초입방체 [0,1]ⁿ: 부피 1, 꼭짓점 2ⁿ개. 비트 문자열 {0,1}ⁿ과 일대일 — CS의 친구.
  • 교차 다포체(cross-polytope): |x₁|+…+|xₙ| ≤ 1. L1 노름의 단위공. 부피 2ⁿ/n!.
  • 이 셋(단체, 큐브, 교차 다포체)이 고차원 기하의 3대 기준 도형이다.

V-표현 vs H-표현

  • 같은 다포체를 두 가지로 적을 수 있다:
  • V-표현: 꼭짓점들의 볼록 껍질 — conv{v₁, …, vₖ}
  • H-표현: 부등식(반공간)들의 교집합 — { x : Ax ≤ b }
  • 선형계획법의 feasible region은 H-표현, 계산기하의 볼록 껍질 출력은 V-표현.
  • 두 표현 사이 변환은 최악의 경우 지수적으로 비싸다 — 알고리즘 설계에서 늘 의식해야 하는 지점.
  • 8장의 정수계획법은 "H-표현 다포체 안의 격자점 찾기"다.

무게중심(centroid)의 정의

c(K) = (1/Vol K) ∫_K x dx
  • 도형을 균일한 밀도의 판이라 생각했을 때의 질량 중심. 좌표별 평균값.
  • 삼각형이면 꼭짓점 좌표의 평균 (A+B+C)/3. 단체면 (n+1)개 꼭짓점의 평균.

무게중심은 왜 특별한 점인가

  • 무게중심을 지나는 어떤 초평면으로 잘라도, 작은 쪽 조각의 부피가 전체의 약 36.8%(= 1/e) 이상이다 — 그륀바움(Grünbaum)의 정리.
  • 즉 무게중심은 "어느 방향으로도 도형이 심하게 쏠려 있지 않은 점".
  • 대칭 도형(원, 정사각형)에서는 대칭 중심 = 무게중심.
  • 에르하르트 추측이 "무게중심이 격자점"이라는 조건을 거는 이유가 바로 이 균형성이다 — 6장에서 이 조건을 빼면 어떻게 되는지 반례로 확인한다.

고차원 직관 파괴: 부피 집중

  • 고차원에서는 저차원 직관이 배신한다:
  • 단위 구의 부피는 차원이 커지면 0으로 수렴한다 (n=20이면 이미 0.026)
  • 초입방체 부피의 대부분은 모서리 근처에 몰려 있다
  • 고차원 오렌지는 껍질이 거의 전부다
  • 그래서 "차원 n마다" 성립하는 정확한 부등식은 귀하다 — 실험으로 감을 잡을 수 없기 때문.
  • 에르하르트 추측이 62년 버틴 이유 중 하나: 저차원 그림으로는 고차원의 극값 구조가 안 보인다.

3장 요약

  • 볼록 = 두 점을 이으면 선분이 안에 머무는 성질. 볼록체 = 볼록 + 유계 + 내부 있음.

  • 고차원은 직관이 무너지는 곳 — 그래서 sharp한 부등식이 값지다.

픽의 정리 (Pick, 1899)

A = I + B/2 − 1
A: 넓이, I: 내부 격자점 수, B: 경계 격자점 수
  • 꼭짓점이 모두 격자점인 단순 다각형이면 어떤 모양이든 성립한다.
  • "연속량(넓이) = 이산량(점 개수)의 산수" — 이 덱 전체 주제의 2차원 완결판.

예제 계산

  • 꼭짓점 (0,0), (4,0), (0,3)인 직각삼각형을 보자.
  • 경계점 B: 밑변에 5개, 세로변이 (0,1) (0,2) (0,3)을 더해 3개, 빗변 위에는 추가 격자점 없음 → B = 8.
  • 변 위 격자점은 gcd로 센다: 빗변 (4,0)→(0,3)의 내부 격자점 수 = gcd(4,3) − 1 = 0
  • 내부점 I: (1,1), (1,2), (2,1) — 3x + 4y < 12를 만족하는 점 3개.
  • 검산: 픽의 공식 I + B/2 − 1 = 3 + 4 − 1 = 6 = 4×3/2 = 넓이 ✓
  • gcd가 등장하는 것에 주목 — 격자 기하에는 정수론이 자연스럽게 스며든다.

구멍이 있으면?

  • 구멍 뚫린 다각형은 A = I + B/2 − 1 + h (h = 구멍 수).
  • 보정항 "−1"과 "+h"의 정체는 오일러 지표 — 위상수학이 살짝 얼굴을 내민다.
  • 공식이 도형의 위상까지 알고 있다는 것: 격자점 세기가 보기보다 깊은 이유.

  • Eugène Ehrhart (1906–2000), 프랑스 알자스 출신.
  • 평생 고등학교 수학 교사로 일하며 독학으로 연구했고, 60세가 되어서야 박사 학위를 받았다.
  • 1960년대에 격자점 세기의 일반 이론(에르하르트 다항식)을 만들었다 — 지금은 조합론 교과서의 표준 챕터.
  • 부피 추측은 1964년 논문에서 제기했다. 스스로 2차원과 몇몇 특수 경우를 증명했다.
  • 위키미디어에 초상 사진이 없을 만큼 조용히 살았던 인물 — 하지만 이론에는 이름이 남았다

에르하르트 다항식의 정의

L_P(t) = #( tP ∩ Zⁿ )
tP = 다포체 P를 t배 확대한 것, t = 1, 2, 3, …
  • 격자 다포체 P를 t배 확대하고 그 안(경계 포함)의 격자점을 센 값 L_P(t).
  • 에르하르트 정리(1962): L_P(t)는 t에 대한 차수 n의 다항식이 된다!
  • 점 개수라는 들쭉날쭉해 보이는 양이 완벽한 다항식으로 정리된다는 것 — 전혀 자명하지 않은 아름다운 사실.
  • 꼭짓점이 유리수 좌표면 준다항식(quasi-polynomial: 계수가 주기적으로 변함)이 된다.

예제: 정사각형과 단체

PL_P(t)t=1t=2t=3
단위 정사각형 [0,1]²(t+1)²4916
표준 삼각형 Δ₂(t+1)(t+2)/23610
단위 큐브 [0,1]³(t+1)³82764
표준 사면체 Δ₃(t+1)(t+2)(t+3)/641020
  • Δ₂의 값 3, 6, 10은 삼각수 — Δ₃의 4, 10, 20은 사면체수. 이름부터 격자점 세기였던 수들이다.

[데모] 에르하르트 다항식 시각화

배율 t를 움직여 보세요. tP 안의 격자점 수가 정확히 다항식 값을 따라갑니다.

최고차 계수 = 부피

L_P(t) = Vol(P)·tⁿ + (저차항)
  • t가 커질수록 "점 개수 ≈ 부피 × 확대 배율ⁿ" — 2장의 가우스 원 직관이 정확한 등식의 최고차항으로 승격된다.
  • 둘째 계수는 표면적의 절반(정규화된), 상수항은 항상 1(오일러 지표).
  • 즉 에르하르트 다항식은 부피·표면적·위상을 한 줄에 담는 "도형의 지문"이다.
  • 이것이 세기(counting)와 재기(measuring)를 잇는 다리 — 부피 추측도 정확히 이 다리 위의 명제다.

에르하르트 상반 법칙 (reciprocity)

L_P(−t) = (−1)ⁿ · L_P°(t)
P° = P의 내부 (경계 제외)
  • 다항식에 음수를 넣으면 내부 격자점 개수가 나온다 — 처음 보면 마법 같은 등식.
  • 예: 정사각형 L(t) = (t+1)²에서 L(−t) = (t−1)². 실제로 t=2배 확대한 [0,2]²의 격자점 9개 중 내부점은 (1,1) 하나 = (2−1)² ✓
  • 경계를 세는 것과 내부를 세는 것이 같은 다항식의 양면이라는 뜻.
  • 조합론의 수많은 상반 정리(그래프 색칠다항식 등)의 원형 중 하나다.

응용 맛보기: 마방진 세기

  • 질문: "행·열 합이 모두 t인 n×n 음이 아닌 정수 행렬(준마방진)은 몇 개인가?"
  • 이 개수 H_n(t)는 놀랍게도 t의 다항식이고, 그 정체는 어떤 다포체의 에르하르트 다항식이다.

Birkhoff 다포체

  • Birkhoff 다포체 B_n = 행·열 합이 1인 음이 아닌 행렬(이중확률행렬) 전체. 꼭짓점은 정확히 n! 개의 순열행렬(Birkhoff–von Neumann 정리).
  • t배 확대한 tB_n 안의 격자점 = 행·열 합 t인 정수 행렬 = 준마방진 → H_n(t) = L_{B_n}(t).
  • 매칭 이론(이분 매칭의 분해)과 격자점 세기가 한 도형에서 만난다 — 알고리즘 수업의 그 정리 맞다.

4장 요약

  • 픽의 정리: 2차원에서는 A = I + B/2 − 1. 점 개수가 넓이를 완전히 결정.
  • Reeve 사면체: 3차원부터는 불가능 — 같은 점 구성, 임의로 큰 부피.
  • 에르하르트의 돌파구: 확대하며 세면 L_P(t)는 다항식이 되고, 최고차 계수가 부피다.
  • 상반 법칙 L_P(−t) = (−1)ⁿL_P°(t) — 경계와 내부는 한 다항식의 양면.
  • 마방진·매칭 같은 조합론 세기가 전부 에르하르트 다항식이다.

헤르만 민코프스키 (1864–1909)

  • 리투아니아 태생의 독일 수학자. 아인슈타인의 스승이자, 특수상대성이론에 4차원 시공간 기하를 입힌 사람.
  • 또 하나의 업적이 오늘의 주제: 기하로 정수론을 푸는 기하학적 수론(geometry of numbers)의 창시.
  • 45세에 요절 — 힐베르트가 평생 그의 죽음을 애도했다.

기하학적 수론의 탄생

  • 1890년대, 민코프스키는 이차형식(quadratic form)의 정수해 문제를 연구하다 발상을 뒤집었다.
  • "방정식을 계산하지 말고, 도형을 그려서 격자점이 있을 수밖에 없음을 보이자."
  • 정수론의 존재 정리들이 "부피가 충분히 크면 점이 있다"는 기하 명제로 환원됐다.
  • 이 도구 상자가 이후 130년간 정수론·최적화·암호학을 먹여 살린다.
  • 에르하르트 부피 추측은 이 전통의 직계 후손이다.

민코프스키 정리 (1889)

K 볼록, 원점 대칭, Vol(K) > 2ⁿ
⇒ K는 0이 아닌 격자점을 포함한다
  • 원점 대칭: x ∈ K이면 −x ∈ K. (2차원에서 2² = 4가 문턱.)

세 가지 조건은 왜 필요한가

  • 볼록성: 초승달처럼 휘어진 도형은 넓이가 커도 격자점 사이를 "빠져나갈" 수 있다.
  • 원점 대칭: 원점에서 한쪽으로 치우친 도형은 격자점 없는 곳으로 밀어낼 수 있다.
  • 부피 > 2ⁿ: 정확히 문턱값이다 — 한 변 길이 2−ε인 정사각형 (−1+ε/2, 1−ε/2)²은 부피가 4에 아무리 가까워도 내부 격자점이 원점뿐이다.
  • 세 조건이 모두 빠질 수 없는 sharp한 정리 — "최선의 상수"라는 감각을 여기서 익혀 두자. 에르하르트 추측도 같은 종류의 sharp함을 주장한다.

부피 2ⁿ 문턱의 의미

  • 2ⁿ = 한 변이 2인 큐브의 부피. 왜 하필 2인가?
  • 직관: K를 반으로 축소한 ½K의 부피가 1(= 격자 타일 하나)을 넘으면, 타일링에서 겹침이 생긴다.
  • 겹침 = 서로 다른 두 점이 같은 위치로 포개짐 = 그 차이가 격자 벡터.
  • 대칭성과 볼록성이 그 차이 벡터를 다시 K 안으로 데려온다 — 다음 두 슬라이드에서 이 논리를 그대로 밟는다.

[데모] 민코프스키 정리 체험

원점 대칭 타원의 크기와 납작함을 조절해 보세요. "넓이 > 4인데 0 아닌 격자점(금색)이 없는" 상태를 만들 수 있는지 도전!

아무리 길고 납작하게 눕혀도, 넓이가 4를 넘는 순간 격자점이 걸려든다.

증명 스케치 ①: Blichfeldt 보조정리

Vol(S) > 1 ⇒ 서로 다른 x, y ∈ S, x − y ∈ Zⁿ
  • 부피가 1을 넘는 집합(볼록 아니어도 됨)에는 "차이가 격자 벡터인 두 점"이 반드시 있다.
  • 증명: 공간을 단위 큐브 타일로 자르고, 모든 조각을 한 큐브 위로 포갠다.
  • 총 부피 > 1 = 큐브 부피이므로 어딘가는 두 겹 이상 — 포개진 두 점이 답이다.
  • 이것은 비둘기집 원리의 연속(측도) 버전이다. "부피가 넘치면 겹친다."

증명 스케치 ②: 반으로 줄여 접기

  • Vol(K) > 2ⁿ 이라 하자. 반으로 축소한 ½K는 Vol(½K) = Vol(K)/2ⁿ > 1.
  • Blichfeldt에 의해 ½K 안에 x − y = v ∈ Zⁿ, v ≠ 0 인 두 점 x, y가 있다.
  • 2x ∈ K, 2y ∈ K. 대칭성으로 −2y ∈ K. 볼록성으로 중점 (2x + (−2y))/2 = x − y = v ∈ K.
  • 즉 0 아닌 격자점 v가 K 안에 있다 ∎
  • 다섯 줄짜리 증명이 정수론의 수문을 열었다 — 다음 세 슬라이드가 그 물줄기다.

응용 1: 디리클레 근사 정리

임의의 실수 α, 자연수 Q에 대해
|qα − p| ≤ 1/Q, 1 ≤ q ≤ Q 인 정수 p, q 존재
  • "모든 실수는 분모 대비 놀랍도록 좋은 유리수 근사를 가진다."
  • 민코프스키식 증명: 평면에서 |qα − p| ≤ 1/Q, |q| ≤ Q 로 정의되는 평행사변형은 원점 대칭·볼록이고 넓이가 정확히 4 — 정리가 격자점을 보장한다.
  • 연분수, 무리수 판정, 그리고 격자 암호 공격(9장 LLL)의 뿌리가 되는 정리.

응용 2: 네 제곱수 정리 (라그랑주)

  • 모든 자연수는 제곱수 4개의 합이다: 7 = 4+1+1+1, 310 = 289+16+4+1.
  • 민코프스키식 증명의 뼈대: 소수 p마다 적당한 4차원 격자를 만들고, 부피가 2⁴·det를 넘는 구를 잡으면 —
  • 정리가 보장하는 0 아닌 격자점의 좌표 제곱합이 정확히 p의 배수이면서 2p보다 작음 → p 자체가 네 제곱수 합.
  • "계산 없이 존재만으로" 정수론 정리를 뽑아내는 기하학적 수론의 대표 시연.

응용 3: 암호학의 민코프스키 한계

λ₁(L) ≤ √n · det(L)^(1/n)
λ₁ = 격자 L의 0 아닌 최단 벡터 길이
  • 민코프스키 정리를 구(球)에 적용하면: 모든 격자에는 이 길이 이하의 짧은 벡터가 반드시 존재한다.
  • 격자 암호(9장)에서 "얼마나 짧은 벡터가 존재할 수 있나"는 보안 강도 추정의 출발점이다.
  • 존재는 보장하지만 찾는 법은 말해주지 않는다 — 존재(쉬움)와 탐색(어려움)의 간극이 곧 암호의 안전성이다.

민코프스키의 역방향 질문 — 에르하르트의 출발점

  • 민코프스키: 대칭 볼록체가 내부에 원점 하나만 격자점으로 가지면 → 부피 ≤ 2ⁿ.
  • 에르하르트의 질문(1964): 대칭 조건을 무게중심 조건으로 바꾸면?
  • "무게중심이 그 유일한 내부 격자점이라면, 부피의 최대값은 얼마인가?"
  • 대칭(강한 조건)을 균형(약한 조건)으로 완화한 만큼 답은 2ⁿ보다 커야 한다 — 얼마나?
  • 에르하르트의 예상: (n+1)ⁿ/n!, 달성 도형은 단체. 이것이 오늘의 추측이다. 다음 장에서 본격 해부한다.

  • 그리고 묻는다 — "이 격자점이 내부의 유일한 격자점이 되도록 하면서, 도형을 얼마나 크게 만들 수 있는가?"

추측의 정확한 진술 (Ehrhart, 1964)

K ⊂ Rⁿ 볼록체, 무게중심 c(K) ∈ Zⁿ,
int(K) ∩ Zⁿ = { c(K) } 이면
Vol(K) ≤ (n+1)ⁿ / n!
등호는 K가 (n+1)Δₙ과 unimodular 동치일 때, 그리고 그때뿐
  • 세 문장으로: ① 볼록체의 무게중심이 격자점이고 ② 내부에 다른 격자점이 없으면 ③ 부피는 (n+1)ⁿ/n!을 못 넘는다.
  • 2026년 8월 1일, 이 명제 전체(등호 조건 포함)가 정리가 되었다.

수식 뜯어보기: (n+1)ⁿ/n!

조각출신
1/n!표준 단체 Δₙ의 부피 (3장)
(n+1)ⁿ단체를 (n+1)배 확대 → 부피는 (n+1)ⁿ배
  • 즉 (n+1)ⁿ/n! = Vol( (n+1)Δₙ ) — 상한 자체가 "n+1배 확대한 표준 단체의 부피"다.
  • 왜 n+1배인가? 단체의 꼭짓점이 n+1개이고, 무게중심이 꼭짓점 좌표의 평균이기 때문 — 다음 검증에서 눈으로 확인된다.
  • 스털링 근사로 (n+1)ⁿ/n! ≈ eⁿ⁺¹·√(n/2π)/... ≈ 대략 eⁿ 스케일: 민코프스키의 2ⁿ보다 지수적으로 크다.

n=1에서 손으로 검증

(1+1)¹/1! = 2
  • 1차원 볼록체 = 구간 [a, b]. 무게중심 = 중점 (a+b)/2.
  • 중점이 0(격자점)이고 내부에 다른 정수가 없으려면: 구간은 (−L, L) 꼴이고 내부에 ±1이 없어야 → L ≤ 1.
  • 최대 길이 = 2, 달성 도형 = [−1, 1]. 이것이 정확히 2Δ₁(길이 2 선분)을 중심 맞춘 것.
  • 추측값 2와 일치 ✓ — 가장 낮은 차원에서 공식이 옳게 작동한다.

n=2에서 손으로 검증

(2+1)²/2! = 9/2 = 4.5
  • 삼각형 T: 꼭짓점 (−1,−1), (2,−1), (−1,2)를 보자.
  • 무게중심 = ((−1+2−1)/3, (−1−1+2)/3) = (0, 0) — 격자점 ✓
  • 내부 격자점: 후보 (0,0), (1,0), (0,1), (1,−1)… 부등식 x>−1, y>−1, x+y<1을 만족하는 정수점은 (0,0) 하나뿐 ✓
  • (1,0)과 (0,1)은 x+y=1 — 빗변 '위'라 내부가 아니다. 아슬아슬하게 걸쳐 있다!
  • 넓이 = 3×3/2 = 4.5 — 추측의 상한을 정확히 달성 ✓ 에르하르트는 2차원에서 이것이 최대임을 증명했다.

극값 도형: (n+1)Δₙ

  • 표준 단체를 (n+1)배 확대하고 무게중심을 원점에 놓은 도형이 모든 차원의 챔피언.
  • n=3: 꼭짓점 (−1,−1,−1), (3,−1,−1), (−1,3,−1), (−1,−1,3). 무게중심 (0,0,0), 내부 격자점 원점뿐, 부피 4³/3! = 10.67.
  • 내부점 하나를 "품은 채" 부풀릴 수 있는 한계 도형이다.

왜 하필 단체가 최대인가 — 직관

  • 내부 격자점을 늘리지 않고 부피를 키우려면, 도형이 격자점들을 경계 위에 아슬아슬하게 걸치도록 늘어나야 한다.
  • n=2 극값 삼각형: 경계 위 격자점이 9개나 된다 — 어느 방향으로 밀어도 그중 하나가 내부로 굴러 들어온다.
  • 대칭 도형은 반대쪽도 함께 커져서 일찍(2ⁿ) 한계에 닿는다. 단체는 "한쪽 꼭짓점 방향으로 길게" 뻗는 최선의 비대칭 전략.
  • 가장 마른 도형(부피 1/n!)이 가장 큰 상한의 주인공이 되는 역설 — 마른 만큼 멀리 뻗을 수 있기 때문이다.

무게중심 조건이 없으면? — 상한 자체가 없다

"내부 격자점이 1개"라는 조건만으로는 부피를 전혀 제한할 수 없다. 무게중심 조건이 빠지면 추측은 거짓이 아니라 성립 불가능한 명제가 된다.
  • 반례 아이디어: 격자점이 하나도 없는 납작한 띠(slab)는 얼마든지 넓게 만들 수 있다.
  • 예: 0.1 < y < 0.9, 0 ≤ x ≤ N 인 직사각형 — 정수 y좌표가 없어 내부 격자점 0개, 넓이 0.8N
  • 여기에 격자점 하나만 살짝 물리면 "내부점 정확히 1개 + 넓이 무한대" 완성. 구성은 다음 슬라이드.

반례 구성 도식

K = conv( B(0, 0.05) ∪ [0,N]×[0.1, 0.9] )
원점 주변 작은 원판 + 길이 N인 띠의 볼록 껍질
  • 원점 (0,0)은 작은 원판 덕분에 K의 내부점이다.
  • 띠 부분에는 격자점이 없고, 원판에서 띠로 이어지는 아래쪽 경계선은 y = 0.1x/N 근방 — (1,0), (2,0) 같은 격자점들은 이 선 아래라 K 밖이다.
  • 결과: 내부 격자점은 (0,0) 하나, 넓이는 약 0.8N → N을 키우면 무한정 커진다.
  • 단, 무게중심은 대략 (N/2, 0.5) — 격자점이 아니다! 그래서 추측의 반례가 아니라, 무게중심 조건이 왜 필수인지를 보여주는 예다.

무게중심 조건의 힘

  • 앞의 반례는 격자점 하나를 도형의 극단 구석에 밀어 넣는 꼼수였다.
  • 무게중심 조건은 그 꼼수를 원천 봉쇄한다: 격자점이 도형의 "균형점"이어야 하므로 도형이 한쪽으로만 뻗을 수 없다.
  • 그륀바움 정리(3장)로 정량화: 무게중심을 지나는 모든 절단은 양쪽에 부피의 1/e 이상을 남긴다 — 한쪽으로 뻗으면 반대쪽도 어느 정도 따라와야 하고, 그러면 새 격자점을 삼키게 된다.
  • "대칭"보다 훨씬 약한데도 유한한 상한을 만들어 내는 최소한의 균형 조건 — 추측의 미학이 여기 있다.

알려져 있던 부분 결과

  • Ehrhart 본인: n = 2 완전 해결, 그리고 K가 단체인 경우를 임의 차원에서 증명.
  • "챔피언이 단체라면, 단체 리그 안에서는 (n+1)Δₙ이 1등"까지는 알고 있었던 것
  • Nill–Paffenholz (2014): 등호 사례 분석 — 특정 다포체 부류(reflexive simplex 관련)에서 등호 도형의 유일성 확인.
  • 일반 볼록체·일반 차원에 대해서는 상한 자체가 열려 있었다 — 알려진 일반 상한은 추측값보다 훨씬 컸다.
  • "쉬운 케이스는 다 됐는데 일반화가 안 되는" 전형적인 난제 패턴.

왜 62년 동안 안 풀렸나

  • 대칭이 없으면 민코프스키식 "접기" 트릭(½K, x−y)이 작동하지 않는다 — 도구 상자의 핵심 공구가 무용지물.
  • 무게중심은 적분으로 정의되는 "부드러운" 양이라, 격자의 "딱딱한" 이산 구조와 연결하기 어렵다.
  • 고차원 극값 문제의 고질병: 후보 도형(단체)이 최적임을 보이려면 모든 볼록체와 비교해야 한다 — 탐색 공간이 무한 차원.
  • 3장에서 본 대로 고차원 직관은 실험으로 보강할 수 없다. 저차원 성공(n=2)이 일반화 전략을 주지 않았다.

등호 조건: unimodular 동치

  • 추측(현 정리)의 완전한 형태: 등호 Vol(K) = (n+1)ⁿ/n!은 K가 (n+1)Δₙ의 unimodular 변환 + 평행이동 이미지일 때, 그리고 그때만.
  • 2장의 unimodular 변환(정수 행렬, det ±1)은 격자와 부피를 함께 보존하므로, 챔피언의 변환상도 챔피언 — 자연스러운 동치류.
  • "상한 + 달성 가능 + 달성자의 완전 분류"까지 갖춰야 sharp한 해답이다. Astra의 결과는 이 세 박자를 모두 담았다.

Astra가 증명한 것 — 다시 읽기

"The sharp maximum volume in every dimension for a convex
body whose centroid is its only interior lattice point"
  • 이제 이 영어 문장이 완전히 읽힐 것이다:
  • sharp maximum volume = 상한 (n+1)ⁿ/n! + 등호 분류
  • in every dimension = 임의의 n (n=2만이 아니라)
  • convex body whose centroid is its only interior lattice point = 6장 전체
  • Lean 파일 이름이 EhrhartVolumeInequality인 이유: 추측이 부등식으로 증명되어 '정리'가 되었기 때문.

6장 요약

  • 추측: 무게중심이 유일한 내부 격자점인 볼록체는 Vol ≤ (n+1)ⁿ/n!. 등호는 (n+1)Δₙ의 unimodular 상뿐.
  • 상한의 정체 = (n+1)배 확대한 표준 단체의 부피. n=1은 길이 2 구간, n=2는 넓이 4.5 삼각형.
  • 무게중심 조건이 없으면 상한 자체가 존재하지 않는다(슬랩 반례) — 조건이 명제의 심장.
  • 민코프스키(대칭, 2ⁿ)의 균형 버전 — 137년 만에 쌍이 완성.
  • 62년 표류의 원인: 대칭 부재로 고전 도구가 무력 + 고차원 극값 문제의 본질적 어려움.

Blichfeldt 정리 — 점 개수의 상한

#(K ∩ Zⁿ) ≤ n! · Vol(K) + n
  • 5장의 보조정리를 다듬으면: 볼록체 안의 격자점 개수는 부피의 n!배 수준을 넘지 않는다.
  • 방향에 주목 — "부피가 작으면 점도 적다". 에르하르트 추측은 반대로 "점이 적으면(1개) 부피도 작다".
  • 부피와 점 개수는 양방향으로 서로를 통제한다. 이 양방향 사전(dictionary)이 분야의 뼈대다.

van der Corput 정리 — 민코프스키의 일반화

Vol(K) > k · 2ⁿ ⇒ 원점 외 격자점 쌍 ±v를 k개 이상 포함
  • 부피가 2ⁿ의 k배를 넘으면 격자점이 "하나"가 아니라 "k개 이상" 있다 — 정량 버전.
  • 패턴을 보라: 부피 문턱을 하나씩 넘을 때마다 격자점이 하나씩 강제된다.
  • 에르하르트 방향의 유사 질문 "내부점이 k개면 부피 최대는?"도 자연스럽게 제기된다 — 다음 슬라이드.

Hensley 정리 — 내부점 k개의 세계

  • Hensley (1983): 내부 격자점을 k ≥ 1개 가진 격자 다포체의 부피는 n과 k에만 의존하는 상수로 유계.
  • 후속 연구(Lagarias–Ziegler 등)가 상수를 개선했지만, 최적 상수는 여전히 대부분 미지.
  • 주의: 이 정리는 꼭짓점이 격자점인 다포체 대상 — 에르하르트 추측은 임의 볼록체 대상이라 조건(무게중심)이 필요했다.
  • "k=1 + 무게중심 + 임의 볼록체"의 정확한 상수를 못 박은 것이 이번 결과의 위치다.

Scott 부등식 — 2차원의 완결판

2차원 격자 다각형, I ≥ 1 ⇒ A ≤ 2I + 7/2… 최적은 A ≤ 4.5 (I=1)
  • Scott (1976): 내부점 I ≥ 1인 격자 다각형의 넓이 상한을 완전히 정리했다.
  • I = 1일 때 최대 넓이 4.5, 달성 도형은 3Δ₂ — 에르하르트의 n=2 결과와 딱 맞물린다.
  • 2차원은 픽 정리 덕분에 "점 개수 ↔ 넓이" 사전이 완벽해서 이런 완결이 가능했다.
  • 3차원 이상은 픽이 무너지므로(Reeve, 4장) 문제가 질적으로 어려워진다.

Flatness 정리 — 격자점 없는 도형은 납작하다

int(K) ∩ Zⁿ = ∅ ⇒ 격자폭(K) ≤ w(n)
  • 내부에 격자점이 하나도 없는 볼록체는, 부피는 커도(6장의 슬랩!) 어떤 정수 방향으로는 반드시 얇다.
  • 격자폭 = 정수 벡터 방향으로 잰 도형의 두께 중 최솟값. 상수 w(n)은 차원에만 의존.
  • 이 정리가 8장 Lenstra 알고리즘의 심장이다: "격자점이 없다면 도형이 납작하다 → 납작한 방향으로 잘라 차원을 낮춘다."
  • k=0(flatness), k=1(에르하르트), k≥1(Hensley) — 내부점 개수별 구조 정리 3부작.

연속 최소량과 Mahler — 도구 상자의 나머지

  • 연속 최소량 λ₁ ≤ λ₂ ≤ … ≤ λₙ: 도형을 몇 배 키워야 독립 격자 벡터를 1개, 2개, … n개 삼키는지 재는 값.
  • 민코프스키 제2정리: λ₁λ₂…λₙ · Vol(K) 가 2ⁿ det(L)과 상수 배 이내 — 최소량과 부피의 정밀한 거래.
  • Mahler 콤팩트성: "너무 찌그러지지 않은" 격자들의 공간은 콤팩트 — 극값 문제에서 "최악의 격자가 존재한다"를 보장하는 표준 장비.
  • 이런 장비들이 9장 격자 암호의 보안 분석 언어가 된다.

지도 위의 에르하르트 추측

내부 격자점알려진 구조
0개부피 무제한, 대신 납작함 (Flatness 정리)
1개 (무게중심)Vol ≤ (n+1)ⁿ/n! — 에르하르트 추측 = 2026년 정리
1개 (조건 없음)임의 볼록체: 부피 무제한 / 격자 다포체: 유계 (Hensley)

  • 이번 증명은 이 지도에서 마지막까지 비어 있던 "정확한 상수" 칸 하나를 채운 것이다 — 그리고 그 증명 기법이 이웃 칸들(k≥2)로 번질 가능성이 수학계의 다음 관심사다.

7장 요약

  • 부피와 격자점 개수는 양방향 사전: Blichfeldt(점 ≤ 부피), 민코프스키·van der Corput(부피 ⇒ 점).
  • 내부점 0개 = flatness(납작함), 1개+무게중심 = 에르하르트, k개 = Hensley — 3부작 구조.
  • 2차원은 Scott으로 완결, 고차원 정확 상수는 에르하르트 케이스가 최초 수준.
  • 연속 최소량·Mahler 콤팩트성이 이 분야의 공용 장비 — 다음 장들에서 응용으로 재등장.

정수계획법(Integer Programming)이란

max cᵀx s.t. Ax ≤ b, x ∈ Zⁿ
  • 선형계획법(LP)에 "해는 정수"라는 조건 하나를 더한 것 — 그 하나로 다항시간이 NP-hard가 된다.
  • 기하로 번역하면: 다포체 { Ax ≤ b } 안의 격자점 중 cᵀx 최대인 것 찾기. 2~3장의 언어 그대로다.

LP 완화와 정수해의 간극

  • 정수 조건을 지우면 LP — 다항시간에 풀린다. 이 답을 "LP 완화 해"라 한다.
  • LP 최적해는 보통 꼭짓점 = 분수 좌표. "반올림하면 되지 않나?" — 안 된다:
  • 반올림한 점이 영역 밖으로 나가거나, 최적과 한참 먼 격자점일 수 있다
  • 애초에 다포체 안에 격자점이 하나도 없을 수도 있다 (7장의 납작한 도형!)
  • "이 다포체 안에 격자점이 존재하는가?"(feasibility)부터가 이미 NP-hard — 격자점 존재 문제의 어려움이 IP 어려움의 본체다.

NP-hard인데 왜 실무에서 풀리나

  • 항공 스케줄, 물류 최적화, 반도체 배치 — 수백만 변수 IP가 매일 현업에서 풀린다.
  • 비결은 "최악의 경우"와 "현실의 경우"의 간극: 구조(희소성, 특수 형태)를 파고드는 휴리스틱과 이론의 총력전.
  • 그 총력전의 두 축이 분기 한정법(branch & bound)과 절단 평면(cutting plane) — 그리고 둘 다 밑바닥에서 격자 기하를 쓴다.
  • 다음 슬라이드부터 그 연결 고리를 따라간다.

분기 한정법 (Branch and Bound)

  • LP 완화를 풀어 x₃ = 2.7 같은 분수 해가 나오면, 문제를 둘로 쪼갠다: x₃ ≤ 2 인 세계와 x₃ ≥ 3 인 세계.
  • 각 가지에서 다시 LP를 풀고, LP 상한이 현재 최고 정수해보다 나쁜 가지는 통째로 버린다(한정, pruning).
  • 기하학적 의미: 다포체를 격자 초평면 사이의 "판"으로 썰어 가며 격자점을 포위하는 과정.
  • 어느 변수로 쪼갤 것인가(분기 규칙)가 성능을 좌우한다 — 좋은 규칙은 "격자점이 있을 수 없는 납작한 방향"을 빨리 찾는 것. 7장 flatness의 감각이다.

절단 평면과 격자 기하

  • 절단 평면: LP 영역에서 정수점은 하나도 잃지 않으면서 분수 영역만 깎아내는 부등식.
  • 이상적 목표는 정수 껍질(integer hull) = 격자점들의 볼록 껍질에 도달하는 것.
  • Gomory 절단(1958)이 원조 — 한동안 "이론용"으로 취급되다 1990년대에 실전 부활, 현대 솔버 성능의 주역이 됐다.
  • 어떤 절단이 유효한가의 판정이 곧 "이 반공간 밖에 격자점이 없는가"라는 격자 기하 질문이다.

Lenstra 1983 — 고정 차원의 기적

변수 개수 n이 고정이면, IP는 다항시간에 풀린다
  • H. W. Lenstra Jr.의 1983년 정리. 변수 5개짜리 IP는 제약이 수백만 개여도 다항시간.
  • 2장 난이도 스펙트럼의 실전판: "차원이 상수냐 변수냐"가 격자 문제의 운명을 가른다.
  • 이 정리는 순수한 알고리즘 발명이 아니라 — 기하학적 수론(민코프스키, flatness)을 알고리즘으로 번역한 것이다.

Lenstra 알고리즘의 심장 = 격자 기하

  • 절차의 뼈대:
  • ① 다포체를 선형변환으로 "둥글게" 만든다 (타원체 근사)
  • ② 둥근 도형이 크면 → 민코프스키식 논리로 격자점이 반드시 있다 → 찾으면 끝
  • ③ 작으면 → flatness 정리로 어떤 정수 방향으로 납작하다 → 그 방향의 격자 초평면 몇 장만 검사
  • ④ 각 초평면 = 차원이 1 줄어든 같은 문제 → 재귀
  • "부피가 크면 격자점이 있다"와 "없으면 납작하다"의 이중주 — 5~7장에서 배운 정리들이 알고리즘의 부품으로 작동한다.

"부피 ⇒ 정수점" 논리의 쓰임

  • 솔버가 어떤 가지(부분 다포체)를 만났을 때:
  • 부피·폭이 문턱 이상 → "정수해 존재 확실" — 탐색 없이 존재 보장
  • 납작함이 문턱 이하 → "이 방향 초평면 몇 장만 보면 됨" — 탐색 공간 폭발 방지
  • 이런 문턱값들이 바로 민코프스키 2ⁿ, flatness w(n), 그리고 에르하르트형 상수들이다.
  • 상수가 sharp할수록 판정이 공격적이어도 안전하다 — 더 좋은 상수 = 더 빠른 가지치기. 순수수학의 부등식 개선이 솔버 성능 이론의 개선으로 이어지는 회로다.

에르하르트형 부등식과 feasibility 증명서

  • 에르하르트 정리를 대우로 읽으면: 무게중심이 격자점인 볼록체의 부피가 (n+1)ⁿ/n!을 넘으면, 내부 격자점이 2개 이상이다.
  • 즉 "해가 최소 2개"라는 존재 증명서를 부피 계산만으로 발급할 수 있다 — 유일해 가정을 깨거나, 대안 해 존재를 보장하는 용도.
  • 실무 솔버가 오늘 이 부등식을 그대로 호출하는 것은 아니다 — 하지만 Lenstra의 역사가 보여주듯, 이런 sharp한 부등식은 훗날 알고리즘 설계자의 부품함에 들어간다.
  • 민코프스키 정리(1889)가 Lenstra(1983)와 LLL(1982)의 부품이 되기까지 약 90년이 걸렸다

배낭 문제로 보는 예

  • 0/1 배낭 = 초입방체 {0,1}ⁿ의 꼭짓점 중 부등식 하나(무게)를 만족하며 가치 최대인 것 — IP의 최소 예제.
  • 알고리즘 수업의 DP 풀이는 "유사 다항시간" — 무게 숫자가 지수적으로 크면 무력해지고, 그때 격자·기하 기반 기법이 등판한다.
  • 배낭형 격자는 9장에서 암호 깨기(LLL)의 무대로 다시 등장한다.

실전 솔버와 이 이론의 관계

  • CPLEX, Gurobi, SCIP, OR-Tools — 현대 IP 솔버의 층위:
  • 표면: 분기 규칙, 휴리스틱, 병렬화 (엔지니어링)
  • 중간: 절단 평면 라이브러리, 전처리 (조합 최적화 이론)
  • 기반: "격자점이 언제 존재하는가"의 수학 (이 덱의 5~7장)
  • 기반층의 정리가 하나 sharp해지면 위 두 층의 보증이 함께 단단해진다.
  • 여러분이 OR-Tools로 근무표를 짤 때, 호출 스택 저 아래에 민코프스키가 있다.

케이스 스터디: 근무표 짜기

# 간호사 근무표: x[i][d][s] = 간호사 i가 d일 s교대 근무 여부 (0/1)
# 제약: 하루 1교대 이하, 야간 후 휴식, 주당 근무시간…
model = cp_model.CpModel()
x = {(i,d,s): model.NewBoolVar(f"x{i}{d}{s}") ...}
# 이 모든 제약의 교집합 = 고차원 다포체
# 가능한 근무표 = 그 안의 격자점 (0/1 벡터)
  • "가능한 근무표가 존재하는가" = "다포체에 격자점이 있는가" — 6장의 문장이 그대로 실무 문장이 된다.
  • 제약을 하나 더할 때마다 다포체가 깎이고, 어느 순간 격자점이 사라진다(infeasible) — 그 경계를 이론이 설명한다.

8장 요약

  • IP = 다포체 안의 격자점 최적화. feasibility부터 NP-hard.
  • 분기 한정·절단 평면 — 실전 솔버의 두 축, 둘 다 격자 기하 위에서 작동.
  • Lenstra 1983: 고정 차원 IP 다항시간 — 민코프스키+flatness를 알고리즘으로 번역.
  • 에르하르트 정리의 대우 = "부피 초과 ⇒ 정수해 2개 이상"이라는 존재 증명서.
  • sharp한 상수는 더 공격적인 가지치기의 안전 보증 — 부등식 개선이 성능 이론 개선이다.

RSA 이후: 양자 위협

  • RSA·ECC의 안전성 = 소인수분해·이산로그의 어려움. 그런데 Shor 알고리즘(1994)은 양자 컴퓨터로 둘 다 다항시간에 깬다.
  • "수확 후 해독(harvest now, decrypt later)": 암호문을 지금 수집해 두고 양자 컴퓨터가 생기면 푸는 공격 — 오늘 보내는 데이터도 이미 위험하다.
  • 그래서 NIST가 2016년부터 양자내성암호(PQC) 공모를 진행했고, 2024년 표준이 확정됐다.
  • 당선작들의 수학적 기반이 바로 — 격자다.

격자 기반 암호란

  • NIST 표준: ML-KEM(키 교환, 구 Kyber), ML-DSA(서명, 구 Dilithium) — 모두 격자(module lattice) 기반.
  • 이미 배포 중이다: Chrome·TLS의 하이브리드 키 교환, Signal 메신저의 PQXDH, iMessage PQ3.
  • 기본 구도: 비밀 = 격자 근처의 짧은 벡터. 공개 = 일부러 "나쁜 기저"로 뒤섞은 격자 정보(+노이즈, LWE).
  • 공격자가 해야 하는 일이 정확히 SVP/CVP류 격자 문제 — 다음 두 슬라이드.

SVP — 최단 벡터 문제

주어진 격자 L에서 0 아닌 가장 짧은 벡터 찾기
  • 2차원이면 쉽다(가우스의 축약 알고리즘). 차원 수백이면? — NP-hard(무작위 축소 하에서).
  • 민코프스키(5장)가 보장하는 것: 길이 √n·det^(1/n) 이하의 벡터가 존재한다.
  • 그러나 존재 증명은 비구성적 — 실제로 찾으려면 지수 시간. 이 "존재와 탐색의 간극"이 암호의 존재 기반이다.
  • ML-KEM-768의 보안은 대략 "차원 ~600+ 격자의 SVP 근사가 2¹⁴⁰번 연산으로도 안 됨"에 걸려 있다.

CVP — 최근접 벡터 문제

격자 밖의 점 t가 주어질 때, t에 가장 가까운 격자점 찾기
  • SVP의 비균질 버전 — 일반적으로 SVP보다 어렵다(SVP를 CVP로 환원 가능).
  • 암호 해독과의 대응: 암호문 = 격자점 + 작은 노이즈. 복호화 = 노이즈 낀 점에서 원래 격자점 복원 = CVP.
  • 정당한 수신자는 비밀(좋은 기저)이 있어 CVP가 쉽고, 공격자는 나쁜 기저뿐이라 CVP가 어렵다 — 비대칭성의 정체.
  • 오류정정부호의 복호화와 수학적으로 같은 문제라는 점도 기억해 두자(10장).

가우시안 휴리스틱: 부피 ↔ 점 개수

#(K ∩ L) ≈ Vol(K) / det(L)
⇒ λ₁(L) ≈ √(n/2πe) · det(L)^(1/n)
  • "영역 안의 격자점 수 ≈ 부피 ÷ 격자 타일 부피" — 2장 가우스 원 직관의 암호학 버전.
  • 이 근사로 "최단 벡터 길이가 대략 얼마일지"를 예측하고, 공격 알고리즘의 성공 확률과 비용을 견적한다.
  • 보안 파라미터 표의 숫자들(차원, 모듈러스, 노이즈 폭)이 전부 이 부피 계산에서 나온다.
  • 휴리스틱이 어긋나는 특수 격자가 있는지 — 그것을 통제하는 것이 5~7장 부등식들의 일이다.

민코프스키 한계와 보안 파라미터

  • 설계자의 체크리스트에서 부피 부등식이 하는 일:
  • 상한(민코프스키): "이보다 짧은 벡터는 존재할 수 있다" → 공격자에게 유리한 최악 케이스 상정
  • 하한(전이 정리, 쌍대 격자): "이보다 짧을 수는 없다" → 복호 실패율 통제
  • 노이즈가 너무 크면 정당한 복호가 실패하고, 너무 작으면 공격이 쉬워진다 — 그 사이 안전 구간의 존재를 부피 논법이 증명한다.
  • "부피로 격자점을 통제한다"는 에르하르트류 수학이 파라미터 표 뒤에서 일하는 방식이다.

LLL 알고리즘 (1982)

  • Lenstra–Lenstra–Lovász: 다항시간에 "적당히 짧은"(2^(n/2) 근사) 기저를 찾는 알고리즘.
  • 정확한 SVP는 못 풀지만, 근사만으로 응용 수십 개가 무너지고/세워졌다 — 다음 슬라이드.
  • 8장 Lenstra IP 알고리즘의 ①단계("둥글게 만들기")를 실제로 수행하는 도구이기도 하다.

LLL이 깨뜨린 것들, 세운 것들

  • 깨뜨린 것:
  • Merkle–Hellman 배낭 암호(1978 제안 → 1982 LLL로 붕괴)
  • 저지수 RSA 공격 (Coppersmith 방법 — 작은 근 찾기를 격자 축약으로)
  • 잘못 구현된 (EC)DSA 서명의 비밀키 복원 (nonce 편향 공격)
  • 세운 것: 정수 관계 탐지(어떤 상수가 대수적 항등식을 만족하는지 발견), 유리수 복원, 그리고 8장의 고정 차원 IP.
  • "격자 축약 한 번으로 40년치 암호 시스템의 생사가 갈렸다" — 격자 기하의 실전 파괴력.

BKZ와 보안 강도 추정

  • BKZ = LLL의 강화판: 블록 크기 β를 키울수록 더 짧은 벡터(품질↑), 대신 시간은 β에 지수적(비용↑).
  • 현대 격자 암호의 보안 주장 형식: "이 파라미터를 깨려면 BKZ 블록 β ≥ 400이 필요하고, 그 비용은 2¹⁴⁰ 이상."
  • 즉 방어 강도가 "최고 성능 격자 알고리즘의 비용 곡선"으로 정의된다 — 곡선 견적의 재료가 앞의 가우시안 휴리스틱과 부피 부등식.
  • 격자 기하 정리 하나가 바뀌면 전 세계 보안 파라미터 표가 다시 계산된다.

ten-proofs 7번: GapCVP — 같은 발표에!

"Polynomial-factor hardness of approximation for the
closest vector problem" — GapCVP.lean
  • 1장 목록의 7번을 기억하는가 — Astra는 에르하르트 추측과 같은 발표에서 CVP의 다항 인자 근사 경도(hardness)도 증명했다.
  • GapCVP: "최근접 거리가 r 이하인가, γ·r 이상인가"의 판별 문제. 근사 인자 γ가 클수록 어려움을 보이기 힘들다.
  • 다항 인자까지 어렵다는 것은 기존에 알려진 경도 결과를 크게 밀어 올린 것이다.

GapCVP 결과의 의미

  • 격자 암호의 신뢰 구조: "깨려면 CVP/SVP 근사를 잘해야 한다 + 그 근사는 어렵다(고 믿는다)".
  • 둘째 믿음의 증거가 강해질수록 격자 암호의 이론적 기반이 단단해진다 — 이번 결과는 그 방향의 전진.
  • 주의: 암호가 실제 쓰는 근사 인자(다항식보다 훨씬 큰)까지 어렵다는 증명은 여전히 미해결 — 과장 금물
  • 한 발표에서 "격자의 극값 기하(8번)"와 "격자의 계산 경도(7번)"가 동시에 나왔다는 것: 이 두 세계가 한 분야임을 보여주는 상징적 장면.

9장 요약

구 채우기 문제

  • 같은 크기의 공을 공간에 겹치지 않게 놓을 때, 공간의 몇 %까지 채울 수 있는가?
  • 격자점마다 공을 놓는 "격자 채우기"가 유력 후보 — 또 격자다.

케플러 추측 400년

  • 케플러(1611): "3차원 최밀 배열은 과일가게 오렌지 쌓기(면심입방), 밀도 π/√18 ≈ 74.05%."
  • 이 한 문장의 증명에 383년이 걸렸다 — 힐베르트 18번 문제의 일부이기도 했다.
  • 1998년 Thomas Hales가 방대한 컴퓨터 계산으로 증명 — 그런데 새 문제가 생겼다: "이 증명을 누가 다 검사하나?"

Hales의 증명과 Flyspeck

  • 1998년 증명은 300쪽 논문 + 수 GB의 계산. 심사위원단은 4년 검토 끝에 "99% 확신"이라는 이례적 결론을 냈다.
  • Hales의 응답이 Flyspeck 프로젝트(2003–2014): 증명 전체를 HOL Light·Isabelle 증명 보조기로 형식화 — 11년 만에 완료.
  • "사람이 다 못 읽는 증명은 기계로 검사한다" — 12장에서 볼 Astra 검증 체계의 직계 조상이다.

격자 채우기와 밀도

밀도 = Vol(구) / det(L) (격자 채우기의 경우)
  • 격자 채우기의 밀도 = 공 하나의 부피 ÷ 격자 타일 부피 — 2장의 기본 영역이 그대로 분모다.
  • 최단 벡터 λ₁이 공 반지름의 한계를 정한다(공 지름 ≤ λ₁) — SVP(9장)와 같은 수학.

E8과 Leech — 기적의 차원

  • 2016년 Maryna Viazovska: 8차원 최밀 채우기는 E8 격자 — 필즈상(2022).
  • 곧이어 24차원 Leech 격자도 해결. 8과 24에서만 "마법의 함수"가 존재해 상한과 구성이 정확히 만난다.
  • 일반 차원의 최적 밀도는 여전히 미해결 — 그 상한 개선이 Astra의 1번 결과다(이 장 마지막).

통신 = 고차원 구 채우기

  • Shannon(1948)의 통찰: 길이 n의 신호 = n차원 공간의 점. 잡음 = 점 주위의 불확실성 구(球).
  • 오류 없이 통신하려면 신호점들의 잡음 구가 겹치지 않아야 한다 — 채널 용량 문제가 구 채우기 문제가 된다.
  • 더 빽빽한 채우기 = 같은 대역폭에 더 많은 신호 = 더 빠른 통신.
  • 모뎀의 성상도(constellation), 5G의 변조 설계가 전부 이 기하 위에 있다. E8 격자는 실제로 격자 부호(lattice code)로 쓰인다.

오류정정부호

  • 이진 부호 = 초입방체 {0,1}ⁿ 꼭짓점들의 부분집합. 최소 거리 d = 코드워드 사이 최소 해밍 거리.
  • 거리 d 부호는 반지름 (d−1)/2 해밍 구들이 서로 겹치지 않음 — 이산 버전의 구 채우기.
  • 복호화 = "받은 벡터에서 가장 가까운 코드워드 찾기" = CVP(9장)의 해밍판.

부호 한계와 부피 논법

해밍 한계: |C| ≤ 2ⁿ / Vol(해밍 구)
GV 한계: |C| ≥ 2ⁿ / Vol(반지름 d−1 구)
  • 부호 이론의 기본 상한·하한이 문자 그대로 부피 나누기다 — "겹치지 않는 구의 개수 ≤ 전체 부피 ÷ 구 부피".
  • 더 정밀한 한계(선형계획 한계, Delsarte)는 이 부피 논법을 최적화(LP!)로 강화한 것 — 8장과 도구가 합류한다.
  • 60년째 열려 있는 질문: 이진 부호에서 상한과 하한 사이의 지수적 간극을 누가 좁힐 것인가 — 그리고 2026년 8월, 그 간극이 움직였다.

ten-proofs 1·2번 — 이 분야도 움직였다

  • 1번 SpherePacking.lean: 일반 차원 구 채우기 밀도의 점근 상한을 개선, Cohn–Elkies 문턱값 도달 — Viazovska 이후 최대급 진전.
  • 2번 MetricCodes.lean: 모든 최소 거리에서 이진 부호 상한을 지수적으로 강화 + 구면 부호 대응 결과.
  • 즉 이번 발표는 "에르하르트 하나"가 아니라 — 격자·부피·채우기·부호로 이어지는 이 덱의 수학 전체에 대한 동시 다발 진전이었다.
  • 10개 중 4개(1, 2, 7, 8)가 이 지도 위의 문제다. 우연이 아니라, 이 분야가 "정밀한 부등식"의 밀도가 높은 지형이기 때문.

격자점 세기의 복잡도

  • "다포체 안의 격자점 개수는?" — 존재 판정(8장)보다 한 단계 더 어려운 질문.
  • 일반 차원에서는 #P-hard: 개수 세기 문제의 NP-hard급. (0/1 배낭 해의 개수 세기부터 이미 #P-완전.)
  • 그런데 차원을 고정하면? 8장 Lenstra가 "존재"를 다항시간으로 만들었듯 —
  • "개수"도 다항시간이 된다. 그 돌파구가 Barvinok 알고리즘이다.

Barvinok 1994 — 고정 차원 다항시간 세기

Σ_{z ∈ P∩Zⁿ} x^z 를 짧은 유리함수의 합으로 표현
  • 아이디어: 격자점을 하나씩 세지 않고, 모든 격자점의 생성함수를 통째로 짧은 수식으로 압축한다.
  • 부품: 다포체를 꼭짓점 뿔(cone)로 분해 + 각 뿔을 unimodular 뿔들로 재귀 분해 — 재귀의 수렴을 LLL(9장!)이 보장한다.
  • 기하학적 수론의 도구들이 총출동하는 알고리즘 — 이 덱에서 배운 부품이 전부 들어 있다.
  • x = (1,…,1)을 대입하면 격자점 개수, 미분하면 합계·평균 통계까지 나온다.

통계: 분할표 세기

  • 분할표(contingency table): 행 합·열 합이 고정된 음이 아닌 정수 행렬 — 4장 준마방진의 통계학 이름.

    body();                // 몇 번 실행되나?
// 인덱스 공간 = 삼각형 tΔ₂ 꼴 → 답 = N(N+1)/2
// = 파라미터 N에 대한 에르하르트 (준)다항식!
  • 2장의 복선 회수: polyhedral 컴파일러(LLVM Polly, GCC Graphite)는 루프 실행 횟수를 barvinok 라이브러리로 기호적으로 센다.
  • 이 숫자로 무엇을 하나 — 벡터화 이득 판단, 타일 크기 선택, GPU 스레드 배분, 통신량 견적.
  • 에르하르트 이론이 "매일 빌드되는 코드"가 된 가장 직접적인 사례.

캐시 분석과 준다항식

  • "이 루프가 캐시 미스를 몇 번 내는가?" — 재사용 거리 계산은 격자점 세기로 환원된다.
  • 타일 크기 B가 파라미터로 들어가면 답이 B의 준다항식(나머지에 따라 계수가 주기적으로 변함)이 된다 — 4장에서 스치듯 본 개념이 실전에서 이렇게 나타난다.
  • WCET(최악 실행 시간) 분석, 임베디드 메모리 배치 최적화도 같은 수학을 쓴다.
  • "컴파일러 백엔드 엔지니어 채용 공고에 격자점 세기가 나오는" 이유다.

기하 알고리즘과 격자

  • 격자의 보로노이 셀 = "이 격자점이 가장 가까운 영역" — CVP(9장)의 기하학적 정답 지도.
  • 부피 계산 자체도 알고리즘 문제: 볼록체 부피의 정확 계산은 #P-hard, 무작위 워크로 근사는 다항시간 — 세기와 재기의 복잡도가 여기서도 얽힌다.

덤: 반사 다포체와 물리학

  • 반사(reflexive) 다포체: 내부 격자점이 정확히 1개(원점)이고 쌍대도 격자 다포체인 것 — 에르하르트 추측의 사촌 조건이다.
  • Batyrev(1994): 반사 다포체 쌍이 끈이론의 거울 대칭 Calabi–Yau 공간 쌍을 만든다.
  • 4차원 반사 다포체는 473,800,776개 — 물리학자들이 격자점 세기 소프트웨어로 전수 조사했다.
  • "내부 격자점 1개짜리 도형"의 분류가 이론물리의 데이터베이스가 된 것 — 이번 추측의 등호 도형 분류도 같은 과의 수학이다.

11장 요약

  • 격자점 세기는 일반적으로 #P-hard, 고정 차원에서는 Barvinok으로 다항시간.
  • LattE·barvinok·Normaliz — 이미 설치해 쓸 수 있는 실용 도구 생태계.
  • 통계(분할표), 조합론(마방진·유량·색칠), DB 추정 — 세기 문제는 어디에나 있다.
  • 컴파일러 루프 분석·캐시 모델이 에르하르트 (준)다항식을 매일 계산한다.
  • 반사 다포체("내부점 1개" 조건의 사촌)는 끈이론 데이터베이스까지 갔다.

추론 기록 문서 (reasoning walkthroughs)

  • 논문·코드와 함께 "모델이 어떻게 생각했는가"를 정리한 별도 문서가 공개됐다.
  • 왜 중요한가: 결과만 보면 "어디까지가 모델이고 어디부터가 사람인가"를 알 수 없다 — 2025년 10월 사건의 정확한 쟁점이었다.
  • 수학자들에게는 증명 그 자체보다 "새로운 아이디어가 어디서 나왔는가"가 관심사다 — 기법이 새로우면 다른 문제에도 번진다.
  • cdn.openai.com/pdf/reasoning-walkthroughs.pdf — 원문을 직접 읽을 수 있다

Lean 4란 무엇인가

  • 증명 보조기(proof assistant)이자 프로그래밍 언어. 마이크로소프트 리서치의 Leonardo de Moura가 시작, 현재는 Lean FRO 재단이 개발.
  • 수학 명제를 타입으로, 증명을 그 타입의 항(프로그램)으로 적는다 — 증명 검사가 곧 타입 검사.
  • 핵심 설계: 검사의 최종 권위는 약 수천 줄짜리 작은 커널 — 이것만 옳으면 나머지가 아무리 복잡해도 결론은 안전하다.
  • mathlib: 전 세계 기여자들이 쌓은 형식화 수학 라이브러리 — 학부~대학원 수학의 방대한 영역이 이미 코드로 존재한다.

EhrhartVolumeInequality.lean — 인증서란

-- (개념 예시) 형식화된 정리 진술의 모양
theorem ehrhart_volume_inequality
    (K : ConvexBody n) (hc : K.centroid ∈ lattice)
    (h1 : K.interiorLatticePoints = {K.centroid}) :
    K.volume ≤ (n+1)^n / (n)! := by
  -- … 수천 줄의 기계 검사 가능한 증명 단계 …
  • 인증서(certificate) = "이 진술이 mathlib의 공리·정의로부터 유도된다"는 기계 검사 가능한 파일.
  • 사람은 이제 증명의 옳음이 아니라 진술이 원래 추측과 일치하는지만 확인하면 된다 — 검토 대상이 수백 쪽에서 몇십 줄로 준다.

Comparator 독립 검증

  • 저장소에는 Comparator라는 별도 절차가 포함되어 있다 — Lean 본체와 독립적으로 형식화를 다시 검사하는 장치.
  • 왜 이중 검사인가: "Lean 커널 자체에 버그가 있다면?"이라는 마지막 의심까지 줄이기 위한 다중화.
  • 형식 검증계의 관행: 서로 다른 구현의 검사기(예: 외부 proof checker)로 같은 인증서를 교차 검사한다.
  • 보안에서 다중화(defense in depth)를 쓰는 것과 같은 공학적 사고방식이다.

인간 수학자의 역할

  • 이번 발표에서 사람이 한 일:
  • 문제 선정(무엇이 중요하고 미해결인지), 결과의 신규성 확인(문헌 대조)
  • 모델 논증의 수학적 검토와 논문 집필 — 증명의 '서사'를 사람이 읽을 수 있게
  • 형식화된 진술이 원래 추측과 일치하는지 확인
  • "자율적으로 해결"이라는 표현과 "인간이 논문을 썼다"는 사실 사이의 긴장 — 정직하게 말하면, 발견은 모델이, 보증은 인간+기계가 나눠 맡은 협업이다.

형식 검증이 결정적인 이유

  • LLM의 고질병: 그럴듯하지만 미묘하게 틀린 논증(hallucination). 수학 증명에서는 한 줄의 비약이 전체를 무효화한다.
  • 사람 검토의 한계: 249쪽 × 10개 결과를 심사할 전문가 시간은 세상에 충분하지 않다 — Hales 사건(10장)에서 이미 본 병목.
  • Lean 검사는 비약을 원천 차단한다: 커널이 통과시키지 않으면 발표할 수 없다.
  • 즉 형식 검증은 "AI 수학"의 신뢰 문제에 대한 유일하게 확장 가능한(scalable) 해답이다 — 이번 발표의 진짜 혁신은 증명보다 이 신뢰 아키텍처라는 평가도 있다.

창의성인가, 탐색인가

  • 회의적 해석: "방대한 문헌의 기법들을 초인적 속도로 조합 탐색했을 뿐" — 그래도 결과는 결과다.
  • 낙관적 해석: 기존 도구가 실패하던 지점(6장: 대칭 부재)을 새 조합으로 돌파했다면 그것이 곧 수학적 창의성이다.
  • 판정 기준은 하나: 기법의 재사용성. 이 증명의 아이디어가 Hensley 상수(7장) 같은 이웃 문제를 연쇄적으로 무너뜨리면 "창의성" 쪽 판정승.
  • 수학계가 지금 walkthroughs 문서를 뒤지는 이유가 그것이다.

전문가들의 반응

  • 5월 발표부터 Noga Alon, Melanie Wood, Thomas Bloom 등이 검토자로 이름을 올렸다 — 발표 형식 자체에 수학계가 참여하는 모양새.
  • 테렌스 타오는 수년 전부터 "AI + 형식 검증이 수학 연구의 협업 규모를 바꿀 것"이라 공개적으로 전망해 왔다 — 이번 발표는 그 전망의 실증 사례로 인용된다.

한계와 회의론 — 정직한 결산

  • 남아 있는 유효한 의심들:
  • 문제 선정 편향: 10개는 "모델이 잘 푸는 유형"으로 골라진 표본일 수 있다 — 실패한 시도가 몇 개였는지는 공개되지 않았다
  • 재현성: Astra는 미공개 내부 모델 — 외부 연구자가 같은 능력을 검증할 수 없다
  • 비용: 문제당 계산 비용이 공개되지 않았다 — "수학자보다 싼가?"는 미지수
  • 그럼에도 흔들리지 않는 사실: Lean 인증서는 모델과 무관하게 옳다. 증명의 진위는 이제 논쟁거리가 아니다.

12장 요약

  • 인증서 덕분에 사람의 검토 대상이 "증명 전체"에서 "진술의 일치"로 축소됐다.

4색 정리 1976 — 최초의 컴퓨터 증명

  • Appel과 Haken(1976): 문제를 1,936개의 경우로 환원하고, 컴퓨터로 전수 검사해 증명 완료.
  • 수학 난제가 "사람이 다 읽을 수 없는 계산"으로 처음 해결된 사건 — 124년 만의 해결이자 논쟁의 시작.

"그것도 증명인가" 논쟁

  • 1976년 수학계의 반발: "아무도 전체를 검증할 수 없는 것을 증명이라 부를 수 있는가?"
  • 쟁점의 본질: 증명의 정의가 "동료가 읽고 납득하는 텍스트"에서 "검사 가능한 절차"로 이동하는 문제였다.
  • 해소의 역사가 의미심장하다: 2005년 Gonthier가 4색 정리를 Coq 증명 보조기로 완전 형식화 — "컴퓨터 때문에 못 믿겠다"를 "컴퓨터 덕분에 가장 확실하다"로 뒤집었다.
  • 50년 뒤 Astra 발표가 논쟁 없이 수용되는 바탕에는 이 역사가 있다.

케플러 추측과 Flyspeck — 다시 보기

  • 10장에서 본 이야기의 형식 검증 관점 요약:
  • 1998 Hales 증명 → 심사위원단 "99% 확신" — 인간 검토의 한계 노출
  • 2003–2014 Flyspeck: HOL Light·Isabelle로 전체 형식화 — 99%가 검사 가능한 확실성으로
  • 교훈 두 가지: 거대 증명의 검증은 기계화 외에 답이 없다 / 형식화에는 11년이 걸렸다.
  • Astra가 바꾼 것은 둘째 줄이다 — 형식화 자체를 모델이 수행해 "11년"을 압축했다.

Lean과 mathlib 공동체

  • mathlib: 수천 명이 기여하는 오픈소스 수학 라이브러리 — 정의·정리가 서로 참조하는 거대한 의존성 그래프.
  • PR·리뷰·CI로 수학이 축적된다: 새 정리는 기존 정의와 충돌 없이 컴파일되어야 병합된다.
  • 페르마의 마지막 정리 형식화(Kevin Buzzard 주도) 같은 대형 프로젝트가 진행 중 — 수학의 "표준 라이브러리"가 만들어지는 중이다.
  • ten-proofs가 곧바로 검증 가능했던 것은 이 공동체가 20년 가까이 쌓은 기반 위에 서 있기 때문이다.

Liquid Tensor Experiment — 예행연습

  • 2020년, 필즈상 수상자 Peter Scholze가 도전장을 냈다: "내 최신 정리의 증명이 옳은지 나도 100% 확신이 없다. 형식화해 달라."
  • Lean 공동체가 2022년 완수 — 현대 수학 최전선의 증명도 형식화 가능함을 실증했다.
  • 과정에서 실제로 논증의 미묘한 지점들이 정리·단순화됐다 — 형식화가 검증을 넘어 이해를 개선한 사례.
  • "최전선 수학 + 형식 검증"의 결합이 준비된 상태에서 AI가 도착한 것 — 타이밍의 역사다.

게임 AI에서 증명 AI로

  • 2016 AlphaGo → 2024 AlphaProof(IMO 은메달급, Lean 사용) → 2025 IMO 금메달급(구글·OpenAI) → 2026 미해결 문제.
  • 공통 구조: 정답 검증기가 있는 영역(승패 판정, Lean 커널)에서 AI는 자기 학습으로 초인간 수준에 도달한다.
  • "검증기가 강하면 생성기는 대담해질 수 있다" — 이 원리가 10년 만에 바둑판에서 정리 증명으로 이동했다.

신뢰의 체인 점검하기

  • "Lean이 통과시켰다"를 믿기 위해 실제로 믿어야 하는 것들:
  • ① 커널(수천 줄)이 논리 규칙을 옳게 구현했다 — 소규모, 다중 구현으로 교차 검증됨
  • ② 공리 체계(ZFC급)가 무모순이다 — 수학 전체가 공유하는 전제
  • ③ 형식화된 진술이 원래 추측과 같은 말이다 — 사람이 확인해야 할 유일한 고리
  • ③이 실전 취약점이다: 정의를 미묘하게 다르게 넣으면 "다른 정리"를 증명하고도 통과한다. ten-proofs를 읽는 수학자들이 집중하는 부분도 바로 진술부다.
  • 보안 감사와 완전히 같은 구조 — "코드는 옳다, 그런데 스펙이 맞나?"

커리–하워드: 증명 = 프로그램

명제 = 타입, 증명 = 그 타입의 프로그램
증명 검사 = 타입 검사
  • 여러분이 매일 하는 일과의 놀라운 동형: 타입체커를 통과하는 프로그램 작성 = 정리 증명.
  • 예: 함수 타입 A → B의 구현 = "A이면 B" 명제의 증명. 제네릭 = 전칭 명제.
  • Rust의 borrow checker, TypeScript의 타입 좁히기를 다뤄 봤다면 — 이미 가벼운 정리 증명을 해 본 것이다.
  • 컴공 4학년에게 Lean 진입 장벽은 생각보다 낮다. 14장에서 시작 경로를 안내한다.

핵심 공식 카드

픽: A = I + B/2 − 1
에르하르트: L_P(t) = Vol(P)tⁿ + … + 1, L_P(−t) = (−1)ⁿL_P°(t)
민코프스키: 대칭 볼록, Vol > 2ⁿ ⇒ 0 아닌 격자점 존재
부피 추측(정리): 무게중심 유일 내부 격자점 ⇒ Vol ≤ (n+1)ⁿ/n!
등호 ⇔ (n+1)Δₙ의 unimodular 상 · n=2에서 4.5 (넓이 9/2 삼각형)

용어집 I — 기하 편

  • 격자(lattice): 기저 벡터들의 정수 계수 결합 전체. 기본형은 Zⁿ.
  • 볼록체(convex body): 볼록 + 유계 + 내부가 비지 않은 집합.
  • 단체(simplex): n+1개 꼭짓점의 최소 다포체. Vol(Δₙ) = 1/n!.
  • 무게중심(centroid): 부피 기준 평균 위치. 그륀바움: 어느 절단이든 1/e 이상 남긴다.
  • unimodular 변환: 정수 행렬, det ±1 — 격자와 부피를 함께 보존.
  • 격자폭/flatness: 내부 격자점 없는 볼록체는 어떤 정수 방향으로 납작하다.

용어집 II — 계산 편

  • 에르하르트 다항식 L_P(t): tP 안의 격자점 수 — t의 다항식이 된다.
  • SVP/CVP: 최단/최근접 격자 벡터 문제 — 격자 암호의 어려움 원천.
  • LLL/BKZ: 격자 기저 축약 알고리즘 — 공격·IP·정수관계 탐지의 만능 도구.
  • Barvinok 알고리즘: 고정 차원 격자점 세기 다항시간 — 생성함수 압축.
  • 증명 보조기(Lean 등): 명제=타입, 증명=프로그램 — 커널이 검사.
  • 인증서(certificate): 기계 검사 가능한 증명 파일 — lake build로 재검증.
