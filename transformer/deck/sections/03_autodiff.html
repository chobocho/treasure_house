1장

수치미분의 한계

흔들어 보는 방법은 검사에는 좋고 학습에는 못 쓴다

학습에 필요한 것 — 모든 파라미터의 기울기

한 스텝의 학습은 손실 ℓ 을 파라미터 θ1, …, θN 각각으로 미분한 값이 필요합니다. 옵티마이저(8부)는 그 기울기 벡터를 받아 파라미터를 옮깁니다.

  • 식을 손으로 미분해 코드로 옮기는 방법은 모델을 바꿀 때마다 다시 해야 하고, 한 곳만 틀려도 조용히 학습이 망가집니다.
  • 가장 쉬운 기계적 방법은 수치미분 — 파라미터를 조금 흔들고 손실이 바뀐 양을 재는 것입니다.
  • 이 장은 그 방법이 왜 학습에는 못 쓰이는지를 두 가지 비용으로 유도합니다. 정확도의 벽과 계산량의 벽입니다.
  • 그리고 나머지 장에서, 순전파 한 번 비용의 상수 배로 모든 기울기를 얻는 역방향 자동미분을 직접 짓습니다.
설명용

전진 차분은 O(h), 중심 차분은 O(h²)

테일러 전개 f(x ± h) = f ± f′h + f″h2/2 ± f‴h3/6 + ⋯ 에서 출발합니다.

전진 차분
f(x+h) − f(x)h = f′ + f″2h + ⋯

잘림 오차가 h 에 비례합니다.

중심 차분
f(x+h) − f(x−h)2h = f′ + f‴6h2 + ⋯

짝수 차 항이 빼기에서 지워져 잘림 오차가 h2 에 비례합니다.

그러면 h 를 아주 작게 하면 되지 않을까요? 다음 장이 그럴 수 없는 까닭입니다.

설명용

정확도의 벽 — 잘림과 반올림의 줄다리기

컴퓨터의 f 값에는 상대 크기 ε 쯤의 반올림 오차가 있습니다(double 이면 ε = 2−52). 거의 같은 두 값을 빼고 작은 h 로 나누면 그 오차가 1/h 배로 커집니다.

중심 차분의 전체 오차
E(h) ≈ |f‴|6h2 + ε|f|h

E′(h) = 0 으로 두면 h3 = 3ε|f|/|f‴|. 함수의 크기와 굽이가 1 쯤이면 h* ~ ε1/3, 그때 E ~ ε2/3 입니다.

  • double 에서 ε1/3 은 10−6 과 10−5 사이입니다. 이 덱의 시험이 h=1e-6 을 쓰는 까닭입니다.
  • 전진 차분으로 같은 계산을 하면 h* ~ ε1/2, 오차도 ε1/2 — 훨씬 나쁩니다.
  • 어느 쪽이든 오차에 바닥이 있습니다. float32 로 학습하는 C 에서는 ε 이 훨씬 커서 바닥이 더 높습니다.
설명용

계산량의 벽 — 파라미터마다 순전파 두 번

중심 차분은 파라미터 하나의 기울기에 손실 계산 두 번이 듭니다. 모든 기울기에는

순전파 2N 번 × 한 번에 O(N) 곱셈 = O(N2)
  • GPT-2 small 의 파라미터는 124,439,808 개입니다(SPEC.md §3.4). 기울기 한 번에 순전파가 그 두 배, 약 2억 5천만 번 필요합니다.
  • 순전파 한 번이 그 자체로 억 단위의 곱셈이니, 학습 한 스텝의 곱셈이 1016 을 넘습니다. 그리고 학습은 이런 스텝을 수없이 되풀이합니다.
  • 역방향 자동미분은 순전파 한 번과 역전파 한 번 — 순전파 비용의 작은 상수 배로 N 개를 전부 줍니다. 그 상수는 7부에서 셉니다.
그래도 버리지 않는다 — 작은 입력에서 한두 번 돌리는 것은 싸고, 무엇보다 미분 코드를 믿지 않아도 됩니다. 그래서 수치미분은 학습 도구가 아니라 역전파를 검사하는 증인으로 씁니다. 이 부의 마지막 장이 그 습관입니다.

스칼라 Value

값 하나와 그 기울기, 그리고 "어디서 왔나"

아이디어 — 계산하면서 그래프를 적어 둔다

2부의 결론은 "연산마다 자기 국소 미분만 알면, 출력에서부터 곱해 내려오면 된다" 였습니다. 그러려면 순전파 때 기록이 남아야 합니다.

Value 가 드는 것왜
data순전파 값
grad∂출력/∂이 노드 — 역전파가 채운다
prev이 값을 만든 입력 노드들 — 그래프의 간선
_back내 기울기를 입력들에게 나눠 주는 함수 — 국소 미분
op사람이 읽으려는 연산 이름

파이썬 연산자(+, *)를 덮어쓰면 평범한 수식을 쓰는 것만으로 그래프가 만들어집니다. 연산은 트랜스포머를 설명하는 데 필요한 것만 남겼습니다.

설명용

코드 — Value 의 몸

  • __slots__ 는 인스턴스마다 딕셔너리를 두지 않게 합니다. 노드가 수천 개씩 생기므로 메모리가 줄어듭니다.
  • 잎 노드(입력·상수)는 prev 가 비어 있고 _back 이 없습니다. 역전파는 거기서 멈춥니다.
  • grad 는 0 으로 시작합니다. 역전파는 여기에 더해 갑니다.
실행 검증

덧셈 — 기울기를 그대로 나눠 준다

o = a + b ⇒  ∂ℓ∂a = ∂ℓ∂o · 1,  ∂ℓ∂b = ∂ℓ∂o · 1
  • def 바로 아래 줄은 x + 3 처럼 상대가 그냥 수일 때 상수 노드로 감쌉니다.
  • back 은 클로저입니다. 만들어질 때의 self·other·out 을 붙잡고 있다가, 역전파 때 그 순간의 out.grad 를 읽습니다.
실행 검증

곱셈 — 상대의 값을 곱해 돌려준다

o = ab ⇒  ∂o∂a = b,  ∂o∂b = a
  • 역전파에 순전파의 값(other.data, self.data)이 필요합니다. 그래서 순전파가 끝나도 노드를 버릴 수 없습니다 — 학습이 추론보다 메모리를 많이 먹는 근본 까닭입니다.
  • 덧셈은 기울기의 "통로", 곱셈은 기울기의 "교환기" 입니다. 한쪽 입력이 크면 다른 쪽의 기울기가 커집니다.
실행 검증

거듭제곱·지수·로그

  • __pow__ 는 지수가 상수일 때만 받습니다. 지수로도 미분하려면 xy = ey log x 로 짜면 됩니다.
  • exp 는 순전파 결과 e 를 역전파에서 다시 씁니다 — (ex)′ = ex 이니 한 번 더 계산할 필요가 없습니다.
  • log 의 미분 1/x 는 입력 값을 읽습니다.
실행 검증

tanh 와 ReLU

  • tanh′ = 1 − tanh2 — 순전파 값 t 로 끝납니다. 입력이 커서 t 가 ±1 에 붙으면 기울기가 0 에 가까워집니다(2부의 쏠림과 같은 현상).
  • ReLU 는 0 에서 미분이 없습니다. 이 코드는 0 으로 정했고, 주석이 그 관례를 밝힙니다. 실수 입력이 정확히 0 에 떨어지는 일은 드물어 어느 쪽으로 정해도 학습은 거의 같습니다.
실행 검증

나머지 연산은 공짜

  • a − b = a + (−1)b, a/b = a · b−1. 새 역전파를 하나도 짜지 않았습니다.
  • 합성된 연산의 기울기는 작은 노드들을 지나며 연쇄법칙이 알아서 만듭니다. 대신 노드가 더 생깁니다 — 속도와 메모리를 위해 4부가 소프트맥스·교차엔트로피를 한 덩어리로 짜는 까닭입니다.
  • __radd__ 류는 2 * x 처럼 왼쪽이 파이썬 수일 때 불립니다.
실행 검증

증인 — 연산마다 중심 차분과

ReLU 는 0 을 피해 양쪽에서 한 번씩 봅니다. 0 에서는 차분이 ½ 을 내므로 관례값 0 과 맞지 않습니다.

Q. double 로 중심 차분을 할 때 h=1e-12 로 줄이면 기울기가 더 정확해집니까? 그리고 Value 에 sin 을 더한다면 back() 안에 무엇을 적어야 합니까?

A. 아닙니다. 잘림 오차 h2 는 줄지만 반올림 오차 ε/h 가 커져, 최적점 ε1/3 근처보다 나빠집니다. sin 의 국소 미분은 cos 이므로 self.grad += math.cos(self.data) * out.grad — 덮어쓰지 않고 더합니다.

위상정렬과 역순

기울기가 다 모인 노드만 지나간다

차례가 틀리면 답이 틀린다

12노드 그래프에서 n7 = exp x1 의 back() 을 n8 보다 먼저 불렀다고 해 봅시다.

  • 그 시점의 n7.grad 는 아직 0 입니다. x1 은 지수 길에서 0 을 받습니다.
  • 뒤늦게 n8 이 n7.grad 를 채워도, n7 의 back() 은 이미 지나갔습니다. x1 의 기울기에서 한 길이 통째로 빠집니다.
  • 규칙: 노드의 back() 은 그 노드를 쓴 모든 노드의 back() 이 끝난 뒤에만 부릅니다.

"나를 쓴 노드가 모두 먼저" 는 "나를 만든 입력이 모두 먼저" 의 거울상입니다. 뒤의 차례를 구해서 뒤집으면 됩니다.

설명용

위상정렬 — 간선이 늘 앞에서 뒤로

정의 방향 그래프의 노드를 한 줄로 늘어놓되, 모든 간선 u → v 에 대해 u 가 v 보다 앞에 오게 한 차례.
  • 순환이 없는 그래프(DAG)에만 있습니다. 계산 그래프는 "값은 이미 계산된 값으로만 만든다" 는 사실 때문에 늘 DAG 입니다.
  • 하나로 정해지지 않습니다. 12노드 그래프에서 n7 과 n9 는 서로 무관해 어느 쪽이 앞이어도 됩니다.
  • 입력이 먼저 오는 차례를 뒤집으면 "쓴 쪽이 먼저" 가 되어, 앞 장의 규칙을 만족합니다.
  • 깊이 우선 탐색에서 자식을 다 끝낸 뒤 자신을 적으면(후위 순회) 이 차례가 나옵니다. 여기서는 부모가 prev, 즉 입력입니다.
설명용

코드 — 재귀 없는 후위 순회

  • (v, False) 를 꺼내면 "다녀왔음" 을 표시하고, (v, True) 를 먼저 쌓은 뒤 입력들을 쌓습니다. 입력들이 전부 처리된 다음에야 (v, True) 가 나와 order 에 붙습니다.
  • seen 은 id 로 셉니다. 값이 같은 두 노드는 다른 노드이기 때문입니다.
실행 검증

코드 — backward 는 일곱 줄

  • self.grad = 1.0 — ∂출력/∂출력 = 1. 2부의 gL 이 수 하나일 때의 씨앗입니다.
  • reversed(order) — 출력이 맨 먼저, 입력이 맨 나중입니다.
  • 노드마다 back() 을 딱 한 번 부르고, back() 은 입력 수만큼만 일하므로 전체가 O(노드 + 간선) 입니다.

4장 퀴즈

Q. order 를 뒤집지 않고 앞에서부터 back() 을 부르면 12노드 그래프의 입력 기울기는 무엇이 됩니까?

A. 모두 0 입니다. 앞쪽의 n4 같은 노드가 먼저 불리는데, 그때 자신의 grad 는 아직 0 이라 0 만 전합니다. 출력의 씨앗 1 은 맨 마지막에 n12 가 불릴 때에야 n11 로 한 칸 내려가고 거기서 끝납니다.
설명용

역전파가 붙잡고 있는 것

역전파는 O(노드) 시간에 끝나지만 공짜는 아닙니다. 순전파 동안 만든 것을 역전파가 끝날 때까지 버리지 못합니다.

  • 각 back 클로저가 입력·출력 노드와 순전파 값(e, t)을 붙잡습니다.
  • 그래서 학습의 메모리는 "파라미터" 에 "중간값(활성값)" 이 더해집니다. 중간값은 배치·문맥 길이·층 수에 비례해 늘어납니다.
  • 추론만 할 때는 기울기가 필요 없으니 중간값을 곧바로 버릴 수 있습니다. 텐서 판은 기울기가 필요 없는 연산에서 아예 기록을 남기지 않습니다(다음 장의 make).

퍼짐을 색인표 하나로

크기 1 인 축의 보폭을 0 으로 두는 것이 요령입니다. 그 축을 따라 출력에서 움직여도 입력의 같은 칸을 읽습니다.

손으로 — 입력 (3,) 을 출력 (2, 3) 으로

입력을 (1, 3) 으로 보면 보폭은 (3, 1), 크기 1 인 첫 축은 0 으로 바꿔 (0, 1). 출력 칸 (i, j) 는 입력 칸 0·i + 1·j = j 를 읽으므로 표는 [0, 1, 2, 0, 1, 2] 입니다.

색인표 길이는 출력 칸 수와 같습니다 — O(출력 칸) 시간·공간. 순전파는 이 표로 읽고, 역전파는 같은 표로 쌓습니다.

행렬곱과 모양 연산의 역전파

dA = dY Bᵀ, dB = Aᵀ dY, 그리고 칸 옮기기

행렬곱의 역전파 유도

Y = AB, A 는 [n, m], B 는 [m, p], 위에서 온 기울기 G = dY 는 [n, p].

정리
dA = G B⊤,   dB = A⊤ G
증명

Aik 는 Yij = Σk AikBkj 의 i 행에만, 계수 Bkj 로 나타납니다. 모든 j 에서 몫을 더하면 ∂ℓ/∂Aik = Σj GijBkj = (GB⊤)ik. 같은 방법으로 ∂ℓ/∂Bkj = Σi AikGij = (A⊤G)kj.

외울 필요가 없습니다. 모양만 맞추면 답이 하나뿐입니다 — [n, m] 을 만들려면 [n, p] 뒤에 [p, m] = B⊤ 를 붙일 수밖에 없습니다.

설명용

코드 — matmul 순전파

  • 안쪽 두 줄이 2부의 "읽기 2" 입니다: A[i][k] 를 계수로 B 의 k 행을 출력 i 행에 더합니다.
  • 앞의 배치 축은 브로드캐스팅합니다. 어텐션의 [B, h, n, dk] 곱이 이 경로를 탑니다.
  • MULTS 는 실제 곱셈 수를 셉니다. 7부가 연산량 식을 이 계수기로 확인합니다.
실행 검증

코드 — matmul 역전파

  • s 는 Σj GijBkj = (GB⊤)ik, 둘째 루프는 AikGij 를 dBkj 에 쌓습니다 — 앞 장 증명의 두 합 그대로입니다.
  • B 가 배치로 퍼졌으면 ob 가 여러 t 에서 같아, 기울기가 배치를 따라 더해집니다.
  • 곱셈 수는 순전파와 같은 차수입니다. 행렬곱 하나의 역전파는 행렬곱 둘입니다.

7장

브로드캐스팅의 역전파

늘어난 축을 따라 더한다

왜 "더한다" 인가

편향 더하기 Yij = Xij + bj 에서 bj 는 j 열의 모든 행에 쓰였습니다.

유도
∂ℓ∂bj = Σi ∂ℓ∂Yij ∂Yij∂bj = Σi Gij

2부의 다변수 연쇄법칙 — 쓰인 곳마다의 몫을 더한 것 — 그대로입니다.

일반 규칙 입력 모양이 출력 모양으로 퍼졌다면, 입력 기울기는 출력 기울기를 퍼진 축들을 따라 더해 입력 모양으로 줄인 것입니다. 앞에 새로 붙은 축은 통째로, 크기 1 이던 축은 크기 1 로 남기며 더합니다.

이 코드는 이 규칙을 따로 구현하지 않습니다. _binary 의 색인표와 += 가 같은 합을 칸마다 만듭니다.

설명용

증인 — 편향의 기울기는 행의 수

  • 앞 두 줄은 행 방향 퍼짐과 열 방향 퍼짐을 차분과 견줍니다.
  • 마지막은 닫힌 값입니다. 손실이 모든 칸의 합이면 Gij = 1, 행이 넷이라 Σi 1 = 4.

rel(a, b) = maxk |ak − bk|max(maxk|ak|, maxk|bk|, 10−12)
  • 칸마다 나누지 않는 까닭 — 참 기울기가 0 근처인 칸은 차분 잡음(바닥 ε2/3)만 남아, 칸마다 나누면 오차가 부풀려집니다.
  • 절대 오차를 쓰지 않는 까닭 — 기울기 크기가 연산마다 몇 자릿수씩 달라, 한 기준으로는 큰 쪽이 늘 불리합니다.
  • 분모의 1e-12 는 둘 다 0 인 벡터에서 0 으로 나누지 않으려는 것입니다.
실행 검증

출력이 텐서면 — 무작위 가중합으로 스칼라를 만든다

역전파는 스칼라 출력에서만 시작합니다. 출력 f(x) 가 텐서면 고정된 무작위 가중치 w 로

ℓ = Σk wk fk(x) ⇒  ∇xℓ = w J
  • 2부의 벡터-야코비안 곱을 w 방향으로 한 번 시험하는 셈입니다.
  • w 의 칸이 모두 0 이 아닌 무작위 값이라, 야코비안의 어느 칸이 틀려도 결과에 흔적이 남습니다. 모든 칸이 1 이면 출력 칸들에 걸쳐 합쳐진 값만 보게 되어, 출력끼리 서로 상쇄되는 오류를 놓칩니다.
  • 이 방식으로 tensor·ops·attention 의 모든 연산을 같은 도우미 하나로 시험합니다.
실행 검증

연산마다의 기울기 검증 표

위 표의 오차는 모두 1장의 차분 바닥 근처에 모여 있고, 시험의 기준 TOL = 1e-5 보다 몇 자릿수 작습니다. 역전파에 잘못된 항 하나가 섞이면 오차는 바닥이 아니라 기울기 크기의 자릿수로 뛰어오릅니다 — 그 사이의 넓은 틈 덕분에 판정이 흔들리지 않습니다.

표의 아래쪽 연산(소프트맥스·레이어놈·GELU 등)은 4부에서, scaled_dot_product 는 6부에서, rope 는 7부 4장에서 유도합니다. 식을 보기 전에 검증이 먼저 끝나 있는 셈입니다.

실행 검증

습관 — 새 연산을 넣을 때마다

  • 먼저 시험 — 역전파를 짜기 전에 차분 시험을 적고, 빨간불(RED)이 맞는 이유로 나는지 봅니다.
  • 작은 모양, 어긋난 크기 — (2, 3, 4) 처럼 축마다 크기를 다르게 둡니다. 모두 같으면 전치를 빠뜨려도 모양이 맞아 떨어집니다.
  • 퍼짐과 재사용을 따로 — 편향 퍼짐, 배치 퍼짐, 같은 텐서 두 번 쓰기를 각각 한 줄씩.
  • 닫힌 값 하나 — 차분과 맞아도 둘 다 틀릴 수 있습니다(같은 버그를 공유하는 순전파). 손으로 센 값 하나를 함께 박습니다.
  • 기준을 늘리지 않는다 — 오차가 크면 코드를 의심합니다. float32 처럼 바닥이 정말 다른 경우에만 까닭을 적고 기준을 정합니다(SPEC.md §9).
  • 매끄럽지 않은 점을 피한다 — ReLU 의 0 처럼 미분이 없는 점에서는 차분이 관례값과 다릅니다.
설명용

3부 정리 — 그리고 4부로

  • 수치미분은 오차에 바닥이 있고, 파라미터마다 순전파 두 번이 들어 학습에 못 씁니다. 검사에는 씁니다.
  • Value 는 값·기울기·입력·국소 미분을 들고, 연산자 덮어쓰기로 그래프를 스스로 적습니다.
  • 역전파 = 위상정렬 → 씨앗 1 → 역순으로 back(). 기울기는 += 로 모입니다.
  • 텐서는 편 리스트 + 모양 + 보폭. 퍼짐은 색인표 하나로, 역전파는 같은 표로 흩어 더합니다.
  • 행렬곱의 역전파는 dA = GB⊤, dB = A⊤G.
  • 모든 연산은 무작위 가중합 + 중심 차분 + 상대 오차로 시험합니다.

이 부품으로 모델 전체를 조립할 수도 있지만 느리고 불안정합니다. 4부는 소프트맥스·교차엔트로피·레이어놈을 한 덩어리 연산으로 짜고, 그 역전파를 손으로 유도합니다.
