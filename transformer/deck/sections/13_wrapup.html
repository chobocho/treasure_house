2장

흔한 오해 열 가지

짧게 틀리고 길게 바로잡는다

오해 1~2

1. "어텐션 가중치가 곧 모델의 설명이다"

가중치는 값 벡터를 섞는 비율일 뿐, 섞인 뒤 Wo·FFN·다음 블록이 그것을 어떻게 쓰는지는 말하지 않습니다. 6부 7장의 지도는 "어디를 보았나" 이지 "왜 그렇게 답했나" 가 아닙니다.

2. "√d 로 나누는 것은 수치 안정성 때문이다"

넘침을 막는 것은 소프트맥스 안의 최댓값 빼기(4부)입니다. √d 는 점수의 분산을 1 로 맞춰 소프트맥스가 쏠리지 않게 합니다(6부 2장).

설명용

오해 3~4

3. "멀티헤드는 파라미터를 헤드 수만큼 늘린다"

Wqkv 는 헤드 수와 무관하게 [d, 3d] 입니다. 폭을 나눌 뿐입니다(6부 4장).

4. "인과 마스크는 추론 때만 필요하다"

학습 때가 더 중요합니다. 줄 전체가 한꺼번에 들어오므로 가리지 않으면 다음 토큰을 베낍니다 (6부 3장).

설명용

오해 5~6

5. "파라미터 수는 논문에 적힌 대로다"

GPT-2 small 의 "117M" 과 센 124,439,808 이 다릅니다. 셀 수 있으면 셉니다(7부 6장).

6. "Adam 에 L2 를 더하면 AdamW 와 같다"

L2 를 기울기에 섞으면 √v̂ 로 나뉘어 파라미터마다 감쇠의 세기가 달라집니다. AdamW 는 감쇠를 따로 더합니다(8부).

설명용

오해 7~8

7. "float32 와 float64 는 같은 코드면 같은 답을 낸다"

상쇄가 있는 합에서는 끝자리가 크게 흔들리고, 참값이 0 인 기울기는 잡음만 남습니다. 대조 기준을 어떻게 적느냐부터가 설계입니다(9부 5장).

8. "스레드를 늘려도 결과는 같다"

합을 나눠 쌓으면 괄호가 바뀌어 끝자리가 달라집니다. 출력 칸마다 한 스레드가 차례로 계산해야 같습니다(9부 6장).

설명용

오해 9~10

9. "KV 캐시는 근사다"

인과 마스크 아래에서는 정확히 같은 로짓을 냅니다. 시험이 1e-9 안에서 봅니다(10부 3장).

10. "LoRA 는 처음부터 A 와 B 가 함께 배운다"

B = 0 에서 시작하면 A 의 기울기는 정확히 0 입니다. B 가 먼저 움직여야 A 가 배웁니다(11부). 이 덱의 계획서도 처음에 이것을 거꾸로 적었습니다.

종합 퀴즈

부를 넘나드는 물음

종합 1

Q. 어휘 512, 폭 64, 블록 3, 문맥 48, 학습 위치 임베딩, dff = 4d 인 모델의 파라미터 수를 7부의 식으로 세어 보십시오.

A. V·d = 512·64 = 32,768, T·d = 48·64 = 3,072, 블록 하나 12·64² + 13·64 = 49,152 + 832 = 49,984, 블록 셋 149,952, 마지막 LN 128. 합 32,768 + 3,072 + 149,952 + 128 = 185,920 입니다. 8부 한국어 모델의 캡처 첫 줄(설정 줄)의 파라미터 수와 견줘 보십시오.
설명용

종합 2

Q. 학습을 시작한 첫 스텝의 손실이 ln V 보다 한참 크게 나왔습니다. 의심할 곳을 셋만 꼽으십시오.

A. (1) 초기화 — 0.02 대신 큰 표준편차로 뽑아 로짓이 커졌다(7부 5장). (2) 출력 사영 — wte 를 묶지 않고 다른 행렬을 쓰거나 전치를 빠뜨려 크기가 어긋났다. (3) 손실 계산 — 평균 대신 합을 냈거나, 정답을 한 칸 밀지 않아 엉뚱한 토큰을 맞히게 했다(8부 배치). ln V 는 "로짓이 모두 0 에 가깝다" 는 가정에서 나오므로(4부), 그 가정을 깨는 곳부터 봅니다.
설명용

종합 3

Q. C 모델이 파이썬과 로짓은 1e-5 로 맞는데 기울기 하나의 텐서만 크게 어긋납니다. 어텐션 역전파의 어느 줄을 먼저 보겠습니까?

A. 어긋나는 텐서가 무엇이냐에 따라 다릅니다. bqkv 의 k 부분이면 참값이 0 이라 잡음일 수 있으니 기준부터 봅니다(9부 5장). Wqkv 전체가 어긋나면 dq·dk 에 곱한 1/√d 를 빠뜨렸거나 두 번 곱했는지, dK = dSᵀQ 에서 전치를 빠뜨렸는지 봅니다. Wo 만 어긋나면 헤드를 합칠 때 열의 차례가 뒤바뀌었는지(SPEC §3.1) 봅니다. 로짓이 맞는다는 것은 순전파가 맞다는 뜻이라, 역전파에만 있는 줄이 용의자입니다.
