1장

벡터와 내적

두 토큰이 얼마나 닮았는지를 곱셈 d 번으로 잰다

벡터는 수의 목록입니다

트랜스포머 안에서 토큰 하나는 실수 d 개의 목록으로 삽니다. 이 목록을 벡터라 부르고 x ∈ ℝd 로 적습니다.

  • 각 칸 xi 는 뜻이 정해진 특징이 아닙니다. 학습이 쓰임새를 정합니다.
  • 그래서 칸 하나를 읽기보다 두 벡터 사이의 관계를 읽는 편이 쓸모 있습니다 — 방향이 같은가, 얼마나 긴가.
  • 이 덱은 벡터를 행 벡터(가로로 누운 1×d)로 둡니다(SPEC.md §2). 토큰 n 개를 위에서 아래로 쌓으면 곧바로 n×d 행렬이 됩니다.
왜 행 벡터인가 — 메모리에 행 우선으로 펴 놓은 배열에서 토큰 하나가 연속한 d 칸이 됩니다. 파이썬 리스트와 C 배열이 같은 차례로 읽힙니다.
설명용

내적 — 칸끼리 곱해서 더한다

정의 — 내적
a·b = Σi=1d ai bi
결과는 벡터가 아니라 수 하나입니다.
  • 비용은 곱셈 d 번, 덧셈 d 번 — O(d) 입니다. 이보다 싼 "닮음" 척도는 드뭅니다.
  • 순서를 바꿔도 같습니다: a·b = b·a.
  • 각 인자에 선형입니다: (αa + c)·b = α a·b + c·b. 미분할 때 이 성질을 계속 씁니다.
  • 자기 자신과의 내적은 길이의 제곱입니다: ‖a‖2 = a·a.
설명용

내적의 기하 — 길이 × 길이 × 코사인

정리
a·b = ‖a‖ ‖b‖ cos θ
θ 는 두 벡터가 이루는 각입니다.
증명

선형성으로 펼치면 ‖a − b‖2 = ‖a‖2 + ‖b‖2 − 2 a·b 입니다. 한편 a, b, a−b 는 두 벡터가 펼치는 평면 위의 삼각형이므로 코사인 법칙이 ‖a − b‖2 = ‖a‖2 + ‖b‖2 − 2‖a‖‖b‖ cos θ 를 줍니다. 두 식을 견주면 끝납니다.

차원이 몇이든 두 벡터는 평면 하나를 펼치므로, 고등학교 삼각형 그림이 그대로 통합니다.

설명용

코사인 유사도 — "얼마나 닮았나"

정의
cos θ = a·b‖a‖ ‖b‖
값기하읽는 법
1같은 방향길이만 다를 뿐 같은 것을 가리킵니다
0직교서로에 대해 아무것도 말해 주지 않습니다
−1반대 방향정반대를 가리킵니다

길이 1 인 벡터 u 와의 내적 a·u 는 a 를 u 방향으로 사영한 성분입니다. "이 방향의 특징이 얼마나 들어 있나" 를 재는 탐지기로 읽을 수 있고, 이 읽기가 행렬곱의 세 번째 읽기로 이어집니다.

설명용

어텐션은 코사인이 아니라 내적을 씁니다

어텐션 점수는 q·k 입니다. 길이로 나누지 않습니다.

  • 장점 — 나눗셈과 제곱근이 없어 싸고, 길이 자체도 신호가 됩니다. "이 키는 크게 외친다" 를 벡터 길이로 표현할 수 있습니다.
  • 대가 — 길이가 제멋대로 자라면 점수도 자랍니다. 점수가 크면 소프트맥스가 한 칸에 쏠리고 (3장), 쏠린 소프트맥스는 기울기가 거의 0 입니다(4장).
  • 그래서 길이를 관리하는 장치가 둘 들어갑니다. 레이어놈이 벡터의 크기를 행마다 맞추고(4부), 점수를 √dk 로 나눕니다(6부). 나누는 값이 왜 하필 √dk 인지는 이 부의 6장이 준비합니다.
설명용

2장

행렬곱의 세 가지 읽기

같은 곱셈을 사상으로, 행의 가중합으로, 열의 탐지기로

행렬은 행 벡터를 쌓은 것

한 줄의 토큰 n 개를 폭 d 로 표현하면 X ∈ ℝn×d 입니다. 행 하나가 토큰 하나입니다.

메모리에는 행 우선(row-major)으로 1차원에 폅니다. (r, c) 칸은 r × 열수 + c 번째입니다(SPEC.md §2). 시험이 이 약속을 박아 둡니다.

3부에서 이 편 배열 위에 모양(shape)과 보폭(stride)을 얹어 텐서를 만듭니다.

실행 검증

행렬곱의 정의와 모양

정의 — 선형층(SPEC.md §2)
Y = XW,   Yij = Σk Xik Wkj
X 는 [n, 입력], W 는 [입력, 출력], Y 는 [n, 출력].
  • 모양 규칙은 "안쪽 둘이 같아야 하고, 바깥 둘이 남는다" 입니다.
  • 곱셈 수는 n · 입력 · 출력 입니다. 7부에서 모델의 연산량을 이 수로 셉니다.
  • 논문은 흔히 열 벡터로 Wx 라 적습니다. 그 W 는 [출력, 입력] 모양이고, 이 덱의 W 는 그 전치입니다. 식을 옮길 때 모양부터 확인하십시오.
설명용

읽기 1 — 모든 토큰에 같은 사상

Y 의 i 행은 X 의 i 행만으로 정해집니다:

yi = xi W
  • 같은 W 가 모든 토큰에 똑같이 적용됩니다. 토큰끼리 섞이지 않습니다.
  • 그래서 n 개를 한꺼번에 곱해도 하나씩 곱한 것과 같습니다. 병렬화가 공짜입니다.
  • 선형 사상이므로 (x + x′)W = xW + x′W. 잔차 스트림에 더해진 성분들이 따로따로 사영됩니다(7부).
  • 토큰을 섞는 일은 트랜스포머에서 어텐션 한 곳만 합니다. FFN·레이어놈·임베딩은 전부 이 읽기의 "토큰마다 따로" 입니다.
설명용

읽기 2 — 출력 행은 W 의 행들의 가중합

정의를 k 로 묶어 다시 적으면

yi = Σk Xik · (W 의 k 행)

입력의 칸 값이 W 의 행을 얼마나 섞을지 정하는 계수입니다. 아래 시험의 첫 행 [1, 2] 는 W 의 0 행을 1 번, 1 행을 2 번 더하라는 뜻이고, 그 합이 기댓값의 첫 행입니다.

어텐션의 출력이 바로 이 꼴입니다 — 가중치 행렬의 한 행이 값 벡터들을 섞습니다(6부). 3부의 matmul 루프가 i-k-j 차례인 것도 이 읽기 그대로입니다.

실행 검증

읽기 3 — 칸 하나는 내적, 열 하나는 탐지기

같은 정의를 j 로 보면 칸 하나는 입력 행과 W 의 열의 내적입니다:

Yij = xi · w·j
  • W 의 j 열은 "특징 j 의 방향" 입니다. 출력 j 칸은 그 방향으로의 사영, 즉 1장의 탐지기입니다.
  • 열 방향으로 보면 Y 의 j 열 = Σk Wkj · (X 의 k 열) — 입력 특징(열)들의 선형 조합입니다.
  • 시험의 둘째 행 [3, 4] 와 W 의 0 열 [1, 2] 의 내적은 3 + 8 = 11, 기댓값의 (1, 0) 칸과 같습니다.
읽기이 덱에서 쓰이는 자리
1 사상선형층·FFN 이 토큰마다 따로 돈다
2 행의 가중합어텐션 출력, 임베딩, 루프 차례 i-k-j
3 열의 탐지기q·k 점수, 로짓 = 잔차 × 임베딩 전치
설명용

편향 더하기 — 모양이 다른 둘의 덧셈

Y = XW + b,   Yij = Σk Xik Wkj + bj

XW 는 [n, 출력] 인데 b 는 [출력] 하나뿐입니다. 수학 책은 "모든 행에 더한다" 고 한 줄로 넘어가지만, 코드는 이것을 규칙으로 가져야 합니다.

  • 이 규칙이 브로드캐스팅입니다 — 모양을 오른쪽 끝부터 맞추고, 없는 축은 늘려 씁니다.
  • 순전파에서는 편리할 뿐이지만, 역전파에서는 뜻이 있습니다. 편향 한 칸이 출력 n 칸에 쓰였으므로 기울기도 n 칸에서 모여야 합니다.
  • 그 "모은다" 의 근거는 4장의 "길이가 여럿이면 더한다" 이고, 3부 7장에서 유도·구현·시험합니다.
설명용

전치 — 행과 열을 맞바꾼다

정의
(A⊤)ij = Aji
[n, m] 이 [m, n] 이 됩니다.
성질
(AB)⊤ = B⊤A⊤
증명

((AB)⊤)ij = (AB)ji = Σk AjkBki = Σk (B⊤)ik(A⊤)kj.

전치는 두 곳에서 핵심입니다. 어텐션 점수 QK⊤ 는 [n, d]·[d, n] = [n, n] 로 "모든 질의 × 모든 키" 의 내적표이고, 행렬곱의 역전파 dA = dY B⊤ 에도 전치가 나옵니다(3부).

설명용

2장 퀴즈

Q. 선형층 가중치가 이 덱의 약속대로 [입력, 출력] = [64, 256] 모양입니다. 토큰 10개짜리 입력 X 에 곱하면 출력의 모양은 무엇이고, 출력의 (3, 7) 칸은 어떤 두 벡터의 내적입니까?

A. 출력은 [10, 256] 입니다. (3, 7) 칸은 X 의 3 행(토큰 3 의 64칸 벡터)과 W 의 7 열(64칸)의 내적입니다 — 읽기 3. 같은 행 전체는 W 의 64개 행을 토큰 3 의 칸 값으로 섞은 것입니다 — 읽기 2.
설명용

3장

소프트맥스와 로그합지수

점수를 확률로 — 그리고 넘치지 않게

소프트맥스 — 아무 실수나 확률로

정의
pi = eziΣj ezj
z 를 로짓(logit)이라 부릅니다.
  • 모든 pi > 0 이고 합은 1 — 확률분포입니다.
  • 순서를 지킵니다. 로짓이 큰 칸이 확률도 큽니다.
  • 이름은 "부드러운 argmax" 에서 왔습니다. 가장 큰 칸에 1 을 주는 대신 크기에 따라 몫을 나눠 줍니다.
  • 트랜스포머에서 두 번 나옵니다 — 어텐션 가중치(6부)와 다음 토큰의 확률(7부).
설명용

왜 지수인가 — 차이만 본다

두 칸의 확률 비는 로짓의 차이에만 달려 있습니다:

pipj = ezi − zj

로짓이 1 오르면 확률 비가 e 배 — 로짓은 "로그 확률의 눈금" 입니다. 음수 로짓도 문제없습니다.

정리 — 이동 불변 모든 칸에 같은 상수 c 를 더해도 소프트맥스는 같습니다.
증명

ezi+c / Σj ezj+c = ecezi / (ec Σj ezj) — 분자·분모의 ec 가 약분됩니다.

이 한 줄이 다음 장의 안정한 계산법과, 6부의 "모든 키에 같은 벡터를 더해도 점수가 안 바뀐다" 의 뿌리입니다.

설명용

그냥 계산하면 넘친다

아래 캡처의 셋째 줄처럼 로짓이 천 단위만 되어도 ez 는 double 의 최댓값을 넘습니다. 그런데 이동 불변이므로 최댓값을 먼저 빼고 계산해도 답은 같습니다. 그러면 가장 큰 지수가 e0 = 1 이 되어 절대 넘치지 않습니다.

위 표의 세 줄은 로짓의 간격이 같아 확률도 같아야 합니다. 셋째 줄에서 "그냥 exp" 만 넘쳤고, 최댓값을 뺀 판은 첫 줄과 같은 값을 냈습니다.

실행 검증

코드 — 한 행의 소프트맥스

  • 행 전체가 −∞ 이면 확률을 정의할 수 없으므로 조용히 NaN 을 내지 않고 멈춥니다.
  • math.fsum 은 반올림 오차를 보정한 합입니다. 칸이 많아도 합이 1 에서 덜 벗어납니다.
실행 검증

온도 — 쏠림을 조절하는 손잡이

pi(τ) = softmax(z / τ)i
  • τ → 0: 비 e(zi−zj)/τ 가 무한히 커져 argmax 가 됩니다.
  • τ → ∞: 모든 지수가 0 으로 가 고른 분포 1/n 이 됩니다.
  • 10부의 샘플링이 이 손잡이를 씁니다. 6부의 √d 로 나누기도 "온도를 올리는" 일과 같습니다.
실행 검증

온도 표 — 숫자로 보기

위 표에서 온도를 반으로 줄일 때마다 가장 큰 칸의 몫이 커지고, 두 배로 늘릴 때마다 네 칸이 서로 가까워집니다. 온도를 바꿔도 칸의 순서는 그대로입니다 — 1/τ 는 양수 배율일 뿐이라 로짓의 순서를 못 바꿉니다.

실행 검증

로그합지수 — 로그 확률을 곧장 계산하기

손실은 확률이 아니라 로그 확률을 씁니다(5장). 소프트맥스를 먼저 구하고 로그를 취하면, 아주 작은 확률이 0 으로 반올림된 뒤 log 0 = −∞ 가 됩니다. 로그 공간에서 바로 계산해야 합니다.

정의 — 로그합지수(LSE)와 로그소프트맥스
LSE(z) = log Σj ezj = m + log Σj ezj − m,  m = max z
log pi = zi − LSE(z)
성질 — 부드러운 최댓값
m ≤ LSE(z) ≤ m + log n
증명

합 Σj ezj−m 에는 1 인 항이 하나 있고, 모든 항이 1 이하이며 항이 n 개이므로 합은 [1, n] 에 있습니다. 로그를 취하면 됩니다.

설명용

코드 — 로그소프트맥스

증인 시험은 확률이 적당히 큰 입력에서 두 길이 같은 값을 내는지 봅니다. 확률이 반올림으로 0 이 되는 입력에서는 math.log(0) 이 오류를 내고 멈춥니다.

4장

연쇄법칙과 야코비안

역전파가 왼쪽에서 곱하는 까닭

미분은 국소 선형 근사, 연쇄법칙은 그 합성

f(x + h) ≈ f(x) + f′(x) h

미분 f′(x) 는 "입력을 조금 흔들면 출력이 몇 배로 흔들리나" 입니다. y = f(x), z = g(y) 를 이으면 흔들림도 이어집니다.

연쇄법칙(스칼라)
dzdx = dzdy · dydx

배율에 배율을 곱할 뿐입니다. 이 덱의 자동미분은 이 곱셈을 기계적으로 되풀이하는 장치입니다. 각 연산은 자기 배율(국소 미분)만 알면 되고, 전체 식을 알 필요가 없습니다.

설명용

길이 여럿이면 더한다

x 가 u 와 v 두 곳에 쓰이고 z = g(u, v) 이면, x 를 흔든 영향은 두 길로 동시에 퍼집니다.

연쇄법칙(다변수)
∂z∂x = ∂z∂u∂u∂x + ∂z∂v∂v∂x
  • 예: z = x · x. 두 길이 각각 x 를 주어 합이 2x — 곱의 미분법과 같습니다.
  • 한 노드의 기울기는 그 노드를 쓴 모든 곳에서 온 몫의 합입니다.
  • 코드에서는 기울기를 = 로 덮어쓰지 않고 += 로 쌓는다는 뜻입니다. 3부의 시험이 이 규칙을 지킵니다.
설명용

야코비안 — 배율이 행렬이 될 때

정의 y = f(x), x ∈ ℝn, y ∈ ℝm 일 때
J ∈ ℝm×n,   Jij = ∂yi∂xj

국소 선형 근사가 Δy ≈ Δx J⊤ 꼴이 되고, 합성의 야코비안은 곱입니다:

Jg∘f = Jg Jf

행렬곱의 성분 Σk (∂zi/∂yk)(∂yk/∂xj) 이 바로 앞 장의 "길마다 곱해서 더한다" 입니다. 중간 변수 yk 하나하나가 길 하나입니다.

설명용

왜 왼쪽부터 곱하나 — 벡터-야코비안 곱

신경망은 x → h1 → ⋯ → hL → ℓ 이고, 끝의 손실 ℓ 은 수 하나입니다.

∂ℓ∂x = gL JL JL−1 ⋯ J1,   gL = ∂ℓ/∂hL (행 벡터)
  • 오른쪽부터 곱하면 행렬 × 행렬입니다. 폭이 w 인 층에서 w×w 야코비안을 만들고 곱해야 합니다. 한 줄 n 토큰·폭 d 이면 w = nd 라 칸이 (nd)2 개입니다.
  • 왼쪽부터 곱하면 매번 (행 벡터) × (행렬) = 행 벡터 입니다. 중간 결과는 늘 층의 폭만 합니다.
  • 게다가 gJ 는 J 를 만들지 않고도 계산됩니다. 연산마다 이 곱 하나를 짜 두는 것이 역전파(vector-Jacobian product, VJP)입니다.
설명용

역방향과 순방향 — 몇 번 돌려야 하나

순방향 모드(오른쪽부터)역방향 모드(왼쪽부터)
한 번에 얻는 것입력 방향 하나에 대한 출력 전체의 변화 Jv출력 하나에 대한 입력 전체의 기울기 gJ
모든 ∂ℓ/∂θ 를 얻으려면파라미터 수 N 번한 번
대가추가 메모리가 거의 없다순전파의 중간값을 역전파까지 들고 있어야 한다

학습은 "출력 하나(손실), 입력 수억(파라미터)" 이므로 역방향이 압도적으로 쌉니다. 3부 1장의 수치미분이 순방향과 같은 처지 — 파라미터마다 따로 돌려야 합니다 — 라서 학습에 못 씁니다.

설명용

소프트맥스의 야코비안

정리
∂pi∂zj = pi(δij − pj),   J = diag(p) − p⊤p
p 는 행 벡터라 p⊤p 가 n×n 외적입니다.
증명

log pi = zi − LSE(z) 를 zj 로 미분합니다. ∂LSE/∂zj = ezj/Σkezk = pj 이므로 (1/pi) ∂pi/∂zj = δij − pj. 양변에 pi 를 곱합니다.

대각 칸은 pi(1 − pi) 로 양수, 나머지는 음수입니다 — 한 칸을 올리면 다른 칸이 내려갑니다(합이 1 이니까).

설명용

증인 — 닫힌 식과 차분 야코비안

시험용 함수입니다. 실제 역전파는 이 행렬을 만들지 않습니다 — 다음 장.

실행 검증

소프트맥스의 역전파 — 야코비안 없이 O(n)

위에서 온 기울기 g = ∂ℓ/∂p 에 야코비안을 왼쪽에서 곱합니다.

유도
gJ = g diag(p) − (gp⊤) p = p ⊙ (g − ⟨g, p⟩)

gp⊤ = ⟨g, p⟩ 는 수 하나이므로 내적 한 번, 원소별 곱 한 번이면 끝납니다.

같은 방법으로 — 로그소프트맥스

∂ log pi/∂zj = δij − pj 이므로 (gJ)j = gj − pj Σi gi.

야코비안을 만들면 n2 칸, 이 식은 n 칸입니다. 어휘가 수만인 출력층에서 이 차이가 곧 가능과 불가능의 차이입니다.

설명용

코드 — 소프트맥스 순전파와 역전파

  • back 은 순전파가 계산한 P 를 붙잡아 둡니다. 역전파가 순전파의 중간값을 들고 있어야 하는 이유가 이것입니다.
  • gx[...] += — 앞 장의 "길이 여럿이면 더한다" 입니다.
  • 차분과의 대조는 test_backward 가 합니다. 3부 끝의 기울기 검증 표에 softmax·log_softmax 줄로 실립니다.
실행 검증

쏠린 소프트맥스는 배우지 못한다

한 칸이 거의 1 을 가져간 p ≈ ek 를 야코비안에 넣어 봅니다.

Jij = pi(δij − pj) → 0  (모든 i, j)
  • i ≠ k 인 행은 pi ≈ 0 이라 0 입니다.
  • i = k 인 행은 pk(δkj − pj) 인데, j = k 면 1 − pk ≈ 0, 아니면 pj ≈ 0 입니다.
  • 야코비안이 0 이면 위에서 어떤 기울기가 내려와도 로짓으로는 거의 아무것도 안 갑니다. 그 앞의 가중치는 배우지 못합니다.

점수의 분산이 크면 이 상태가 됩니다. 6장이 그 분산을 계산하고, 6부가 어텐션에서 실제로 잽니다.

설명용

4장 퀴즈

Q. 폭이 1000 인 층이 열 개 이어진 망에서 손실의 입력 기울기를 구합니다. 야코비안을 오른쪽부터(입력 쪽부터) 곱하면 중간 결과가 어떤 모양이고, 왼쪽부터 곱하면 어떤 모양입니까? 소프트맥스 층이라면 gJ 를 어떻게 계산합니까?

A. 오른쪽부터면 1000×1000 행렬끼리의 곱이 아홉 번 — 칸 백만 개짜리 중간 결과입니다. 왼쪽부터면 늘 길이 1000 인 행 벡터입니다. 소프트맥스는 야코비안을 만들지 않고 p ⊙ (g − ⟨g, p⟩) 로 O(n) 에 끝냅니다.
설명용

5장

교차엔트로피·퍼플렉시티·KL

모델이 얼마나 놀랐는지를 재는 법

음의 로그 가능도 — 정답에 준 확률만 본다

언어 모델은 위치마다 다음 토큰의 분포 p 를 냅니다. 실제 다음 토큰이 t 였다면 채점은 한 칸만 봅니다:

−log pt
정답에 준 확률−log pt뜻
10전혀 놀라지 않았다
1/V (고르게 찍음)log V아무것도 모른다
→ 0→ ∞확신하고 틀렸다 — 무한한 벌점

왜 로그인가. 문장 전체의 확률은 토큰 확률의 곱이고, 로그를 취하면 합이 됩니다. 곱은 금방 0 으로 반올림되지만 합은 안정하고, 평균을 내면 문장 길이와 무관한 척도가 됩니다.

설명용

교차엔트로피와 이 덱의 손실

정의 — 교차엔트로피
H(y, p) = −Σi yi log pi
참 분포 y 로 사건이 일어날 때, 모델 p 가 느끼는 평균 놀람입니다.

정답이 원-핫 y = et 이면 합에서 한 항만 남아 −log pt 입니다. 이 덱의 손실은 모든 (배치, 위치) 에 대한 그 평균입니다(SPEC.md §3.3). 이 절에서 N 은 파라미터 수가 아니라 (배치, 위치) 행의 수입니다:

ℓ = −1N Σr=1N log pr, tr

계산은 로그소프트맥스로 합니다: −log pt = LSE(z) − zt. 소프트맥스를 거치지 않으니 넘침도 0 의 로그도 없습니다.

설명용

코드 — 교차엔트로피

실행 검증

로짓 기울기는 p − y

정리
∂∂z (−log pt) = p − y
N 행 평균이면 행마다 (p − y)/N.
증명

−log pt = LSE(z) − zt. 첫 항의 미분은 4장에서 본 pj, 둘째 항의 미분은 δjt = yj 입니다.

  • 소프트맥스 야코비안과 로그의 미분이 약분되어 뺄셈 한 번만 남습니다. 둘을 따로 역전파하면 같은 값을 멀리 돌아서 얻습니다.
  • 각 칸은 [−1, 1] 에 있고 행의 합은 1 − 1 = 0 입니다. 정답 칸은 끌어올리고, 나머지는 받은 확률만큼 밀어 내립니다.
  • 이미 정답에 1 을 준 행은 기울기가 0 — 잘 맞힌 예제는 더 가르치지 않습니다.
설명용

증인 — p − y 열과 역전파 열

위 표의 "p − y" 열은 식으로 계산했고 "역전파한 기울기" 열은 backward() 가 냈습니다. 두 열이 칸마다 같습니다. 열의 합이 0 인지도 눈으로 더해 보십시오.

실행 검증

처음 손실은 ln V

로짓이 모두 같으면 pi = 1/V 이므로 손실은 정확히 −log(1/V) = ln V 입니다. 가중치를 작게 초기화한 모델은 로짓이 거의 같아 이 값 근처에서 출발합니다.

디버깅 습관 — 학습 첫 스텝의 손실을 ln V 와 견주십시오. 훨씬 크면 초기화가 너무 크거나 로짓이 한쪽으로 쏠린 것이고, 훨씬 작으면 정답이 입력에 새고 있을 수 있습니다.
실행 검증

퍼플렉시티 — "몇 갈래에서 헤매나"

정의
PPL = exp(ℓ) = exp(−1N Σr log pr, tr)
다르게 쓰면
PPL = (Πr 1pr, tr)1/N

로그 평균의 exp 는 기하평균입니다. 정답에 준 확률의 역수를 기하평균한 값입니다.

  • 고르게 찍는 모델은 PPL = exp(ln V) = V — V 면 주사위를 굴리는 것과 같은 헷갈림입니다.
  • 완벽한 모델은 1 입니다. 퍼플렉시티 20 은 "매 토큰마다 20 갈래 중에서 고르는 만큼 헷갈린다" 로 읽습니다.
  • 손실(nats)보다 사람이 읽기 쉬워 논문 표에 흔히 쓰입니다. 다만 어휘가 다른 모델끼리는 견줄 수 없습니다 — 토큰 하나가 뜻하는 글자 양이 다르기 때문입니다(5부).
설명용

엔트로피와 KL 발산

정의
H(y) = −Σi yi log yi,   KL(y ‖ p) = Σi yi log yipi
(0 log 0 = 0 으로 약속합니다.)

로그를 쪼개면 세 양이 한 줄로 묶입니다:

H(y, p) = H(y) + KL(y ‖ p)
  • H(y) 는 데이터 자체의 불확실성이라 모델이 못 바꿉니다. 그래서 교차엔트로피를 줄이는 것은 KL 을 줄이는 것과 같습니다.
  • 원-핫 정답은 H(y) = 0 이라 두 값이 같습니다.
  • KL 은 대칭이 아닙니다 — KL(y‖p) ≠ KL(p‖y). 거리라기보다 "y 를 p 로 흉내 낸 비용" 입니다.
설명용

KL 은 음수가 아니다

정리(깁스 부등식) KL(y ‖ p) ≥ 0, 등호는 y = p 일 때만.
증명

모든 u > 0 에서 log u ≤ u − 1 이고 등호는 u = 1 뿐입니다. yi > 0 인 칸에서 u = pi/yi 로 두면 −KL = Σ yi log(pi/yi) ≤ Σ (pi − yi) ≤ 1 − 1 = 0.

따름 결과 — 고른 분포 u 에 대해 KL(p ‖ u) = ln V − H(p) ≥ 0. 엔트로피는 ln V 를 넘지 못하고, 고르게 찍을 때 최대입니다. 앞 장의 "처음 손실 ln V" 가 가장 모르는 상태라는 말의 근거입니다.

설명용

6장

기댓값과 분산

6부의 1/√d 를 미리 증명해 둔다

기댓값 — 더하기는 늘, 곱하기는 독립일 때만

정의 확률변수 X 의 기댓값 E[X] 는 가능한 값을 확률로 가중한 평균입니다.
두 규칙
E[aX + bY] = a E[X] + b E[Y]  (언제나)
E[XY] = E[X] E[Y]  (X, Y 가 독립일 때)
  • 첫째는 선형성입니다. 변수들이 얼마나 얽혀 있든 성립합니다.
  • 둘째는 독립이 필요합니다. 반례: X 가 ±1 을 반씩 가지면 E[X] = 0 인데 E[X·X] = 1.
  • 독립인 두 변수의 함수 f(X), g(Y) 도 독립입니다 — 곧 X2, Y2 에 씁니다.
설명용

분산 — 퍼짐의 제곱

정의
Var[X] = E[(X − μ)2] = E[X2] − μ2,   μ = E[X]
표준편차는 그 제곱근입니다.
성질
Var[aX] = a2 Var[X]
Var[Σi Xi] = Σi Var[Xi]  (서로 독립일 때)
둘째 성질의 증명

평균을 빼 둔 Yi = Xi − μi 로 쓰면 E[(Σ Yi)2] = Σi E[Yi2] + Σi≠j E[Yi]E[Yj]. 교차항은 독립이라 곱으로 쪼개지고 각 인자가 0 입니다.

첫째 성질이 "√d 로 나누면 분산은 d 로 나뉜다" 를 줍니다.

설명용

독립인 두 변수의 곱

q, k 가 독립이고 둘 다 평균 0, 분산 1 이라 합시다.

보조정리
E[qk] = 0,   Var[qk] = 1
증명

독립이므로 E[qk] = E[q]E[k] = 0. 분산은 E[(qk)2] − 02 = E[q2k2] 인데, q2 와 k2 도 독립이라 E[q2]E[k2] 로 쪼개집니다. 평균이 0 이니 E[q2] = Var[q] = 1, k 도 같습니다.

정규분포일 필요도 없습니다. 평균 0 · 분산 1 · 독립, 이 셋만 썼습니다.

설명용

내적의 분산은 d — 그래서 √d 로 나눈다

정리 q, k ∈ ℝd 의 성분 2d 개가 모두 독립이고 평균 0, 분산 1 이면
E[q·k] = 0,   Var[q·k] = d,   Var[q·k√d] = 1
증명

q·k = Σi qiki 의 항들은 서로 다른 성분만 쓰므로 독립입니다. 앞 장의 보조정리로 항마다 평균 0 · 분산 1, 독립 합의 분산 규칙으로 합은 분산 d. 마지막은 Var[aX] = a2Var[X] 에 a = 1/√d.

표준편차가 √d 로 자라므로 폭을 넓힐수록 점수가 퍼지고, 4장의 쏠림이 옵니다. 원 논문은 이 논증을 각주로 적고 점수를 1/√dk 배 합니다. 실제 가중치는 이 가정을 정확히 따르지 않습니다 — 이것은 "왜 이 크기의 배율인가" 의 설명이지 학습 중의 보장이 아닙니다.

논문 근거

증인 — 뽑아서 재 본 분산

위 표의 "Var(q·k)/d" 와 "Var(q·k/√d)" 열이 모두 1 근처입니다. 표본 1만 쌍의 흔들림 안에서 정리와 맞습니다.

표를 만든 함수 dot_variance 와 그림은 6부에서 어텐션과 함께 봅니다.

실행 검증

덤 — 고차원의 무작위 벡터는 거의 직교한다

같은 정리를 1장의 코사인에 넣어 봅니다. 성분이 평균 0 · 분산 1 이면 E[‖q‖2] = Σ E[qi2] = d 이고, d 가 크면 길이는 √d 근처에 몰립니다.

cos θ = q·k‖q‖ ‖k‖ ≈ q·kd,   표준편차 ≈ √dd = 1√d
  • 폭이 넓을수록 무작위 두 방향의 코사인은 0 에 몰립니다. 넓은 공간에는 "서로 간섭하지 않는 방향" 이 아주 많습니다.

5~6장 퀴즈

Q. 어휘 V 인 모델의 첫 스텝 손실이 ln V 였습니다. 그때의 퍼플렉시티는 얼마이고, 한 행의 로짓 기울기 p − y 의 정답 칸 값은 얼마입니까? 또 성분 분산이 1 인 폭 64 의 질의·키라면 점수 q·k 의 표준편차는 얼마이고, √d 로 나눈 뒤에는 얼마입니까?

A. 퍼플렉시티는 exp(ln V) = V 입니다. 모든 칸이 1/V 이므로 정답 칸의 기울기는 1/V − 1(나머지 칸은 1/V) 입니다. 점수의 분산은 64 라 표준편차 8, √64 = 8 로 나누면 표준편차 1 입니다.
