# SPEC — 파이썬과 C 가 함께 지키는 약속

이 문서는 `py/transformerlib`(참조 구현)와 `c/`(C99 재구현)가
**같은 답을 내기 위해** 지켜야 할 것을 전부 적는다. 두 시험 묶음이
이 문서의 절 번호를 인용한다. 코드보다 먼저 쓰였고, 코드가 이 문서와
어긋나면 코드가 틀린 것이다.

허용 오차(§9)는 여기서만 정한다. 시험을 통과시키려고 늘리지 않는다.

## 1. 난수 — splitmix64 로 씨앗을 펴고 xoshiro256** 로 뽑는다

모든 64비트 연산은 2⁶⁴ 에서 넘친다(파이썬은 `& (2**64-1)` 로 흉내).

### 1.1 씨앗 펴기 (splitmix64)

```
x ← seed
네 번 되풀이:
  x ← x + 0x9E3779B97F4A7C15
  z ← x
  z ← (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9
  z ← (z ^ (z >> 27)) * 0x94D049BB133111EB
  상태에 z ^ (z >> 31) 을 차례로 넣는다 (s0, s1, s2, s3)
```

### 1.2 한 번 뽑기 (xoshiro256**)

```
결과 ← rotl(s1 * 5, 7) * 9
t  ← s1 << 17
s2 ← s2 ^ s0;  s3 ← s3 ^ s1
s1 ← s1 ^ s2;  s0 ← s0 ^ s3
s2 ← s2 ^ t;   s3 ← rotl(s3, 45)
```

### 1.3 파생 분포

| 이름 | 정의 |
|---|---|
| `uniform()` | `(next() >> 11) × 2⁻⁵³` — [0, 1) 의 double |
| `normal()` | `u1 = 1 − uniform()`, `u2 = uniform()` 를 **이 차례로** 뽑고 `√(−2 ln u1) · cos(2π u2)` |
| `randint(n)` | `⌊uniform() × n⌋` — 0 ≤ r < n |
| `permutation(n)` | 0‥n−1 을 늘어놓고 i = n−1 부터 1 까지 `j = randint(i+1)`, i 와 j 를 바꾼다 |

`normal()` 은 Box–Muller 의 짝 가운데 코사인 쪽만 쓰고 사인 쪽은
버린다. 남겨 두었다가 다음 호출에 주는 캐시를 두지 않는다 —
캐시가 있으면 두 언어가 "몇 번째 호출인가" 까지 맞춰야 한다.
`u1 = 1 − uniform()` 은 ln 0 을 피하려는 것이다(u1 ∈ (0, 1]).

### 1.4 박아 둔 값 (씨앗 42)

펼친 상태:

```

s2 = 0x47526757130f9f52   s3 = 0x581ce1ff0e4ae394
```

`next()` 처음 여덟:

0xae17533239e499a1  0xecb8ad4703b360a1
0xfde6dc7fe2ec5e64  0xc50da53101795238

## 2. 텐서 배치와 선형층

- 모든 행렬은 **행 우선**(row-major)으로 1차원에 편다.
  `(r, c)` 원소는 `r × 열수 + c` 번째다.
- 입력은 행 벡터다. 토큰 n 개의 폭 d 표현은 `X ∈ ℝ^{n×d}`.
- 선형층 가중치는 `[입력, 출력]` 모양이고 `Y = X W + b` 다.
  즉 `Y[i][j] = Σ_k X[i][k] · W[k][j] + b[j]`.
- 파이썬은 float64, C 는 float32 로 계산한다. 체크포인트는 float32.
  파이썬이 읽으면 float32 값이 그대로 float64 로 올라온다.

## 3. 모델 — GPT 형 디코더

설정: `V` 어휘, `T` 최대 문맥, `d` 폭, `L` 블록 수, `h` 헤드,
`d_ff` FFN 폭. `d % h == 0`, `d_k = d / h`.

```
x = wte[토큰] + (위치 방식이 learned 면 wpe[위치], sin 이면 §3.2)
블록마다:
  a = LN1(x)
  qkv = a Wqkv + bqkv         모양 [n, 3d] → q, k, v 로 3등분
  q,k,v 를 [h, n, d_k] 로 나눈다 (§3.1), rope 면 q,k 를 돌린다
  att = softmax(q kᵀ / √d_k + 인과 마스크) — 헤드마다
  o = (att v 를 [n, d] 로 합침) Wo + bo
  x = x + o
  f = GELU(LN2(x) W1 + b1) W2 + b2
  x = x + f
로짓 = LNf(x) wteᵀ           (출력 사영은 임베딩과 묶는다)
```

### 3.1 헤드 나누기

`q` 의 `[n, d]` 에서 헤드 `j` 는 열 `j·d_k ‥ (j+1)·d_k − 1` 이다.
합칠 때는 같은 자리에 되돌려 놓는다.

### 3.2 위치 인코딩

- **learned**: `wpe ∈ ℝ^{T×d}` 를 더한다.
- **sin**: `PE(p, 2i) = sin(p / 10000^{2i/d})`,
  `PE(p, 2i+1) = cos(p / 10000^{2i/d})`. 파라미터가 아니다.
- **rope**: 헤드 안의 짝 `(2i, 2i+1)` 을 각
  `θ = p · 10000^{−2i/d_k}` 만큼 돌린다 — q 와 k 에만.
  `(a, b) → (a cos θ − b sin θ, a sin θ + b cos θ)`.

### 3.3 부품의 정확한 식

| 부품 | 식 |
|---|---|
| LayerNorm | `μ = mean(x)`, `σ² = mean((x−μ)²)`, `y = g ⊙ (x−μ)/√(σ²+1e-5) + b` |
| GELU | `0.5 x (1 + tanh(0.7978845608028654 · (x + 0.044158 x³)))` |
| softmax | `z − max(z)` 를 먼저 빼고 `exp` 를 정규화한다 |
| 인과 마스크 | `j > i` 인 칸은 더하지 않는다(−∞ 와 같다) |
| 손실 | 모든 `(배치, 위치)` 의 `−ln p[정답]` 평균 |

GELU 상수 `0.7978845608028654` 는 `√(2/π)` 를 17자리로 적은 것이다.
두 언어가 같은 10진 문자열에서 같은 double 을 얻는다.

### 3.4 파라미터 수

d_ff = 4d 일 때 블록 하나는 `12d² + 13d`,
전체는 `V·d + T·d(learned 일 때) + L(12d² + 13d) + 2d`.
GPT-2 small(V 50257, T 1024, d 768, L 12)은 124,439,808 이다.

### 3.5 초기화

체크포인트 차례(§4) 그대로 초기화 생성기에서 뽑는다.

| 텐서 | 값 |
|---|---|
| `wte`, `wpe`, `Wqkv`, `W1` | `normal() × 0.02` |
| `Wo`, `W2` (잔차로 들어가는 사영) | `normal() × 0.02 / √(2L)` |
| 모든 편향 | 0 (뽑지 않는다) |
| LN 의 `g` / `b` | 1 / 0 (뽑지 않는다) |

## 4. 체크포인트 `.ckpt`

모든 수는 리틀 엔디언.

```
0   4바이트  마법수 "TFS1"
4   int32 ×7 V, T, d, L, h, d_ff, flags
32  float32 배열이 아래 차례로 이어진다
```

`flags` 비트 0 = 1(임베딩 묶음, 늘 켠다),
비트 1‥2 = 위치 방식(0 learned · 1 sin · 2 rope).

배열 차례:

```
wte [V, d]
wpe [T, d]            ← learned 일 때만 있다
블록마다:
  ln1_g [d]  ln1_b [d]
  Wqkv [d, 3d]  bqkv [3d]
  Wo [d, d]  bo [d]
  ln2_g [d]  ln2_b [d]
  W1 [d, d_ff]  b1 [d_ff]
  W2 [d_ff, d]  b2 [d]
lnf_g [d]  lnf_b [d]
```

### 4.1 풀어 본 예 — V 2, T 2, d 2, L 1, h 1, d_ff 4, learned

| 바이트 | 내용 | float 수 |
|---|---|---|
| 0‥3 | `54 46 53 31` ("TFS1") | — |
| 4‥31 | 2 2 2 1 1 4 1 | — |
| 32‥47 | wte | 4 |
| 48‥63 | wpe | 4 |
| 64‥79 | ln1_g · ln1_b | 2 + 2 |
| 80‥127 | Wqkv | 12 |
| 128‥151 | bqkv | 6 |
| 152‥175 | Wo · bo | 4 + 2 |
| 176‥191 | ln2_g · ln2_b | 2 + 2 |
| 192‥223 | W1 | 8 |
| 224‥239 | b1 | 4 |
| 240‥271 | W2 | 8 |
| 272‥279 | b2 | 2 |
| 280‥295 | lnf_g · lnf_b | 2 + 2 |

파라미터는 66개이고 파일은 머리말 32바이트 + `4 × 66` = 정확히 296바이트다.

### 4.2 옵티마이저 상태 `.opt`

```
"TFO1"  int32 step  float32 m[...]  float32 v[...]
```

`m`, `v` 는 체크포인트와 같은 차례로 파라미터 전체를 잇는다.

## 5. 토크나이저

### 5.1 어휘 `.vocab` · 병합 `.merges`

- `.vocab`: 한 줄에 `id<TAB>16진 바이트`. id 는 0 부터 빈틈 없이.
- **기본 토큰**은 한 바이트짜리 줄들이다. 바이트 BPE 는 0‥255 가
  그대로 기본이고, 과제용 문자 어휘는 쓰는 바이트만 오름차순으로 둔다.
- `.merges`: 한 줄에 `왼쪽id<TAB>오른쪽id`, 순위 차례.
  순위 r 의 병합이 만드는 토큰 id 는 `기본 토큰 수 + r` 이다.
- 기본 토큰에 없는 바이트를 만나면 인코드는 실패한다(조용히 넘기지 않는다).

### 5.2 사전 토크나이저 — 어디서 자르나

글자(유니코드 코드 포인트)마다 부류를 매긴다.

| 부류 | 해당 |
|---|---|
| `S` | 공백 U+0020 하나 |
| `W` | U+0009 ‥ U+000D (탭·줄바꿈 등) |
| `D` | `0`‥`9` |
| `P` | 나머지 ASCII, U+2000‥U+206F, U+3000‥U+303F, U+FF00‥U+FF65 |
| `L` | ASCII 영문자, 그리고 U+0080 이상 중 `P` 가 아닌 것 전부(한글 포함) |

자르기 규칙(왼쪽부터, 결정표):

| 지금 글자 | 조건 | 조각 |
|---|---|---|
| `S` | 다음 글자가 `L`·`D`·`P` | 공백 + 다음 글자 부류의 연속 |
| `S`·`W` | 위에 해당하지 않음 | `S`·`W` 의 연속. 단 연속의 끝이 `S` 이고 그 뒤가 `L`·`D`·`P` 이며 연속이 두 글자 이상이면 마지막 `S` 는 남긴다 |
| `L`·`D`·`P` | — | 같은 부류의 연속 |

"같은 부류의 연속" 은 부류가 바뀌기 직전까지다. 조각은 UTF-8 로
바꾼 바이트열이다. 조각 경계를 넘는 병합은 없다.

### 5.3 BPE 학습

1. 말뭉치를 조각으로 나누고 조각(바이트열)마다 개수를 센다.
2. 모든 조각의 이웃한 두 토큰 짝을 (개수로 가중해) 센다.
3. 가장 많은 짝을 고른다. **동률이면 (왼쪽id, 오른쪽id) 가 사전순으로
   작은 짝.** 개수가 2 보다 작으면 멈춘다.
4. 모든 조각에서 그 짝을 왼쪽부터 겹치지 않게 새 id 로 바꾼다.
5. 어휘가 목표 크기가 될 때까지 2 로.

### 5.4 인코드

조각마다: 이웃한 짝 가운데 순위가 가장 낮은 병합을 찾아 그 짝의
모든 출현을 왼쪽부터 겹치지 않게 바꾼다. 적용할 병합이 없을 때까지.

### 5.5 토큰 파일 `.bin`

uint16 리틀 엔디언 id 의 나열. 머리말 없음.
**파이썬과 C 는 같은 말뭉치에서 바이트까지 같은 `.bin` 을 낸다.**

## 6. 학습 한 걸음

### 6.1 배치

시작 가능 위치 목록 `starts` 를 먼저 만든다.
- 일반: `0 ≤ i ≤ N − T − 1` 인 모든 i.
- 줄 맞춤(`aligned`): 위 범위 안에서 `i = 0` 이거나 `tok[i−1]` 이
  줄바꿈 토큰인 i.

배치의 행 `b = 0‥B−1` 마다 배치 생성기로 `s = starts[randint(len)]`,
입력 `tok[s ‥ s+T−1]`, 정답 `tok[s+1 ‥ s+T]`.

### 6.2 AdamW

스텝 `t` 는 1 부터. 모든 파라미터 원소 θ 와 기울기 g 에 대해
(`β1 0.9 · β2 0.95 · ε 1e-8`):

```
m ← β1 m + (1−β1) g
v ← β2 v + (1−β2) g²
m̂ = m / (1 − β1ᵗ)      v̂ = v / (1 − β2ᵗ)
θ ← θ − lr · ( m̂ / (√v̂ + ε) + wd · θ )
```

`wd` 는 `wte wpe Wqkv Wo W1 W2` 에만 0.1, 나머지(편향·LN)는 0.
괄호 안의 θ 는 갱신 전 값이다.

### 6.3 기울기 자르기

`n = √(Σ g²)` (모든 파라미터). `n > 1.0` 이면 모든 g 에
`1.0 / (n + 1e-6)` 을 곱한다. 합은 double 로 쌓는다.

### 6.4 학습률 일정

```
t ≤ warmup:  lr = lr_max · t / warmup
그 뒤:       p = (t − warmup) / max(1, total − warmup)
             lr = lr_min + ½ (lr_max − lr_min)(1 + cos πp)
```

## 7. 생성

- 로짓을 온도 τ 로 나눈다. **τ = 0 이면 argmax**(동률은 작은 id).
- 확률을 내림차순으로 늘어놓는다(같으면 작은 id 가 앞).
- top-k: 앞의 k 개만 남긴다. top-p: 누적합이 처음 p 이상이 되는
  가장 짧은 앞부분만 남긴다. 둘 다 주면 k 를 먼저.
- 남은 확률을 합으로 나누고, `u = uniform()` 하나를 뽑아
  앞에서부터 double 로 누적해 처음으로 `u < 누적` 인 토큰을 고른다.
  반올림으로 끝까지 못 고르면 마지막 토큰.
- KV 캐시로 한 토큰씩 늘려 계산한 로짓은 전체를 다시 계산한 로짓과 같다
  (파이썬 ≤ 1e-9, §9).

## 8. 컴파일과 스레드

- C 는 `-O2 -std=c99 -ffp-contract=off -fno-fast-math` 로만 만든다.
  FMA 가 `a*b+c` 를 한 번에 계산하면 반올림이 달라진다.
- 스레드는 **정적 분할**만 쓴다: 출력 원소 하나는 정해진 스레드 하나가
  정해진 차례로 계산한다. 합을 스레드끼리 나눠 쌓지 않는다.
  그래서 1 스레드와 N 스레드의 체크포인트는 바이트까지 같다.

## 9. 허용 오차 (float64 파이썬 ↔ float32 C)

| 무엇 | 오차 | 뜻 |
|---|---|---|
| 난수·`.bin`·체크포인트 머리말 | 0 | 정수 산출물은 정확히 같다 |
| 같은 `.ckpt` 에서 로짓 | 상대 ≤ 1e-4 | float32 의 유효 자릿수 |
| 같은 입력에서 기울기 | 상대 ≤ 1e-3 | 역전파는 곱이 길어 더 흔들린다 |
| 같은 20스텝 뒤 손실 | 절대 ≤ 1e-3 | 스텝이 쌓이면 오차도 쌓인다 |
| 더 긴 학습 | 추세만 | 수백 스텝 뒤 두 궤적은 갈라진다 |

상대 오차는 `|a − b| / max(|a|, |b|, 1e-6)` 이다.
