이 책은 무엇인가

최적화는 “가장 좋은 것을 고르는 일”을 수학으로 옮긴 분야다. 학습률을 정하는 일도, 배송 경로를 짜는 일도, 공정의 병목을 찾는 일도 결국 같은 문제의 다른 얼굴이다.

✔ 이 책이 하는 것
  • 정리를 끝까지 증명한다 — “알려져 있다”로 넘어가지 않는다
  • 모든 알고리즘을 순수 파이썬으로 처음부터 만든다
  • 수렴 속도를 실제로 측정해 이론과 대조한다
  • 실패하는 경우를 일부러 만들어 왜 실패하는지 본다
✘ 이 책이 하지 않는 것
  • 솔버 API 사용법 나열 — 그건 문서를 보면 된다
  • 검증하지 않은 의사코드
  • “직관적으로 자명하다”로 끝내는 설명
  • 측정 없이 “빠르다”고 주장하기
한 줄 요약 — 이 책은 최적화 알고리즘을 스스로 만들어 낼 수 있게 하는 것이 목표다. 고르는 법이 아니라 만드는 법이다.

반복형 최적화의 공통 골격
  1. 시작: 초기점 x0 를 고른다

표준형

최적화 문제는 언제나 아래 꼴로 적는다. 이 책 전체가 이 다섯 줄 위에 서 있다.

minimizex ∈ ℝn   f0(x)
subject to   fi(x) ≤ 0,   i = 1, …, m
subject to   hj(x) = 0,   j = 1, …, p
용어 x 는 결정변수, f0 는 목적함수, fi ≤ 0 은 부등식 제약, hj = 0 은 등식 제약이다. 제약을 모두 만족하는 점들의 집합 𝒳 = {x : fi(x) ≤ 0 ∀i, hj(x) = 0 ∀j} 을 실행가능집합, 그 원소를 실행가능점이라 한다.
최대화는 따로 다루지 않는다 — max g(x) 는 min −g(x) 와 같은 문제다. 최적값의 부호만 뒤집으면 되고 최적해는 그대로다. 마찬가지로 fi ≥ 0 은 −fi ≤ 0 으로 적는다.
등호의 방향을 마음대로 바꾸지 말 것 — 5부에서 KKT 조건을 유도할 때 승수의 부호가 ≤ 방향에 묶여 있다. 표준형을 지키면 부호 실수가 사라진다.

최적값과 최적해는 다른 것이다

정의 1.1 (최적값) p⋆ = inf { f0(x) : x ∈ 𝒳 } 관례로 𝒳 = ∅ 이면 p⋆ = +∞ (실행불가능), 아래로 유계가 아니면 p⋆ = −∞ (비유계)라 쓴다.
정의 1.2 (최적해) x⋆ ∈ 𝒳 이면서 f0(x⋆) = p⋆ 인 점. 존재하지 않을 수 있고, 여럿일 수도 있다.

셋을 구분해야 하는 이유 — 세 가지 다른 실패

상황예p⋆최적해
실행불가능x ≤ −1, x ≥ 1+∞없음
비유계min x, x ∈ ℝ−∞없음
하한에 도달 못 함min ex, x ∈ ℝ0없음
정상min x², x ∈ ℝ0x⋆ = 0
여러 개min sin x−1무한히 많음
세 번째 줄이 핵심이다 — ex 는 아래로 유계(0)이고 하한도 명확한데 그 값을 얻는 점이 없다. 그래서 “아래로 유계이면 최소가 있다”는 참이 아니다. 이 간극을 메우는 것이 다음 장의 존재성 정리다.

최소점의 종류

정의 1.3 x⋆ ∈ 𝒳 에 대하여
전역 최소f(x⋆) ≤ f(x) for all x ∈ 𝒳

해가 존재할 조건 — 바이어슈트라스

정리 1.4 (바이어슈트라스 최대·최소 정리) S ⊆ ℝn 가 공집합이 아니고 유계이며 닫혀 있고, f : S → ℝ 가 연속이면 f 는 S 위에서 최솟값과 최댓값을 실제로 얻는다.
증명 (최솟값 쪽)
  1. p⋆ = infS f 라 두자 (−∞ 일 수도 있다고 열어 둔다). 하한은 실수의 완비성으로 항상 정의된다.
  2. 정의에 의해 f(xk) → p⋆ 인 수열 {xk} ⊆ S 가 있다. 하한은 “아무리 가까이 가도 그보다 작은 값이 있다”는 뜻이므로 그런 수열을 뽑을 수 있다.
  3. S 가 유계이므로 볼차노–바이어슈트라스에 의해 수렴하는 부분수열 xkj → x⋆ 가 있다. 유계 수열은 수렴 부분수열을 갖는다 — 유한차원이라서 쓸 수 있는 성질이다.
  4. S 가 닫혀 있으므로 x⋆ ∈ S. 닫힌 집합은 자기 극한점을 포함한다. 이 줄이 “닫혀 있음”을 쓰는 유일한 자리다.
  5. f 가 연속이므로 f(x⋆) = lim f(xkj) = p⋆. 연속성은 “극한과 함수 적용의 순서를 바꿔도 된다”는 말이다.
  6. 따라서 p⋆ 는 유한하고 x⋆ 에서 달성된다.
세 조건이 모두 필요하다 — 유계가 빠지면 min x on ℝ(−∞), 닫힘이 빠지면 min x on (0,1](하한 0 미달성), 연속이 빠지면 계단함수에서 최소가 없다.

유계가 아니어도 되는 경우 — 강제성

실전에서 𝒳 = ℝn 인 무제약 문제가 훨씬 많다. 이때는 유계 조건을 함수의 성질로 대신할 수 있다.

정의 1.5 (강제적 · coercive) ‖x‖ → ∞ 일 때 f(x) → +∞ 이면 f 를 강제적이라 한다.
정리 1.6 f : ℝn → ℝ 가 연속이고 강제적이면 f 는 전역 최소점을 갖는다.
증명
  1. 아무 점 x0 을 잡고 c = f(x0) 라 하자.
  2. 강제성에서, ‖x‖ > R ⇒ f(x) > c 인 R 이 존재한다. “무한대로 간다”의 정의를 c 라는 문턱에 적용한 것이다.
  3. 따라서 최솟값 후보는 전부 K = {x : ‖x‖ ≤ R} 안에 있다. 밖은 값이 c 보다 크므로 x0 에 지고, x0 ∈ K 이다.
  4. K 는 닫혀 있고 유계이므로 정리 1.4 를 적용하면 K 위에서 최소점 x⋆ 가 존재한다.
  5. K 밖의 모든 점은 f > c ≥ f(x⋆) 이므로 x⋆ 는 ℝⁿ 전체의 최소점이다.
실무에서의 쓸모 — 손실함수에 (λ/2)‖x‖² 정칙화 항을 더하면 그 함수는 자동으로 강제적이 된다. “정칙화가 해를 존재하게 만든다”는 말의 정확한 뜻이 이것이다. 4부에서 다시 만난다.

코시–슈바르츠 부등식

정리 2.1 모든 x, y ∈ ℝn 에 대하여 |x⊤y| ≤ ‖x‖ ‖y‖ 이고, 등호는 x 와 y 가 평행할 때(한쪽이 다른 쪽의 실수배일 때)에만 성립한다.
증명 (판별식 논법)
  1. y = 0 이면 양변이 0 이므로 자명하다. 이제 y ≠ 0 이라 하자.
  2. 임의의 실수 t 에 대해 g(t) = ‖x − t y‖² ≥ 0 이다. 노름의 제곱은 음이 될 수 없다 — 이것이 유일하게 쓰는 성질이다.
  3. 전개하면 g(t) = ‖y‖²t² − 2(x⊤y)t + ‖x‖² — t 에 대한 이차식이고 최고차항 계수가 양수다.
  4. 모든 t 에서 음이 아니려면 판별식이 0 이하여야 한다: (2x⊤y)² − 4‖y‖²‖x‖² ≤ 0 이차식이 실근을 두 개 가지면 그 사이에서 음수가 된다.
  5. 정리하면 (x⊤y)² ≤ ‖x‖²‖y‖², 양변에 제곱근을 취해 결론을 얻는다.
  6. 등호는 판별식이 0 일 때, 곧 g(t0) = 0 인 t0 가 있을 때다. 그러면 x = t0y.
이 부등식이 이 책에서 하는 일 — “−∇f 가 가장 가파른 하강 방향”이라는 사실(3장)의 증명이 통째로 이것이다. 나중에 수렴 증명에서도 거의 매번 등장한다.

노름 세 가지와 그 관계

‖x‖1 = ∑i|xi|   ·   ‖x‖2 = √∑ixi²   ·   ‖x‖∞ = maxi |xi|
정리 2.2 (노름의 동치성 — 유한차원) 모든 x ∈ ℝn 에 대하여 ‖x‖∞ ≤ ‖x‖2 ≤ √n‖x‖∞,    ‖x‖2 ≤ ‖x‖1 ≤ √n‖x‖2
증명
  1. ‖x‖∞² = max xi² ≤ ∑xi² = ‖x‖2² — 항 하나는 전체 합 이하.
  2. ∑xi² ≤ n·max xi² 이므로 ‖x‖2 ≤ √n‖x‖∞.
  3. ‖x‖1² = (∑|xi|)² = ∑xi² + ∑i≠j|xixj| ≥ ‖x‖2² — 교차항이 음이 아니다.
  4. 마지막은 코시–슈바르츠에 y = (1,…,1) 을 넣은 것이다: ‖x‖1 = ∑|xi|·1 ≤ ‖x‖2·√n.
왜 중요한가 “수렴한다”는 말이 어느 노름을 쓰든 같은 뜻이 된다. 유한차원에서만 참이며, 상수 √n 이 차원에 의존한다는 점이 고차원에서 종종 문제가 된다 — 8부에서 다시 만난다.

def norm(x):
    """유클리드 노름. 제곱을 먼저 하면 1e200 에서 넘치므로 최대 성분으로 스케일한다.

    if not x:
        return 0.0
    s = max(abs(a) for a in x)
    if s == 0.0:
        return 0.0
    return s * math.sqrt(math.fsum((a / s) ** 2 for a in x))

  4. 등호는 x 가 해당 고유벡터일 때 달성되므로 이 한계는 최선이다.
이 정리가 3부의 심장이다 — λmin = μ 는 강볼록 상수가 되고 λmax = L 은 평활 상수가 된다. 경사하강의 수렴 속도는 정확히 κ = L/μ 로 결정된다.

명제 2.6 (야코비 회전은 반드시 진전한다) 비대각 성분의 제곱합 off(A) = ∑i≠jaij² 라 하자. (p,q) 성분을 0 으로 만드는 회전 J 을 적용하면 off(J⊤AJ) = off(A) − 2apq²
증명

  2. 회전은 p, q 행·열만 건드리므로 app² + aqq² + 2apq² 가 a′pp² + a′qq² + 0 으로 바뀐다.
  3. 전체 제곱합은 그대로인데 대각 제곱합이 2apq² 만큼 늘었으므로, 비대각 제곱합은 그만큼 줄었다.
  4. 매 회전마다 off 가 단조 감소하고 0 이 하한이므로 수렴한다.

def eigh(A, tol=1e-13, sweeps=100):
    """대칭행렬의 고윳값·고유벡터 — 순환 야코비 회전.

       비대각 성분 하나를 회전으로 0 으로 만드는 일을 반복한다. 그때마다
       비대각 제곱합이 반드시 줄어들기 때문에 수렴이 보장된다(2부에서 증명).
       O(n³) 정도, 대칭행렬에 대해 매우 정확하다.

       반환: (오름차순 고윳값 리스트, 고유벡터 행렬 V) — V 의 k번째 '열'이 k번째 고유벡터.
    """
    n = len(A)
    D = [[float(v) for v in row] for row in A]
    V = identity(n)
    for _ in range(sweeps):
        off = math.sqrt(math.fsum(D[i][j] ** 2 for i in range(n) for j in range(n) if i != j))
        if off <= tol * max(1.0, frobenius(D)):
            break
        for p in range(n - 1):
            for q in range(p + 1, n):
                if abs(D[p][q]) < 1e-300:
                    continue
                theta = (D[q][q] - D[p][p]) / (2.0 * D[p][q])
                t = (1.0 if theta >= 0 else -1.0) / (abs(theta) + math.sqrt(theta * theta + 1.0))
                c = 1.0 / math.sqrt(t * t + 1.0)
                s = t * c
                for k in range(n):
                    dkp, dkq = D[k][p], D[k][q]
                    D[k][p] = c * dkp - s * dkq
                    D[k][q] = s * dkp + c * dkq
                for k in range(n):
                    dpk, dqk = D[p][k], D[q][k]
                    D[p][k] = c * dpk - s * dqk
                    D[q][k] = s * dpk + c * dqk
                for k in range(n):
                    vkp, vkq = V[k][p], V[k][q]
                    V[k][p] = c * vkp - s * vkq
                    V[k][q] = s * vkp + c * vkq
    vals = [D[i][i] for i in range(n)]

def cholesky(A):
    """A = L Lᵀ (L 은 하삼각, 대각 > 0).  O(n³/6) — LU 의 절반.

       최적화에서 이것이 중요한 이유: 뉴턴 방향을 구할 때 헤세 행렬에 촐레스키를
       시도해 보면 "양의 정부호인가"라는 2차 최적성 조건을 공짜로 검사하게 된다.
       실패하는 지점이 곧 하강 방향이 보장되지 않는 지점이다.
    """
    n = len(A)
    L = zeros(n, n)
    for i in range(n):
        for j in range(i + 1):
            s = math.fsum(L[i][k] * L[j][k] for k in range(j))
            if i == j:
                d = A[i][i] - s
                if d <= 0.0:
                    raise NotPositiveDefinite('대각 %d 에서 %r ≤ 0' % (i, d))
                L[i][j] = math.sqrt(d)
            else:
                L[i][j] = (A[i][j] - s) / L[j][j]
    return L

def lu_factor(A):
    """부분 피벗팅 LU 분해.  PA = LU 를 한 배열에 겹쳐 담는다.

       왜 피벗팅이 필요한가: [[0,1],[1,0]] 은 정칙인데도 (1,1) 성분이 0 이라
       그대로 소거하면 0 으로 나눈다. 크기가 가장 큰 행을 위로 올리면 그 사고가
       사라지고, 증배 계수 |l| ≤ 1 이 보장돼 오차 증폭도 억제된다.

       O(n³/3) 시간, O(n²) 공간.  반환: (LU, piv, sign)
    """
    n = len(A)
    LU = copy_mat([[float(v) for v in row] for row in A])
    piv = list(range(n))
    sign = 1.0
    for k in range(n):
        p = max(range(k, n), key=lambda i: abs(LU[i][k]))
        if abs(LU[p][k]) < 1e-300:
            raise SingularMatrix('%d번째 피벗이 0' % k)
        if p != k:
            LU[k], LU[p] = LU[p], LU[k]
            piv[k], piv[p] = piv[p], piv[k]
            sign = -sign
        pivot = LU[k][k]
        for i in range(k + 1, n):
            f = LU[i][k] / pivot
            LU[i][k] = f                      # L 의 증배 계수를 그 자리에 저장
            if f != 0.0:
                row_i, row_k = LU[i], LU[k]
                for j in range(k + 1, n):
                    row_i[j] -= f * row_k[j]
    return LU, piv, sign

def qr(A):
    """하우스홀더 반사로 A = QR.  Q 는 m×m 직교, R 은 m×n 상삼각.  O(2mn² − 2n³/3).

       그람–슈미트 대신 반사를 쓰는 이유: 그람–슈미트는 열이 거의 평행할 때
       직교성을 잃는다(수치적으로 무너진다). 반사는 매 단계가 직교변환이라
       오차가 증폭되지 않는다.
    """
    m, n = len(A), len(A[0])
    R = [[float(v) for v in row] for row in A]
    Q = identity(m)
    for k in range(min(n, m - 1)):
        x = [R[i][k] for i in range(k, m)]
        nx = norm(x)
        if nx < 1e-300:
            continue
        # 부호를 x[0] 와 같게 잡아야 v 가 0 에 가까워지는 상쇄를 피한다.
        alpha = -nx if x[0] >= 0 else nx
        v = x[:]
        v[0] -= alpha
        nv = norm(v)
        if nv < 1e-300:
            continue
        v = [vi / nv for vi in v]
        # R ← (I − 2vvᵀ) R,  Q ← Q (I − 2vvᵀ)   — 행렬곱이 아니라 랭크-1 갱신
        for j in range(k, n):
            s = 2.0 * math.fsum(v[i - k] * R[i][j] for i in range(k, m))
            for i in range(k, m):
                R[i][j] -= s * v[i - k]
        for i in range(m):
            s = 2.0 * math.fsum(Q[i][j] * v[j - k] for j in range(k, m))
            for j in range(k, m):
                Q[i][j] -= s * v[j - k]
    for i in range(m):                        # 상삼각 아래를 정확히 0 으로
        for j in range(min(i, n)):
            R[i][j] = 0.0
    return Q, R

def svd(A, tol=1e-14, sweeps=60):
    """A = U diag(s) Vᵀ,  s 는 내림차순.  한쪽(one-sided) 야코비.

       A 의 열끼리 직교가 될 때까지 2×2 회전을 돌린다. 끝나면 열의 길이가
       특잇값, 정규화한 열이 U 의 열, 누적한 회전이 V 다.
       AᵀA 를 만들어 고윳값을 구하는 방법보다 정확하다 — 제곱하면서 잃는
       유효숫자가 없기 때문이다.
    """
    m, n = len(A), len(A[0])
    if m < n:                                  # 가로로 긴 행렬은 전치해서 풀고 되돌린다
        U, s, V = svd(transpose(A), tol, sweeps)
        return V, s, U
    B = transpose([[float(v) for v in row] for row in A])   # B[j] = A 의 j번째 열
    V = identity(n)
    for _ in range(sweeps):
        done = True
        for p in range(n - 1):
            for q in range(p + 1, n):
                app = math.fsum(v * v for v in B[p])
                aqq = math.fsum(v * v for v in B[q])
                apq = math.fsum(a * b for a, b in zip(B[p], B[q]))
                if abs(apq) <= tol * math.sqrt(app * aqq) or apq == 0.0:
                    continue
                done = False
                theta = (aqq - app) / (2.0 * apq)
                t = (1.0 if theta >= 0 else -1.0) / (abs(theta) + math.sqrt(theta * theta + 1.0))
                c = 1.0 / math.sqrt(t * t + 1.0)
                s_ = t * c
                for i in range(m):
                    bp, bq = B[p][i], B[q][i]
                    B[p][i] = c * bp - s_ * bq
                    B[q][i] = s_ * bp + c * bq
                for i in range(n):
                    vp, vq = V[i][p], V[i][q]
                    V[i][p] = c * vp - s_ * vq
                    V[i][q] = s_ * vp + c * vq
        if done:
            break
    sing = [norm(col) for col in B]
    order = sorted(range(n), key=lambda j: -sing[j])
    s = [sing[j] for j in order]
    U = zeros(m, n)
    for k, j in enumerate(order):
        if s[k] > 1e-300:
            for i in range(m):
                U[i][k] = B[j][i] / s[k]
    Vo = [[V[i][j] for j in order] for i in range(n)]
    return U, s, Vo

등고선과 화살표의 관계를 보라 — 화살표는 언제나 등고선에 수직이다(명제 3.5). 로젠브록에서는 골짜기 바닥을 따라가는 방향의 기울기가 거의 0 이라, 초록 화살표가 골짜기를 가로지르는 쪽을 가리킨다. 3부에서 경사하강이 왜 지그재그를 그리는지가 여기 이미 보인다.

기울기는 등위집합에 수직이다

명제 3.5 등위집합 Lc = {x : f(x) = c} 위를 지나는 매끄러운 곡선 γ(t) 에 대해 ∇f(γ(t))⊤γ′(t) = 0 이다.
증명 f(γ(t)) = c 는 t 에 무관한 상수다. 양변을 t 로 미분하고 연쇄법칙을 적용하면 d/dt f(γ(t)) = ∇f(γ)⊤γ′ = 0.
그림으로 — 등고선을 따라 걸으면 높이가 변하지 않는다. 높이가 가장 빨리 변하는 방향은 등고선에 수직이다. 5부의 라그랑주 조건 ∇f = λ∇h 는 “두 등위면이 접한다”는 이 사실의 다른 표현이다.
미리 보는 5부 — 제약 h(x)=0 위에서 최소인 점에서는, f 의 등위면과 h 의 등위면이 접한다. 접한다는 것은 법선이 평행하다는 것이고, 그것이 곧 ∇f = λ∇h 다. 라그랑주 승수는 이 한 줄에서 나온다.

하강 보조정리 — 이 책에서 가장 많이 쓰이는 부등식

정의 3.11 (L-평활) ‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖ 가 모든 x,y 에서 성립하면 f 를 L-평활하다고 한다. (기울기가 립시츠 연속)
보조정리 3.12 (하강 보조정리 · descent lemma) f 가 L-평활이면 모든 x, y 에 대해 f(y) ≤ f(x) + ∇f(x)⊤(y−x) + L2‖y−x‖²
증명
  1. p = y − x 라 두고 정리 3.10 의 적분 형태를 스칼라 버전으로 쓴다: f(y) − f(x) = ∫₀¹ ∇f(x+tp)⊤p dt.
  2. 양변에서 ∇f(x)⊤p 를 빼면 f(y) − f(x) − ∇f(x)⊤p = ∫₀¹ [∇f(x+tp) − ∇f(x)]⊤p dt.
  3. 코시–슈바르츠로 피적분함수를 위로 누른다: [·]⊤p ≤ ‖∇f(x+tp) − ∇f(x)‖·‖p‖.
  4. 립시츠 조건으로 ‖∇f(x+tp) − ∇f(x)‖ ≤ L‖tp‖ = Lt‖p‖.
  5. 따라서 적분은 ≤ ∫₀¹ Lt‖p‖² dt = (L/2)‖p‖². 정리하면 결론.
읽는 법 — “함수는 그 접평면 위로 (L/2)‖·‖² 이상 솟아오르지 않는다.” 즉 함수를 위에서 덮는 이차함수가 항상 있다. 그 이차함수를 최소화하는 것이 곧 α = 1/L 의 경사하강이다 — 3부 2장에서 이 한 줄로 수렴을 증명한다.

상쇄 — 뺄셈이 유효숫자를 지운다

가까운 두 수를 빼면 앞자리가 사라지고 뒷자리의 반올림 오차만 남는다. 차분 미분이 딱 이 모양이다.

f(x+h) − f(x)h  — 분자는 h→0 일수록 서로 가까운 두 수의 차
정리 4.1 (최적 차분 스텝) f 의 값에 상대오차 ε 이 있을 때, 전진차분의 전체 오차는 E(h) ≈ h2|f″| + 2ε|f|h 이고, 이를 최소화하는 h 는 h⋆ = 2√ε|f|/|f″| ≈ 2√ε ≈ 3×10−8, 그때 오차는 O(√ε) ≈ 10−8.
증명
  1. 테일러: f(x+h) = f + hf′ + (h²/2)f″ + … 이므로 절단오차는 (h/2)|f″|.
  2. f 값 각각에 최대 ε|f| 의 오차가 있고 둘을 빼서 h 로 나누므로 반올림오차는 2ε|f|/h.
  3. E′(h) = |f″|/2 − 2ε|f|/h² = 0 을 풀면 h⋆ = 2√(ε|f|/|f″|). E 는 볼록(두 항 모두 볼록)이므로 이 정류점이 최소다.
  4. h⋆ 을 대입하면 E(h⋆) = 2√(ε|f||f″|) — √ε 규모다.
따름정리 4.2 (중심차분) 절단오차가 (h²/6)|f‴| 로 줄어드므로 같은 계산에서 h⋆ ≈ (3ε)1/3 ≈ 9×10−6, 오차는 O(ε2/3) ≈ 4×10−11. 함수 호출 두 배로 정밀도 세 자리를 산다.

def grad_complex(f, x, h=1e-30):
    """복소 스텝 미분:  f′(x) ≈ Im f(x + ih) / h.

       테일러 전개  f(x+ih) = f(x) + ih f′(x) − h²f″/2 − ih³f‴/6 + …
       의 허수부를 h 로 나누면 f′(x) + O(h²) 이고, 뺄셈이 없어 상쇄가 일어나지 않는다.
       그래서 h 를 1e-30 까지 줄여 기계정밀도의 기울기를 얻는다.
       조건: f 가 복소수 인자를 그대로 받아 해석적으로 계산되어야 한다
             (math.exp 대신 cmath.exp, abs()·max() 금지).
    """
    g = [0.0] * len(x)
    for i in range(len(x)):
        xc = [complex(v, 0.0) for v in x]
        xc[i] = complex(x[i], h)
        g[i] = f(xc).imag / h
    return g
