{{N}}규격은 이미 있다

이 프로토콜은 3편(C++ WASM 8인 온라인)에서 정한 v3 그대로다. Go 서버·파이썬 서버·브라우저 JS 세 구현이 이미 이 규격으로 말하고 있고, 여기 TS 구현이 네 번째로 합류한다.

JSON 텍스트

메시지는 전부 JSON 한 줄이다. 바이너리는 판 스냅샷 하나뿐이고, 그것도 base64 문자열로 실어 보낸다.

서버는 규칙을 모른다

서버가 아는 건 좌석·공격 라우팅·탈락뿐이다. 테트리스 규칙은 각자의 코어 안에 있다.

{{N}}클라이언트 → 서버

타입 하나가 곧 규격서다. t 필드로 갈라지는 판별 유니온이라, switch (msg.t) 안에서 TS 가 각 가지의 모양을 자동으로 좁혀 준다 — 서버 코드에서 캐스팅이 사라진다.

클라이언트                      서버

   │            hi {pid, v}      │   ← 너는 몇 번 PC 인가
   │ ◀────────────────────────── │

   │ ◀────────────────────────── │
   │  seat {i, kind, name, lv}   │   ← 좌석 잡기 (i = -1 이면 자동 배정)
   │  ready {v}                  │

   │  ─── 경기 중 ───             │

화면 상태(st)만 초당 10회고 나머지는 사건이 있을 때만 오간다. 실측 트래픽은 파트 15에서 잰다.

{{N}}설정 병합의 함정

클라이언트가 {max: 0} 을 보냈을 때 "좌석 0개짜리 방"을 만들면 아무도 못 들어온다. Go·파이썬 구현이 이미 0을 기본값으로 대체하고 있어서, 여기서도 같은 규칙을 따른다.

규격보다 구현이 먼저다이 규칙은 규격서에 또렷이 적혀 있지 않다. 하지만 실제 통신 상대는 문서가 아니라 돌고 있는 서버다. 문서와 구현이 다르면 구현에 맞추고, 그 사실을 주석에 남긴다.

{{N}}200칸을 몇 바이트로

관전 화면에는 남의 판이 필요하다. 200칸을 그대로 보내면 초당 10회 × 8석 = 16 KB/s 다. 런렝스로 접으면 빈 판이 13바이트가 된다.

칸 값 0~8 을 4비트, 반복 횟수 1~16 을 4비트에 담아 한 바이트로:

  [ 반복-1 (4bit) | 색 (4bit) ]

  빈 판 200칸  →  (16칸 × 12번) + (8칸 × 1번) = 13바이트
  꽉 찬 판     →  실측 평균 70바이트, 최악 118바이트

{{N}}btoa 도 Buffer 도 없는 곳이 있다

브라우저에는 btoa, Node 에는 Buffer 가 있지만 둘은 서로 없다. 서버·클라이언트·테스트가 같은 파일을 쓰려면 어느 쪽에도 기대지 않는 게 싸다.

그래도 Node 의 Buffer 와 결과가 같은지는 테스트가 확인한다. 직접 구현했다는 건 "다르게 만들었다"는 뜻이 아니다.

{{N}}길이는 16에서 끊는다

4비트에 담아야 하므로 한 번에 최대 16칸이다. 빈 판 한 줄(10칸)이 한 바이트가 되고, 200칸이 13바이트가 되는 계산이 여기서 나온다.

{{N}}보이는 판 + 지금 조각

스냅샷에는 굳은 블록과 지금 떨어지고 있는 조각이 함께 들어간다. 고스트는 뺀다 — 남의 판에서까지 고스트가 보일 필요는 없고, 그만큼 바이트가 는다.

상태 배열 12칸 중 서버가 읽는 건 s[0](진행 상태)과 s[4](높이) 둘뿐이다. 나머지는 관전 화면용이다.

{{N}}"100바이트 이하"는 사실이 아니다

규격서 §6 은 "꽉 찬 판도 100바이트를 넘지 않는다"고 적었다. 실제로 재 보면 평균 70바이트, 최악 118바이트이고, 색이 번갈아 나오는 이론적 최악은 200바이트다.

테스트가 수치를 다시 잰다규격서의 문장을 옮겨 적는 대신, AI 가 실제로 둔 판 수천 개를 매번 다시 재서 상한을 확인한다. 문서는 낡지만 테스트는 낡지 않는다.

{{N}}보낸 것이 그대로 도착하는가

무작위 판 200개를 왕복시키고, AI 가 둔 판 수천 개의 크기를 잰다. "이론적으로 작다"가 아니라 "실제로 이만큼이다"를 남긴다.

{{N}}규격의 자리에 규격의 값

칸 번호를 하나만 밀어도 서버는 "높이"를 읽으려다 "대기 줄 수"를 읽는다. 그런 실수는 조용히 잘못 도는 형태로 나타나므로, 자리마다 값을 못 박아 둔다.
