JSON-RPC 요청 하나 — 세 언어, 같은 글자

A2A 의 기본 바인딩은 JSON-RPC 2.0 입니다. 요청 하나를 표준 라이브러리만으로 만들어 찍어 보면, 세 언어가 글자 하나 다르지 않은 JSON 을 냅니다.

같은 요청 — TypeScript

같은 요청 — Go

Go 의 map 은 키를 정렬해 버리므로, 순서를 지키려고 구조체를 씁니다.

탭을 거쳐 카드 한 장 받기

표준 라이브러리로 만든 카드 서버 앞에 와이어 탭을 세우고, curl 로 탭에 카드를 청합니다. 서버는 바깥에서 닿는 주소(탭)를 --url 로 받아 카드에 적습니다.
