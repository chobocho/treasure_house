$ python 07/executor_api.py
AgentExecutor — 채워야 할 추상 메서드:
  async def cancel(context: RequestContext, event_queue: EventQueue)
  async def execute(context: RequestContext, event_queue: EventQueue)
EventQueue — 채워야 할 추상 메서드:
  async def enqueue_event(event: Event)
Event = Message | Task | TaskStatusUpdateEvent | TaskArtifactUpdateEvent
RequestContext 속성: call_context configuration context_id current_task message metadata related_tasks requested_extensions task_id tenant
