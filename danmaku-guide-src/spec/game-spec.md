# 공통 게임 사양

네 구현은 같은 탄막 슈팅 게임을 만든다. 논리 화면은 480 × 640이며 원점은 왼쪽 위, 아래쪽이 양의 y 방향이다. 입력과 게임 상태는 1/60초 고정 간격으로 갱신한다. 렌더링은 이전 상태와 현재 상태 사이를 보간할 수 있지만, 게임 규칙은 실제 경과 시간을 읽지 않는다.

플레이어는 보통 한 스텝에 4픽셀, 집중 이동 중에는 1.6픽셀 움직인다. 피격 반지름은 2.5픽셀, 그레이즈 반지름은 16픽셀이다. 총알 4096개, 적 128개, 입자 2048개를 고정 크기 풀로 관리한다. 새 객체를 매 프레임 만들지 않고 제거할 때는 마지막 살아 있는 요소와 교환한다.

난수는 시드 `0x2F6E2B1`의 xorshift32를 사용하고 언어마다 32비트 무부호 마스킹을 명시한다. 삼각함수는 게임용 `dsin`·`dcos`를 직접 구현하고 각도 단위는 0부터 1까지의 회전수다. 조준탄은 제곱근 정규화로 방향을 구한다. 모든 실수 계산은 IEEE 754 배정밀도이며 C++에서는 FMA 융합을 끈다.

T1에서 삼각함수는 13차 홀수 다항식으로 고정했다. 회전수의 정수 부분을 내림으로 제거하고, 0.25보다 크고 0.75 이하이면 0.5에서 빼며 0.75보다 크면 1을 빼서 사분파 구간으로 접는다. 접은 값에 6.283185307179586을 곱한 뒤 제곱 값을 사용하는 Horner 순서로 계산한다. 계수는 차례대로 1, −1/6, 1/120, −1/5040, 1/362880, −1/39916800, 1/6227020800이며 코사인은 회전수에 0.25를 더한 사인이다. 실제 실행 구현은 `examples/foundations/core.mjs`에 있다.

Lv1은 이동과 발사, Lv2는 적·충돌·목숨, Lv3은 링·조준 부채꼴·나선·파동 패턴, Lv4는 3단계 보스, Lv5는 그레이즈·폭탄·파워업·점수, Lv6은 데이터 기반 스테이지, Lv7은 입자·소리·시작/종료 화면·최고 점수를 추가한다.

골든 파일은 pygame 구현에서 먼저 만든다. 입력 스크립트를 실행한 프레임 60, 600, 1800에서 총알 수, 적 수, 점수, 목숨, 보스 단계와 체크섬을 기록한다. 체크섬은 살아 있는 총알을 풀 순서대로 순회하여 `Σ(floor(x × 16) × 31 + floor(y × 16)) mod 2^32`로 계산한다. 다른 세 구현은 골든 값을 정확히 재현해야 한다.

## Lv1에서 확정한 갱신 규칙

입력 비트는 왼쪽 1, 오른쪽 2, 위 4, 아래 8, 발사 16, 집중 32, 폭탄 64, 시작 128, 일시 정지 256이다. 각 단계에서 아직 구현하지 않은 행동은 무시한다. 플레이어는 (240, 560)에서 시작하고 양쪽 반대 입력은 상쇄한다. 대각선은 제곱근 정규화 후 속도를 곱하며 중심 좌표를 (12, 12)부터 (468, 628)까지 제한한다.

갱신은 플레이어 이동, 발사, 탄환 이동 순서다. 대기 시간이 양수면 먼저 1을 줄이고 발사 입력이 유지되며 0이 되었을 때 총알을 만든 뒤 8로 설정한다. 총알은 현재 플레이어보다 14픽셀 위에서 생기고 속도 (0, -8), 반지름 3을 가진다. 생성한 스텝에도 탄환을 이동한다. 화면에서 32픽셀의 여유 범위를 벗어나면 역순 순회 중 교환 삭제한다. 풀 포화 시 새 발사를 버린다.

재생 입력의 frame 0은 첫 step 호출 전이며 frame 60 기록은 60번 호출한 후의 상태다. 체크섬에는 적탄과 플레이어 탄환을 포함한 활성 탄환 풀 전체를 사용한다. 새 기준 파일은 생성기가 독점 생성 모드로 쓰며 기존 파일을 덮어쓰지 않는다. Lv1의 검증된 체크섬은 60프레임 989440, 600프레임 1264329, 1800프레임 2121696이다.

## Lv2에서 확정한 적과 충돌

프레임을 90으로 나눈 나머지가 30일 때 일반 적을 생성한다. 생성 위치 x는 32 + (다음 난수 mod 416), y는 −16이며 난수는 생성 실패 시에도 한 번 소비한다. 적 속도는 (0, 1.2), 반지름 12, 체력 3이다. 이동 뒤 나이가 60의 배수인 적은 현재 위치보다 12픽셀 아래에서 속도 (0, 2.5), 반지름 4인 적탄을 만든다. 적은 y가 672를 넘으면 발사 전에 제거한다.

무적 시간을 먼저 감소시키고 플레이어 이동·발사, 적 생성·이동, 모든 탄환 이동을 처리한다. 플레이어 탄환과 적, 적탄과 플레이어, 적 몸체와 플레이어 순으로 충돌을 검사한다. 원 접선도 충돌에 포함한다. 플레이어 탄환은 체력을 1 줄이고 사라지며 처치에 100점을 준다. 실제 피격은 목숨을 1 줄이고 120스텝 무적과 시작 위치 복귀를 적용한다. 몸체 충돌로 사라진 적은 점수를 주지 않는다. 목숨은 0 아래로 내려가지 않으며 게임 오버 상태와 재시작 화면은 Lv7에서 추가한다.

## Lv3에서 확정한 발사 패턴

일반 적은 생성 당시 `(frame // 90) mod 4`를 패턴 표식으로 저장한다. 이 선택은 난수를 추가로 소비하지 않는다. 표식 0은 링, 1은 조준 부채꼴, 2는 나선, 3은 파동이다. 기본 탄수 8과 탄속 2.5로 나이가 60의 배수일 때 쏜다. 나선 적만 나이가 6의 배수일 때 두 팔(탄수 2)을 쏜다. 모든 적탄 반지름은 4다.

링의 회전수는 시작 회전수 + i/n이다. 부채꼴은 플레이어와 발사점의 차이를 제곱근으로 정규화하고, 길이가 0이면 (0, 1)을 사용한다. 각도 차이는 `(i − (n−1)/2) × 0.025`이며 회전한 벡터 두 성분에 탄속을 곱한다. 나선은 논리 틱 × 0.007을 링의 시작 회전수로 전달하며 탄수는 팔의 수다. 링 전체를 드물게 쏘면 회전이 1/n바퀴 대칭에 상쇄되므로 나선은 짧은 주기로 이어 쏜다. 파동의 회전수는 `0.25 + dsin(tick/180) × 0.12 + (i − (n−1)/2) × 0.025`다. 위상은 시간에만 두어 부채꼴 전체가 흔들리며, 인덱스를 위상에 더하면 대칭인 두 탄환이 겹친다. 탄수 0은 발사하지 않고 풀 포화 시 가능한 추가만 수행하며 패턴 번호 0~3 이외는 거부한다.

## Lv4에서 확정한 보스 상태 머신

입력 프레임 600부터 성공할 때까지 보스를 적 풀에 한 번 생성한다. 종류는 1, 체력은 180, 반지름은 28이며 y는 100이다. 보스 나이를 먼저 1 늘리고 x를 `240 + 140 × dsin(age/240)`으로 계산하며 새 x와 이전 x의 차이를 보간용 속도로 저장한다. 일반 적과 보스는 함께 존재할 수 있고 검색은 종류를 기준으로 한다.

공격 상태는 1~3, 등장 전은 0, 처치 완료는 4다. 현재 상태가 3 미만이고 단계 타이머가 300에 도달하거나 체력이 `180 − phase×60` 이하가 되면 한 단계만 올리고 타이머를 0으로 바꾸며 적탄만 제거한다. 단계 1은 45스텝마다 12발·속도 2의 링(시작 회전수 frame×0.001), 단계 2는 32스텝마다 7발·속도 3의 조준 부채꼴, 단계 3은 4스텝마다 세 팔·속도 2.5의 나선을 쏘고, 그중 20스텝마다 6발·속도 3의 파동을 이어서 쏜다. 발사점 y는 보스보다 24 아래이며 타이머 0인 진입 스텝에도 공격한다.

보스 처치는 1000점과 완료 상태 4를 기록하고 적 풀에서 제거한다. 적탄 제거 요청은 플레이어 탄환 충돌 순회 뒤, 적탄 피격 검사 전에 적용한다. 몸체 접촉은 플레이어에게 피해를 줄 수 있지만 보스를 제거하지 않는다. 체력 막대는 현재 체력/180을 0~1로 제한해 그린다.

## Lv5 보상과 알림

- 그레이즈: 적탄 mark=0, 목숨>0, 무적=0이며 큰 원(16+탄환 반지름) 안이고 피격 원(2.5+탄환 반지름) 밖이면 mark=1, 점수+10, 횟수+1.
- 폭탄: 새 BOMB 눌림에 재고(초기 3)를 하나 소비한다. 적탄만 제거하고 개당 5점, 무적=max(기존,180), 모든 적에 피해 30. 재고 0 또는 목숨 0이면 무효.
- 일반 적 세 처치마다 그 위치에 아이템(용량64, 반지름6, 아래 속도1.5)을 드롭한다. 수집 원은 플레이어 반지름12. 수집하면 파워=min(3,파워+1), 점수+50. 화면 아래672 초과 시 삭제.
- 파워 초기1, 최대3. 발사 x 오프셋은 (i-(power-1)/2)*8, 발사 주기8은 그대로다.
- 스텝별 이벤트 큐는 고정64개이며 포화에서는 알림만 생략한다. 종류 1~8: 발사, 피격, 일반 처치, 그레이즈, 폭탄, 수집, 단계 전환, 보스 처치.
- 갱신 순서는 이벤트 초기화→무적 감소→이동·발사→적 생성→폭탄→적·탄환 이동→플레이어탄 충돌→지연 정리→적탄·몸체 충돌→그레이즈→아이템 이동·수집→프레임 증가다.

## Lv6 스테이지

로직 생성자는 외부에서 읽은 stage 배열을 주입받으며 생략 시 빈 스테이지다. 파일 읽기는 main.py에서 수행한다. 이벤트는 최대4096개, 음이 아닌 정수 frame의 오름차순이며 같은 시점은 파일 순서다. enemy는 frame/kind/pattern(정수0~3), boss는 frame/kind 키만 허용한다. 검증 뒤 튜플로 복사하여 원본 변경을 격리한다. 이동 전 현재 프레임 이하의 이벤트를 모두 한 번 소비한다. 적 풀 포화 시 일반 적은 생략하되 난수를 소비한다. 보스 요청은 성공할 때까지 매 스텝 재시도하며 중복 요청은 한 보스만 만든다. 기존 주기 생성 타이머는 이 단계에서 제거한다.

## Lv7 완성 상태와 효과

- status 0 시작, 1 플레이, 2 게임 오버, 3 완료. 기본 생성자는 플레이 상태, 대화형 어댑터만 시작 상태다. 새 START 눌림은 비플레이 상태에서 시드·스테이지·최고 점수를 보존하고 재시작한다. 새 PAUSE 눌림은 플레이 상태의 정지를 전환한다.
- frame은 호출 횟수이며 매 호출 증가한다. time은 플레이 갱신에만 증가하고 스테이지와 패턴 시간에 사용한다. 정지·종료 상태에서 전투는 멈춘다. 한 스텝 끝에 목숨0이면 게임 오버, 그렇지 않고 phase4면 완료다.
- 입자 풀2048, 수명30. 효과 난수는 seed XOR 0x9E3779B9이며 게임 난수를 소비하지 않는다. 스텝 끝에 기존 입자를 이동·수명 삭제하고 이벤트마다 발사2개/폭탄·보스 처치24개/기타6개 생성한다. 회전수=next/2^32, 속도=1+(next%300)/100, 반지름2. 포화 시 새 입자만 생략한다.
- 최고 점수는 max(기존,현재점수). 파일·오디오 접근은 어댑터만 수행한다. 점수 저장은 0~9007199254740991 정수만 허용하고 임시 파일 교체를 사용한다. 실패와 손상 파일은 게임을 막지 않는다.
- 자체 합성 오디오는 22050Hz/16비트/모노이며 초기화 실패 시 무음으로 동작한다. 시각 효과와 오디오가 전투 상태를 바꾸지 않는다.
