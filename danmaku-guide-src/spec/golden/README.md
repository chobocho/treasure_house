# 단계별 기준 기록

이 디렉터리에는 pygame의 각 단계 작업에서 실제 실행으로 생성한 `lv1.json`부터 `lv7.json`까지 보관합니다. 아직 게임 예제가 없으므로 미리 만든 수치나 빈 기준 파일을 두지 않습니다.

각 파일은 프레임별 입력 스크립트와 프레임 60, 600, 1800의 상태를 포함해야 합니다. 상태 필드는 `frame`, `bullets`, `enemies`, `score`, `lives`, `phase`, `checksum`입니다. 게임 규칙은 상위의 `game-spec.md`, 공통 수치는 `constants.json`을 따릅니다.

Canvas·Three.js·C++ wasm은 이 기록을 읽어 정확히 일치하는지 검사합니다. 다른 트랙의 실패를 없애려고 기준 파일을 다시 만들지 않습니다. 기준 자체에 문제가 의심되면 사용자에게 보고합니다.
