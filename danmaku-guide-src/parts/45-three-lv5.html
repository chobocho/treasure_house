Lv5 · 그레이즈·폭탄·파워업

보상 규칙을 보존하고 아이템 인스턴스·집중 링·자원 HUD로 결과를 표시합니다.

보상 상태

파워와 폭탄은 서로 다른 자원입니다. 파워는 발사 수를 늘리고 폭탄은 눌림 순간에 재고를 하나 소비합니다.

three-ts/lv5/game.ts

그레이즈 원

중심 사이 거리가 그레이즈 반지름과 탄환 반지름의 합 이내이면 보상 후보입니다. 보이는 이미지 크기와 구분합니다.

three-ts/lv5/game.ts

피격 원 제외

가까운 모든 탄환에 점수를 주면 피격도 보상이 됩니다. 작은 피격 원과 겹치는 경우를 명시적으로 제외합니다.

three-ts/lv5/game.ts

한 탄환 한 보상

탄환의 mark를 한 번만 올립니다. 스치고 멀어진 뒤 다시 접근해도 같은 탄환으로 두 번 보상하지 않습니다.

three-ts/lv5/game.ts

무적 중 보상

무적 상태에서는 위험이 사라지므로 그레이즈를 계산하지 않습니다. 목숨이 없는 중간 단계에서도 보상하지 않습니다.

three-ts/lv5/game.ts

표식 초기화

새 탄환은 재활용된 칸에 들어가도 표식이 영으로 시작합니다. 삭제에서는 위치와 표식이 같은 탄환을 따라 이동합니다.

three-ts/lv5/game.ts

보상 점수

그레이즈 하나는 10점입니다. 이벤트 큐의 성공 여부와 관계없이 게임 상태에 먼저 점수를 반영합니다.

three-ts/lv5/game.ts

이벤트 용도

게임 로직은 소리를 직접 재생하지 않습니다. 종류와 발생 좌표를 적어 두면 다음 단계에서 효과음과 입자가 소비할 수 있습니다.

three-ts/lv5/game.ts

고정 이벤트 배열

종류는 Int32Array, 좌표는 Float64Array로 미리 할당합니다. 한 스텝에 64개까지 저장하며 객체를 매번 생성하지 않습니다.

three-ts/lv5/game.ts

이벤트 추가

다음 빈 칸에 세 값을 함께 쓰고 개수를 늘립니다. 알림을 읽는 쪽은 활성 구간만 순회하면 됩니다.

three-ts/lv5/game.ts

큐 포화

큐가 가득 차면 새 알림만 생략합니다. 점수나 폭탄 피해를 이벤트 소비 단계에 맡기면 포화가 게임 규칙을 바꿉니다.

three-ts/lv5/game.ts

스텝별 큐 초기화

이벤트는 한 스텝의 결과입니다. 여러 스텝을 한 화면에 처리한다면 렌더링 직전까지 기다리지 말고 매 스텝 뒤 소비해야 합니다.

폭탄 눌림 경계

현재 입력에 폭탄이 있고 이전 입력에 없을 때만 새 눌림입니다. 키를 계속 누르는 동안에는 재고가 반복 소비되지 않습니다.

three-ts/lv5/game.ts

폭탄 재고

처음에는 폭탄 세 개를 보유합니다. 재고가 영이거나 목숨이 없으면 입력 기록만 갱신하고 사용하지 않습니다.

three-ts/lv5/game.ts

적탄만 제거

같은 풀 안의 플레이어 탄환을 보존하며 적탄만 역순으로 지웁니다. 화면 밖에서 아직 살아 있는 적탄도 제거 대상입니다.

three-ts/lv5/game.ts

제거 보상

제거한 적탄 개수에 5점을 곱해 더합니다. 교환 삭제가 탄환 순서를 바꾸어도 개수와 보상은 같아야 합니다.

three-ts/lv5/game.ts

폭탄 무적

폭탄을 쓰면 무적 시간이 최소 180스텝이 됩니다. 기존 무적이 더 길면 짧게 덮어쓰지 않습니다.

three-ts/lv5/game.ts

광역 피해

모든 적에게 체력 30의 피해를 줍니다. 처치된 적은 일반 탄환과 같은 함수를 거쳐 점수와 드롭을 처리합니다.

three-ts/lv5/game.ts

보스와 폭탄

보스도 같은 피해를 받지만 체력 180이므로 한 번에 사라지지 않습니다. 체력 임계 전환은 보스 갱신에서 처리합니다.

three-ts/lv5/game.ts

지연 정리 유지

일반 탄환으로 보스를 처치할 때는 탄환 순회가 끝난 뒤 적탄을 지웁니다. 폭탄 추가 뒤에도 이 순서를 유지합니다.

three-ts/lv5/game.ts

파워업 풀

아이템도 고정 용량 풀을 사용합니다. 탄환과 다른 활성 개수를 가지므로 두 종류가 서로의 용량을 빼앗지 않습니다.

three-ts/lv5/game.ts

세 처치당 드롭

일반 적을 세 번 처치할 때마다 마지막 적 위치에 아이템을 하나 만듭니다. 보스 처치는 일반 적 처치 횟수를 늘리지 않습니다.

three-ts/lv5/game.ts

아이템 이동

아이템은 스텝마다 아래로 1.5픽셀 이동합니다. 생성된 스텝에도 이동하므로 기준 기록의 연산 순서를 고정합니다.

three-ts/lv5/game.ts

화면 밖 아이템

화면 아래 여유 범위를 넘으면 아이템을 삭제합니다. 역순 삭제로 마지막 칸에서 옮겨 온 아이템이 두 번 이동하지 않습니다.

three-ts/lv5/game.ts

수집 반경

수집은 플레이어 중심 반지름 12와 아이템 반지름 6으로 검사합니다. 탄환의 작은 피격 원과 다른 편의 규칙입니다.

three-ts/lv5/game.ts

파워 상한

수집할 때 파워를 하나 올리되 최대 3으로 제한합니다. 더 많은 아이템을 먹어도 발사 수가 무한히 늘지 않습니다.

three-ts/lv5/game.ts

최대 파워 보상

파워가 이미 최대여도 아이템은 사라지고 50점을 받습니다. 수집 여부와 능력 상승 여부를 서로 분리합니다.

three-ts/lv5/game.ts

다중 발사

중심을 기준으로 8픽셀 간격으로 배치합니다. 두 발이면 중심 양옆 4픽셀, 세 발이면 양옆 8픽셀입니다.

three-ts/lv5/game.ts

발사 간격 유지

파워가 올라도 재사용 대기 시간은 8스텝입니다. 같은 스텝의 여러 탄환을 생성한 뒤 한 번만 대기 시간을 설정합니다.

three-ts/lv5/game.ts

발사 이벤트

풀에 실제로 들어간 탄환에 대해서만 발사 알림을 씁니다. 풀이 가득 차면 탄환 없는 발사 효과를 만들지 않습니다.

three-ts/lv5/game.ts

이벤트 종류

번호 1부터 8은 발사·피격·일반 처치·그레이즈·폭탄·수집·단계 전환·보스 처치입니다. 표시 효과가 로직으로 역류하지 않게 합니다.

three-ts/lv5/game.ts

HUD 캐시 확장

캐시 키에 파워와 폭탄 재고를 추가합니다. 점수와 목숨이 같아도 폭탄 사용 결과가 달라지면 HUD 텍스처를 갱신해야 합니다.

three-ts/lv5/render.ts

아이템 인스턴스

아이템은 별도의 64칸 InstancedMesh에 표시합니다. 공유 원 기하와 황금색 재질을 사용하고 활성 행렬 범위만 갱신합니다.

three-ts/lv5/render.ts

집중 링 표시

RingGeometry로 반지름 16의 표시 원을 만들고 집중 입력이 있을 때만 보이게 합니다. 중심 점과 게임 판정은 그대로 보존합니다.

three-ts/lv5/render.ts

갱신 순서

폭탄은 적 이동 전에 적용합니다. 탄환 충돌 뒤 그레이즈를 계산하고 마지막에 아이템 이동과 수집을 처리합니다.

포화 상태 검사

이벤트가 넘쳐도 점수가 유지되는지 확인합니다. 아이템 풀이 가득 찬 경우 새 드롭을 생략하고 기존 아이템을 보존합니다.

three-ts/lv5/game.ts

Lv5 기준 비교

자동 입력의 폭탄 눌림은 목숨을 모두 잃은 뒤라 쓰이지 않으므로 그레이즈 점수까지 pygame Lv5의 세 체크포인트와 비교하고, 폭탄 효과는 단위 검사로 따로 확인합니다. 기준 기록은 변경하지 않습니다.
