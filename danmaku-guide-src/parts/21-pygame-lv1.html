플레이어를 움직이고 집중 이동으로 속도를 바꾸며 일정한 간격으로 총알을 발사하는 독립 실행 게임을 만듭니다.

게임 상태의 최소 구성

Lv1은 플레이어 좌표, 발사 대기 시간과 살아 있는 총알만 갱신합니다. 적 풀은 비어 있고 점수와 목숨은 아직 바뀌지 않으므로 이동과 발사부터 따로 확인할 수 있습니다.

pygame/lv1/game.py

입력 비트 약속

한 입력 정수에 여러 버튼의 상태를 담습니다. 왼쪽과 발사는 다른 비트를 사용하므로 두 버튼을 함께 누른 상태도 한 값으로 전달할 수 있습니다.

pygame/lv1/game.py

논리 프레임 계수

논리 스텝을 마칠 때 frame을 하나 늘립니다. 렌더 횟수를 세는 변수와 분리해야 화면을 그리지 않는 자동 실행에서도 같은 체크포인트를 찾을 수 있습니다.

pygame/lv1/game.py

플레이어 시작 좌표

플레이어는 가로 중앙의 x 240, 아래쪽의 y 560에서 시작합니다. 초기 상태를 생성자에 모아 두면 다시 실행했을 때 같은 위치와 빈 총알 풀로 출발합니다.

pygame/lv1/game.py

이전 좌표 보관

이동 직전에 이전 좌표를 저장합니다. 렌더러는 두 좌표 사이를 보간하지만 이전 좌표나 보간 결과를 다음 논리 스텝의 입력 위치로 사용하지 않습니다.

pygame/lv1/game.py

좌우 입력 상쇄

오른쪽 입력의 참 값에서 왼쪽 입력의 참 값을 뺍니다. 오른쪽만 누르면 양수이고 왼쪽만 누르면 음수이며 동시에 누르면 0입니다.

pygame/lv1/game.py

상하 입력 상쇄

화면의 아래쪽이 양의 y 방향이므로 아래 입력에서 위 입력을 뺍니다. 상하 입력을 동시에 누르면 세로 성분이 사라지고 가로 입력만 남을 수 있습니다.

pygame/lv1/game.py

대각선 정규화

방향의 길이가 1보다 크면 이동 크기를 그 길이로 나누어 줍니다. 가로와 세로를 함께 눌러도 한 스텝의 이동 거리는 일반 속도 4픽셀을 유지합니다.

pygame/lv1/game.py

집중 이동 속도

집중 입력은 방향을 바꾸지 않고 속도만 1.6으로 선택합니다. 정규화 전에 속도를 고르고 같은 이동식을 쓰면 축 방향과 대각선에서 같은 배율이 적용됩니다.

pygame/lv1/game.py

화면 경계 제한

플레이어 중심 좌표를 화면 안의 허용 범위로 제한합니다. 이동한 다음 제한해야 여러 방향 입력과 집중 속도를 별도의 가장자리 처리 없이 같은 규칙으로 다룰 수 있습니다.

pygame/lv1/game.py

정지 입력 검사

입력이 없으면 방향 길이가 0이므로 나눗셈을 실행하지 않습니다. 정지 상태에서 좌표가 유효한 수로 유지되는지 검사하면 영벡터 정규화 오류를 찾을 수 있습니다.

pygame/lv1/game.py

발사 버튼 유지

발사 비트가 유지되는 동안 대기 시간이 0이 될 때마다 총알을 만듭니다. 버튼 이벤트를 받을 때 한 번만 발사하는 방식과 달리 운영체제의 키 반복 설정에 의존하지 않습니다.

pygame/lv1/game.py

재사용 대기 시간

발사한 뒤 대기 시간을 8스텝으로 설정합니다. 다음 스텝부터 하나씩 감소시키므로 일정한 논리 간격으로 발사하고 렌더 프레임 속도와 분리됩니다.

pygame/lv1/game.py

첫 스텝 발사

초기 대기 시간이 0이므로 처음부터 발사 키를 누르면 바로 총알이 생깁니다. 첫 발까지 불필요하게 8스텝을 기다리는 구현과 구분해서 경계 검사를 작성합니다.

pygame/lv1/game.py

총알 초기 좌표

총알은 플레이어 중심보다 14픽셀 위에서 생깁니다. 플레이어 이동을 먼저 처리한 뒤 발사하므로 이동하며 쏠 때 새 위치를 기준으로 총알이 만들어집니다.

pygame/lv1/game.py

총알 속도 부호

플레이어 총알의 y 속도는 -8이므로 화면 위쪽으로 이동합니다. 생성한 스텝에도 이동을 적용하기 때문에 첫 스텝을 마친 총알의 y 좌표는 538입니다.

pygame/lv1/game.py

총알 풀 초기화

총알 저장 공간은 시작할 때 4096칸을 확보합니다. x와 y, 속도와 표식을 배열 열로 두고 살아 있는 개수만 바꾸어 매번 새 탄환 컨테이너를 만들지 않습니다.

pygame/lv1/game.py

고정 용량 초과 처리

pygame/lv1/game.py
