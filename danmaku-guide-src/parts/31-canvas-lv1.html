Lv1 · 이동과 발사

화면과 로직을 분리하고 같은 입력을 pygame 기준과 정확하게 비교합니다.

순수 로직 모듈

게임 클래스는 DOM과 Canvas를 가져오지 않습니다. Node 자동 재생과 브라우저가 같은 함수를 실행하도록 나눕니다.

canvas-ts/lv1/game.ts

입력 상수

방향과 행동을 비트로 정합니다. pygame과 같은 번호를 사용하므로 동일한 입력 JSON을 바꾸지 않고 재생합니다.

canvas-ts/lv1/game.ts

배정밀도 숫자

JavaScript number와 Float64Array로 위치를 저장합니다. Float32Array로 줄이면 누적 오차가 기준 체크섬을 바꿀 수 있습니다.

canvas-ts/lv1/game.ts

열 배열 풀

좌표·속도·반지름·체력은 실수 열이고 종류·나이·표식은 정수 열입니다. 활성 개수까지만 갱신하고 그립니다.

canvas-ts/lv1/game.ts

용량 검증

생성자에서 음수와 정수가 아닌 용량을 거부합니다. 영 용량 풀은 정상적으로 만들되 모든 추가를 실패시킵니다.

canvas-ts/lv1/game.ts

추가와 포화

풀이 가득 차면 -1을 반환합니다. 배열을 자동으로 늘리지 않아 실행 중 용량 정책을 예측할 수 있습니다.

canvas-ts/lv1/game.ts

교환 삭제

삭제할 칸에 마지막 칸을 옮기고 개수를 줄입니다. 배열 중간의 모든 요소를 이동시키지 않아 삭제 비용이 일정합니다.

canvas-ts/lv1/game.ts

모든 필드 이동

위치만 옮기면 종류와 표식이 다른 탄환을 가리킵니다. 선언한 모든 필드를 같은 인덱스에서 함께 복사합니다.

canvas-ts/lv1/game.ts

상태 초기화

플레이어는 (240, 560)에서 시작합니다. 시드와 풀·점수·목숨·단계가 명시적인 게임 상태를 구성합니다.

canvas-ts/lv1/game.ts

이전 위치

갱신 전에 현재 위치를 이전 위치에 보관합니다. 화면은 두 상태 사이를 보간하고 로직은 현재 상태만 사용합니다.

canvas-ts/lv1/game.ts

입력 상쇄

오른쪽과 왼쪽을 모두 누르면 두 참값의 차가 영입니다. 반대 입력의 우선순위를 키 이벤트 도착 순서로 정하지 않습니다.

canvas-ts/lv1/game.ts

대각선 정규화

방향 벡터 길이로 속도를 나눕니다. 대각선에서 축 두 개를 각각 전체 속도로 이동하면 더 빨라집니다.

canvas-ts/lv1/game.ts

집중 이동

집중 비트가 있으면 스텝당 1.6을 사용합니다. 같은 나눗셈과 곱셈 순서를 유지하여 pygame과 좌표를 맞춥니다.

canvas-ts/lv1/game.ts

경계 제한

플레이어 중심은 화면 가장자리에서 12픽셀 안쪽으로 제한합니다. 이동 후 제한하여 큰 누적 입력도 범위를 벗어나지 않습니다.

canvas-ts/lv1/game.ts

발사 대기

대기 시간을 먼저 감소시키고 영이 되면 발사합니다. 첫 스텝 발사와 이후 8스텝 간격을 기준으로 고정합니다.

canvas-ts/lv1/game.ts

탄환 생성

탄환은 플레이어보다 14픽셀 위에서 시작하고 위로 8픽셀씩 움직입니다. 생성된 스텝에도 이동합니다.

canvas-ts/lv1/game.ts

탄환 이동

배열의 활성 구간을 역순으로 갱신합니다. 교환 삭제로 옮겨 온 마지막 탄환이 같은 스텝에 다시 움직이지 않습니다.

canvas-ts/lv1/game.ts

화면 밖 제거

논리 화면 밖 32픽셀 여유를 둡니다. 정확히 경계에 있는 탄환은 유지하고 넘어간 탄환만 제거합니다.

canvas-ts/lv1/game.ts

입력 범위

0부터 511 사이 정수만 받습니다. null·문자열·실수가 비트 연산에서 자동 변환되기 전에 거부합니다.

canvas-ts/lv1/game.ts

논리 갱신 순서

플레이어 이동 뒤 발사하고 모든 탄환을 이동한 다음 프레임을 증가시킵니다. 포트 간 순서가 바뀌면 기준도 달라집니다.

canvas-ts/lv1/game.ts

체크섬 내림

좌표에 16을 곱해 내림한 뒤 가중 합을 계산합니다. 음수에서 버림과 내림은 다르므로 floor를 사용합니다.

canvas-ts/lv1/game.ts

무부호 변환

합의 마지막을 0비트 무부호 오른쪽 이동(>>> 0)으로 32비트에 맞춥니다. 음수 체크섬으로 출력하지 않습니다.

canvas-ts/lv1/game.ts

키 코드

물리 키를 나타내는 code를 비트에 매핑합니다. 키보드 문자 대소문자와 방향 키가 서로 다른 경로로 흔들리지 않게 합니다.

canvas-ts/lv1/input.ts

누름과 뗌

눌린 키 이름을 집합으로 보관하고 읽을 때 비트를 합칩니다. 같은 행동을 두 키로 눌러도 하나를 떼면 다른 키가 유지됩니다.

canvas-ts/lv1/input.ts

포커스 해제

캔버스가 포커스를 잃으면 눌린 키를 비웁니다. 키를 누른 채 다른 창으로 이동했을 때 계속 움직이는 문제를 막습니다.

canvas-ts/lv1/input.ts

기본 스크롤 방지

게임에 사용하는 키만 기본 동작을 막습니다. 캔버스에 포커스가 있을 때 방향 키가 페이지까지 움직이지 않게 합니다.

canvas-ts/lv1/input.ts

고정 스텝 누적

화면 콜백이 받은 실제 시간을 누적하고 1/60초마다 로직을 실행합니다. 화면 한 번에 여러 갱신이 가능해야 합니다.

canvas-ts/lv1/main.ts

긴 프레임 제한

한 콜백에서 더하는 시간을 0.25초로 제한합니다. 긴 정지 뒤 수천 스텝을 한꺼번에 따라잡지 않게 합니다.

canvas-ts/lv1/main.ts

시간 보정

누적 시간 비교에 작은 오차 여유를 두고 감소 뒤 영 아래로 내려가지 않게 합니다. 경계 반올림이 한 스텝을 잃지 않게 합니다.

canvas-ts/lv1/main.ts

렌더 보간

남은 시간을 스텝 길이로 나눈 계수로 이전 위치와 현재 위치를 섞습니다. 렌더 함수가 게임 좌표를 수정하지 않습니다.

canvas-ts/lv1/render.ts

우주선 이모지

우주선은 시스템 글리프이며 별도 파일을 내려받지 않습니다. 코드에는 유니코드 이스케이프를 써서 코드 글꼴 요구와 분리합니다.

canvas-ts/lv1/render.ts

탄환 그리기

살아 있는 탄환만 중심과 반지름으로 그립니다. 캔버스 경로를 매 탄환마다 시작하여 이전 원과 연결되지 않게 합니다.

canvas-ts/lv1/render.ts

입력과 로직 분리

입력 어댑터는 비트만 반환합니다. 자동 재생에서는 키보드 이벤트 없이 같은 step 함수에 JSON의 비트를 전달합니다.

canvas-ts/lv1/input.ts

독립 번들

각 레벨의 main과 game을 별도 산출물로 만듭니다. 브라우저 페이지와 Node 검사 모듈이 같은 원본 로직을 사용합니다.

canvas-ts/build.mjs

자동 재생

변경 프레임에만 입력 비트를 바꾼 뒤 매 프레임 스텝을 호출합니다. 체크포인트는 호출이 끝난 상태에서 수집합니다.

canvas-ts/run.mjs

새 TypeScript 구현의 결과를 pygame 기준과 비교합니다. 세 체크포인트의 모든 필드가 같아야 통과합니다.

canvas-ts/lv1/game.ts
