C++ 게임 상태

프레임과 플레이어 좌표, 이전 좌표, 발사 대기 시간, 탄환 풀을 한 상태에 보관합니다. 명시적 초기화는 활성 개수를 영으로 돌리고 플레이어를 시작 위치로 옮겨 같은 인스턴스에서 재시작할 수 있게 합니다.

cpp-wasm/lv1/game.cpp

역순 이동과 삭제

활성 구간의 뒤에서 앞으로 순회합니다. 삭제할 때 마지막 탄환이 현재 위치로 오지만 그 탄환은 이미 이동했으므로 다시 움직이지 않습니다. 부호 없는 인덱스의 영 아래 감소를 피하도록 남은 개수로 반복합니다.

cpp-wasm/lv1/game.cpp

교환할 때 모든 필드 이동

좌표뿐 아니라 속도와 나이도 마지막 요소에서 복사합니다. 잘못된 인덱스는 거부합니다. 삭제 후 순서는 달라지지만 활성 구간이 연속되어 다음 순회를 단순하게 유지합니다.

cpp-wasm/lv1/game.hpp

한 번 호출하면 한 스텝

입력이 유효하면 이동·발사·탄환 갱신 순서로 실행한 뒤 프레임을 올립니다. C++는 실제 시간을 읽지 않습니다. 잘못된 비트는 상태를 바꾸기 전에 거부하며 JS도 정수와 범위를 먼저 확인합니다.

cpp-wasm/lv1/game.cpp

cpp-wasm/lv1/game.cpp

C ABI로 게임 호출

버전 확인 뒤 시드로 초기화하고 입력 비트로 step을 호출합니다. 프레임·탄환 수·체크섬과 플레이어 좌표를 내보냅니다. 이번 단계의 시드는 보관만 하며 난수는 아직 소비하지 않습니다.

cpp-wasm/lv1/game.cpp

JS 입력 검증

JS 숫자는 소수나 음수도 담을 수 있지만 wasm 정수 인자는 변환됩니다. 변환 전에 정수·범위를 검사하여 잘못된 입력이 조용히 다른 값으로 바뀌는 경우를 막습니다.

cpp-wasm/lv1/replay.mjs

화면을 클릭하면 키보드 입력을 받습니다. Z와 스페이스는 발사, Shift는 집중 이동입니다. 포커스를 잃거나 문서가 숨겨지면 키 집합을 지워 누른 상태가 남지 않게 합니다.

cpp-wasm/lv1/main.js

이동과 발사 · 이해 확인

C++에서 플레이어 위치와 탄환을 갱신할 때 매번 실제 시각을 읽어야 할까요?

게임의 한 호출은 한 고정 스텝입니다. JS가 시간 누적과 입력을 담당하고 C++는 같은 입력에 같은 순서로 상태를 갱신합니다. 이 경계 덕분에 Node에서도 같은 기준 기록을 재현할 수 있습니다.
