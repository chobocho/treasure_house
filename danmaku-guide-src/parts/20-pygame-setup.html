2부 · Python + pygame

pygame으로 일곱 단계 완성하기

창을 열고 입력을 받는 방법부터 충돌, 보스, 스테이지와 소리까지 같은 게임을 단계별로 만듭니다.

설치와 실행 확인

게임 규칙을 작성하기 전에 실행기, 창, 이미지와 자동 검사 환경을 실제로 확인합니다.

Python 실행기 확인

설치에 쓴 Python과 실행에 쓰는 Python이 같아야 합니다. 명령 파일은 이 프로젝트의 가상환경이 있으면 그 실행기를 선택하고, 없으면 시스템의 python3을 사용합니다.

pygame/commands.sh

pygame 버전

이 환경의 pygame 모듈은 pygame-ce 배포판 2.5.8에서 제공합니다. 모듈 이름과 배포 패키지 이름이 다르므로 요구 사항 파일에는 실제 배포 이름을 고정합니다.

pygame/requirements.txt

작업 디렉터리

예제의 상대 경로 명령은 danmaku-guide-src를 기준으로 실행합니다. 이미지 경로는 실행한 셸의 위치 대신 Python 파일의 위치에서 계산해 다른 디렉터리에서도 찾을 수 있게 합니다.

pygame/setup.py

설치 명령과 재현

프로젝트 안의 가상환경에 pygame-ce 2.5.8을 설치합니다. 전역 Python 환경의 패키지를 바꾸지 않고 같은 버전의 실행 환경을 다시 만들 수 있습니다.

pygame/commands.sh

창 초기화

화면 서브시스템을 초기화하고 논리 해상도의 창을 엽니다. 이 확인 예제는 소리를 사용하지 않으므로 믹서를 초기화하지 않아 오디오 장치가 없어도 실행됩니다.

pygame/setup.py

논리 화면 크기

게임의 가로와 세로는 480과 640픽셀로 고정합니다. 창의 크기와 월드 좌표가 다른 구현을 만들더라도 규칙의 좌표계는 이 크기를 기준으로 유지합니다.

pygame/setup.py

이벤트 큐 비우기

운영체제가 보낸 이벤트는 매 프레임 읽어야 합니다. 큐를 처리하지 않으면 화면이 그려져도 창을 닫거나 움직이는 요청에 반응하지 않는 것처럼 보일 수 있습니다.

pygame/setup.py

종료 이벤트

창을 닫는 요청을 받으면 반복 조건을 바꾸고 루프를 끝냅니다. 루프 중간에서 프로그램을 강제로 종료하기보다 정리 코드까지 도달하도록 흐름을 유지합니다.

pygame/setup.py

이미지 파일 위치

이미지는 examples/assets/noto-emoji 아래에 원본 버전과 함께 보관합니다. 실행 코드에서 임의의 외부 URL로 이미지를 가져오지 않으므로 테스트와 오프라인 실행이 같은 파일을 읽습니다.

pygame/setup.py

투명 이미지 변환

PNG를 읽은 뒤 화면 형식에 맞는 투명 이미지로 변환합니다. convert_alpha는 화면 모드가 만들어진 뒤 호출하고, 게임 루프 안에서 매번 다시 변환하지 않습니다.

pygame/setup.py

이미지 크기 조절

원본 이미지의 해상도와 게임에서 보여 줄 크기는 다릅니다. 확인 예제는 시작할 때 한 번 64픽셀 크기로 조절하고 매 프레임에는 이미 만들어진 결과를 그립니다.

pygame/setup.py

화면 지우기

매 프레임 배경색으로 화면을 채우면 이전 프레임의 그림이 남지 않습니다. 전체 화면을 다시 그리는 단순한 방식부터 시작하고 필요할 때 갱신 영역을 줄이는 방법을 검토합니다.

pygame/setup.py

이미지 그리기

blit의 위치는 이미지의 왼쪽 위 좌표입니다. 플레이어 상태를 중심 좌표로 관리한다면 이미지 가로와 세로의 절반을 빼서 그릴 위치를 구해야 합니다.

pygame/setup.py

화면 갱신

화면 표면에 그린 결과를 display.flip으로 창에 표시합니다. 이동 상태를 바꾸는 단계와 실제로 보여 주는 단계를 구분하면 렌더링의 책임이 분명해집니다.

pygame/setup.py

검사 가능한 프레임 제한

자동 검사에서는 창을 계속 열어 두지 않고 지정한 프레임 수 뒤에 종료합니다. 유효하지 않은 값은 시작 전에 거부해 무한 대기나 빈 실행을 정상 결과로 기록하지 않습니다.

pygame/setup.py

더미 비디오 드라이버

화면 장치가 없는 검사는 SDL_VIDEODRIVER를 dummy로 지정해 실행하고, 이때는 실제 시간 대기를 건너뜁니다. 픽셀을 그리는 코드 자체는 그대로 실행하되 실제 창의 입력 감각이나 장치 호환성은 별도로 확인해야 합니다.

pygame/setup.py

Noto 이미지 라이선스

사용한 PNG 세 개는 Noto Emoji v2.048의 고정 커밋에서 받았고 이미지용 Apache-2.0 안내와 라이선스 원문을 함께 저장했습니다. 글꼴 파일은 이 이미지 묶음에 포함하지 않습니다.

고정 원본 버전 · 원본 안내는 examples/assets/noto-emoji/LICENSE, 전체 원문은 APACHE-2.0.txt에 보관합니다.

설치 이해 확인

pip 설치는 성공했는데 pygame을 불러오지 못하면 무엇부터 확인할까요?

설치에 쓴 Python과 실행에 쓴 Python이 같은지 확인합니다. pygame-ce는 배포 패키지 이름이고 코드에서는 pygame을 불러옵니다.
