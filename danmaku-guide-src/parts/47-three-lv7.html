Lv7 · 효과·셰이더·완성 화면

실제 GLSL을 컴파일하여 탄환을 표시하고 입자·소리·저장소와 내장 게임을 완성합니다.

화면 상태

시작·플레이·게임 오버·완료 상태를 Game이 보관합니다. Three 장면의 객체 유무로 게임 상태를 추측하지 않습니다.

three-ts/lv7/game.ts

시작 화면

브라우저 어댑터는 시작 상태로 만들고 Enter를 기다립니다. Node 자동 재생은 플레이 상태에서 같은 기준 입력을 실행합니다.

three-ts/lv7/main.ts

눌림 보관

짧은 Enter·P·X 입력을 다음 논리 스텝까지 보관합니다. 게임 키 이벤트는 캔버스 밖으로 전파하지 않아 덱 이동과 충돌하지 않습니다.

three-ts/lv7/input.ts

재시작

시드·스테이지·최고 점수를 보존하고 라운드를 초기화합니다. 렌더러는 같은 Game 객체에서 새 풀 상태를 다시 읽습니다.

three-ts/lv7/game.ts

최고 점수

현재 점수와 기록의 큰 값을 유지합니다. 저장소를 읽고 쓰는 책임은 순수 Game 밖에 둡니다.

three-ts/lv7/game.ts

일시 정지

새 P 눌림에서 정지 상태를 바꿉니다. 정지 중에는 전투와 입자 시간이 멈추고 표시도 현재 좌표를 그대로 사용합니다.

three-ts/lv7/game.ts

호출과 시간

검사용 호출 프레임과 실제 플레이 시간을 구분합니다. 종료 뒤에도 호출 수는 세되 패턴과 스테이지 시간은 멈춥니다.

three-ts/lv7/game.ts

게임 오버

목숨이 영이 된 스텝 뒤 게임 오버 상태로 전환합니다. 다음 스텝부터 새 탄환과 적을 진행하지 않습니다.

three-ts/lv7/game.ts

보스 처치 완료

보스 완료 단계 사를 읽어 완료 화면을 표시합니다. 같은 스텝에 마지막 목숨도 잃으면 게임 오버가 먼저 적용됩니다.

three-ts/lv7/game.ts

입자 풀

입자 최대 이천사십팔 칸을 따로 보관합니다. 효과 포화가 탄환 풀이나 적 풀의 용량을 빼앗지 않습니다.

three-ts/lv7/game.ts

입자 인스턴스

입자도 고정 용량 InstancedMesh로 표시합니다. 아이템과 같은 원 기하를 공유하되 색 재질과 활성 개수는 독립입니다.

three-ts/lv7/render.ts

효과 난수

효과 전용 난수 상태를 사용합니다. 입자 수나 표시 방식을 바꾸어도 적 위치와 탄막의 난수 소비는 바뀌지 않습니다.

three-ts/lv7/game.ts

이벤트 소비

충돌과 보상을 확정한 같은 스텝에 입자를 만듭니다. 오디오는 어댑터가 논리 스텝 직후 소비하여 중간 알림을 놓치지 않습니다.

three-ts/lv7/main.ts

입자 수명

기존 입자를 이동하고 삼십 스텝이 되면 삭제합니다. 새 입자 생성은 기존 입자 갱신 뒤에 수행합니다.

three-ts/lv7/game.ts

활성 범위

활성 입자 수에 맞춰 행렬 범위를 갱신합니다. 입자가 없으면 count를 영으로 하고 불필요한 속성 갱신을 요청하지 않습니다.

three-ts/lv7/render.ts

표시 보간

탄환·적·아이템·입자를 같은 계수로 표시합니다. 정지와 종료에서는 계수를 일로 고정해 위치가 흔들리지 않게 합니다.

three-ts/lv7/render.ts

정점 셰이더

정점 셰이더는 기하의 정점에 인스턴스·모델·카메라 변환을 적용합니다. 실제로 빌드해 브라우저에서 컴파일한 원문을 읽습니다.

three-ts/lv7/bullet.vert.glsl

인스턴스 행렬

instanceMatrix를 적용해야 같은 평면 기하가 각 탄환의 위치와 반지름으로 표시됩니다. 게임 위치 계산은 CPU에 남깁니다.

three-ts/lv7/bullet.vert.glsl

인스턴스 색

CPU에서 기록한 종류별 색을 varying으로 전달합니다. 각 탄환마다 별도 ShaderMaterial을 만들지 않습니다.

three-ts/lv7/bullet.vert.glsl

UV 전달

평면의 UV 좌표를 조각 단계로 전달합니다. 탄환 위치와 무관하게 같은 영부터 일 범위로 원 모양을 판단할 수 있습니다.

three-ts/lv7/bullet.vert.glsl

조각 원

UV 중심에서의 길이가 영 점 오 이내인 조각만 유지합니다. 사각형 기하를 쓰면서 화면에서는 원으로 표시합니다.

three-ts/lv7/bullet.frag.glsl

모서리 버림

원 밖 조각은 discard로 버립니다. 실제 픽셀 검사는 사각형 모서리에 배경이 남는지 확인합니다.

three-ts/lv7/bullet.frag.glsl

색 공간

인스턴스 색은 선형 공간의 값입니다. 렌더러의 출력 색 공간 변환 조각을 포함하여 색을 올바르게 표시합니다.

three-ts/lv7/bullet.frag.glsl

표시 시간 uniform

플레이 시간으로 uniform을 갱신하여 미세한 밝기 변화를 만듭니다. 이 사인 함수는 시각 효과이며 게임 삼각함수와 분리합니다.

three-ts/lv7/render.ts

GPU와 게임 정밀도

표시용 행렬과 셰이더는 GPU의 실수 표현을 사용합니다. Game의 위치·충돌·체크섬은 계속 배정밀도로 계산합니다.

three-ts/lv7/render.ts

합성 소리

외부 소리 파일 없이 표준 파형으로 효과음과 멜로디를 합성합니다. 게임 난수와 좌표를 소리 합성에 사용하지 않습니다.

three-ts/lv7/audio.ts

사용자 제스처

키나 포인터 입력 뒤 AudioContext를 활성화합니다. 초기화 요청이 겹치면 진행 중 플래그로 중복 배경음을 막습니다.

three-ts/lv7/audio.ts

오디오 실패

장치를 만들거나 활성화할 수 없으면 무음으로 계속합니다. 소리 실패가 게임 갱신이나 WebGL 렌더를 중단시키지 않습니다.

three-ts/lv7/audio.ts

중복 소리 제한

같은 스텝의 같은 종류 알림은 한 번만 재생합니다. 여러 탄환의 동시 발사로 같은 소리가 과도하게 겹치지 않게 합니다.

three-ts/lv7/audio.ts

저장소 읽기

같은 출처의 저장소에서 최고 점수를 읽습니다. 저장소 접근 자체가 실패할 수 있으므로 안전하게 얻고 검증합니다.

three-ts/lv7/storage.ts

손상 처리

최고 점수는 안전한 범위의 음이 아닌 정수여야 합니다. 잘못된 값과 저장 실패를 처리해 플레이를 계속할 수 있게 합니다.

three-ts/lv7/storage.ts

HUD와 종료 패널

상단 HUD와 가운데 종료 패널을 다른 텍스처로 분리합니다. 패널은 상태·정지·최고 점수가 바뀔 때만 다시 그립니다.

three-ts/lv7/render.ts

리소스 해제

평면과 원 기하·재질·인스턴스·패널 텍스처를 각각 해제합니다. 공유 원 기하는 아이템과 입자마다 중복 해제하지 않습니다.

three-ts/lv7/render.ts

셰이더 오류 검사

실제 WebGL에서 셰이더를 컴파일하고 페이지 예외와 콘솔 오류를 수집합니다. 문자열 파일이 존재하는 것만으로 검증을 끝내지 않습니다.

three-ts/lv7/bullet.frag.glsl

실제 픽셀

탄환 중심과 모서리·입자·패널을 실제 WebGL 픽셀로 검사했습니다. 표시용 객체 수와 화면 내용이 모두 맞는지 확인합니다.

three-ts/lv7/render.ts

기준 비교

pygame Lv7의 세 체크포인트와 모든 필드가 같습니다. 셰이더·소리·입자는 전투 결과를 변경하지 않습니다.

three-ts/lv7/game.ts

내장 데모

캔버스에 포커스를 두고 Enter로 시작합니다. 방향키·Z·Shift·X·P를 사용하며 다른 슬라이드에서는 게임 시간과 소리가 멈춥니다.
