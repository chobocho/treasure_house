Lv3 · 네 가지 탄막 패턴

자체 사분파 다항식과 같은 연산 순서로 네 가지 패턴을 재현합니다.

게임용 삼각함수

게임 규칙의 방향 계산에는 직접 구현한 dsin과 dcos를 사용합니다. 표준 라이브러리의 사인 구현 차이가 좌표 누적과 체크섬에 영향을 주지 않도록 같은 다항식으로 계산합니다.

canvas-ts/lv3/game.ts

회전수 단위

각도 1은 한 바퀴이고 0.25는 아래쪽을 향하는 사분의 일 회전입니다. 각도를 라디안으로 사용하는 함수와 섞지 않도록 패턴 함수의 입력 단위를 하나로 고정합니다.

canvas-ts/lv3/game.ts

음수 회전 정리

입력에서 내림한 정수 부분을 빼면 음수 회전도 0 이상 1 미만으로 정리됩니다. 단순한 정수 절삭과 다른 결과가 나오는 음수 경계를 함께 검사합니다.

canvas-ts/lv3/game.ts

사분면 접기

대칭성을 이용해 입력을 사분의 일 회전 안쪽으로 접습니다. 이 구간에만 다항식을 적용하면 먼 각도까지 같은 다항식을 그대로 대입하는 것보다 근사 범위를 관리하기 쉽습니다.

canvas-ts/lv3/game.ts

Horner 계산

가장 높은 차수의 계수부터 이전 결과에 x의 제곱을 곱하고 다음 계수를 더합니다. 같은 수식도 계산 순서를 바꾸면 마지막 비트가 달라질 수 있으므로 이 순서를 포트에서도 유지합니다.

canvas-ts/lv3/game.ts

다항식 계수

13차까지의 홀수 항을 사용하고 마지막에 x를 곱합니다. 계수와 곱셈 순서를 공통 사양에 기록해 더 정확해 보이는 다른 근사식으로 포트만 바꾸지 않도록 합니다.

canvas-ts/lv3/game.ts

코사인 이동

별도 다항식 대신 사인 입력에 0.25를 더해 코사인을 구합니다. 각도 정리와 사분면 처리도 같은 구현을 공유하므로 두 함수의 경계 규칙이 달라지지 않습니다.

canvas-ts/lv3/game.ts

축 방향 확인

회전수 0에서는 오른쪽, 0.25에서는 아래쪽으로 향합니다. 원형 패턴이 예상과 반대로 돌아가면 화면 y축과 회전수 단위를 먼저 확인합니다.

canvas-ts/lv3/game.ts

속도 벡터 구성

방향의 코사인과 사인에 같은 탄속을 곱하면 두 속도 성분이 됩니다. 반지름이나 이미지 크기를 이 값에 섞지 않아 그림과 이동 규칙을 분리합니다.

canvas-ts/lv3/game.ts

링 탄수

링은 한 바퀴를 탄수로 나눈 간격으로 발사합니다. 인덱스가 탄수보다 작을 때까지만 사용하므로 첫 방향과 마지막 방향이 같은 곳에 중복되지 않습니다.

canvas-ts/lv3/game.ts

링 시작 방향

모든 탄환의 회전수에 같은 시작값을 더하면 링 전체가 돌아갑니다. 개별 탄환의 속도를 바꾸지 않고도 다음 발사의 빈 공간을 다른 위치로 옮길 수 있습니다.

canvas-ts/lv3/game.ts

링 한 발

탄수가 1이면 첫 방향으로 한 발만 만듭니다. 여러 발에서만 맞아 보이는 구현을 피하려면 한 발과 균등한 여러 발을 별도로 검사합니다.

canvas-ts/lv3/game.ts

링 영 발

탄수가 0이면 반복이 실행되지 않으므로 나눗셈도 실행되지 않습니다. 발사를 생략하는 경계 입력에서 풀 개수나 기존 탄환이 바뀌지 않는지 확인합니다.

canvas-ts/lv3/game.ts

조준 방향

플레이어 위치에서 발사점을 빼고 길이로 나누어 기준 방향을 만듭니다. 현재 스텝의 플레이어 이동이 먼저 끝났기 때문에 적은 갱신된 위치를 향합니다.

canvas-ts/lv3/game.ts

영 조준 벡터

발사점과 플레이어 위치가 같으면 나눌 길이가 0입니다. 이 경우 아래 방향을 명시적으로 사용해 속도 성분이 유효하지 않은 값이 되는 일을 막습니다.

canvas-ts/lv3/game.ts

부채꼴 중심

인덱스에서 탄수와 관련된 중앙값을 빼고 회전 간격 0.025를 곱합니다. 모든 각도를 같은 기준 방향에서 회전시켜 부채꼴이 목표를 중심으로 퍼지게 합니다.

canvas-ts/lv3/game.ts

짝수와 홀수 탄수

홀수 탄수에는 각도 차이가 0인 중앙 탄환이 있고 짝수 탄수에는 중앙 양쪽의 두 탄환이 있습니다. 가운데를 정수 나눗셈으로 자르면 짝수 부채꼴의 대칭이 깨집니다.

canvas-ts/lv3/game.ts

회전한 x 성분

기준 벡터의 x에 코사인을 곱하고 y에 사인을 곱한 값을 뺍니다. 단순히 x 성분에 일정한 값을 더하는 방식은 회전이 아니므로 속도 크기가 달라질 수 있습니다.

canvas-ts/lv3/game.ts

회전한 y 성분

기준 x의 사인 성분과 기준 y의 코사인 성분을 더합니다. x와 y를 같은 회전식으로 함께 계산해야 대칭인 각도에서 같은 탄속을 유지합니다.

canvas-ts/lv3/game.ts

역삼각함수 없이 조준

조준 방향을 각도로 바꾸었다 다시 벡터로 되돌릴 필요가 없습니다. 제곱근 정규화와 작은 회전만 사용하면 atan2의 언어별 구현에 의존하지 않습니다.

canvas-ts/lv3/game.ts

나선의 논리 시간

나선의 시작 회전수는 논리 틱에 0.007을 곱해 구합니다. 실제 시각이나 렌더 프레임을 사용하지 않아 자동 재생에서도 같은 방향으로 발사합니다.

canvas-ts/lv3/game.ts

링을 재사용한 나선

나선은 매번 다른 시작 회전수로 링을 발사하는 함수로 구현하며 탄수 인자는 팔의 수가 됩니다. 링의 탄속 계산과 풀 추가 규칙을 재사용하므로 별도의 탄환 이동 코드가 필요하지 않습니다.

canvas-ts/lv3/game.ts

나선 회전량

0.007은 한 논리 틱당 바뀌는 회전수입니다. 8발 링을 60스텝마다 쏘면 0.42바퀴 회전이 1/8바퀴 대칭에 상쇄되어 0.045바퀴만 보입니다. 그래서 나선 적은 두 팔을 6스텝마다 쏘아 발사마다 0.042바퀴씩 돌립니다.

canvas-ts/lv3/game.ts

파동 기준 방향

파동은 아래쪽 방향인 0.25를 기준으로 부채꼴 전체가 좌우로 흔들립니다. 사인 값이 0인 순간은 부채꼴 중심이 곧장 아래를 향하고 양쪽 극값에서는 기준에서 같은 크기로 벗어납니다.

canvas-ts/lv3/game.ts

파동 진폭

사인 값에 곱한 0.12는 방향이 흔들리는 최대 회전 폭입니다. 이 값을 바꾸는 것과 탄속을 바꾸는 것은 회피 공간에 서로 다른 영향을 줍니다.

canvas-ts/lv3/game.ts

파동 주기

틱을 180으로 나누므로 시간에 따른 흔들림은 180스텝마다 같은 위상으로 돌아옵니다. 발사 간격과 주기가 정수 배 관계인지에 따라 반복해서 보이는 모양이 달라집니다.

canvas-ts/lv3/game.ts

탄환별 간격

한 번의 발사 안에서 인덱스는 위상이 아니라 0.025 간격의 부채꼴로 펼칩니다. 인덱스를 위상에 더하면 사인 한 주기를 한꺼번에 찍어 묶음이 흔들리지 않고 대칭인 두 탄환이 같은 방향으로 겹칩니다.

canvas-ts/lv3/game.ts

패턴 선택 함수

번호 0부터 3을 링, 조준 부채꼴, 나선과 파동 함수에 연결합니다. 공통 인자인 발사점, 탄수와 탄속을 유지하면 적이나 보스가 같은 패턴 인터페이스를 사용할 수 있습니다.

canvas-ts/lv3/game.ts

적의 패턴 표식

생성 프레임을 기준으로 적마다 사용할 패턴 번호를 기록합니다. 적의 나이는 발사 시점을 결정하고 표식은 어떤 패턴을 발사할지 결정하므로 역할이 다릅니다.

canvas-ts/lv3/game.ts

난수 소비 유지

패턴 번호를 고를 때 새 난수를 소비하지 않습니다. 생성 프레임에서 번호를 계산하므로 위치 생성에 쓰이는 난수열은 Lv2와 같은 소비 순서를 유지합니다.

canvas-ts/lv3/game.ts

풀 포화와 패턴

여러 발을 발사하는 중에 풀이 가득 찰 수 있습니다. 각 추가가 실패를 반환하도록 두면 배열 밖에 쓰지 않고 빈칸이 허용하는 만큼만 만들어집니다.

canvas-ts/lv3/game.ts

잘못된 패턴 번호

약속한 범위 밖의 번호는 조용히 다른 모양으로 바꾸지 않고 오류로 거부합니다. 데이터나 보스 상태에 잘못된 번호가 들어오면 원인을 가까운 위치에서 찾을 수 있습니다.

canvas-ts/lv3/game.ts

근사 오차 검사

표준 삼각함수와의 오차는 테스트에서만 비교합니다. 근사 코사인은 회전수 영에서도 수학적 일과 약간 다르므로 포트는 기존 계산값을 유지합니다.

canvas-ts/lv3/game.ts

화면 주기와 발사

적의 발사 시점은 나이로 정하며 나선 적은 6스텝, 나머지 적은 60스텝의 배수에서 쏩니다. 화면이 빠르거나 느리게 그려져도 발사 횟수와 나선·파동에 전달하는 틱 값이 같아야 합니다.

canvas-ts/lv3/game.ts

이전 규칙 유지

패턴을 늘려도 이동 속도, 플레이어 발사, 충돌과 무적 처리 순서는 유지합니다. 새로운 탄환 역시 같은 풀과 같은 원 충돌을 사용하므로 기능을 단계별로 비교할 수 있습니다.

canvas-ts/lv3/game.ts

패턴 뷰어와 비교

공통 기초의 뷰어에서 같은 탄수와 속도를 선택해 모양을 먼저 관찰할 수 있습니다. 실제 게임에서는 충돌과 적의 위치가 추가되지만 방향 벡터를 만드는 원리는 같습니다.
