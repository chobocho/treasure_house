Lv7 · C++ 완성 게임

시작과 종료·입자·합성 소리·저장을 연결하고 같은 기준 기록을 유지합니다.

호출 프레임과 게임 시간

frame은 호출 횟수이고 time은 실제 전투가 진행된 스텝 수입니다. 정지나 시작 대기 중에는 frame만 증가합니다. 스테이지와 패턴은 time을 사용해 정지 후 재개해도 전투 진행이 건너뛰지 않게 합니다.

cpp-wasm/lv7/game.cpp

시작·게임 오버·클리어

상태 0은 시작 대기, 1은 진행, 2는 게임 오버, 3은 클리어입니다. 전투 갱신 후 목숨 영과 보스 완료 단계 4를 검사합니다. 정지 상태는 별도 플래그로 보관해 진행 상태와 구분합니다.

cpp-wasm/lv7/game.cpp

정지 키의 한 번 눌림

현재 입력과 이전 제어 입력의 차이로 눌림을 구합니다. P를 누르고 있어도 정지가 반복 전환되지 않습니다. 시작이나 종료 상태에서 Enter를 새로 누르면 재시작합니다.

cpp-wasm/lv7/game.cpp

스테이지와 최고 점수 보존

재시작은 전투 상태와 풀 개수를 초기화하지만 스테이지 데이터와 최고 점수는 유지합니다. 고정 스테이지 배열의 내용을 덮어쓰지 않고 개수와 커서를 재설정합니다. 이전 탄환과 입자는 활성 구간에서 제외됩니다.

cpp-wasm/lv7/game.cpp

효과 난수 분리

입자는 별도 xorshift 상태를 사용합니다. 효과를 많이 만들거나 입자 풀이 가득 차도 적 생성용 난수는 바뀌지 않습니다. 기준 기록 비교는 보이는 효과와 전투 규칙의 독립성을 확인합니다.

cpp-wasm/lv7/game.cpp

입자의 수명과 포화

입자는 2048개 풀에서 좌표·속도·나이·수명을 보관합니다. 먼저 기존 입자를 이동하고 수명이 끝나면 삭제한 뒤 새 이벤트 입자를 만듭니다. 발사는 2개, 폭탄과 보스 처치는 24개, 다른 이벤트는 6개를 생성합니다.

cpp-wasm/lv7/game.cpp

입자 표시 버퍼

입자도 활성 x/y만 별도 연속 배열로 복사합니다. JS는 기존 메모리 어댑터로 읽고 작은 밝은 사각형으로 표시합니다. 전투 탄환·입자·아이템은 각각의 용량과 활성 개수를 사용합니다.

cpp-wasm/lv7/game.cpp

짧은 키 입력 보관

브라우저가 다음 논리 스텝을 실행하기 전에 keyup이 와도 눌림 비트를 보관합니다. 스텝을 한 번 실행한 뒤만 지워 Enter나 P의 짧은 입력을 놓치지 않습니다. 내장 데모의 방향키는 상위 덱으로 전파하지 않습니다.

cpp-wasm/lv7/main.js

각 스텝 직후 알림 소비

한 표시 프레임에서 여러 고정 스텝이 실행될 수 있으므로 매 스텝 직후 이벤트를 읽습니다. 이벤트 종류를 오디오 입력 배열로 옮기고 새 최고 점수가 생기면 저장을 시도합니다. 마지막 스텝의 알림만 읽지 않습니다.

cpp-wasm/lv7/main.js

상태 패널과 최고 점수

시작·정지·게임 오버·클리어 안내를 캔버스 위 패널로 표시합니다. 최고 점수는 별도 글로 보여줍니다. 입자를 그린 뒤 상태 패널을 올려 입력 안내가 효과에 가리지 않게 합니다.

cpp-wasm/lv7/main.js

합성 효과음

주파수와 지속 시간으로 샘플을 생성하고 시작과 끝에 진폭을 줄입니다. 소리 합성은 게임 난수를 사용하지 않습니다. 실제 오디오 장치가 없어도 샘플 길이·유한 값·진폭을 단위 검사로 확인합니다.

cpp-wasm/lv7/audio.ts

사용자 입력 뒤 오디오 열기

처음 키 입력이나 포인터 입력에서 AudioContext를 활성화합니다. 활성화 중복을 막고 장치나 정책 오류를 잡아 게임을 계속 실행합니다. 소리 재생 허용을 가정해 시작 시 자동 재생하지 않습니다.

cpp-wasm/lv7/audio.ts

짧은 합성 배경음

여덟 음을 합성해 반복 재생하는 배경음 버퍼를 만듭니다. 외부 음원 파일이나 네트워크 요청 없이 실행합니다. 효과음과 배경음의 생성은 초기 활성화 때 수행합니다.

cpp-wasm/lv7/audio.ts

같은 종류 효과음 중복 제한

한 스텝의 같은 종류 이벤트는 한 번만 재생합니다. 발사가 여러 발이어도 소리가 과도하게 겹치지 않게 비트 마스크로 기록합니다. 진행·정지 상태에 따라 배경음의 이득도 조절합니다.

cpp-wasm/lv7/audio.ts

비활성 화면의 소리 정지

데모를 떠나거나 캔버스 포커스를 잃으면 게임의 누적 시간을 버리고 입력을 지웁니다. 오디오도 suspend하고 다시 활성화되면 재개합니다. 정지 중에도 소리를 중단하도록 처리합니다.

cpp-wasm/lv7/audio.ts

손상된 최고 점수 읽기

최고 점수는 JSON으로 읽고 영 이상 안전한 정수인지 확인합니다. 손상된 JSON·문자열 점수·음수·저장소 접근 거부는 영으로 처리합니다. wasm 전용 키로 저장하여 다른 트랙과 분리합니다.

cpp-wasm/lv7/storage.ts

저장 실패가 게임을 막지 않기

유효한 점수만 저장하고 저장소가 없거나 쓰기를 거부하면 실패를 반환합니다. JS는 점수가 높아질 때 저장을 시도합니다. 저장 성공 여부는 전투 점수나 최고 점수 상태를 바꾸지 않습니다.

cpp-wasm/lv7/storage.ts

리소스 해제

종료 시 음악 소스를 멈추고 연결을 끊은 뒤 AudioContext를 닫습니다. 브라우저 루프의 해제 함수는 requestAnimationFrame과 전역 visibility 리스너도 정리합니다. 내장 데모는 pagehide에서 해제합니다.

cpp-wasm/lv7/audio.ts

고정 메모리와 상태 ABI

상태·정지·게임 시간·최고 점수·입자 수를 C ABI로 제공합니다. 메모리는 1MiB 고정이며 뷰의 버퍼 교체도 검사합니다. 시작 화면 진입과 저장된 최고 점수 주입은 JS가 호출합니다.

cpp-wasm/lv7/game.cpp

세 환경의 기존 기준 기록

완성 게임 · 이해 확인

각 스텝 직후 소비합니다. 다음 스텝 시작에 이벤트 개수가 초기화되므로 마지막 상태만 읽으면 중간 효과와 소리를 잃을 수 있습니다.
