Lv2 · 적과 탄환 인스턴싱

적·피격 규칙을 보존하면서 많은 탄환의 표시를 인스턴싱으로 묶습니다.

순수 피격 로직

Canvas Lv2의 규칙을 독립 복사합니다. 렌더러는 충돌과 목숨을 계산하지 않으며 같은 pygame 기준을 비교합니다.

three-ts/lv2/game.ts

난수

xorshift의 무부호 이동과 시드를 보존합니다. GPU 리소스를 생성하는 일이 적 위치의 난수를 소비하지 않습니다.

three-ts/lv2/game.ts

생성

논리 프레임으로 적을 생성하고 위치 난수 한 개를 소비합니다. 장면의 화면 콜백 횟수를 등장 타이머로 사용하지 않습니다.

three-ts/lv2/game.ts

충돌

제곱 거리와 두 반지름의 합으로 판정합니다. Three 기하의 삼각형과 게임의 충돌 원은 별도 자료입니다.

three-ts/lv2/game.ts

무적

첫 피격이 무적 시간을 설정합니다. 같은 스텝의 다른 적탄은 추가 목숨을 줄이지 않으며 감소 경계도 기존과 같습니다.

three-ts/lv2/game.ts

점수

처치 시점에만 점수를 올립니다. Sprite가 화면에서 숨겨지는 것을 적 처치의 원인으로 사용하지 않습니다.

three-ts/lv2/game.ts

편 구분

탄환 kind로 충돌 상대와 표시 색을 구분합니다. 같은 풀 안에 있다고 자기 편끼리 충돌시키지 않습니다.

three-ts/lv2/game.ts

목숨

목숨이 영 아래로 내려가지 않습니다. 이 중간 단계는 전투를 계속하며 종료 화면과 정지 처리는 Lv7에서 완성합니다.

three-ts/lv2/game.ts

렌더 풀

게임 풀과 표시용 Sprite 배열은 별개입니다. 표시 상태는 매 화면 현재 활성 풀에서 다시 채웁니다.

three-ts/lv2/render.ts

인스턴싱 목표

같은 기하와 재질의 탄환을 하나의 InstancedMesh로 그립니다. 논리 풀 구조를 바꾸지 않고 표시 제출 방식을 바꿉니다.

공식 InstancedMesh 문서

three-ts/lv2/render.ts

공유 기하

반지름 1의 원 기하를 모든 인스턴스가 공유합니다. 탄환마다 다른 반지름은 변환 행렬의 배율로 나타냅니다.

three-ts/lv2/render.ts

공유 재질

기본 재질 색은 흰색으로 두고 인스턴스 색을 곱합니다. 적탄과 플레이어 탄환 때문에 재질 객체를 계속 만들지 않습니다.

three-ts/lv2/render.ts

용량

최대 4096개 인스턴스를 미리 할당합니다. 생성자 용량과 매 화면의 활성 count는 서로 다른 값입니다.

three-ts/lv2/render.ts

활성 개수

count를 실제 탄환 개수로 맞춥니다. 풀을 비웠을 때 이전 행렬이 남아 있어도 count가 영이면 그리지 않습니다.

three-ts/lv2/render.ts

변환 행렬

하나의 Matrix4를 재사용하며 각 탄환의 배율과 이동을 기록합니다. 반복문 안에서 행렬 객체를 새로 할당하지 않습니다.

three-ts/lv2/render.ts

위치 변환

게임 y를 화면 높이에서 빼 장면 위치로 전달합니다. 인스턴싱에서도 논리 좌표를 직접 뒤집지 않습니다.

three-ts/lv2/render.ts

반지름 배율

원 기하에 x와 y 같은 반지름 배율을 적용합니다. z 배율은 1로 두어 평면 탄환을 유지합니다.

three-ts/lv2/render.ts

행렬 기록

setMatrixAt은 지정 인스턴스의 행렬 데이터를 복사합니다. 공유 Matrix4를 다음 탄환에 재사용해도 앞 기록은 유지됩니다.

three-ts/lv2/render.ts

색 배열

종류별 색을 보관할 인스턴스 색 배열을 초기화합니다. 표시용 GPU 배열의 정밀도와 게임 위치 배열의 정밀도를 구분합니다.

three-ts/lv2/render.ts

편별 색

적탄은 붉은색, 플레이어 탄환은 푸른색을 기록합니다. Color 객체 하나를 재사용하여 각 인스턴스에 복사합니다.

three-ts/lv2/render.ts

동적 사용

자주 바뀌는 행렬과 색 속성은 DynamicDrawUsage로 설정합니다. 사용 방식의 힌트이며 성능 향상 비율을 보장하지 않습니다.

three-ts/lv2/render.ts

갱신 알림

CPU 배열을 수정한 뒤 needsUpdate를 켜야 GPU 쪽 데이터가 갱신됩니다. count 변경과 데이터 갱신은 별도로 처리합니다.

three-ts/lv2/render.ts

경계 구

이번 구현은 인스턴스 메시의 프러스텀 컬링을 끕니다. 행렬 변경 뒤 오래된 경계 구가 탄환을 잘못 숨기는 일을 피합니다.

three-ts/lv2/render.ts

적 텍스처

시스템 적 이모지를 캔버스 텍스처로 한 번 만듭니다. 여러 적 Sprite가 같은 텍스처와 재질을 공유합니다.

three-ts/lv2/render.ts

Sprite 풀

적 최대 용량만큼 Sprite를 초기화합니다. 살아 있는 적까지만 표시하여 이전 인덱스의 그림이 남지 않게 합니다.

three-ts/lv2/render.ts

적 보간

현재 적 위치와 속도로 표시 위치를 보간합니다. 적의 나이나 공격 간격은 렌더러에서 증가시키지 않습니다.

three-ts/lv2/render.ts

피격 점멸

무적 타이머를 읽어 플레이어 Sprite의 visible을 번갈아 바꿉니다. 중심 점은 유지하여 위치를 계속 읽을 수 있게 합니다.

three-ts/lv2/render.ts

HUD 캔버스

작은 투명 캔버스를 HUD 텍스처로 만듭니다. 장면 위쪽에 놓고 깊이 검사를 끈 Sprite로 표시합니다.

three-ts/lv2/render.ts

텍스처 갱신

HUD의 텍스트가 바뀌면 캔버스를 다시 그리고 텍스처 갱신을 요청합니다. 매번 새 Texture를 만들지 않습니다.

three-ts/lv2/render.ts

캐시

점수와 목숨을 캐시 키로 사용합니다. 값이 같으면 캔버스 재그리기와 텍스처 업로드 요청을 생략합니다.

three-ts/lv2/render.ts

그리기 순서

적·플레이어·탄환·HUD를 갱신한 뒤 한 번 렌더합니다. HUD는 별도 renderOrder로 화면 위에 표시합니다.

three-ts/lv2/render.ts

리소스 해제

공유 텍스처·재질·기하와 인스턴스 리소스를 해제합니다. 많은 Sprite가 참조해도 공유 자료는 한 번만 해제합니다.

three-ts/lv2/render.ts

1000발을 넣어 활성 count와 실제 호출 수를 확인했습니다. HUD와 플레이어를 포함한 호출은 4회 이내였습니다.

픽셀 검사

실제 WebGL 픽셀과 컨텍스트 손실 여부를 함께 확인합니다. 인스턴스 count만 맞고 화면에 나타나지 않는 오류를 놓치지 않습니다.
