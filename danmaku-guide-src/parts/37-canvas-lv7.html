Lv7 · 효과와 완성 화면

같은 완성 규칙에 웹 오디오·저장소·시작 화면을 연결하고 덱 안에서 직접 조작합니다.

화면 상태

상태 영은 시작, 일은 플레이, 이는 게임 오버, 삼은 완료입니다. 일시 정지는 플레이 상태에 별도 플래그로 보관합니다.

canvas-ts/lv7/game.ts

시작 화면

브라우저는 시작 화면에서 Enter를 기다립니다. 생성자의 start 값을 거짓으로 지정하되 Node 자동 재생은 기본 플레이 상태로 시작합니다.

canvas-ts/lv7/main.ts

시작 눌림 경계

현재 입력과 이전 입력의 차집합으로 새 눌림을 구합니다. Enter를 누른 채 유지해도 계속 새 게임을 만들지 않습니다.

canvas-ts/lv7/game.ts

재시작 초기화

재시작은 시드와 스테이지를 보존하고 새 라운드를 만듭니다. 재시작 시의 할당은 매 스텝 갱신의 할당 금지와 별개입니다.

canvas-ts/lv7/game.ts

최고 점수 유지

재시작 때 현재 점수와 풀은 초기화하지만 최고 점수는 전달합니다. 새 라운드가 이전 기록을 지워서는 안 됩니다.

canvas-ts/lv7/game.ts

일시 정지

플레이 중 P를 새로 누르면 일시 정지를 전환합니다. 유지 입력은 무시하고 정지 중에는 이동·충돌·입자 시간을 멈춥니다.

canvas-ts/lv7/game.ts

논리 시간과 호출 횟수

frame은 검사 호출 횟수이고 time은 실제 플레이 시간입니다. 정지·종료 중에는 time이 멈추므로 패턴과 스테이지도 멈춥니다.

canvas-ts/lv7/game.ts

게임 오버

한 스텝의 충돌 처리가 끝난 뒤 목숨이 영이면 게임 오버입니다. 다음 호출부터 이동과 발사를 막고 남은 입자는 수명을 마칩니다.

canvas-ts/lv7/game.ts

보스 처치 완료

보스 처치로 phase가 사가 되면 완료 화면으로 전환합니다. 같은 스텝에 마지막 목숨을 잃으면 게임 오버를 먼저 적용합니다.

canvas-ts/lv7/game.ts

입자 풀

입자 용량은 이천사십팔입니다. 기존 풀 자료구조를 사용하되 탄환·적·아이템과 독립하여 효과 포화가 전투를 바꾸지 않습니다.

canvas-ts/lv7/game.ts

입자 수명

입자는 좌표와 나이를 갱신하고 삼십 스텝이 되면 삭제합니다. 역순 교환 삭제로 같은 입자를 중복 이동하지 않습니다.

canvas-ts/lv7/game.ts

효과 난수 분리

시드를 다른 상수와 배타적 논리합하여 효과 전용 난수를 만듭니다. 입자 수를 바꾸어도 적의 다음 등장 위치는 바뀌지 않습니다.

canvas-ts/lv7/game.ts

이벤트 소비

충돌과 보상을 확정한 뒤 같은 스텝의 이벤트로 입자를 만듭니다. 다음 스텝에 이벤트 개수를 초기화하므로 지연 소비하지 않습니다.

canvas-ts/lv7/game.ts

효과별 입자 수

발사는 두 개, 폭탄과 보스 처치는 스물네 개, 나머지는 여섯 개를 만듭니다. 규칙의 강도와 화면 효과의 강도를 분리합니다.

canvas-ts/lv7/game.ts

입자 포화

입자 풀이 가득 차면 새 입자를 생략합니다. 효과 난수는 계속 소비하여 나중에 빈 칸이 생겼을 때도 예측 가능한 흐름을 유지합니다.

canvas-ts/lv7/game.ts

입자 보간

입자 좌표도 논리 갱신 사이를 보간합니다. 정지와 종료 화면에서는 현재 좌표를 그대로 그려 보간 계수 변화에 따른 떨림을 막습니다.

canvas-ts/lv7/render.ts

효과음 합성

외부 음원 대신 표준 배열과 사인파로 소리를 만듭니다. 합성은 초기화 때 수행하며 게임 로직의 삼각함수 제한과 별개입니다.

canvas-ts/lv7/audio.ts

오디오 버퍼

자체 합성은 이만이천오십 헤르츠 모노 Float32 샘플을 사용합니다. 이 버퍼는 소리 출력용이며 게임 위치는 계속 배정밀도입니다.

canvas-ts/lv7/audio.ts

음량 포락선

시작은 짧게 올리고 끝은 내려 파형의 갑작스러운 단절을 줄입니다. 부동소수 샘플의 진폭을 낮춰 유효 범위 안에서 소리를 합성합니다.

canvas-ts/lv7/audio.ts

음색 주파수

이벤트 종류마다 다른 주파수를 사용합니다. 발사·피격·그레이즈·폭탄·수집을 화면을 보지 않고도 구분할 단서를 제공합니다.

canvas-ts/lv7/audio.ts

배경음 멜로디

여덟 음을 순서대로 합성해 한 반복 구간을 만듭니다. 별도 파일을 내려받지 않아 오프라인 실행과 배포가 단순합니다.

canvas-ts/lv7/audio.ts

배경음 반복

멜로디를 반복하는 소스를 만들고 Gain으로 음량을 조절합니다. 슬라이드가 보이지 않으면 컨텍스트를 정지하여 배경음도 멈춥니다.

canvas-ts/lv7/audio.ts

사용자 제스처

키나 포인터 입력을 받은 뒤 AudioContext를 활성화합니다. 중복 요청이 겹쳐도 초기화 중 플래그로 배경음을 여러 번 만들지 않습니다.

canvas-ts/lv7/audio.ts

소리 사용 불가

장치나 AudioContext를 만들 수 없으면 무음으로 계속합니다. 활성화 실패를 게임 로직의 예외로 전파하지 않습니다.

canvas-ts/lv7/audio.ts

소리 중복 제한

같은 스텝의 같은 이벤트 종류는 한 번만 재생합니다. 여러 탄환이 동시에 발사되어도 같은 소리를 무제한 겹치지 않습니다.

canvas-ts/lv7/audio.ts

스텝마다 효과 소비

누적 시간 루프에서 논리 스텝 직후 오디오를 소비합니다. 한 화면에서 여러 스텝을 처리해도 중간 이벤트를 놓치지 않습니다.

canvas-ts/lv7/main.ts

소리 종료

데모를 종료하면 배경음을 멈추고 오디오 컨텍스트를 닫습니다. 화면 루프와 키 이벤트도 함께 정리할 수 있도록 해제 함수를 반환합니다.

canvas-ts/lv7/audio.ts

최고 점수 읽기

localStorage 접근 자체도 실패할 수 있으므로 안전하게 얻습니다. 저장소가 없거나 값이 손상되어도 최고 점수 영으로 시작합니다.

canvas-ts/lv7/storage.ts

손상 파일 처리

저장된 값이 없거나 JSON이 깨졌거나 점수가 잘못되면 영으로 시작합니다. 저장소 데이터 문제로 게임 실행을 막지 않습니다.

canvas-ts/lv7/storage.ts

값 범위 검사

최고 점수는 음이 아닌 정수이며 웹과 공유할 안전한 정수 범위 이내입니다. 참값과 실수를 점수로 받아들이지 않습니다.

canvas-ts/lv7/storage.ts

최고 점수 저장

웹에서는 같은 출처의 localStorage에 JSON 값을 씁니다. 파일 시스템의 임시 파일 교체와 다른 저장 모델이므로 구현을 구분합니다.

canvas-ts/lv7/storage.ts

저장 실패 처리

권한이나 저장소 정책으로 저장할 수 없으면 거짓을 반환합니다. 메모리 안의 최고 점수는 남기고 게임을 계속합니다.

canvas-ts/lv7/storage.ts

어댑터 책임

최고 점수가 증가할 때만 저장하고 실패하면 저장 완료 값을 올리지 않습니다. 다음 스텝에서 다시 시도하며 게임 상태는 유지합니다.

canvas-ts/lv7/main.ts

화면 안내

시작·종료 화면에는 Enter와 최고 점수를 표시합니다. 정지 화면에는 P 안내를 보여 다음 조작을 찾을 수 있게 합니다.

canvas-ts/lv7/render.ts

실제 픽셀 검사

화면 테스트는 시작 화면 패널과 입자 중심의 픽셀 색을 확인합니다. 상태 값만 검사해서 렌더링 누락을 놓치지 않습니다.

canvas-ts/lv7/render.ts

Lv7 기준 비교

보스 3단계에 이른 1800스텝 전투 상태까지 pygame Lv7의 기준과 비교합니다. 이식이 실패해도 기존 기준을 바꾸지 않습니다.

canvas-ts/lv7/game.ts
