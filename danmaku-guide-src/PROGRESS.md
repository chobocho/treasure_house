## T0 결과와 재개 시 주의점

- 총 10장(표지 1, 장 표지 1, 일반 7, 퀴즈 1), 0부 최소 10장 충족.
- `npm test`: 36 passed, 0 failed. 실제 산출물의 내장 글꼴 검사와 모든 인라인 스크립트 문법 검사 통과.
- V1~V23 검사와 출처 추출·빌드·실제 산출물 검사를 구축했으며, 전체 장수 V2는 1,500~2,000장 기준을 유지한다.

- T5는 설치와 메모리/ABI를 별도 작업으로 나누어 Lv1을 T5.2에 배치한다.
