1장

왜 갈아탔나

CDMA 를 버린 이유

광대역에서 CDMA 가 부딪친 벽

  • 등화가 어려워진다 — 대역이 넓어질수록 분해되는 경로가 늘고, RAKE 갈래가 감당 못 하는 지연 확산이 생긴다
  • 직교가 더 잘 깨진다 — 다중경로가 OVSF 를 어긋나게 한다. 셀 안에서도 간섭이 는다
  • 빠른 스케줄링과 안 맞는다 — 사용자마다 부호를 주는 구조라 밀리초 단위로 자원을 옮기기가 번거롭다
OFDMA 는 이 셋을 한 번에 푼다. 다중경로는 CP 로 막고, 직교는 주파수 축에서 지켜지고, 자원은 격자의 칸이라 나눠 주기가 쉽다.
설명용

CP — 이 덱에서 가장 깔끔한 결과

CP 가 가장 긴 지연보다 길면 한 탭 등화 뒤 오차가 10−14 다 — 수치 오차 수준, 곧 0 이다. 짧으면 0.75 로 망가진다.

이것이 OFDM 의 마법이다. 다중경로 채널이 부반송파 마다 복소수 하나의 곱셈이 된다. 등화기가 나눗셈 한 번이다. GSM 이 훈련열과 비터비 등화기로 하던 일이 사라진다.
실행 검증

왜 하필 '순환' 전치인가

앞을 그냥 0 으로 채워도 ISI 는 막는다. 그런데 끝을 복사해 붙여야 하는 이유가 따로 있다.

까닭 그래야 한 심볼 구간 안에서 채널과의 연산이 순환 합성곱이 된다. 순환 합성곱은 DFT 영역에서 곱셈이다. 그래서 채널이 부반송파마다 상수 하나가 된다.

0 을 채우면 선형 합성곱이 되어 이 성질이 안 나온다. 수학적 필요에서 나온 설계다.

설명용

CP 의 값

표의 마지막 칸이 CP 부담이다. 1024점 FFT 에 CP 72 이면 6.6 % 를 그냥 버린다.

LTE 는 보통 CP 4.7 μs(정규)를 쓴다. 빛으로 1.4 km 다 — 도심 다중경로에는 넉넉하다. 지연 확산이 큰 곳(산악·대형 셀)을 위해 16.7 μs 확장 CP 도 있다.
7 %를 버리고 등화기를 없앤 것 — 이 맞바꿈이 4G 의 출발점이다.
실행 검증

공짜가 아닌 이유 — 주파수 오차

부반송파 간격 대비 1 % 만 어긋나도 ICI 가 −34.8 dB 로 생긴다. 실측이 근사식 (πε)²/3 과 잘 맞는다.

OFDM 은 주파수 오차에 예민하다. CDMA 는 확산 때문에 둔했다. 그래서 LTE 는 기준 신호를 촘촘히 두고 단말이 주파수를 계속 따라가게 한다. 도플러가 큰 고속 이동이 특히 불리하다.
실행 검증

직접 해 보기 — 직교성이 깨지는 순간

ε 을 0 에서 조금씩 올려 보라. 0.01 만 되어도 내적이 0 이 아니다.

부반송파 내적
ICI 전력의 근사식 (πε)²/3 도 같이 보인다. out/ofdm.txt 2절의 실측과 견줘 보라.
실행 검증

PAPR — 상향이 다른 이유

부반송파 1024개에서 OFDM 평균 PAPR 8.72 dB, SC-FDMA 5.93 dB — 2.78 dB 차이다.

기지국은 전원을 꽂고 있으니 증폭기를 크게 만들면 된다. 단말은 배터리로 돈다. 2.78 dB 는 증폭기 효율에서 큰 수 이고, 곧 통화 시간이다. 그래서 LTE 는 하향 OFDMA, 상향 SC-FDMA 로 갈랐다.
실행 검증

평균이 아니라 꼬리를 본다

8 dB 문턱에서 OFDM 은 37.5 %, SC-FDMA 는 0 % 다. 증폭기 설계에서 중요한 것은 평균이 아니라 얼마나 자주 넘치나 이므로, 이 표가 앞의 표보다 실제에 가깝다.

실행 검증

SC-FDMA — DFT 를 한 번 더

심볼을 부반송파에 바로 얹지 않고, 먼저 DFT 로 펼쳐 놓고 그것을 부반송파에 얹는다. 그러면 시간 영역 파형이 단일 반송파에 가까워져 봉우리가 낮아진다.

그래서 DFT-s-OFDM 이라고도 부른다. 5G NR 도 상향에서 이것을 고를 수 있게 남겨 두었다 — 셀 가장자리에서는 여전히 값이 있기 때문이다(11부).
설명용

2장

자원 그리드

15 kHz 라는 한 수

격자의 산술

부반송파 간격15 kHz
유용 심볼 길이1/15000 s = 66.67 μs
슬롯0.5 ms, 심볼 7개(정규 CP)
서브프레임1 ms — 스케줄링 단위
PRB12 부반송파 × 1 슬롯 = 180 kHz

15 kHz × 66.67 μs = 1 — 이것이 직교 조건이다. 유용 심볼 안에 각 부반송파가 정수 번 진동한다.

규격 근거

왜 15 kHz 였나

  • 도플러를 견딜 만큼 넓게 — 350 km/h·2 GHz 에서 도플러가 648 Hz 다. 15 kHz 대비 4.3 %면 (πε)²/3 으로 ICI 가 −22 dB — 견딜 만하다
  • 지연 확산 대비 심볼이 길게 — 66.67 μs 심볼에 CP 4.7 μs 는 7 % 부담. 더 좁히면 심볼이 길어져 좋지만 도플러에 약해진다
  • WCDMA 와 맞물리게 — 3.84 Mcps ÷ 256 = 15 kHz 다
세 번째가 재미있다. 기존 장비·클록과 어울리도록 고른 흔적이다. 규격의 수는 물리와 현실의 교집합에서 나온다.

규격 근거

기준 신호 — 격자에 박은 말뚝

셀 특정 기준 신호(CRS)를 시간·주파수 격자에 규칙적으로 뿌린다. 단말은 그 점에서 채널을 재고 사이는 보간한다.

얼마나 촘촘해야 하나는 2부 7장의 간섭성 시간과 간섭성 대역폭이 정한다. 그보다 촘촘하면 낭비, 성기면 못 따라간다.
CRS 는 안테나 포트마다 다른 자리에 놓인다 — 그래야 각 포트의 채널을 따로 잴 수 있고, MIMO 가 성립한다.
규격 근거

PSS·SSS — 셀을 찾는 법

  • PSS — 길이 62 의 Zadoff-Chu, 세 종류. 심볼 동기와 셀 ID 의 나머지(0·1·2)를 준다
  • SSS — m-수열 두 개를 엮은 것, 168 종류. 프레임 동기와 셀 ID 그룹을 준다
셀 ID = 3 × N(1) + N(2),  168 × 3 = 504개

1부에서 본 1972년 추의 수열과 7부의 m-수열이 여기서 만난다.

규격 근거

PRACH — 왜 Zadoff-Chu 인가

Zadoff-Chu 는 진폭이 일정하고 순환 이동한 것끼리 직교한다. 이 두 성질이 랜덤 액세스에 딱 맞는다.

  • 일정 진폭 → PAPR 이 낮다. 단말이 세게 보낼 수 있다
  • 순환 이동 직교 → 뿌리 하나에서 프리앰블 여럿을 만든다
  • 상관 봉우리의 위치가 곧 왕복 지연 → TA 를 바로 얻는다
6부의 GSM 은 액세스 버스트의 가드를 길게 두어 이 문제를 풀었다. LTE 는 부호의 성질로 푼다.

설명용

알라무티 — 기울기가 달라진다

SISO 기울기 0.98, 알라무티 1.71. 다이버시티 차수가 곧 기울기라는 2부 8장의 말이 수로 확인된다.

이론값 2 에 못 미치는 것은 유한한 시행에서 오는 것이고, 낮은 SNR 구간이 곡선에 섞여 있기 때문이다. 측정값을 이론값으로 반올림해 적지 않는다.
실행 검증

ZF 와 MMSE

SNR 0 dB 에서 ZF 의 오차가 9.15, MMSE 가 0.53 이다. 17배 차이다. 높은 SNR 에서는 둘이 가까워진다.

ZF 는 간섭을 완전히 지운다 — 그 대가로 잡음을 키운다(행렬의 역을 곱하니까). MMSE 는 간섭을 조금 남기더라도 전체 오차를 줄인다. 낮은 SNR 에서는 간섭보다 잡음이 무섭다.
실행 검증

SVD — 채널을 평행한 관으로

두 모듈이 서로를 검산한다 — log2det 으로 구한 용량과 특잇값으로 구한 용량이 소수점 아래까지 같다.

특잇값이 고를수록 용량이 크다. 시도 1 은 1.804·1.197 로 고르고 용량 8.37, 시도 3 은 1.526·0.143 으로 치우쳐 4.50 이다. 안테나 수가 아니라 채널의 랭크가 속도를 정한다.

규격 근거

CQI·PMI·RI — 단말이 보고하는 셋

  • RI — 스트림을 몇 개나 받을 수 있나(랭크)
  • PMI — 코드북에서 어느 프리코딩 행렬이 좋은가
  • CQI — 그 조건에서 어떤 변조·부호율이 맞나
셋이 순서대로 물린다. 랭크를 정해야 프리코딩이 정해지고, 프리코딩이 정해져야 품질이 정해진다.
코드북을 쓰는 이유는 피드백 비트를 아끼기 위해서다. 채널 행렬 전체를 보내는 대신 "몇 번" 만 보낸다.

4장

부호와 재전송

터보·레이트 매칭·HARQ

터보 r=1/3, K=4

LTE 데이터 채널은 구속장 4 짜리 8상태 터보 부호를 쓴다. WCDMA 와 같은 구조이고, 내부 인터리버만 QPP(이차 순열 다항식)로 바뀌었다.

QPP 인터리버가 중요한 이유는 병렬 복호다. 수식으로 주소가 계산되고 충돌이 없어서, 복호기를 여러 개 나란히 돌릴 수 있다. 300 Mbit/s 를 실시간으로 복호하려면 병렬이 필수다.
이론의 성능만이 아니라 구현의 병렬성이 규격을 정한다.
규격 근거

레이트 매칭 — 부호율을 자유롭게

터보는 언제나 r=1/3 로 찍어 낸다. 실제로 필요한 부호율은 스케줄러가 정한 크기에 따라 다르다. 그 차이를 메우는 것이 순환 버퍼다.

  • 체계 비트와 패리티 비트를 원형 버퍼에 늘어놓는다
  • 필요한 만큼 잘라 낸다(천공) — 부호율이 올라간다
  • 모자라면 한 바퀴 더 돈다 — 반복이 된다
  • 재전송 때는 다른 자리에서 읽는다 → 증분 잉여
한 부호기로 모든 부호율과 HARQ 를 다 하는 구조다. 5G NR 의 LDPC 도 같은 방식을 쓴다(11부).
규격 근거

HARQ 타이밍 — 8 프로세스

FDD 하향에서 서브프레임 n 에 받은 것의 응답을 n+4 에 보내고, 재전송은 다시 4 ms 뒤다. 왕복이 8 ms 이므로 프로세스 8개를 돌려 채운다.

정지 대기 방식은 응답을 기다리는 동안 논다. 프로세스를 여러 개 두면 기다리는 동안 다른 것을 보낸다. 4 ms 라는 수는 단말이 복호하고 응답을 준비하는 데 걸리는 시간이다 — 규격의 타이밍은 곧 칩의 처리 시간이다.

5장

EPC

망이 평탄해지다

층이 하나 사라졌다

GSM 은 BTS–BSC–MSC, UMTS 는 Node B–RNC–SGSN 이었다. LTE 는 eNB–코어 둘뿐이다. RNC 의 일이 eNB 로 내려갔다.

왜 내려갔나 — 지연 때문이다. 스케줄링과 HARQ 를 무선에 가까운 곳에서 해야 밀리초를 지킬 수 있다. 9부의 HSDPA 가 스케줄링을 Node B 로 내린 것의 완성이다.
대신 소프트 핸드오버를 포기했다. 합성해 줄 층이 없기 때문이다.

"모든 패킷은 평등하다" 가 아니라 등급을 두고 다르게 다룬다 — 이동통신망이 인터넷과 다른 점이다.

규격 근거

VoLTE — 음성이 패킷이 되다

LTE 에는 회선 교환이 없다. 음성을 하려면 IMS 위에서 패킷으로 해야 한다.

  • QCI 1 의 보장 베어러로 지연과 손실을 지킨다
  • 코덱은 AMR-WB — 6부의 AMR 이 광대역으로
  • 초기에는 CSFB 로 때웠다 — 전화가 오면 2G/3G 로 떨어뜨린다
CSFB 는 통화 연결이 몇 초 늦어지는 임시방편이었다. 그래서 GSMA 가 IR.92 로 VoLTE 프로파일을 못 박았다(8부). 규격에 선택지가 많으면 합의가 필요하다는 예다.

보안 — 층이 둘로

LTE 는 NAS(단말–MME)와 AS(단말–eNB)를 따로 보호한다. 키도 KASME 에서 가지를 쳐 따로 뽑는다.

기지국이 길가에 서 있다는 사실을 인정한 설계다. eNB 가 뚫려도 NAS 키는 안전하고, 핸드오버 때마다 키를 새로 뽑아(전방 보안) 지나간 통신을 못 풀게 한다.
3G 까지는 RNC 가 안전한 곳에 있다고 보았다. LTE 는 그 가정을 버렸다.

반송파 집성

20 MHz 를 여러 장 묶는다. Rel-10 은 5장(100 MHz)까지, 뒤에 32장까지 늘었다.

  • 연속 내 대역 — 같은 대역의 붙은 반송파. 가장 쉽다
  • 비연속 내 대역 — 같은 대역이지만 떨어져 있다
  • 대역 간 — 다른 대역끼리. RF 가 가장 어렵다
사업자가 가진 주파수는 여기저기 조각나 있다. CA 는 그 조각들을 하나처럼 쓰게 하는 기술이다 — 순수한 무선 기술이라기보다 주파수 배정의 현실에 대한 답이다(11부).

와이브로와의 싸움

한국이 개발한 와이브로(모바일 WiMAX)는 2006년에 상용화됐다. OFDMA 기반으로, LTE 보다 3년 빨랐다.

기술이 앞서도 지는 이유 · 생태계가 작았다 — 단말 제조사와 칩 공급이 제한적이었다.
· 기존 망과 이어지지 않았다 — LTE 는 3GPP 계열이라 EPC 로 매끄럽게 넘어갔지만 와이브로는 별도 망이었다.
· 음성 해법이 늦었다 — 사업자에게 음성은 여전히 매출의 축이었다.
6부에서 본 GSM 의 MoU 와 정확히 반대다. 기술이 아니라 규모와 연속성이 이긴다는 이 덱의 반복되는 결론이다.

2007 — 수요가 먼저 왔다

LTE 규격이 동결된 것은 2008년 12월(Rel-8)이다. 그런데 그 한 해 전에 데이터를 많이 쓰는 단말이 나왔다.

3G 망은 금세 포화됐다. 9부에서 본 "3G 는 약속을 못 지켰다" 는 평가의 상당 부분이 이 시기의 혼잡에서 왔다.
기술이 수요를 만든 것이 아니라 수요가 기술을 재촉한 드문 시기다.

10부 퀴즈 ①

Q. LTE 는 하향에 OFDMA, 상향에 SC-FDMA 를 쓴다. 상향에도 OFDMA 를 쓰면 스케줄링이 더 단순할 텐데 왜 그러지 않나?

A. 단말의 전력 증폭기 때문이다.
OFDM 은 수백 개 부반송파를 더한 파형이라 가끔 봉우리가 아주 높아진다. 표에서 부반송파 1024개일 때 평균 PAPR 이 8.72 dB, 8 dB 를 넘을 확률이 37.5 %다.
증폭기는 그 봉우리에서도 일그러지지 않아야 하므로, 평균보다 훨씬 큰 여유를 두고 설계해야 한다. 그 여유가 곧 효율 저하이고 배터리다.
SC-FDMA 는 같은 조건에서 5.93 dB, 8 dB 초과 확률 0 %다. 2.78 dB 의 차이는 증폭기 설계에서 아주 큰 수다.
기지국은 전원을 꽂고 있으므로 이 걱정이 없다. 같은 규격 안에서 상·하향이 다른 답을 고르는 것은 7부의 IS-95 부터 이어지는 패턴이다.
실행 검증

10부 퀴즈 ②

Q. CP 를 아주 길게 잡으면 어떤 다중경로든 다 막을 수 있다. 왜 4.7 μs 에서 멈췄나?

A. CP 는 버리는 시간이기 때문이다.
표의 마지막 칸이 CP 부담이다. FFT 1024 에 CP 72 면 6.6 %를 그냥 버린다. CP 를 두 배로 늘리면 13 %를 버린다 — 용량이 그만큼 준다.
4.7 μs 는 빛으로 1.4 km 다. 도심의 지연 확산은 보통 1 μs 안쪽, 교외에서도 수 μs 이므로 넉넉하다. 드문 최악이 아니라 흔한 경우에 맞춘 것이다.
그래서 지연 확산이 정말 큰 배치(대형 셀·산악·단일 주파수 방송망) 를 위해 16.7 μs 의 확장 CP 를 따로 두었다. 필요한 곳만 값을 치르게 한 설계다.
CP 길이를 고르는 일은 결국 "얼마나 자주 있는 나쁜 경우에 얼마를 낼 것인가" 라는 물음이다.

10부 퀴즈 ③

Q. LTE 는 소프트 핸드오버를 버렸다. 7부에서 그것이 CDMA 의 큰 장점이라고 했는데, 손해가 아닌가?

A. 손해이긴 하지만, 바꿔 얻은 것이 더 컸다.
먼저 왜 못 하나 — 소프트 핸드오버는 두 기지국의 신호를 합쳐야 한다. 합칠 층(RNC)을 없앤 것이 LTE 의 평탄한 구조다. 층을 없앤 이유는 지연이었고, 지연을 줄인 덕에 1 ms 스케줄링과 빠른 HARQ 가 가능해졌다.
그리고 OFDMA 에서는 덜 아쉽다. CDMA 는 이웃 셀이 같은 주파수를 쓰므로 경계에서 간섭이 심했지만, OFDMA 는 경계 사용자에게 서로 다른 부반송파를 주는 식으로 피할 수 있다. 자원이 격자로 나뉘어 있어 가능한 일이다.
그래도 아쉬움은 남아서, Rel-11 의 CoMP 가 비슷한 이득을 다른 방식으로 노렸다. 다만 백홀 지연 때문에 널리 쓰이지는 못했다.
