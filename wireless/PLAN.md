## 0. Non-negotiables (read twice)

1. **The deck HTML is a build artifact.** Never edit it by hand. Edit `wireless/deck/sections/*.html`
   or the sources they cite, then `make all`.
2. **No hand-written code, numbers or captures in the deck.** Every `<pre><code>` is a
   `<!--CODE file=… lines=A-B|sym=…-->` directive filled from a real file under `wireless/`. Every
   terminal capture is `<!--OUT file=…-->` from `wireless/out/`. Every table of simulated numbers
   (BER, capacity, Erlang, latency, path loss) is `<!--TABLE file=…-->` generated by `run_all.py`.
   `verify_deck.py` re-checks deck ↔ source on every build.
3. **Every formula has a witness.** A formula that yields a number (capacity, BER, Doppler, Erlang B,
   path loss, orbital period…) must have a unit test in `tests/` that evaluates the code against the
   closed form (or a Monte-Carlo run against theory within a stated tolerance). Purely structural
   formulas (definitions, derivation steps) are exempt but must be marked `ill` (§6). No formula
   is typed twice: the deck cites the same symbol the test checks.
4. **Every fact has a source.** Dates, first-calls, launch cities, spec numbers, clause numbers,
   bit counts, chip rates, frame lengths — each goes in `deck/claims.md` as
   `claim | source | verified-how | date` **before** it appears on a slide. Sources in order of
   preference: the spec itself (3GPP TS/TR with clause — **download the zip with `tools/fetch.sh` and
   quote the clause text from the .docx via `tools/spec_text.py`**; ITU-R Recommendation; GSMA PRD number),
   a primary paper (Shannon 1948, Gilhousen et al. 1991, Viterbi 1967, Arıkan 2009…), a museum or
   company archive page, then a Wikipedia article **with its own citation followed**. A claim that
   cannot be sourced is either dropped or marked in the deck as `<span class="unv">미확인</span>`.
5. **Knowledge-cutoff discipline.** Anything dated 2025 or later (Rel-20/21 timelines, 6G spectrum
   at WRC-27, direct-to-cell launches, Starlink counts) must be re-verified with WebSearch at build
   time and written with an explicit "2026-09 기준" stamp. Do not present a roadmap as a fact.
6. **Tests before code (RED → GREEN)** for every module in `py/`. Never loosen a tolerance to pass.
7. **This machine is a Galaxy Fold under Termux/proot with ~200 MB free RAM.** At most **2 subagents**,
   no JVM, no numpy/scipy/PIL (not installed — pure Python stdlib only, as in `optim/`).
   Monte-Carlo runs are sized to finish in < 60 s each and run sequentially. Check `free -m`
   before heavy steps. Checkpoint everything to disk; assume the session can be killed any moment.
8. **Foldable layout.** `<pre>` ≤ 45 lines and ≤ 72 columns (Korean counts as 2), captures ≤ 108
   columns, `<li>` ≤ 14 per list, no box-drawing characters in prose, no `①②③` inside monospace,
   formulas set with the CSS math kit (§4) — never as ASCII art, never as images of text.
   SVG figures use `viewBox` width 340 so they fit 374 px. The assembler errors on all of these.
9. **Photos are licensed or absent.** Only Public Domain, CC0, CC BY, CC BY-SA (any version) from
   Wikimedia Commons, fetched by `tools/fetch_photos.py` through the Commons API with the license
   recorded in `deck/photos/manifest.tsv`. Every photo slide carries the credit line the assembler
   generates from the manifest. No screenshots of other people's slides, no press images, no
   "found on the web". If a wanted photo has no free version, draw an SVG or use text.
10. **Commit granularity:** one module, one figure batch, or one deck part per commit; split
    "source commit" from "deck-body commit". Korean, no-prefix commit subject (repo convention),
    `Co-Authored-By` trailer per the session reminder. Never `git push` unless asked.
11. Keep Korean comments in code (UTF-8, no BOM). Identifiers in English. Do not touch other decks.

## 3. Simulation library (`py/wirelesslib/`) — what gets written, in order

Pure Python, deterministic (`Random(seed)`), each module ≤ ~350 lines with Korean comments,
each with a `tests/test_<module>.py` written first. Floats are allowed (this is not the
compression deck) but every number that reaches the deck is produced by `run_all.py` and must be
identical across three runs (`tools/record.sh --check`).

| # | Module | Content | Witness test (formula ↔ code) |
|---|---|---|---|
| 1 | `dsp` | complex sequences, radix-2 FFT/IFFT, convolution, raised-cosine/RRC pulse, up/down-sampling, PSD via periodogram | FFT vs naive DFT (1e-9); RRC matched-filter pair is Nyquist (ISI = 0 at symbol instants) |
| 2 | `modem` | BPSK/QPSK/8PSK/16–1024QAM Gray maps, AWGN, hard/soft demap (LLR), BER/SER Monte-Carlo, Q-function | simulated BER within 5 % of `Q(√(2Eb/N0))` for BPSK and the QAM closed form at Eb/N0 ≥ 4 dB |
| 3 | `channel` | Rayleigh/Rician from Gaussian I/Q, Clarke/Jakes Doppler (sum-of-sinusoids), tapped delay line, coherence time/bandwidth, FSPL, Okumura-Hata, COST-231, 3GPP TR 38.901 UMa/UMi LOS/NLOS, log-normal shadowing | Rayleigh envelope pdf/cdf match; level-crossing rate vs `√(2π) f_D ρ e^{−ρ²}`; FSPL at 1 km/2 GHz = 98.5 dB |
| 4 | `info` | Shannon capacity (AWGN, Rayleigh ergodic/outage), MIMO capacity `log det(I + ρ/N_t HH^H)`, water-filling, mutual information of a constellation | AWGN capacity at 0 dB = 1 bit/s/Hz; MIMO 2×2 ≈ 2× SISO at high SNR |
| 5 | `codes` | CRC (GSM/LTE/NR polynomials), Hamming(7,4), cyclic codes, convolutional encoder (GSM rate-1/2 K=5, IS-95 K=9, LTE tail-biting K=7), Viterbi hard/soft, block/diagonal interleavers | Viterbi corrects every ≤ t-error pattern on short frames; CRC-24A of the NR spec's example |
| 6 | `turbo` | LTE PCCC (RSC 13/15, QPP interleaver), BCJR log-MAP / max-log-MAP, iterative decoding, BER vs iterations | BER at 1 dB falls monotonically with iterations; encoder rate 1/3 exact |
| 7 | `ldpc` | NR base graph 2 lifted (small Z), belief propagation and min-sum, layered schedule | decodes to zero-error on a noiseless word; parity check H·c = 0 for every codeword |
| 8 | `polar` | channel polarisation (Bhattacharyya), N=8..256 construction, SC and SCL(L=8) decoding with CRC-aided selection | polarised capacities sum to N·I(W); SCL ≥ SC in BLER at every SNR |
| 9 | `harq` | Chase combining and incremental redundancy on `turbo`/`ldpc`, circular-buffer rate matching, throughput vs SNR | throughput ≤ capacity; IR ≥ CC at equal SNR |
| 10 | `spread` | Walsh/Hadamard (64), OVSF tree (SF 4–512), m-sequences via LFSR (2¹⁵−1 IS-95 short PN, 2⁴²−1 long code mask), Gold codes (WCDMA scrambling), Zadoff-Chu | Walsh cross-correlation = 0; m-sequence autocorrelation two-valued; ZC constant amplitude and zero autocorrelation |
| 11 | `cdma` | IS-95 forward link toy (pilot/sync/paging/traffic on Walsh), despreading, multi-user interference, RAKE with 3 fingers, power-control loop, near-far demo | SNR gain = processing gain (10·log₁₀ 128 ≈ 21 dB); RAKE beats single finger on a 2-path channel |
| 12 | `ofdm` | OFDM/OFDMA (CP, FFT sizes 128–4096), SC-FDMA (DFT-spread), PAPR CCDF, ICI vs Doppler, LTE/NR resource-grid geometry (15 kHz × 2^μ, slot lengths) | orthogonality: zero ICI with CP ≥ delay spread; NR slot length = 1 ms / 2^μ |
| 13 | `cellular` | hex geometry (cluster N = i²+ij+j²), SIR vs N, sectoring, Erlang B/C (recursion), trunking gain, handoff hysteresis, cell breathing (CDMA) | Erlang B(A=10, N=15) = 0.0365; SIR for N=7 ≈ 18.7 dB with γ=4 |
| 14 | `tdma` | GSM burst geometry (156.25 bits, 8 slots, 4.615 ms), 26/51 multiframes, hyperframe (3 h 28 min 53.76 s), timing advance vs distance, GMSK (BT=0.3) phase trellis | frame/multiframe arithmetic exact; TA=63 → 35 km |
| 15 | `mimo` | Alamouti, ZF/MMSE detection, SVD precoding, beam pattern of a ULA (array factor), massive-MIMO channel hardening | Alamouti diversity order 2 (slope); array gain of N elements = 10·log₁₀ N |
| 16 | `orbit` | Kepler period/velocity from altitude, GEO/MEO/LEO one-way delay, Doppler for a LEO pass, coverage angle, NTN timing-advance budget | GEO period = 23 h 56 min; Starlink 550 km one-way ≈ 1.8–4 ms at the given elevation |
| 17 | `link` | link-budget calculator (EIRP, G/T, noise figure, kTB, margin), UE/eNB/gNB/satellite presets, sensitivity for a given BER | matches a hand-computed budget to 0.1 dB |

## 4. Formula policy (senior-undergraduate level)

Derive, don't decorate. Each of the following gets a short derivation box (`.thm`/`.proof`), the
symbols defined once on a notation slide in part 0, and a witness in §3:

Fourier pair and complex baseband · matched filter and the Nyquist criterion · AWGN BER for BPSK/QPSK
and the M-QAM approximation · Shannon–Hartley and the −1.59 dB limit · Rayleigh pdf from two Gaussians,
Jakes spectrum and Doppler spread · coherence time/bandwidth · Friis and log-distance path loss ·
processing gain and the Gilhousen CDMA capacity equation · Walsh orthogonality and m-sequence
autocorrelation · Zadoff-Chu properties · OFDM orthogonality integral and CP argument · PAPR · Erlang B ·
hexagonal reuse SIR · Viterbi path metric · BCJR forward/backward recursion (log domain) · LDPC tanh rule
and min-sum approximation · polarisation I(W⁻)+I(W⁺)=2I(W) · MIMO capacity and water-filling ·
Alamouti decoding · array factor · Kepler's third law and one-way delay · Doppler at a given elevation.

Level check: no measure theory, no random-process rigor beyond WSS; assume Fourier, linear algebra
and probability at 4th-year EE. Every formula is set with the CSS math kit; a formula longer than the
374 px fold is split across lines with `.eq` blocks, never scrolled.
