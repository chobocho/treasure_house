== 2. RV 마다 어디를 읽는가 ==
RV  내보낸 72비트의 출처 (계통/패리티1/패리티2)
--  -------------------------------------------
 0  44 / 14 / 14                               
 1  9 / 32 / 31                                
 2  10 / 31 / 31                               
 3  42 / 15 / 15                               

RV0 은 계통 비트가 많아 혼자서도 복호된다.
RV1·RV2 는 패리티가 많아 증분 잉여로 쓰인다.
RV3 은 버퍼 끝에서 앞으로 되감겨 다시 계통이 많다.

== 3. 체이스 결합과 증분 잉여 ==
Eb/N0 [dB]  방식         전송 1회    2회    3회
----------  -----------  --------  -----  -----
      -2.0  체이스 결합     1.000  0.525  0.100
      -2.0  증분 잉여       1.000  0.250  0.025
      -1.0  체이스 결합     0.950  0.225  0.050
      -1.0  증분 잉여       0.950  0.075  0.000
       0.0  체이스 결합     0.875  0.050  0.000
       0.0  증분 잉여       0.875  0.000  0.000

같은 횟수라면 증분 잉여가 체이스 결합보다 낫거나 같다.
체이스는 같은 자리를 다시 받아 연판정 값을 더할 뿐이고,
증분 잉여는 처음에 안 보냈던 패리티를 더 보내 부호율을 낮춘다.

== 5. 정지 대기와 N-프로세스 ==
프로세스 수 N  닫힌 식 min(1, N/8)  슬롯 800개 모사
-------------  -------------------  ---------------
            1               12.5 %           12.5 %
            2               25.0 %           25.0 %
            4               50.0 %           50.0 %
            6               75.0 %           75.0 %
            8              100.0 %          100.0 %
           16              100.0 %          100.0 %

정지 대기(N=1)는 왕복 8 ms 중 1 ms 만 쓴다. N 이 왕복 길이에 이르면 링크가 찬다 —
LTE FDD 가 8 프로세스를 두는 셈법이 이것이다.
